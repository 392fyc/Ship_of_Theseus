# 剑士天赋树 v2 设计哲学

> 版本: 2026-03-15 | P3-TALENT-V2 设计阶段
> 基线: Codex CLI (sw_codex.json) + opencode 创新点融合

## 1. 设计目标

### 1.1 第一优先级：普通攻击权重提升

v1 天赋树的核心问题：随着技能增多，普攻沦为"没技能可用时的下位替代"。

v2 目标：**普攻在大部分回合中应是最优或次优选择**，而非兜底选项。

### 1.2 三版本差异化方向

| 版本 | 核心机制 | 普攻角色 | 设计参考 |
|------|---------|---------|---------|
| **A: On-Hit Engine** | on-hit 被动链 | 被动引擎启动器 | FE Engage, 暗黑破坏神 |
| **B: Overwatch/Stance** | 架势/待机系统 | Overwatch 自动触发 | XCOM 2, Into the Breach |
| **C: Resource Cycle** | 资源循环经济 | 唯一稳定资源回复 | 火纹战技耐久, 风花雪月 |

## 2. 普通攻击权重提升策略

### 2.1 Version A: On-Hit Engine

**核心理念**: 普攻 = 被动效果的触发器。天赋树中大量被动节点标注"普攻命中时触发"。

**机制链**:
```
普攻命中 → 锐伤(DEF-2) → 剑气+15 → 量谱阈值buff生效
        → 追击触发 → 追击命中 → 锐伤再叠加 → 剑气+15
        → 吸血/标记/debuff 等 on-hit 效果
```

**关键节点设计**:
- 每条路径至少2个"普攻命中触发"的被动节点
- on-hit 效果可叠加，形成正反馈循环
- 主动技能不触发 on-hit 链（或仅触发部分），保持普攻的独特价值

**剑圣特化**:
- A线(双刀): 每次普攻 = 双剑各打一次 = 2次on-hit触发 = 双倍被动收益
- B线(居合): 不移动回合普攻伤害大幅提升 + 蓄势加成

**剑仙特化**:
- A线(飞剑): 飞剑普攻命中 → 恢复剑元 + 概率追加打击
- B线(剑阵): 在阵内普攻附带额外效果(减速/真伤)

### 2.2 Version B: Overwatch/Stance

**核心理念**: 不使用技能的回合进入"架势"状态，普攻变为Overwatch自动反击。

**机制**:
- 新增迅捷技能"进入架势"——消耗迅捷行动，本回合不攻击，进入待机状态
- 待机状态下：敌方单位进入射程/移动经过时，自动发动一次普攻
- 架势普攻享受所有on-hit被动 + 额外架势加成(伤害+20%/必暴等)

**关键节点设计**:
- 架势相关节点: 提升Overwatch触发次数、伤害、范围
- 主动技能 = 打破架势的高伤选择，但失去Overwatch收益
- 形成"主动爆发 vs 被动控场"的战术抉择

**剑圣特化**:
- A线(双刀): Overwatch 双刀连斩 = 每次触发2次打击
- B线(居合): 居合架势 = 超高爆发的单次Overwatch反击

**剑仙特化**:
- A线(飞剑): 飞剑待机 = 远程Overwatch，覆盖更大范围
- B线(剑阵): 剑阵本身作为"永久Overwatch区域"

### 2.3 Version C: Resource Cycle

**核心理念**: 所有技能消耗量谱资源，普攻是唯一稳定的资源回复手段。

**机制**:
- 剑圣: 技能消耗剑气(30-100)，普攻命中恢复剑气(+15/次)
- 剑仙: 技能消耗剑元(10-150)，普攻命中恢复剑元(+3-5%)
- 形成"普攻充能 → 技能释放 → 普攻充能"的循环节奏

**关键节点设计**:
- 强化"普攻→资源回复"的效率
- 增加"资源阈值奖励"——高资源时被动加成
- 技能消耗随天赋树深入增加，要求更多普攻回复

**与 v1 的区别**:
v1 的量谱获取途径多元（暴击+15/闪避+10/反击+20），普攻只是其中之一。
v2-C 将普攻设为**主要**回复手段（+15/次），其他途径降为辅助。

## 3. 行动经济设计框架

### 3.1 技能分配预算

| 行动类型 | 每路径上限 | 设计原则 |
|---------|----------|---------|
| Standard (标准) | ≤ 3 | 与普攻竞争同一槽位，数量必须克制 |
| Swift (迅捷) | 1-2 | 增益/位移/准备类，不与标准竞争 |
| Move (移动) | 0-1 | 特殊位移，替代普通移动 |
| Reaction (反应) | 全树 1-2 | 被动触发，回合外行动 |
| Free (自由) | 全树 0-1 | 极稀有 |

### 3.2 普攻在行动经济中的定位

每回合标准行动只有1次。玩家面临抉择：
- **使用技能**: 高单次伤害，但消耗资源/CD，不触发追击(v1已有规则)
- **使用普攻**: 较低单次伤害，但免费、可追击、触发on-hit链、回复资源

当天赋树充分投入普攻增强后，这个抉择应是**情境性**的（根据战场状态选择），而非"技能永远更优"。

## 4. 转职分支特色定义

### 4.1 刀圣 (Blade Master) — 高速近战、居合爆发

| 维度 | A线: 双刀追击流 | B线: 居合修罗流 |
|------|----------------|---------------|
| 核心身份 | 极致强化普攻连锁 | 放弃移动换超高爆发 |
| 量谱(剑意) | 普攻/追击生成 | 不移动/暴击生成 |
| 普攻角色 | 引擎核心——每次普攻双武器双触发 | 蓄势充能——不移动时普攻获强化 |
| 终极技 | 4连斩(标准) | 扇形释放(标准) |
| 行动模式 | 移动→普攻(追击)→on-hit链 | 原地→蓄势(迅捷)→强化普攻/技能 |

### 4.2 剑仙 (Sword Cultivator) — 飞剑遥控、阵法控场

| 维度 | A线: 万法剑道 | B线: 诛仙四剑 |
|------|-------------|-------------|
| 核心身份 | 远程风筝、飞剑追击 | 阵法演进、领域控制 |
| 量谱(剑元) | 飞剑命中恢复 | 阵内恢复/阵法消耗 |
| 普攻角色 | 飞剑普攻 = 远程Hybrid + 资源回复 | 阵内普攻附带额外效果 |
| 终极技 | 全屏Hybrid贯穿(标准) | 跟随剑阵/引爆(标准) |
| 行动模式 | 走位→飞剑普攻→追加打击 | 布阵(迅捷)→阵内战斗 |

### 4.3 银蔷薇 (Silver Rose) — 中轴桥接

| 维度 | 定位 |
|------|------|
| 核心身份 | 跨系多面手，衔接左右的"收费桥梁" |
| 无专属量谱 | 增强的是通用战斗能力 |
| 普攻角色 | 中轴节点增强普攻泛用性(命中/暴击/闪避反击) |
| 桥接结构 | cm_M11(间歇桥入口) → cm_M13(横向出边) → cm_M16(横向出边) → cm_M20(死端) |

### 4.4 银蔷薇间歇桥规则(继承自 v1)

- cm_M11 + cm_M13: 有横向出边连接两侧路径
- cm_M16: 有横向出边
- cm_M20: **死端**（无出边），不覆盖 Lv 18-20
- requires 使用 `|` (OR) 分隔符

## 5. 节点设计原则

### 5.1 被动节点（passive/trait）— 核心普攻增强载体

- **明确触发条件**: "普攻命中时"、"追击触发时"、"反击时"
- **可叠加效果**: 锐伤(DEF-n)、标记(受伤+%)、量谱获取
- **数值用百分比/倍率**: 不硬编码绝对值
- **每条路径至少2-3个普攻增强被动**

### 5.2 主动技能（active_skill）— 稀缺高光时刻

- **每路径 ≤ 3 个标准行动技能**（含终极）
- **必须标注 action_cost**
- **不触发追击**（保护普攻地位）
- **消耗量谱资源**（保持普攻的资源回复价值）
- **有CD或使用限制**

### 5.3 技能强化（skill_upgrade）— 深潜区主要类型

- 强化已有技能的效果/范围/附加效果
- 不新增行动经济负担
- 让终极技能有进化感

### 5.4 量谱节点（gauge_core/gauge_extend）

- 明确量谱获取/消耗途径
- 阈值效果增强普攻（高剑气时ATK+12%等）
- 量谱管理本身是战术决策

## 6. 三版本共同约束

1. **All node cost = 1**
2. **不硬编码战斗数值** — 使用百分比/倍率/公式引用
3. **暴击率无上限**
4. **格挡与暴击互斥**
5. **pure 伤害无视格挡；pure 暴击 = 固定 1.5x**
6. **hybrid = phys_atk + mag_atk 同时生效**
7. **反击/追击不连锁**
8. **范围攻击不触发反击**
9. **ZOC 不叠加，固定 -2**
10. **距离无衰减**
11. **银蔷薇间歇桥**: cm_M13 + cm_M16 有横向出边，cm_M20 死端
12. **Reaction 技能全树 1-2 个**
13. **路径锚点**: Lv10=转职, Lv15=小门槛, Lv20=大门槛, Lv22-25=终极

## 8. 与 v1 的关键差异总结

| 维度 | v1 | v2 |
|------|----|----|
| 普攻权重 | 低（技能为主） | 高（普攻是引擎/触发器/资源来源） |
| 被动节点设计 | 泛用增益 | 明确"普攻触发"条件 |
| 技能密度 | 较高 | 严格控制(≤3标准/路径) |
| 量谱与普攻 | 多元获取 | 普攻为主要获取手段 |
| 版本多样性 | 单一版本 | 3个差异化版本 |
| 行动经济标注 | 部分缺失 | 全部标注 |
