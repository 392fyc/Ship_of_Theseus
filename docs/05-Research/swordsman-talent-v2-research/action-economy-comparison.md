## 2. 本项目行动经济框架

### 2.1 每回合资源池

| 资源 | 默认配额 | 说明 |
|------|---------|------|
| 移动力 | 由MOV属性决定 | 用于普通移动和[移动行动]技能 |
| 攻击机会 | 1次 | 用于普通攻击和[标准行动]技能 |
| 迅捷行动 | 1次(或无限) | 不消耗移动/攻击资源 |

### 2.2 行动类型与普攻的关系

| 行动类型 | 与普攻的关系 | 对普攻权重的影响 |
|---------|------------|----------------|
| **标准行动** | 与普攻互斥（只能选一） | 直接竞争：技能必须比普攻+on-hit+追击的总收益更高才值得使用 |
| **迅捷行动** | 不与普攻竞争 | 增益型：迅捷buff + 普攻 = 最优组合 |
| **移动行动** | 替代普通移动 | 间接影响：位移技能+普攻 vs 普通移动+标准技能 |
| **反应行动** | 条件触发，不消耗主动资源 | 额外收益：反击=普攻=触发on-hit链 |

## 5. 关键设计洞察

### 5.1 普攻在行动经济中的"地板价值"

普攻的价值 = 基础伤害 + 追击概率 × 追击伤害 + on-hit效果 + 量谱获取 + 反击触发链

当天赋树充分投入普攻增强节点后：
- 基础伤害: ~80% (对比技能150%)
- 追击: +50-100% (高SPD角色)
- on-hit: +15-30% (锐伤/标记/吸血等)
- 量谱: +10-20 剑气/3-5% 剑元
- 反击: 被攻击后反击 = 额外一次普攻

**总期望收益可达 145-210%，与标准行动技能(150%)竞争**

### 5.2 "不普攻的代价"

在三个版本中，不使用普攻的代价分别是：
- Version A: 没有on-hit被动收益 → 整个被动链停转
- Version B: 没有Overwatch触发来源 → 架势白搭
- Version C: 没有资源回复 → 技能用完就空转

这确保普攻在任何build中都不是"死行动"。
