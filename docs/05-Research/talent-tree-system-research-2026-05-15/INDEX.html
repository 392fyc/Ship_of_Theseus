P0 阻断项 — critic 发现的 2 个跨方案盲点

这两项必须先决策，才能比较 3 套方案的真实参数。

P0 阻断 决策项 1：Lv5 奥义二选一形态后另一形态的升级节点如何处理？
三套方案均将「奥义形态选择（Lv5 二选一）」作为核心节点，A 形态（单体溢出）与 B 形态（范围扇形横扫）。但 3 套方案的 14 节点骨架中均只列出了「奥义形态选定后」的下游节点，完全没有说明被放弃形态的升级节点是否仍计入 N 全池。

影响：直接决定 N/M/取舍比例的真实值。若两条形态各 3 个专属节点，方案一实际 N 可能从 30 降至 27，三套方案的参数差异可能被严重压缩。

选项：
  • A. 两条形态升级节点都计入 N，未选形态节点变为不可选但仍占池
  • B. Lv5 选定后另一形态升级节点彻底从 N 中移除
  • C. 两条形态共享同一组升级节点，根据当前形态自动适配
  • D. 其他
P0 阻断 决策项 2：招架被动化 + 招架反击的 handoff 规则边界
三套方案均包含 sw_sa_04（招架变被动触发居合架势 + 反击周围敌人）+ sw_sa_09（招架冰冻反击）叠加。触发路径变为「被动触发居合架势 → 居合反击 → 反击带冰冻」。

规则冲突：handoff 明确「反击/追击 → 不触发连锁」「area 攻击 → 不触发反击」。此叠加是否属于禁止的「反击触发连锁」？

选项：
  • A. 严格解读：sw_sa_04 + sw_sa_09 不可同时存在，需加互锁
  • B. 宽松解读：被动反击 + 反击元素附加不算「反击触发反击」连锁，允许
  • C. 重新定义 handoff 规则边界
