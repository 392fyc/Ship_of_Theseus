TL;DR + 设计三角

TL;DR: L4 = 武器 + 防具. 9 武器 type + 4 防具 type. 4 rarity tier (Common / Uncommon / Rare / Unique). 5 词缀大类 (stat / on-hit / on-crit / conditional / set-flavor).

核心硬约束: 任何 L4 词缀效果 ≤ ±15% 单 stat 或 ≤ 1 个有限触发条件; 不允许"改变职业形态"的效果 (后者归 L5 流派类符文).

单 run 期望: ~12-18 件装备 (random drop + town stable + boss reward). Town 给玩家 mid-tier 稳定底, drop 给 峰值惊喜, boss 给 unique flavor 钩子.

来自 consensus v2 的 4 条硬约束
  1. L4 不承担 build-defining (consensus §1, §7 locked term) → 词缀深度数值上限 (§3)
  2. L4 与 L5 协同但不重复 (§4 跨层耦合矩阵) → 词缀只做"风味放大", 不做"形态改变" (§4)
  3. L4 run-reset (§1 reset 列) → town 提供稳定基线避免空仓库
  4. 玩家不会基于装备构筑 (用户原话) → 词缀随机 + 反 farm 设计 (§5)

词缀强度硬上限 (D4 核心硬约束)

任何 L4 词缀必须满足 BOTH:

  1. 数值上限: 单词缀对单 stat 的修改 ≤ ±15% (Rare) / ≤ ±20% (Unique 固定词条)
  2. 触发深度上限: ≤ 1 个有限触发条件 (e.g. on_crit, vs 低血敌人, 回合开始时); 禁止链式触发 (禁止 on_crit 触发 on_hit 再触发 conditional)

违反上限 = 转移到 L5 流派类符文管辖.

7. 业内 reference 对照

Path of Exile (借鉴: prefix/suffix 互斥 + tier)
  • 采纳: prefix (stat) / suffix (effect) 互斥池
  • 采纳: tier 数值范围, 高 tier 数值更大
  • 不采纳: 6 mod / item — D4 cap 在 2 词缀 (Rare)
  • 不采纳: crafting / divine orb 重 roll — 违反"装备不构筑"
Diablo 2 Unique Items (借鉴: Unique 固定词条 + Boss 钩子)
  • 采纳: Unique 词条 fixed, 设计师手工组合
  • 采纳: Unique = build flavor, 不是 build core (D2 build 仍以 skill tree 为主)
  • 不采纳: D2 set bonus 6 件套 — 复杂度过高且容易 build-defining
Dead Cells (借鉴: gear level + affix slot 上限 + roguelite reset)
  • 采纳: affix 数与 gear level 关联
  • 采纳: minor (stat) / major (effect) 分类
  • 采纳: roguelite reset, 不存在跨 run 装备
  • 不采纳: 6 affix 上限 — D4 cap 在 2 (Rare)
Borderlands Legendary (借鉴: 风味 + 玩法变体, 但反对其 build-defining)
  • 采纳: legendary "red text" 风味描述 + 1 显著效果
  • 采纳: 同 base type 但有特色
  • 明确反对: BL legendary 实际上 是 build-defining (endgame build 围绕 legendary)
Hades Boon (反向参考: NOT 这么做)
  • Hades boon = 强 build-defining, 主玩法循环
  • D4 装备 ≈ Hades 的 weapon aspect (固定不变), 不是 boon
  • build-defining 部分给 L5 流派类符文
