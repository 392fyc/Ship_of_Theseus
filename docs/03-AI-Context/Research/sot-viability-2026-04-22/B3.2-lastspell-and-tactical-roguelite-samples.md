# B3.2 补丁调研：Last Spell + 同类战棋 roguelite 横扫

## 前提修正

S67 B3 原调研基于"永久节点图天赋树"定义，漏掉了整类"**run 内天赋树 + meta 层数值升级**"的参考系。用户本人指出 **The Last Spell** 就是接近 SoT 的样本。本次补丁采用 SoT 真实架构作为筛选条件：

**SoT 实际架构**: Run 内大天赋树（每 run 重置） + Meta 层（英雄成长 + roguelite 数值升级） + 4p co-op + 战棋

### 天赋树架构

**Run 内天赋树**（每 run 重置），但**不是节点图**：
- 英雄最多 11 级 = 10 天赋点
- **8 列分类**: 近战 / 魔法 / 远程 / 毒素 / 减益 / 防御 / 刺客 / 杂项
- **分层解锁**: T1 (0 点可选) → T2 (需 1 点) → T3 (需 3 点) → T4 (需 5 点) → T5 (需 7 点)
- **无分支依赖**: 列内选哪个都行，列与列之间没有"走这条导致不能走那条"的强制分化

**关键差异 vs SoT**:
- Last Spell = **线性分层列表**
- SoT 想做的 = **节点图 + 前置依赖 + 转职分支**

### Meta 层（Oraculum 系统）

保留货币 = Tainted Essences + Prowess 勋章（成就）
- 解锁：新英雄 / 新技能 / 新天赋选项 / 数值升级 / 难度模式
- Run 内天赋**始终重置**（meta 不持久化天赋，只扩展可选池）

### 随机性（用户痛点验证）

**高度随机的系统**：
1. 升级时天赋随机抽取选项（非全列展示）
2. 属性加成随机分配（即使选了"毒素路线"，若无毒素属性加成也无法成型）
3. 敌人 / 战斗环境 / 奖励全随机

**用户原话三点全部有玩家佐证**：

| 用户吐槽 | 玩家社区证据 |
|---------|-------------|
| 天赋单调 ✅ | [Really don't like the new perk system](https://steamcommunity.com/app/1105670/discussions/0/3421062490374327256), [I was hoping for a real perk tree rework before 1.0](https://steamcommunity.com/app/1105670/discussions/0/3820780544816831851) |
| 随机过强 ✅ | [100 hours feedback](https://steamcommunity.com/app/1105670/discussions/0/3177859358961848981/) — "难以实现 build，因为虽然你选了所有毒素天赋，但如果游戏没给你毒素属性加成，你就没办法"；Gideon's Gaming 评测"overreliance on randomness hinders rather than elevates" |
| 人物成长单调 ✅ | Meta 层仅数值升级 + 解锁，无分支 |

但 92% 好评表明**这些缺点不是商业致命伤** —— 玩家仍普遍喜欢。负评聚焦的是"**差一点就更好**"，不是"**不能玩**"。

### Co-op 状态

- **Steam PC 版**: **无官方 co-op**
- 非官方: Steam 远程游玩 / 轮流操作
- 独立产品: Tabula Games 桌游版 1-4p co-op（不同产品）

→ Last Spell 在 co-op 方向**完全未开拓**，这是 SoT 的真实空白。

## T3: SoT 5 大真实差异化空白

### 空白 1: 4p **同时出招**战棋 ⚡ 最独特

**所有高符合度参考系都是轮流制**：
- Last Spell / DD2 / Iratus / Trials of Fire / Thea: 单人或单人式轮流
- For the King 2: 4p co-op 但仍**逐人轮流** + dice roll
- Wildermyth: 同屏战棋但位置固定，无真"同时"

**SoT 空白**: 4 人同时操控 + 同时出招 + 每职业独特能量系统 → **市场上没有**

### 空白 2: 分支转职 + 方向节点树 🌿

**所有参考系都不是真"树"**：
- Last Spell: 8 列线性分层（列内无分支）
- DD2: micro-deckbuild 离散选择
- Gordian Quest: 卡牌池（离散集合非树）
- Iratus: 4 条独立树但**无转职**

**SoT 空白**: 树形前置依赖 + 转职分支（剑士 → 剑圣 vs 剑修）+ run 内方向性规划 → **FtT Advance 以外无先例**

### 空白 3: 结构化随机 vs 盲随机 🎲

**Last Spell 的核心痛点**：
- 升级时完全随机出现天赋，与当前 build 无关
- 属性加成随机不匹配 build 方向

**SoT 差异**: 每 night/stage 给"3-4 选 1 相关选项"（Hades Boon 式 —— 虽然随机但总是合理的组合），不是盲随机

### 空白 4: Co-op 深度耦合 🤝

**所有 co-op 参考系都是弱耦合**：
- For the King 2: 独立 Loadout，4 人并行
- Last Spell: 无 co-op
- 其它: 纯单人

**SoT 空白**: 职业间能量系统相互影响（如法师能量消耗影响骑士行动）+ 共享敌人目标 + 英雄陨落改变小队战术

### 空白 5: Permadeath + 体系化递补 💀

**多数参考系英雄不会真死**：
- Last Spell: 可以失去英雄但非核心
- DD2: 英雄轮换不永久失去
- Children of Morta: 家族共享无陨落

**SoT 潜在空白**（若采用）: Fire Emblem Genealogy 式二代继承 + Hades 式"monument / legend"纪念系统

## B3 原结论修订

### 原 (S67 B3)
> "严格定义固定永久节点图天赋树 × roguelite"样本 = **0**

### 修订 (S67 B3.2)
> "**Run 内天赋树 + Meta 英雄成长**"（SoT 真实架构）样本 = **4-5 高 + 3-4 边缘**
> 其中 **Last Spell 85% 对标**，**For the King 2 是唯一 4p co-op 样本**

### 错误根源
- S67 B3 用"永久节点图"作为搜索条件 → 漏掉"run 内 + meta"主流架构
- "**术语混淆**": 市场主流从来不是"永久节点图 × roguelite"（罕见），而是"run 内选择 + meta 数值升级"（常见）
- B3 前提错误导致 R2-v2 + R3-v2 的 Tier 2 STOP 论据链整体失效
