# 研究报告：复杂天赋树 × Roguelite Run 的 Meta vs Run 解耦技术模式

## Scope

- **问题解释**: 在战棋 + roguelite 框架下，如何设计"持久天赋树 (meta layer) + 单局运行层 (run layer)"的解耦机制，使两层数值不产生膨胀、决策空间不稀释？
- **游戏样本扫描**: Hades (1/2)、Slay the Spire (1/2)、Rogue Legacy 2、Monster Train、Othercide、Dead Cells、Astrea: Six-Sided Oracles
- **Web 源数量**: 8 篇（新鲜度: 2025-2026）
- **关键发现**: 复杂 talent tree + roguelite 的已知成功样本极少；"战棋 + roguelite + MMO-style talent tree"在行业中尚未见成熟设计

## Findings

### 模式 A：持久天赋 + 清零消耗品（Hades 模式）

**特征**: Meta 层永久解锁天赋，Run 层内消耗品一次性使用不保留。

**设计细节**:
- **Hades 1 (Mirror of Night)**: 玩家通过 Darkness（跨 run 积累资源）在镜子中解锁永久被动 talents。每个天赋分 A/B 两个版本（互斥），玩家可随时用 Keys（易得资源）免费重振。**关键约束**: 天赋数量有限（约 16 个大类），选择链呈线性而非树状，避免决策空间爆炸。
- **Hades 2 (Arcana Cards)**: 进化版，Arcana Cards 总数 25 张，解锁后可分配到"Grasp"资源池（有容量上限）。**新机制**: 不再互斥，而是通过容量限制强制取舍。单局内 Arcana 数值固定，无动态调整。
- **数值穿透**: Meta talents 提供基础倍率 (e.g. +10% damage)，run 内奖励独立计算；两层数值是 **multiplicative** 而非 **additive**，避免线性膨胀。

**验证源**: 
- [Hades' Mirror Of Night Does Upgrades Right - TheGamer](https://www.thegamer.com/hades-mirror-of-night-roguelite-progression/)
- [Arcana Cards & Meta-Progression in Hades 2 Have Me Hooked – Frostilyte Writes](https://frostilyte.ca/2025/04/09/arcana-cards-meta-progression-in-hades-2-have-me-hooked/)

---

### 模式 B：难度系数 Meta + Run 内容无关（Slay the Spire 模式）

**特征**: Meta 层是"难度开关"（Ascension 级别），不直接强化角色；Run 层卡组建构、奖励完全独立。

**设计细节**:
- **STS 1 Ascension**: 20 个等级，每级追加 1 个负面修饰符（敌人更强、玩家弱化）。**关键**: Ascension 不解锁新卡、不增加基础数值，仅增加难度。玩家提升是通过**技能学习**而非数值强化。
- **STS 2 Ascension**: 继续此模式，但添加"Ascension-exclusive"卡池变化（某些卡在高难度出现率改变）。
- **Reset 边界**: Ascension 级别持久，卡组构筑完全重置。Meta 与 run 几乎零耦合。
- **决策空间**: 因为 meta 层不增强，run 内选择空间完全由卡池 RNG 决定，无"meta 已锁定"的感觉。

**验证源**:
- [Ascension | Slay the Spire Wiki | Fandom](https://slay-the-spire.fandom.com/wiki/Ascension)
- [Slay the Spire 2 Ascension Guide - GAMES.GG](https://games.gg/slay-the-spire-2/ascension-levels-explained/)

### 模式 C：分层升级树（Rogue Legacy 2 + Monster Train）

**特征**: Meta 层多个独立升级树（不是单一天赋树），每树有"通胀门槛"；Run 层从可用池中自由组合。

**设计细节**:

**Rogue Legacy 2 (Manor)**:
- Meta: 玩家用金币在 Manor 升级多个独立系统（生命值、武器威力、特殊职业解锁）。**通胀机制**: 达到 Lv30 后引入"Labor Costs"——每次购买提高其他升级成本，强制玩家决策取舍。
- Run: 每次进地牢，角色可获得 1-2 个随机特征（Traits，与天赋树无关）；职业由 meta 层解锁，但职业内数值完全由 run 内 RNG 决定。
- **数值穿透**: Manor 升级是**线性加成** (Lv5 生命 +50)，但 run 内倍率可达 10x（通过装备堆叠），所以高难度下 meta 强化的相对权重逐渐被 run 层淹没。

**Monster Train (Clan + Champion Specializations)**:
- Meta: 玩家解锁 5 个 Clan，每局选 1 primary + 1 secondary。Clan 是 **unlock-only**，不提升数值，仅改变卡池。
- Run: 在 Dark Forge 特定节点升级 Champion（3-5 次），每次选一个 specialization path（技能树型）。**关键**: Champion spec 是 **run-persistent**（不清零），但数量有限（5 个选择点），避免爆炸性组合。
- **决策空间**: Clan 选择决定可用卡方向 (meta)，Champion spec 是 run 内递进决策，两层决策空间互补而非重叠。

**验证源**:
- [Upgrades | Rogue Legacy 2 Wiki - Fandom](https://rogue-legacy-2.fandom.com/wiki/Upgrades)
- [Monster Train Beginner's Guide - BlueStacks](https://www.bluestacks.com/blog/game-guides/monster-train/mstn-beginners-guide-en.html)

### 模式 D：战棋 + Roguelite 混血（Othercide）

**特征**: 战术位移 + 女性角色单位持久养成 (meta) + 每局队伍重组 (run)。

**设计细节**:
- **Meta 层 (Remembrances)**: 玩家部队失败后解锁"Remembrances"物品，提升战斗效率。角色通过战斗获得经验，学习新技能，但**角色本体不永久强化**（这是关键差异）。
- **Run 层 (Daughter Composition)**:  每局重新组建 4-5 人队伍，选自已解锁的角色池。单局内通过**记忆系统** (Memories) 改变角色特质（如"速度 +2"），但局内改变一旦失败全清零。
- **数值穿透**: Meta Remembrances 是**技能解锁** (new ability trees)，不是数值加成。Run 内组队决策才是主要数值来源。
- **战棋特性**: 决策空间来自网格战术 + 单位位置，而非 talent 选择堆积。

**验证源**:
- [Othercide PC Review - DSOGaming](https://www.dsogaming.com/special/reviews/othercide-pc-review/)
- [Othercide Review - RPGFan](https://www.rpgfan.com/review/othercide/)

### 模式 E：装备/突变 Meta + 无天赋树（Dead Cells）

**特征**: Meta 层只有"**解锁**"（新武器、新突变可用），无数值强化；Run 层核心是装备 RNG + 突变选择。

**设计细节**:
- **Meta Unlocks**: 玩家收集 Cells（跨 run 资源），在 Collector 处解锁新武器、法术、突变蓝图。**零数值强化**——解锁只是让物品进入 RNG 池。
- **Run 层 (Mutations)**:  每层推进解锁 1 个突变选择（最多 3 个）。突变是即时、一次性效果，无堆积。
- **难度调整**: Custom Mode 允许玩家调节难度参数（敌人生命、伤害等），完全解耦 meta。
- **关键约束**: 因为零 meta 数值强化，skill 压力完全压在"玩家反应"而不是"build 强度"，保持难度曲线平坦。

**验证源**:
- [Mutations - Official Dead Cells Wiki](https://deadcells.wiki.gg/wiki/Mutations)
- [Dead Cells Best Mutations Ranked - TheGamer](https://www.thegamer.com/dead-cells-best-mutations-ranked/)

## Edge Cases / 已知失败模式

### 失败 1：数值膨胀（Talent Stack 破坏难度曲线）

**症状**: Meta 天赋 + Run 奖励**线性相加**，导致高 meta 档位玩家 run 内能力爆炸。

**已知案例**: 未找到发表的 post-mortem，但以下设计原则可推断风险：
- Rogue Legacy 2 的 Manor 升级线性设计 + run 内倍率可达 10x，早期玩家感受明显但末期逐渐平滑（通胀门槛缓解）。
- Monster Train 若 Champion spec 采用加法而非乘法，5 个 +25% damage spec 将变成 +125%，破坏平衡。

**防护**:
1. **乘法而非加法**: Hades 2 的 multiplicative Arcana。
2. **容量限制**: Monster Train Champion spec 点数有限，Hades 2 Grasp 池有容量。
3. **通胀门槛**: Rogue Legacy 2 的 Labor Costs（每次升级后续升级贵）。
4. **难度可调**: Dead Cells Custom Mode，允许玩家自调。

---

### 失败 2：决策稀释（Meta 已锁定，Run 内选择变虚）

**症状**: Meta 层天赋树设计过大（如典型 RPG 的 80+ 节点），玩家在 meta 层已确定"我是火法"，进入 run 后剩余选择只是微调，决策空间消失。

**已知案例**: 
- 标准 MMORPG 天赋树 + roguelite run（如假设的"Path of Exile roguelite 模式"）在论文和 GDC 中未见成功案例。
- **信号**: Astrea: Six-Sided Oracles、Hades 系列、Monster Train 都**刻意避免**超大天赋树；取而代之是中等规模的选择点（10-25 个决策）或"unlock-only meta"。

**防护**:
1. **Meta 无树状**: Slay the Spire Ascension、Dead Cells Unlock 都是线性/集合而非树。
2. **Run 内递进天赋**: Monster Train Champion spec 在 run 内逐步解锁（5 个 Dark Forge 节点），而非全预设。
3. **互斥而非堆积**: Hades Mirror 的 A/B 互斥版本，Hades 2 Arcana 的容量限制。

## 关键信号：行业空白

**核心发现**: "复杂 talent tree + roguelite + 战棋"的**成熟商业设计迄今未见**。

- **Othercide** 是最接近的案例（战棋 + roguelite），但其 meta 层**刻意回避天赋树**，改用"技能解锁 + 单位记忆特质"。
- **Hades 2** 升级了 meta 层（Arcana），但仍是"中等规模互斥选择"而非"复杂树状"。
- **Monster Train** 的 Clan unlock + Champion spec 是"分层"而非"树状"。

**推论**: Ship of Theseus 若采用"MMO-style 80+ 节点天赋树 + roguelite run"，在设计复杂度和平衡难度上**属于已知的行业盲点**，没有成熟的参考设计可直接借鉴。这是**风险信号也是创新机会**。

## Handoff

### 给 game-analyst 的开放问题

1. **模式适配**: SoT 的 4 角色 co-op + MMO 天赋树应采用上述 5 种模式中的哪一种？
   - 若采用"Hades 模式"（互斥天赋）：4 人队伍每人独立选择会导致 meta 层决策空间过大（每人 16 选择点 × 4 = 64 个决策轴）；能否通过"共享 Grasp 池"（如 Hades 2）缩减？
   - 若采用"Slay the Spire 模式"（难度系数 meta）：SoT 的多职业系统如何不被 meta 难度影响而只被 run 内职业选择驱动？

2. **数值膨胀 Quantify**: 设计指标如何验证"meta 强化不破坏 run 难度曲线"？
   - 建议指标: 定义"meta 强化倍率" (e.g. Lv0 基础 × 1.0, Lv20 meta 满解锁 × 1.5x)，与"run 内倍率范围"(e.g. 0.5x–10x 由装备堆积) 的比值；比值应 <20% 在末期，避免 meta 沦为决定性因素。

3. **决策空间保护**: Run 内是否需要"meta-agnostic 奖励路线"（如 Slay the Spire 的 RNG 卡池），确保高 meta 玩家依然面对新选择？

### 给 game-critic 的对立角度

1. **"Talent tree + roguelite 天然不稳定"假设的批评**:
   - Hades 2、Monster Train 的成功表明此组合**可行**，但仅限于"中等规模树"（20-25 节点）或"unlock-only meta"。
   - **反方**: MMO-style 树（80+ 节点）+ roguelite 在平衡和新手引导上的成本是否超过设计创新收益？SoT 若走此路，是否面临"玩家从未体验过的复杂度"而非"久经考验的乐趣"？

2. **Co-op × Meta 解耦的协调成本**:
   - 4 人 co-op 下，若每人独立 meta 进度（如不同玩家 Lv10 vs Lv25 meta），run 内难度如何平衡？
   - 已知 Rogue Legacy 2 通过"Manor 升级影响全家族"回避此问题；Monster Train 单人制；**Othercide 虽支持多角色，但无多人 co-op**。
   - **信号**: 多人 roguelite 常见于"共享 meta"（如 Risk of Rain 2），而非"独立 meta"。SoT 的 4 人共享天赋树还是独立解锁，将直接影响设计复杂度。
