0 · 设计前提

剑士剑圣 4+1 中轴线（来自 handoff 锁定）：1 默认被动 + 1 普攻 + 2 小技能（一闪/招架） + 1 奥义（Lv5 二选一形态）。剑气 0-100 连续型阈值条，特色暴击 + 生存闪避。21 关/Run，约 Lv22。

2 · 三套方案核心参数概览

方案一 紧凑高密度

N=30 / M=18
取舍 40% · Hades 风格

借鉴 Hades 系列「每个 Boon 都实质改变机制」。形态变化占比 23%（高于业内均值），节点少而精，重玩疲劳较快需 L5 符文补偿。

方案二 中庸均衡

N=35 / M=20
取舍 43% · 业内主流

handoff 候选方案 A 精细化。5 类比例贴近 Hades 1 跨游戏均值，纯数值 40% 给基础强度。稳健但缺乏鲜明性格。

方案三 长尾高取舍

N=42 / M=18
取舍 57% · STS 风格

借鉴 Slay the Spire「跳过文化」+ Dead Cells 极简上限。牺牲换强占比 14%（业内 3 倍），鼓励 build 鲜明性。

  • Hades「失败即叙事」节点意义化（A1 §2.G 亮点 1）：每节点必须实质改变行为，纯数值仅 8/30 且都绑定具体行为窗口

业内亮点借鉴

  • Slay the Spire「跳过文化」（A2 §2.1）：随机抽取 + 高取舍 57% 让玩家学会「跳过」，破解 A2 §1.2 痛点二最优解陷阱
  • Dead Cells 极简上限（A2 §2.3）：56 突变/3 装备/95% 取舍的极端验证「池大 + 装备少 = 重玩多样性」

设计哲学：池大、点少、跳过多。主要风险：池稀释（鸦卫奇旅反例），补偿措施 = 等级阶梯阀门 + 骨架确定性入池路径。

4 · 设计风险与未定项（需用户决策）

  1. 三套方案选哪套作为主线？ 或选择「方案二 N/M + 方案三取舍比例」类混合策略？
  2. 奥义二选一形态的节点呈现方式：Lv5 选定后另一形态的升级节点是否消失？影响骨架节点数（14 ↔ 11）。
  3. 「肉鸽元素超过 M 上限」机制（handoff 标注「此处不讨论」）何时决策？影响方案一/三的 M=18 是否还需肉鸽预留 1 点。
  4. 随机抽取的「重抽（reroll）」是否允许？A1 §3.D 提到 Hades 2 不可重抽；方案二/三引入随机时需明确。
  5. 天赋互锁实际触发点？方案一 sw_sa_04（居合架势）与 sw_sa_07（一闪电场）是否互锁？需 design review 阶段识别。
  6. L5 符文与 L2 天赋的边界（架构共识 v2 §4）：方案三 sw_sa_13「居合觉醒质变」具有「改变职业形态」特征，是否会跟 L5 流派类符文功能重叠？
