职业解锁 / 收益增益 / 起始属性 / 复活 / run 起始赠送 1 遗物。 Horizontal-only，绝不给 vertical power。

决策时机: run 外

per-class 天赋池。每 run 完全清零，从 Lv1 重新开始。 Class Advancement Lv5 不可逆。

完全 reset 影响 深

L3人物成长
类固定 stat 曲线。转职后 growth rate 改变 (FE 模式)。 受 L5 经济类遗物加成（EXP / 属性 / 天赋点）。
类固定 影响 中
决策时机: 自动
L4装备 (武器 + 防具)
暗金/词缀模式。不承担 build-defining：多数附加额外收益、少数中等改玩法。 武器决定攻击类型 / 攻击方式 / 射程；防具决定防御类型 + 基础属性。
run-reset 影响 小→中

• 流派类: 改变职业形态 (扩散燃烧 / 即时结算燃烧 / 冰冻链 等) — 大影响
run-reset 影响 中→大
决策时机: run 内奖励/商店/事件（城镇渠道暂缓）

2. 渐进式 Layered 可玩性原则

设计验证准则: 每层独立可玩，从下往上叠加。任一上层被剥离，下层仍能跑。

战棋本身（含 L3）可独立成立 → 加 L2 仍成立 → 加 L4+L5 = 完整玩法

3. Run 决策路径

Run 起始选职业 + 初期战斗策略
Lv 5 转职看已持遗物 → 选转职方向
触发 growth rate 切换
转职不占天赋点
奥义形态二选一占 1 点
Lv 6 – 25~30天赋加点 + 遗物组合
(主决策密度)
装备随机捡到
决策密度低

第一重要决策点: Lv 5 转职。玩家依据本 run 已持遗物池决定转职方向， 遗物-转职耦合是核心 build 决策机制。

关卡结构 3 幕 × 8 关 = 24 关，预期终局等级 Lv25–30（class-system.md）。 天赋的组织形态与转职节奏详见 01-Game-Design/Characters/talent-tree.md。

4. 跨层耦合矩阵

→ L1→ L2 → L3→ L4→ L5
L1 ↓ —解锁更多 class轻微初始 stat解锁更多装备种类run 起始赠 1 遗物
L2 ↓ ——转职触发 growth 切换解锁特定攻击类型 / 装备 proficiency—
L3 ↓ —提供投点起点 stat—装备需求 stat 阈值—
L4 ↓ ——装备词缀微 stat—装备/遗物协同 (e.g. 火属性武器 × 燃烧遗物)
L5 ↓ ——经济类遗物 → EXP/属性/天赋点——

Down-row "L? ↓" = 此层向其它层输出； 粗体 = 改变玩法形态的强耦合点。
