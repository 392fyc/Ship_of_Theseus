# ADR：地图棋子的 Buff/Debuff 视觉边界

## 状态

已接受，2026-08-28。

## 适用范围

本裁决适用于地图棋子、棋子血条及其附近的 Buff/Debuff 视觉表现，也用于限定 VA-4“剑圣地图棋子正式导入”里程碑的验收范围。

## 裁决

1. 当前没有要求把 Buff/Debuff 显示在地图小人的血条下方。
2. 血条相关的 Buff/Debuff 样式、尺寸、排列、锚点和与血条的空间关系尚未进入设计，不得在 VA-4 中预先定案。
3. Ship 中现有的通用状态显示若继续存在，只代表当前实现或占位反馈，不构成正式视觉样式批准。
4. Buff/Debuff 的正式视觉样式需要另行设计；在该设计完成前，任何现有显示均不得视为已获批准。
5. 后续任务不得仅因已有占位节点、测试夹具或截图脚本存在，就把其位置提升为设计事实。

## VA-4 验收边界

Buff/Debuff 的正式样式和位置不属于 VA-4 完成条件，也不应出现在该里程碑的强制视觉验收清单中。

## 权威边界

本文保存用户对视觉范围与设计时序的裁决。地图棋子当前运行实现以 Ship 仓为准；任务进度与验收证据以 GitHub/Git 为准；Buff/Debuff 的结构化玩法规则仍以设计库为准。
