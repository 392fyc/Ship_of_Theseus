# ADR：State 连携天赋的当前设计边界

- 日期：2026-08-24
- 状态：已接受
- 相关范围：二刀开刃、剑气回荡、交刃、燕返、舍身，以及〔双持〕与〔背水〕

## 背景

这批天赋并不负责定义〔双持〕或〔背水〕，而是在角色已经满足对应状态时提供构筑收益。需要统一的不是一套覆盖所有未来技能的抽象模型，而是五张卡各自的触发边界、多人结算方式和组合放大上限。

## 裁决

### 〔双持〕是装备事实

〔双持〕用于表示角色当前确实同时装备主手与副手武器。它本身不提供额外加成，装备条件失效时立即退出。因为它记录的是装备事实，所以不会被状态免疫抹除。

### 副手附伤与武器特效由二刀开刃开放

〔二天一流〕负责开放副手装备与基础副手追加攻击。未学习〔二刀开刃〕时，这次追加攻击不携带附伤，也不触发副手武器特效。

学习〔二刀开刃〕后，〔二天一流〕与〔燕返〕产生的副手追加攻击可以携带附伤并触发副手武器特效。每把剑的武器特效必须另行声明副手版本；附伤与武器特效的折算值、触发概率及展示内容以设计库当前规则和具体武器记录为准，不能从原版本临时裁切。

只有实际发生并命中的副手追加攻击才结算这些附伤与武器特效。附伤本身不能触发〔燕返〕，只有副手追加攻击的命中可以继续追加链。

### 副手连击按目标独立收束

〔二天一流〕按攻击动作触发，而不是按主手伤害段触发。一次攻击作用于多个目标时，每个目标各产生一次基础副手追加攻击；对同一目标，无论主手包含多少伤害段，都只产生一次。主手未命中不会取消这次追加攻击，目标在追加攻击开始前已经死亡时则不再结算。

〔剑气回荡〕按目标归并主手暴击：同一目标受到的任一主手直接伤害段暴击，即可强化该目标的一次基础副手追加攻击；同一目标的多次主手暴击不会叠加，也不会强化后续追加攻击。资源收益必须由这次副手追加攻击实际造成伤害后取得，具体数值以设计库为准。

〔燕返〕对每个目标分别建立追加链。每次副手追加攻击独立判定命中与暴击；命中后才按递减后的概率继续，未命中或概率判定失败即结束当前目标的链。

### 自动防守以一次攻击为消费单位

「交刃」在自身回合外、敌方攻击命中后且造成伤害前发动，使该次攻击的全部伤害按招架减伤结算。一次攻击最多发动一次；未命中不发动，也不消耗行动。它与产气天赋形成攻防循环，但多人环境中的连续攻击会自然增加资源压力。

### 低生命收益即时判断并遵守同层代数

「舍身」在每次效果结算时即时判断角色是否仍处于〔背水〕，不记录进入状态时的生命值。普通的伤害提升与伤害降低分别在各自层内相加；只有明确写明在此前结果上再次变化的效果才依次计算，遵守 [[01-Game-Design/rules-catalog|R1.8]]。

## 理由

- 状态只表达条件事实，天赋只表达满足条件后的收益，避免双向保存关系或重复定义状态。
- 多目标与多段效果必须明确以目标、攻击还是伤害段为结算单位，才能避免收益随人数无界放大或资源被重复消费。
- 原效果的触发时机和概率不应因数值折算而被悄然改写。
- 即时状态判断与现行修正代数保持一致，避免同类天赋各自发明结算顺序。

## 权威边界

具体玩家文案、数值、触发元数据、状态关系和审阅状态以设计库当前记录为准。本 ADR 只保存定性裁决及其理由，不保存任务进度，也不描述 Ship 的当前实现情况。
