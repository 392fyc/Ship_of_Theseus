## 两个方案

### Plan-1 多神话交织的多元宇宙

目录 `Plan-1/`。概念之船（连续∧不连续叠加，先于崩坏自在、投影因崩坏而成）穿行于「世界之理崩坏」后的多神话多元宇宙（希腊 / 北欧 / 埃及 / 中国 / 日本）；每一幕进入一个神话世界、被当地的材料替换染色（忒修斯替换）。元目标=修复世界之理 / 重启世界（四维坐标：3 坐标=定位 / 三维投影 v1 可达，第 4 坐标=Act 4 开端 v1 够不到 → 流放循环）。**理的复原度**（world-premise §4.7 [已定]）：理复原到什么程度是一个连续变化的量，它决定三维投影有多清楚、坐标数目决定投影有几维，两轴正交；今日所遇的每一位都是原初世界某位存在的投影实例，理回来一分，它便朝本来的样子靠近一分；理还浅的时候，这副样子叫作「未复原之姿」。敌人三档：精英 / 传奇守门 Boss（Medusa / Fenrir / 八岐大蛇等大名）/ 起源级（提丰 / 盘古等，记的是它们在原初世界里本来的样子，理够不到那里，故始终作叙事引用素材 [已定]）。**难度四档**（§4.8）：简单 / 普通 / 困难 / 旧日重现，理从旧日重现档开始出现。乘员=随船之魂 + 固定英杰名（法师=梅林 / 骑士=罗兰 / 猎人=阿塔兰忒 / 祭司=贞德 [已定]，剑圣=裴旻 [提案]）。

- 6 文档：`world-premise` / `mythic-multiverse-and-acts` / `pantheons` / `legendary-enemies` / `crew-and-identity` + README。
- **量级落差与它的解法**：跨时空多元宇宙、敌人到起源级、元目标宇宙级——叙事量级与实际战斗表现（约 DnD 12 级）之间的落差，正是当初催生 Plan-2 的原因。落差在**叙事层**（守门 Boss 与起源级档的量级填充），机制层对此中性。**2026-07-29 用户裁决：Plan-1 保留全部宏大设定，改由「理的复原度」在设定内部解释这段落差**（world-premise §4.7 [已定]）——今日所遇的每一位都是原初世界某位存在的投影实例，理还没回全的时候，它的能力也只回来一部分，所以当下的战斗强度正是「理尚浅时它的真实强度」；起源级记的是它们在原初世界里本来的样子，理够不到那里，故始终留在叙事引用层。**这与 Plan-2 是方向相反的两种解法**：Plan-2 收窄量级去迁就战斗表现，Plan-1 保留量级、另加一层设定内的解释。

### Plan-2 归潮之海 收缩版

目录 `Plan-2/`。一片人人都在回家的英雄时代之海（希腊人间层），挡在归途上的怪物全是没能回成家的人；你的船替到不了家的人回家。唯一法则「海不认路，认执」。单一世界（非多元宇宙）；量级死守人间层（半神以下、英雄杀得动），奥林匹斯主神 / 创世级只作背景信仰不登场；元目标=人尺度归乡（近景替别人回家、远景船自身归乡）。守门 Boss=大名怪物（塞壬 / 波吕斐摩斯 / 美杜莎等，允许与 Plan-1 重合），明确不设宇宙级 apex 层。乘员命名制度 [待定]（提案池倾向匿名代号制，与 Plan-1 英杰名方向冲突）。

## 机制中性 两方案共用

叙事文档只提供「色彩」、不锁机制。机制真源对叙事**中性**：

- **Act 的叙事身份与抽幕规则由所选方案提供**，机制层（`../Progression/run-loop.md`）不绑具体叙事命名——它就是逐幕增难的 `Act 1 / 2 / 3`，支持每 run 从所选方案的叙事幕池（Plan-1 世界池 / Plan-2 水域集）抽取。两方案「每 run 随机抽 3 幕」在机制层本就成立，无需机制层为「固定命名幕」做改动。
- 敌人 tier 体系（`../Core-Systems/enemy-and-ai.md`）、词条制、五层架构（`../../03-AI-Context/Active-Context/architecture-consensus-v2.md`）同样中性——填谁、填什么量级是叙事自由，机制不要求 Boss 是神祇级，也不预设任何最高档 tier。
- 机制真源：`../Progression/run-loop.md`（run 结构 / 门模式）、`../Core-Systems/enemy-and-ai.md`（tier / 词条）、`../Characters/class-system.md`（职业）、`../Core-Systems/battle-calculation.md`（战斗公式）。
