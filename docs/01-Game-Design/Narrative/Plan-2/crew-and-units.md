## 1. 乘员是归途上的人

### 1.1 摇桨的人自己也在回家

归潮之海没有天选英雄,只有一船**有事要做的人**。摇你桨的乘员,自己也都是归途上的人:家在更远处、凭一己之力过不了这片海,于是用**船工钱换一段航程**——搭这条船朝自己的方向挪近一程,顺路替船把别人的归乡送到。`[已定,依据基石 §5]`

这是归潮之海与「英雄冒险」最根本的分野:乘员上路不是因为宿命拣选,而是因为**有该做的事、且这活儿正好把他往家的方向带**。他们是船工,不是主角;是手艺人,不是救世者。玩家操作的这一队,从头到尾是「一队有营生要做的人」,而非一群等待铺垫的英豪。`[已定,承基石调性锚「归乡是普世的痛,不是英雄的荣耀」]`

### 1.2 各操一门手艺——手艺与故事解耦

每名乘员各操一门手艺:一个使桨、一个开弓、一个懂符念、一个能扛盾、一个会接骨。**手艺与出身无关、与故事无关**——这正是机制侧「职业 kit 与叙事零耦合」的世界内落点。`[已定,机制侧事实]`

- 换句话说:一名乘员**是什么职业**,只决定他在棋盘上怎么打,不决定他是谁、从哪来、要回哪个家。职业是战斗染色,不进世界观因果链。`[已定]`
- 这条解耦让命名可以彻底后置(见 §4):无论将来给乘员起什么名、起不起名,都动不了他们的 kit。名字是叙事皮,手艺是玩法骨,两者互不牵连。`[提案]`

### 1.3 战棋多单位对齐——一个棋子一名乘员

基石把宏观映射钉死:船=一轮航程的载具,船殒=航程结束。本文补齐中观一层:`[提案,承接基石]`

- **一个棋盘单位 = 一名乘员**。多个单位同场,就是这一船手艺人**同时在几个格子上各干各的活**。战棋多单位在叙事上不是抽象拼盘,而是「一船人一起把这趟货送过去」。`[提案]`
- 一支队伍(本轮认下的乘员组合)= 这一程恰好上船的那几个人。换一轮航程,上船的人可能不同——这是每 run 阵容变化的叙事解释。机制侧一轮 **1-4 单位**,对应「一条桨帆船配得起的、也养得起的那几双手」。`[提案,机制事实:队伍 1-4]`
- 职业只给每名乘员**染战斗色**(手感 / 定位),不改「他是归途上的一名船工」这一身份。`[已定]`

| 叙事 | 玩法 |
|---|---|
| 一条桨帆船与船上的手艺人 | 一轮航程(run 容器) |
| 一名乘员(某门手艺的人) | 棋盘上的一个单位(棋子) |
| 本程上船的那几个人 | 本轮队伍 / 阵容(1-4) |
| 乘员各操一门手艺 | 职业 kit(与叙事零耦合) |
| 船碎在海上、众人溺亡 | permadeath、队伍重置 |

### 1.4 乘员与随潮的溺众——同是归途上的人,分野在执名牌

这片海上最普通的敌人,是**没回成家的人**(基石 §9「随潮的溺众」):被这片浅滩的执留住、穿着这片水的执的形状成群出现的活人与溺者。他们是人间层的普通敌人,不是半神以下的怪物量级——量级天花板落在水域主人(Boss)身上,不落在这些溺众身上。`[已定,溺众身份归 legendary-and-enemies 登记]` 值得点破的是:**你的乘员与他们本是同一种人**——都是过不了这片海、被困在归途上的人。分野只在一处:溺众放不下的执把他们**留在了水里**,成了别人归途上的障;而你的乘员**还在船上摇桨**,还朝着家的方向走。`[提案]`

这条对照是全篇的情感底色:你替人回家,打散的却是另一批没回成家的人。**乘员与敌人的差别不是善恶,是「谁还在往家走、谁已经停下」。** 而让「还在走的人」哪怕死了也仍随船往家走的,正是下一节的执名牌。`[提案]`

## 2. 两级死亡:单位阵亡与全船覆没

基石只锁定「全船覆没=一轮终点」。战棋战斗中单个单位会中途阵亡,与整船殒没不是一回事——本节把两级区分讲清,各自的叙事落点分开安放。`[提案]`

### 2.1 单位中途阵亡——溺一个,名牌漂回来

一名乘员死在海上(对应单个单位被击倒),**不是航程终结**,是这一船折了一双手。死不是消失:溺亡乘员随身的**执名牌**会随潮漂回港口,钉进下一块换上的新船板里,人成为船的一部分,航程替他继续。`[已定,依据基石 §5]`

- **叙事落点**:这一程的船,从此多带一个名字上路;队伍以剩下的人继续过水。船没停,活儿没停。`[提案]`
- **机制留白**:一名阵亡乘员能否在本轮内重新上桨、代价几何(复活门道的边界),属**机制轮**(permadeath 的具体结算)。本文只承诺叙事色彩:阵亡=折一双手 + 名牌漂回,不预定本轮内可否复用。`[待定,交机制轮]`

### 2.2 全船覆没——船碎了,一轮就到头

船在海上碎了(团灭),**这一轮才结束**。港口不把沉船当失败,当天气:打捞队把「同一条船」从废料里重新立起来(反正她本没有一块原装板),溺亡乘员的名牌漂回钉进新船,图房重新落墨,下一程再起。`[已定,依据基石 §5,对齐机制 Total Party Wipe → Settlement]`

- **调性落点**:团灭不是罪、不被清算,是这片海的季候。`[已定,承基石调性锚「死是天气,不是悲剧」]` 港口把它说成一句:「这片海上没有沉船,只有还没漂回来的板子。」`[提案,引基石 §5 该句本身标 提案]`
- **机制对应**:全船覆没 → Settlement(回元层)→ 开新一轮;天赋 / 遗物 / 装备 run 内重置=构筑随潮而去(见 §3.3)。`[机制事实]`

### 2.3 两级区分与调性

| | 单位阵亡 | 全船覆没(团灭) |
|---|---|---|
| 世界内事件 | 折一双手,溺一个乘员 | 船碎在海上 |
| 是否终结本轮 | 否——航程继续 | 是——一轮到头 |
| 叙事落点 | 名牌漂回、钉进船板、航程替他继续 | 打捞队重立同船、图房重新落墨、下程再起 |
| 机制映射 | 单位被击倒(结算归机制轮) | Total Party Wipe → Settlement → 新一轮 |
| 调性 | 折损不是耻辱,是海的重量 | 死是天气不是悲剧,不清算 |

设两级区分的作用:让「单位阵亡」与「run 结束」在叙事上不混为一谈,避免每次单位倒下都被读成「一次永久终局」,从而与「死是天气、代价非惩罚」的调性一致。`[提案]`

## 3. 执名牌——给忒修斯替换加一点体温

### 3.1 名牌钉进船板:permadeath 的叙事皮

**执名牌**是乘员随身之物:一块刻着他名号的木牌、铜牌或骨牌 `[提案,形制待美术轮]`。乘员溺亡,名牌不沉,随潮漂回港口,被打捞队钉进下一块换上的新船板——这是 permadeath 落进世界观的具体动作。`[已定,依据基石 §5]`

死者不再能上桨(permadeath),但也没有从这条船上消失:他**成了船身的一部分**,以一块带名的板子继续随船出海。「航程替他继续」这句,由这枚钉进木头的名牌兑现。`[提案]`

### 3.2 每块板一个名字:功能连续解的体温

忒修斯母题的功能连续解——**「她还认得回家的路,她就还是她」**——本身是一句冷的哲学:同一性不落在原装木料上,落在「始终认得归途」这件功能上。`[已定,基石 §3]` 执名牌给这句冷话添了体温:

- 这条船的每一块替换板,都**来自一条没能到家的船**(基石已定);如今每一块换上时,又**钉进一个死在归途上的乘员的名字**。船于是是双重的遗物:失乡之船的木、失乡之人的名。`[提案]`
- 换到最后,船上没有一块木头是当年的,却也没有一块木头是无名的。**她认得回家的路,是因为她整个身子都是由「想回家而没回成的人」拼起来的。** 功能连续解不再是抽象的同一性辩题,而是一船亡者共同记着的一个方向。`[提案]`
- 这正是归潮之海要的温度:忒修斯之船在这里不是思想实验的道具,是**一座还在航行的浮动纪念碑**。她替不了家的人回家,也替死在船上的人继续走。`[提案]`

### 3.3 映射构筑与元层:构筑随潮而去,名字沉淀港城

- **构筑=这一程的换装**:船板、器物、桅饰、天赋都只属于这一程,送达之后随潮而去——对应机制侧天赋 / 遗物 / 装备 **run 内重置**。构筑的无常与船的连续,是同一条法则的两面。`[已定,基石 §3;机制事实]`(注:此处三样对应机制侧 L2 天赋 / L5 遗物 / L4 装备;L3 角色成长是否跨轮完全重置属参数级留白,见 §8。`[待定]`)
- **名字=横向沉淀,不是纵向战力**:一程程死在船上的乘员,其名录不随构筑散去,而是**沉淀进归不得港城**——港城「沉淀下来的是人和见识,不是货」。这与元层伦理「海上不欠,岸上不留」一致:名录是记忆与荣光,**不换算成任何战力加成**(元层只沉淀横向解锁与便利,禁纵向战力)。`[提案,对齐机制:Meta 禁纵向战力]`
- 也就是说:执名牌在**一轮之内**是 permadeath 的皮(名牌钉进本程的船板);在**跨轮**层面,它沉淀为港城墙上一列**越来越长的名录**——玩家攒下的不是更强的船,是一船越走越多的记挂。这道「越送越多人回家、船身却添越来越多亡者名」的张力,呼应远景归乡(基石 §10)。`[提案,承接基石 §10 远景归乡已定]`
- **远景归乡的一种呈现**(叙事连接,权威归属基石 §10 与 `legendary-and-enemies`,本文只提叙事落点):当港城名录累积到某一分量、送达累计过某阈 `[占位阈值,交机制轮]`,某一次图房落墨时,墨线里会画出**一段没有名字的海岸线**——那不是新的委托,是**船自己的归途第一次浮现**。它守在人间层、不重新引入任何宇宙级存在,只是一道极远的地平线:一船亡者共同记着的方向,终于在图上现了形。`[提案]`

### 4.1 本文只说「乘员在世界观里是什么」,不起具体名字

### 4.2 须登记的裁决张力:提案池倾向匿名代号制,与 Plan-1 英杰名冲突

必须留档一条已浮现的张力,供基座定型后一并议:`[待定]`

- **前两波提案池集体倾向匿名代号制**:即乘员以**手艺 / 职守**为称(「使桨的」「开弓的」「接骨的」),或以一枚朴素工牌代号相称,**不配历史 / 传说英杰名**。此倾向与归潮之海的世界法则高度自洽——基石 §5 明写「手艺与出身无关、与故事无关」,一船无名手艺人比一船留名英豪更贴「归乡是普世的痛、不是英雄的荣耀」的调性,也更服务「零介绍可读性」(玩家一眼读到的是「一队船工」,不必先认识七个名人)。`[提案,记录倾向,非裁决]`

## 5. 玩家视角——一队有事要做的人

归潮之海**不设古典意义的英雄主角**。玩家的视角落在这一船乘员身上,而他们是一队**被一桩活儿推着走的手艺人**:那桩活儿就是系缆柱上认下的归乡——把一坛骨灰、一个老兵、一笼信鸽送到它该到的海岸。他们上路,不因天选宿命,只因**有该做的事、且这活儿顺路带他们往家挪近一程**。`[已定,承基石调性锚]`

- **质感示意**:每一程起航,画面落在甲板上这几双手上。他们的第一件事不是自我介绍,而是接活——图房落墨、认下这程要送的人,然后过水。没有人追问「我是谁、我为何在此」,对话围着眼前的货与水展开,像一支已经开工的巡夜队,而不是一群等待铺垫的主角。`[提案]`
- **依附对象**:玩家牵挂的,是「这一船人这趟能不能把人送到、能不能囫囵回港」这件事,以及这条越走越多亡者名的船本身——而非某一个非凡个体的成长弧。`[提案]`

### 5.1 船长定位——每程从乘员里出任,不另立恒定角色

归潮之海**不设一个跨轮恒定、独立于乘员之外的核心角色**。所谓「船长」,是**每一程从本轮上船的 1-4 名乘员里出任的玩家视角落点**:它是这一船人里由谁掌舵的位置皮,不是一个第五名的、永远在场的固定主角。换一轮航程,上船的人可能全换,掌舵的也随之是另一个人。`[提案]`

- **与远景归乡相容**:基石 §10 说「送足够多人回家之后,船自己的归路才会浮现」。这里的「船自己的归乡」不绑在任何单一个人身上——它是**这一船「有事要做的人」共同归途的落点**:船的归乡=一船亡者与幸存者共同记着的那个方向(§3.3 名录所指),而非某位恒定船长一个人的回家。故「依附落在事与船上、不落在某个人」与「船自身的远景归乡」并不矛盾:两者都把终点安在「船 / 这一船人」这个集体尺度上,而非单一主角。`[提案]`
- **是否再叠一个跨轮恒定核心**:要不要在乘员之上再设一个跨轮存续的锚(近似另一套平行设定里的恒定核心框架),依赖尚未锁定的元弧与 L1 / L3 映射,**留 `[待定]`**;但归潮之海的世界内倾向清楚——它更像「每一程一船人、无恒定主角」,依附落在「事」与「船」上,而非某个人。`[待定,倾向无恒定主角]`

## 6. 委托人失败规则——一轮没送到,系缆柱上的人怎么办

一轮失败、委托未送达时,系缆柱上等的人**不会死、不会被清算、不会向你索命**。缆绳仍拴着,委托人继续在系缆柱前等——他们已经等了很多年,再等一汛不算什么。依基石推论 5「海留不住『算了』」,没送到的委托随潮漂回防波堤内,人与缆一起等下一条船。`[提案,深化基石 §8]`

- **专为防止连败被读成「愧疚清算」**:与 Hades 式「重开非惩罚」的调性对齐。委托人下一轮见你时招呼如常,绝无责难;或许其执略有偏移(细节微变、可重入委托池 `[提案]`),但那只是「潮还没对上」,不是你欠了谁。`[提案]`
- **与乘员两级死亡同调**:乘员溺亡不是罪、团灭不是罚、委托没送到也不是过。三者共用一套「死与败都是天气」的港口伦理——「海上不欠,岸上不留」。`[提案,对齐基石调性锚]`
- **机制边界**:委托人如何回到委托池、执如何微偏、是否保底重现,属机制轮 / run-loop 皮;本文只立「不清算、缆仍拴、漂回等下一条船」这条规则的叙事根据。`[待定,交机制轮与 run-loop-mapping]`
