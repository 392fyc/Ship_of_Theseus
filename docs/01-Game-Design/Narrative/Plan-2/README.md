# 归潮之海 叙事文档索引

> 本文件夹（Plan-2）管理「归潮之海」世界观的全部叙事设定，与 Plan-1 平行、不覆盖。Plan-1 是主推方案，本文件夹是平行保留的备选：每份文档开头用一行「备选方案」说明标出这一点，现行叙事以 [Plan-1](../Plan-1/README.md) 为准；除这行说明外，标题与正文不再标注方案编号。
> **归潮之海** = 收缩版世界观：一片人人都在回家的英雄时代之海，挡在归途上的怪物全是没能回成家的人；你的船替到不了家的人回家。量级死守人间层（半神以下、英雄杀得动的对象），元目标是人尺度的归乡，消除 Plan-1「约 DnD 12 级的战斗表现去演宇宙级/创世级故事」的撕裂——撕裂本在叙事量级层，机制骨架（3 幕×8 关、门循环、tier 体系）沿用不动。
> **状态标注约定**：[已定]=用户裁决锁定 / [提案]=待采纳的可回退设计 / [待定]=留位未定 / [占位]=临时数字或待补；另 [机制事实]=引自机制真源的客观事实（区别于用户设计裁决的 [已定]）。
> **生成过程**：三波前提面板（19 案，每案四轴对抗裁判评审）选定基座「归潮之海」（2026-07-24 用户裁决）→ 定向深化为六文档骨架（基石 + 五下游，各经独立 critic 盲审，量级纪律 6/6 通过）→ 参照 Plan-1 体例定稿。

## 文档

- **world-premise.md** — 基石与 canonical 术语表，**其余文档与之冲突时以它为准**。唯一法则「海不认路，认执」（执越重漂得越近岸）+ 五条推论；执是这片海一切现象的通货；忒修斯功能连续解「她还认得回家的路，她就还是她」为 permadeath 与重铸提供统一存在论；归不得港城（据点）；一次航程七步与图房落墨的读缝机理（回应「为何单一世界每轮恰好三片」）；疏浚非斩杀 + 跨轮长账（反派复战与进展的世界规则化）；委托人失败规则；远方的神不下场（量级钳制）；远景归乡（船自身归乡入池为远景终点）。13 条术语表。
- **mythic-structure-and-acts.md** — 幕结构与航程与抽幕机理。一次航程七步映射 3 幕×8 关 + 门 + 商店 + Prep；「越近岸水越凶」= 幕序难度递增；**账簿式落墨 / 折处必淤 / 可航缝淤口上限**（抽幕机理，回应凑设定之疑）；水域集（幕池）登记体例与在册候选池；「每次大的失乡多一片新水域」= 幕池扩写。神格锚点候选一律钳半神以下、不填同名主神本尊。
- **legendary-and-enemies.md** — 传奇敌人与守门与远方的神。Boss 生成公式「主人的执就是他的打法」+ 三样板（塞壬长姊乡愁叠层 / 波吕斐摩斯循声 / 沉舰统帅重演沉船夜）；守关 / 精英 / 随潮溺众三池全压半神以下、明确不设 apex 层；远方的神以署名 / 来历 / 传闻 / 祭坛四法在场不下场（量级防火墙）；疏浚 + 跨轮长账复战条款；守门大名允许与 Plan-1 重合（2026-07-24 用户裁决）。
- **crew-and-units.md** — 乘员与棋子与执名牌。乘员 = 归途上的手艺人（用船工钱换航程、手艺与故事解耦）；一个棋子一名乘员；两级死亡（单位阵亡 vs 全船覆没）；执名牌 = permadeath 叙事皮（阵亡名牌钉进替换船板）；船长 = 每程从 1-4 乘员出任的视角、不另立恒定角色；**乘员命名制度 [待定]**（提案池倾向匿名代号制，与 Plan-1 英杰名裁决方向冲突，只登记不选边）。
- **run-loop-mapping.md** — run 循环的叙事映射。一次航程七步逐条映射 run-loop 机制：战后回收顺序 / 五类门（瞭望手报向）/ 跟潮货郎船（商店，卖遗物）/ 泊夜（Prep 七动作）/ 过主与送达 / 团灭重铸 / 元层港城横向沉淀 / 委托人失败规则。附环节对齐速查表（逐条对真源）。
- **layers-and-principles.md** — 五层架构映射与设计原则。L1-L5 逐层叙事映射（补齐 Plan-1 留白的 L1/L2/L3）；船体替换 = 构筑与五层咬合；四条设计原则：**零介绍可读性（头号）**+ 可读性预算分配表、量级死守人间层、重开非惩罚（对齐 Hades 避开 SOMA）、忒修斯功能连续解。
