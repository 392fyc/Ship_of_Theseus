# 归潮之海 五层架构映射与设计原则 layers-and-principles

> 五层构筑与成长架构在归潮之海里各是一样什么叙事物;船体替换等于构筑如何与五层咬合;以及归潮之海的四条设计原则——零介绍可读性(头号)、量级死守人间层、重开非惩罚的调性、忒修斯母题的功能连续解。本文只承诺叙事皮与设计价值,不锁机制;机制数值归机制轮。

## 0. 这份文档是什么

这是 Plan-2 六文档的收束篇。前五篇立世界、排航程、登记敌人、点乘员、铺 run-loop 皮;本篇做两件事:把五层架构 L1-L5 逐层映射成归潮之海里的叙事物,补齐平行方案留白的 L1/L2/L3;并把用户裁决的设计价值固化成可执行的设计原则,供下游一切内容自检。[已定:文档定位]

一切术语引自基石 world-premise 术语表——执、图房落墨、系缆柱委托、执名牌、疏浚、长账、水域主人、归不得港城、远景归乡、轻归空船、折处必淤与淤口、随潮的溺众、认缆与泊夜,以及换装四物(船板、器物、桅饰、天赋,基石 §3)——不另造。[已定]

四态图例:句尾标注 [已定]=用户裁决 / [提案]=可回退设计 / [待定]=留白待裁 / [占位]=临时数字必须显式标;另用辅助标 [机制事实] 标注引自机制真源的客观事实(区别于用户设计裁决的 [已定])。专名一律 [提案] 示意,属用户裁决域。

术语纪律:全程分 3 幕(片水),每幕 8 关(stage)。「关」一律指 stage(3 幕×8 关=24 关),act-position 一律用「幕 / 片水」,二者不混用;守门 Boss = 每幕第 8 关的水域主人。[机制事实]

## 1. 五层架构叙事映射总表

| 层 | 机制定位(真源) | 归潮之海叙事物 | 这一程 or 跨轮 |
|---|---|---|---|
| L1 Global | 永久横向解锁,禁纵向战力 | 归不得港城年年长出的建成:作坊、船台、图房侧厅,以及愿意上船的新手艺人 | 跨轮沉淀(据点) |

| L3 角色成长 | 类固定曲线,转职改 growth rate,由升级(EXP)驱动属性成长 | 每块换上的船板——即这一程的乘员——固定的长法,随航程精进 | 属于这一程 |
| L4 装备 | run-reset,词缀 affix + 渐进品阶,武器 + 防具两槽,不构筑 build | 泊夜从沉船废料里打捞来的器物、顺手的家伙什 | 属于这一程 |

换装四物「船板、器物、桅饰、天赋」恰好覆盖四个 within-run 层:天赋对 L2、船板承载 L3、器物对 L4、桅饰对 L5;唯一不换的是 L1 港城——它在船外,是跨轮的据点。[提案:映射]

## 2. 逐层展开

### L1 Global 港城的建成(据点,跨轮,横向)

叙事物 = 归不得港城一年年长出的作坊、船台、图房侧厅,以及被这片海吸引、愿意上船的新手艺人。[提案] 机制侧 L1 只解锁横向选项(新职业、新遗物进池、便利升级、复活门道),绝不给纵向战力;港口伦理「海上不欠,岸上不留」正是 horizontal-only 的叙事根据——港城沉淀的是人和见识、不是货,不给你一条更强的船,只给你更多愿意上船的人、更多懂这片海的门道。[已定:horizontal-only][提案:叙事皮]

- 解锁新职业 = 港城来了个新手艺人,愿意用船工钱换一段航程。[提案]
- 解锁新遗物进池 = 港城见识长了,图房记下一种新的「执能落成什么信物」,此后航程里才可能遇上它;这是把选择变多(pool expansion),不是开局白送战力。真源 run-loop.md「Relic pool expansion / 遗物池随 Meta 进度逐步扩展」:Meta 对遗物只做扩池。[已定:horizontal-only][提案:皮]
- 便利升级 = 情报预览更深、商店折扣、奖励重掷之类,只省事不加战力。[提案]
- 更高的建成上限 = Meta 解锁的是新建筑类型与现有建筑「更高的等级上限」(真源「Meta 进度解锁新的建筑类型以及现有建筑更高的等级上限」),指的是建筑 / 器械等级上限,不是角色等级上限;角色纵向战力是元层红线,永不跨轮沉淀。[已定]
- 复活门道 = 打捞队的本事,把落水的人从执里捞回来;它是横向便利、不改变乘员 permadeath 的既定语义(阵亡执名牌钉进新板仍为终局,见 crew-and-units),具体皮与边界留白。[待定]

补留白:平行方案曾把 L1 挂在元弧上未具象。归潮之海用「港城建成物」把 L1 落成一眼可读的据点成长——回港看见多了一间侧厅,就懂你解锁了什么。[提案]

### L2 天赋 这一程的手感(属于这一程,每轮清零)

叙事物 = 这一程摇桨的人被这片海逼出来的手感与临场领悟。[提案] 机制侧 L2 每轮从 Lv1 清零、由升级产出天赋点;叙事根据是「空船不招执」的镜像:天赋是这一程 attach 在这船人身上的执,送到了家、船轻了,这一程练出的东西也随潮卸下,下一程新船新人、手感从头再练。[已定:每轮清零][提案:叙事皮]

- 经济类桅饰催熟手感 = 经济类遗物的加成挂在 L2 天赋点(真源「经济类遗物可加成」天赋点),不落在船板长法(L3)上;叙事上某些桅饰让这一程的人悟得更快、临场手感长得更足。[已定:挂 L2 天赋点][提案:叙事皮]
- 转职(Lv5)= 走到深水区,回头看这一程攒了哪些桅饰,再定这个人往手艺哪条深处走;「转职方向由桅饰 / 遗物池决定」是耦合提案,真源只明文 Meta 解锁转职路线与天赋树区域,方向耦合待机制轮 canonical 核实。[提案:耦合待核][提案:皮]
- 天赋为何不沉淀进港城? 因为港城只留人和见识(L1),不留这一程的执(L2)——「岸上不留」。[提案]

补留白:天赋整轮重置在平行方案只有机制约束、没有叙事解。归潮之海给出「执随送达而卸」的解,使清零不读成惩罚性失去,而是自然的轻归。[提案]

### L3 角色成长 船板的长法(属于这一程)

叙事物 = 每一块换上的船板——也就是这一程的每个乘员——都有固定的长法。[提案] 机制侧 L3 是类固定成长曲线、由升级驱动属性成长、转职改 growth rate(经济类遗物加成不落这里,挂 L2 天赋点)。叙事:木匠有木匠的长脾气,桨手有桨手的,与出身无关、与故事无关(职业 kit 与叙事零耦合,机制事实);深潜手艺后长法变了(转职改曲线)。[机制事实][提案:皮]

- 船板即乘员:每个乘员是一块换上的船板,这一程钉上、这一程长成、送达后随潮去;阵亡则执名牌钉进新板永留为船的一部分——permadeath,详见 crew-and-units。[已定:permadeath][提案:皮]
- L3 跨轮口径:本文叙事皮按「属于这一程」写;L3 成长数值跨轮是否完全重置属机制轮裁定,元层禁纵向战力约束下倾向重置,以真源为准。[待定]

补留白:平行方案的 L3 叙事映射列为待定 hook。归潮之海用「船板的长法」补齐——把角色成长绑进忒修斯船板的换装隐喻,一举同时解释成长、转职与阵亡。[提案]

### L4 装备 打捞的器物(属于这一程,不构筑 build)

叙事物 = 泊夜清点船舱时从沉船废料里打捞来的器物、顺手的家伙什。[提案] 机制侧 L4 run-reset、词缀 affix、渐进品阶(稀有度白 / 蓝 / 紫 / 金 / 红)、武器 + 防具两槽、不承担 build-defining;叙事根据:你不会围着一把捞来的刀规划整程,捞到什么用什么,送达随潮去。[机制事实][提案:皮]

### L5 遗物 挂上桅的信物(6 槽,build-defining)

叙事物 = 挂上桅的信物、图腾、护符,统称桅饰。[提案] 船上有六个能挂东西的位置,对齐机制 6 槽硬上限。[机制事实][提案:叙事皮] 桅饰分量重、改船的性子:经济类桅饰把这一程的手感催得更足(其加成流向 L2 天赋点,真源),流派类桅饰改整船打法(叙事上令 L2 已有节点变了味道——此为叙事皮描述、不含机制承诺);转职看桅饰池定方向是核心 build-defining 耦合提案,待 canonical 核实。[机制事实:run-reset / build-defining / 6 槽][提案:皮与耦合]

- Boss 固定含特殊遗物 = 疏浚一位水域主人,散掉的执里会落下一件最重的桅饰。[机制事实][提案:皮]
- 货郎船也卖桅饰:商店(货郎船)确会售卖遗物与装备(真源:Relic 来源含 shop),桅饰不只来自 Boss。[机制事实]

## 3. 船体替换等于构筑:换装与五层的咬合

基石定:「一轮构筑就是一次彻底换装:船板、器物、桅饰、天赋都只属于这一程,送达之后随潮而去。」(基石 §3)[已定] 这四样恰好覆盖四个 within-run 层——天赋对 L2、器物对 L4、桅饰对 L5、船板承载 L3;不换的只有 L1 港城,它在船外、是跨轮的据点。[提案:映射]

于是五层沿「这一程 vs 跨轮」自然两分:船身(L2、L4、L5,与逐程替换的船板 / 乘员 L3)每程翻新,据点(L1)跨轮沉淀。其中 L2 每轮清零、L4 / L5 run-reset 是既定;L3 船板虽逐程替换,其成长数值跨轮口径仍待机制轮定 [待定]。忒修斯之船的哲学困境正落在这条缝上——船身没有一块原装板,她还是不是同一条船? 世界的回答见 §7。[已定:母题落点]

## 4. 设计原则一:零介绍可读性(归潮之海头号设计价值)

原则:新玩家不读任何设定,也应一眼认出——挡路的是没回成家的人,你在替人回家。[已定] 这是收缩到归潮之海的根本动机,也是归潮之海高于一切的设计价值。理由:肉鸽叙事天然弱、玩家没耐心读设定;素材广为人知等于第一眼定位敌人的故事线与体系。希腊英雄时代加归乡母题正是为此而选。[已定]

可读性预算花在刀刃上:可读性是有限预算,按出现频率分配——最高频的东西必须最易读,生僻概念只放最低频的位置。[已定:原则] 对齐 run-loop 的频率结构:

| 出现频率 | 位置 | 可读性要求 | 神话身份 |
|---|---|---|---|
| 最高频 | 杂兵(每关多次) | 最易读,一眼知生前是谁 | 随潮的溺众:塞壬浅滩的听众、独眼牧岸的牧群 [提案] |
| 高频 | 词条精英(每房收尾) | 词条一眼懂、跨幕通用 | 溺众里执更重的那几个 [提案] |
| 中频 | 守门 Boss(每幕一次,即该幕第 8 关) | 名字即定位 | 大名怪物:塞壬、波吕斐摩斯、美杜莎 [提案,专名待裁] |
| 极低频 | 远方神 / 深潜 / 长账终局 | 可承受需背书的生僻概念 | 波塞冬祭坛、名录轮换等 [提案] |

落地纪律:

- 高频杂兵必须用最广为人知的原型,严禁把生僻神话塞进杂兵位。[已定:预算方向][提案:执行]
- 凡需长篇背书才懂的设定,优先砍;每个专名、每片水域、每个杂兵的形状都要服务「第一眼可读」。[已定]
- 五层叙事皮同守此条:器物、桅饰、船板、天赋一眼可懂是什么,不要求玩家读架构文档;回港多一间侧厅等于解锁,一眼懂。[提案]

对照撕裂诊断:平行方案曾把守门填成美杜莎、芬里尔一级,又在其上叠一层宇宙级 apex(提丰、盘古一类),撕裂出在叙事量级层——守门量级尚在英雄可制范围,apex 却已越到创世级,两者拼在一条战斗曲线上必然割裂。归潮之海守门仍可用大名(美杜莎等可与平行方案重合),但显式砍掉宇宙级 apex 一层——见 §5。[机制事实:撕裂在叙事层][已定:砍 apex]

## 5. 设计原则二:量级死守人间层

原则:战斗天花板 = 英雄杀得动的东西——大名怪物、妖异、半神以下。[已定] 奥林匹斯主神、创世级只作背景信仰、传闻、远方存在,绝不登场、绝不成为战斗内容。[已定] 神在这个世界里是天气的姓氏、诅咒的语气词、出航前泼进海里的那杯酒;他们不下场。[已定]

- 名录守关(塞壬、波吕斐摩斯、美杜莎、喀耳刻、斯库拉与卡律布狄斯等)全是凡人英雄在神话里确实制得住的对象,量级自洽。[已定,专名 [提案]]
- 每位守关须落到基石公式「主人的执就是他的打法」:他放不下的那件回不去的事,就是这一战的机制母题。纯自然之力型的候选(如卡律布狄斯——若只读成一处吞船的大漩涡,便没有「执」、不合归乡母题)须二选一:要么给它「执」的人格化读法(那漩涡是某个再也回不去的人一圈圈打转、放不下的执),要么替换为更贴母题者;具体认执与登记归 legendary-and-enemies,本文只立公式。[提案]
- 机制侧「传奇 tier」只是 tier 名,不要求 Boss 是神祇级;机制无宇宙级 apex tier,填谁是叙事自由。[机制事实] 归潮之海据此显式砍掉平行方案的 apex 宇宙级一层——这正是消除撕裂的关键动作。[已定]
- 守门 Boss 大名允许与 Plan-1 重合(美杜莎等大名可用):此为跨方案许可,来源 = 2026-07-24 用户裁决 + 基石 §11;它不违「方案文件夹隔离」,隔离约束的是文件与叙事量级,不禁用同一则公版神话大名。[已定,来源 2026-07-24 用户裁决]
- 系统侧镜像:元层 L1 禁纵向战力,只沉淀横向解锁。量级纪律在叙事与系统两侧同构——港城不给更强的船,神不下场杀你。[已定]

## 6. 设计原则三:调性锚——重开非惩罚,对齐 Hades 避开 SOMA

归潮之海的忒修斯母题(船之同一性、意识连续)天然可滑向两个方向:SOMA 式的连续性恐怖(「复制出来的我还是不是我」的存在主义无力),或 Hades 式的温暖循环(死亡即叙事推进、无惩罚)。归潮之海明确选 Hades 侧、避开 SOMA。[已定:调性方向]

三条调性子原则:

1. 重开非惩罚。沉船是天气不是罪;permadeath 到 Settlement 到新一轮的叙事皮是「这片海上没有沉船,只有还没漂回来的板子」。港口把团灭当季候,重新立船、重新落墨。[已定]
2. 代价非清算。一轮失败、委托未送达时,系缆柱上等的人不死、不清算——依「海留不住『算了』」,委托随潮漂回防波堤内,人与缆一起等下一条船,下轮招呼如常。专为防止连败被读成愧疚清算。[提案:委托失败规则,基石 §8][已定:调性对齐]
3. 保有能动性,双方都有终点。玩家始终有得选(选门、挂桅饰、认哪根缆);敌方也非永劫无功——疏浚长账让水域主人一汛一汛被送近归途,极慢但有终点(基石 §7)。**长账是纯叙事层的 meta 进展,不改 Boss 战力**:机制上 Act Boss 每轮满状态重置(机制事实),叙事上她每轮重新成形、却更近归途——被一汛汛送近的是执的「账」,不是这一战的强度,下游勿读成 Boss 跨轮数值变弱。双方都不困在无意义的重复里。[已定:双向能动][机制事实:Boss 每轮满状态][提案:桥接口径]

为何避开 SOMA:SOMA 用连续性焦虑制造恐怖,让玩家为「我是不是同一个」而痛苦;归潮之海用功能连续解(§7)给这个问题一个务实温柔的答案,再用「死是天气」把重量卸掉——不制造焦虑,而是收编焦虑。[提案:调性论证]

## 7. 设计原则四:忒修斯母题的功能连续解——不看料看航线

原则(主题锚):「她还认得回家的路,她就还是她。」[已定] 同一性不落在原装木料上(她本就没有一块),落在她始终认得归途这件功能上——这是功能连续解,不是实体连续解。[已定]

它在设计里做什么:

- 为 permadeath 与重铸提供存在论根据:船身全换(L2 每轮清零、L4 / L5 run-reset、船板逐块替换,L3 跨轮口径待机制轮定 [待定])不制造「失去」,因为同一性从不在料上;换装即常态。[已定]
- 让 build 无常(每轮清零)与船连续(L1 据点加「认得归途」跨轮)读成同一条法则的两面,而非矛盾。[已定]
- 一句话执行判据:不看料看航线——评估任何叙事皮是否忠于母题,只问「她还认不认得回家」,不问「她换了多少料」。[提案:执行判据]

与远景归乡的接续:功能连续解也托住远景元目标——送足够多人回家之后,船自己的归路才浮现。船长不是恒定的第五人,而是每一程从这 1-4 名乘员里出任的玩家视角;船的归乡因此不绑单一个人,而是这一船「有事要做的人」共同归途的落点(与远景归乡人尺度终点相容,厘清见 crew-and-units)。[已定,基石 §10][提案:船长厘清]

触发与呈现 [提案]:当累计送达达到某个阈值 [占位],某一次图房落墨时,墨线的尽头会多画出一段没有名字的海岸线——那就是船自己的归途第一次浮现。它守在人间层,不重新引入任何宇宙级存在,也不是一块「通关」结算屏,只是地平线上多了一道人尺度的岸。「还认得回家的路」的船,最后认得的是自己的家。[提案][占位:阈值]
