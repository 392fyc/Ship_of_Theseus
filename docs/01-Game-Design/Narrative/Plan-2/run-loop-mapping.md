# run-loop 循环的叙事映射 —— 一次航程的循环叙事皮

> **备选方案**：本文属于叙事 Plan-2「归潮之海」。用户 2026-07-28 裁决 Plan-1 主推，Plan-2 平行保留备选；现行叙事以 [Plan-1](../Plan-1/README.md) 为准。

> **文档地位**：本文是 `world-premise.md`（归潮之海世界基石）的下游文档，把基石第 6 节「一次航程」与第 8/10 节展开成对齐机制的循环叙事皮。**术语、母题、调性一律以基石为准**；与基石冲突时以基石为准。本文只给「色彩」，不锁机制；机制数值一律归机制轮（真源 `01-Game-Design/Progression/run-loop.md`）。
>
> **状态标注约定**：`[已定]` = 用户已裁决锁定 / `[提案]` = 待采纳的可回退设计 / `[待定]` = 只留结构位、内容未定 / `[占位]` = 临时数字必须显式标。
>
> **术语对齐**：本文「站」= 机制「关」（stage，一片水域泊 8 站）；「片水域 / 幕」= 机制「幕」（act，一程 3 片）；「一程 / 一轮」= 一次 run。act-position 一律用「片水 / 幕」，绝不用「关 / 站」指代整片水域，以免与「站 = stage」串味。
>
> **命名纪律**：船、港城、货郎船、Boss 的专名属**用户裁决域**，一律标 `[提案]`，能用描述性称谓处不硬造专名。
>
> **本轮范围**：只写叙事皮。不改机制口径——本文所述节拍顺序、门数、五类奖励、商店频次、Prep 动作全部照真源；叙事只承诺「怎么讲」，不承诺「怎么算」。

## 1. 一站的节拍：战后回收怎么讲

一片水域泊八站，每站是一场接战；第 8 站是水域主人坐镇的深处（守门 Boss，见 §5）。机制侧战后顺序钉死为**固定金币经验结算 → 每角色独立兑现门奖励 → 选下一扇门 → 进入准备阶段**（真源 run-loop.md）。叙事皮逐拍贴上去：

1. **固定回捞**（固定金币 + 经验）：把这一站的执打散后，水面浮上来的是常例所得——沉底财货的打捞份（金币）+ 乘员在这段风浪里长进的手艺（经验，可能让人升一级）。这份不看运气、每站都有，是「过了一站」的底薪。[提案]
2. **兑现门奖**（每角色独立门奖励）：这一站原是上一站瞭望手报向时你亲手选的那处景物；打赢之后，那处景物的实物摆在眼前，**每个乘员各自上去取自己的一份**——机制侧「每角色独立获得门奖励」在叙事上就是各人各取、互不匀分。[提案，对齐 per-character 门奖励]
3. **再瞭望**（选门）：瞭望手爬上桅顶，报出前方看得见的两三处去向，奖赏摆在眼前、航线自己选（见 §2）。[提案]
4. **泊夜**（Prep）：两站之间把船拖上滩，歇一夜（见 §3）。[提案]

> 关键区分：**固定回捞**是打散执的常例、**门奖**是你上一拍亲手挑的那处的实物。二者叙事上分开讲，机制上也是两笔结算。[提案]

## 2. 瞭望手报向：门选路与五类门奖

每站过后，瞭望手报出前方 **2–3 处**看得见的去向（机制侧 2–3 扇门，下限 2）——**看得见的是「那处有什么」，看不见的是「具体多少」**，对应门上奖励类型前置可见、内容随机。[提案] 全片水域的海图不摊开（Hades 式单步选择），但当前第几站、水域主人坐镇的深处方位始终在望（进度条 + Boss 位恒可见）。[提案]

> **报向发生在哪几站之后**：一片水域 8 站，第 8 站是水域主人坐镇的深处（守门 Boss，位置恒在望）。瞭望手报向只在**前 7 站**过后发生；过主（第 8 站）之后不再报向——要么跨向下一片水（幕间泊夜），要么已是归途最后一片水、直接进入送达（见 §5）。这样「泊八站」已含 Boss，一片水域是 8 次遭遇而非 8+1 次。[提案，对齐 Boss = 第 8 站、门只在前 7 站后]

五类门 = 瞭望手能报出的五种景物：[提案]

| 门（机制） | 瞭望手报的景物 | 叙事物 |
|---|---|---|
| 金币门 | 一艘泡在水里的沉船 | 舱里没沉尽的钱货、漂上来的财箱 |
| 经验门 | 岸上一处战阵火光 | 一场值得打的硬仗、一片能让手艺长进的恶水 |
| 装备门 | 一片打捞得着的残骸场 | 沉船武备——兵刃、甲片、器物 |
| 遗物门 | 一处沉得最深、执浸得最透的水 | 一件被强烈执念浸透的遗留物，能改写一程打法（对应 build-defining 遗物）|
| 事件门 | 一片可疑的平静水面 | 一桩海上遭遇：风险换回报的非战斗抉择，可能翻脸成伏击 |

- **事件门绝不连续两站**（机制硬约束）：叙事皮——平静水面不会一片挨着一片，两片死水之间总隔着要打的凶水。[已定，对齐 events_non_consecutive]
- **遗物保底**（按出现计数，连续 N 站无遗物门则强制供应）：叙事皮——沉得最久的执物，潮迟早会把它托上水面；海留不住「算了」，该浮的执久不浮，下一次涨潮就强推上来。N `[占位 N=3，模拟偏紧待调]`。[提案]
- **同组门奖类型互不相同**：一次报向里不会两处都是沉船——瞭望手报的是三种不同的景物，逼你在「要什么」上真做选择。[提案，对齐 same_offer_types_distinct]

## 3. 泊夜：准备阶段怎么讲

基石「泊夜」原指幕间靠泊，机制侧 Preparation Phase 在**每站之间**都有；本文把泊夜统一读作**站间与幕间两级**的准备阶段皮——两片水域之间、以及每站之间都把船拖上滩过夜。七件事逐一贴皮：[提案，对齐 Prep 七动作 + 泊夜覆盖站间/幕间两级]

1. **烤船底 / 歇桨养伤**（恢复）：拖上滩烤掉船底的藤壶、给乘员养伤。恢复量只随**开局难度档**定、一程之内不变（不随幕涨），且**可按人拒绝**——有人不肯歇、连夜盯着自己的桨位（背水流：低血触发的天赋遗物才是他要的收益）。[已定，对齐恢复只随难度档 + 可拒绝]
2. **清点船舱**（Convoy 运输队大背包）：船舱是随船的大货舱，装着没上身的器物与遗物；泊夜可自由换装，**一旦重新下水，舱门就不再开**（战斗内锁定）。[已定，对齐 Convoy 战斗内锁定]
3. **听传闻**（情报 / View Intel）：听过路船、岸边人讲前方那片水。**有名号的凶物，传闻里带着名字**（精英头目特殊词条进房前可见，可据此在船舱里针对性换装）；**寻常的溺众看不真切**，得到跟前才认得出路数（基础词条进房前不可见）。[提案，对齐词条可见性规则]
4. **磨招式**（技能调整）：换手艺、磨招式。[提案]
5. **架滩头**（建筑布置）：泊岸时先在滩头圈好防线、架起器械（哨塔、路障等战场建筑），等下水开战时它们已经就位。[提案]
6. **候货郎船**（商店，仅两处泊夜有）：见 §4。[提案]
7. **起锚**（Confirm Departure）：重新下水。若有人没养好伤又非满血，起锚前会被提醒一次。[提案]

> v0 至少含 烤船底 / 清点船舱 / 听传闻 / 起锚 四项，其余随系统开放（对齐真源 v0 裁决）。[已定]

## 4. 跟潮的货郎船：商店每幕两回

商店不占门也不占关——它是一条**跟潮的货郎船** `[提案]`，一片水域里遇上你两回（幕中一次、水域主人坐镇的深处之前一次），就着那两夜的泊夜靠过来做买卖。[提案，对齐商店固定插入每幕两次嵌 Prep]

- **货郎只做买卖、不施舍**：一手交金币一手交货，买进卖出金币守恒——这是这片海的排水渠，把打捞来的浮财换成器物药水。[提案，对齐买卖金币守恒]
- **熟客有面子**（Meta 便利：shop_discount）：跟货郎照过几回面、港城替你递过话，价钱能松一点——只松价、不加战力，守横向红线。[提案]
- **货郎的甲板上摆什么**：器物、药水，也捎带几件他自己从浅处捞上来的执物（装备 / 消耗品 / **遗物**）。**沉得最深的执物仍要你亲自下水去取**（那是遗物门的活儿，见 §2），但浮到浅处、货郎顺手捞得着的那些，会明码标价摆上甲板。这样「遗物门 = 自己潜水取最深的执」与「货郎捎卖浅处的执物」叙事上各司其职，不打架。[已定，2026-07-28 用户裁定商店卖遗物；真源行 57 已同步补 Relics、与行 185 口径统一]

## 5. 过主与送达：水域主人与一程终点

每片水域深处坐着它的主人 = 这片水的执念本身，半神以下、英雄杀得动的量级（机制侧 Act Boss，位于每幕第 8 站，固定）。主人的执就是他的打法。[已定]

- **疏浚非斩杀**：你在深处「打赢」主人，不是杀死他，是把他本程淤起来的执**打散**、让这片水暂时通航。执有潮汐，被打散的念想会随下次涨潮回聚、主人重新成形——这就是同一守关能跨关跨轮反复遭遇的世界内根据。「这片海上没有斩杀，只有疏浚。」[已定，复战条款]
- **主人散去时最重的一份浮财**：水域主人被疏浚的那一刻，这片水沉淀最重的执物一并涌上水面——机制侧 Boss 固定包（金币 + 经验 + 装备 + 一件特殊遗物），叙事上是一程报酬里最重的部分。[提案，对齐 Boss 固定包]
- **长账**：疏浚不白费；一汛一汛地磨，若终有一次把某位主人**真正送回了家**（彻底了结其执），这片水永久消散、主人退出名录、幕池腾一个口子上新一片水。敌方视角也有极慢的终点，不是永劫被杀。[已定]
  - **长账是纯叙事层的极慢进展，不改 Boss 战力**：机制侧 Act Boss 每轮以满状态重置是机制事实——长账写的是「主人被一汛一汛送近归途」，不是「他一轮比一轮弱」。桥接一句：**主人每次疏浚后都会重新成形，却也每次都离归途更近一分**；下游勿把长账误读为 Boss 数值跨轮衰减。[提案，桥接口径]
- **送达 = 一轮完成**：认缆时认下的那桩归乡，随三片水疏通后送上他自己的海岸——「到了家的人亲手把船推回海里」，随后**轻归**（空船不招执，回程无战斗，一觉睡回港口）。这是战后回收与新一轮之间的呼吸。[已定]

> 为何恰好数片、且难度自港向岸递增：图房落墨是**读缝**不是发明航路——执在两片水相接的缝处淤成淤口，可航的缝在堵死前只容有限几个可泊淤口，越近岸执越重越难。此机理（账簿式落墨 / 折处必淤 / 可航缝淤口上限）的完整登记归 `mythic-structure-and-acts`，本文只作交叉引用。[提案，机理详见幕结构文档；幕数以机制 3 幕×8 关为准]

## 6. 船殒与重铸：团灭的非惩罚叙事皮

全船覆没才是一轮的终点。机制侧 permadeath / 团灭 → Settlement → 开新一轮，叙事皮如下：[提案，对齐 permadeath → Settlement]

- **团灭 = 船殒**：船在海上碎了，一轮就结束。港口不把沉船当失败，**当天气**。[已定，调性锚：死是天气]
- **重铸 = 打捞重立**：打捞队把「同一条船」从废料里重新立起来（反正她本没有一块原装板）；同一性不落在木料上，落在她始终认得归途——「她还认得回家的路，她就还是她」。[已定，功能连续解]
- **乘员不消失**：溺亡乘员的**执名牌**随潮漂回港口，钉进下一块换上的新船板，人成为船的一部分、航程替他继续。[已定]
- **图房重新落墨**：新一程的海重新画一遍——潮换了，横在你与目的地之间的三片水也换了。[已定]
- 一句话收束：「这片海上没有沉船，只有还没漂回来的板子。」[提案，同基石 §5 该句标注]
- **没送到的委托也漂回来**：本程没送达的归乡随潮漂回防波堤内，在系缆柱上等下一条船（见 §9）。[提案]

## 7. 归不得港城：元层的横向沉淀

海中央那座用沉船木头搭起来的港城 = 玩家据点 = 元层（Meta）。它年年长出新的作坊、船台、图房侧厅——**沉淀下来的是人和见识，不是货**。[提案，对齐 Meta] 这句正是元层「只沉淀横向解锁与便利、禁纵向战力」的叙事皮：[已定]

| 港城长出什么（叙事） | 元层解锁什么（机制） | 性质 |
|---|---|---|
| 新来的手艺人落了脚 | 新职业解锁 | 横向：多一种打法，不是更强的数值 |
| 图房侧厅备了更多缝的账 | 天赋区域解锁（第二转职，真源行 292–304：完成一次 run 解锁） | 横向：多一条转职线，旧线不变强 |
| 打捞队认得更多执物 | 遗物池扩充（只扩池、不起始白送遗物） | 横向：多组合可能，非「基础遗物的强化版」|
| 船台能起更大的器械 | 新建筑 / 更高的**建筑与器械等级上限**（真源行 322；非角色等级） | 横向：多战场手段，不碰角色纵向战力 |
| 跟货郎混熟、看海图看得更细 | 便利升级（折扣 / 重掷 / 情报预览）| 便利：只碰经济与情报，不碰战力 |

> **红线注**：港城长出的一切都是**横向解锁或便利**，绝不给角色更高的基础战斗数值。「更高等级上限」限定为建筑 / 战场器械的等级上限，**不是角色等级上限**——角色纵向战力是元层红线（真源行 322 + Meta 禁纵向战力条款）。[已定]

**港口伦理「海上不欠，岸上不留」**：一程的构筑（船板、器物、桅饰、天赋）送达之后随潮而去，绝不带回港叠着用——港城只留人与见识，不留一程的战力。[提案，对齐 run 内重置 + Meta 横向]

## 8. 为什么再航：近景与远景归乡

- **近景（营生）**：系缆柱上永远还拴着缆。送完一个，潮水送来下一个——你替到不了家的人回家，这是每一轮的直接理由。[已定]
- **远景归乡（远景元目标）**：潮总有一天会把你自己的那片海岸漂进图房的墨线里。送足够多人回家之后，船自己的归路才会浮现——**这不是一块「通关」结算屏，是一道极远的地平线**：一个人尺度的终点意象，给循环一个方向而非一场大结局。[已定，2026-07-24 用户裁决] 元层只沉淀横向解锁，远景归乡是叙事意象、不是纵向战力目标。[已定]
  - **触发与呈现**：给一个可回退的落地方案——**累计送达达到某个阈值** `[占位]` **后，某一次图房落墨会在海图边缘多画出一段没有名字的海岸线**：那不是任何委托人的家，是船自己的归途第一次浮上墨线。呈现只是「地平线上多出一道岸」，不触发结算屏、不重新引入宇宙级、守在人间层。[提案]
  - **归途属于谁**：船的归乡不绑单独一个人。每一程掌舵的是这一船里那几个「有事要做的人」（每程从 **1–4 名乘员**中出任的玩家视角，非另立的恒定「船长」角色；乘员定位登记见 `crew-and-units`）；船自己的归途，是这一船人共同航向的落点。远景归乡与「不绑单一恒定角色」由此相容。[提案，与远景归乡人尺度落点相容]

## 9. 委托人失败规则：连败不是愧疚清算

一轮失败、委托未送达时，系缆柱上等的人**不会死、不会被清算**。[提案，对齐 Hades 式非惩罚]

- 缆绳仍拴着，委托人继续在系缆柱前等——他们已经等了很多年，再等一汛不算什么。[提案]
- 依基石推论 5（海留不住「算了」），没送到的委托随潮漂回防波堤内，人与缆一起等下一条船。[已定，依据基石]
- 下一轮见你时招呼如常，或许执略有偏移（细节微变、**可重入委托池**），但绝无责难。潮还没对上而已，不是你欠了谁——对应「海上不欠，岸上不留」。[提案]
- 设计意图：专为防止连败被读成「愧疚清算」，与「死是天气不是悲剧」的调性对齐（对齐 Hades 式重开非惩罚）。[提案]
