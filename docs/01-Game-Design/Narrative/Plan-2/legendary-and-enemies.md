# 归潮之海 传奇敌人与守门与远方的神

> 下游叙事登记文档。上承基石 world-premise「归潮之海」,只写敌人的叙事皮(色彩),不锁机制数值——机制落地一律归机制轮。四态标注逐条挂句尾:[已定](用户裁决)/[提案](可回退设计)/[待定](留白待裁)/[占位](临时数字必须显式标)。专名(Boss 名、地名)一律 [提案] 示意,归用户裁决域;能用描述性称谓则不硬造专名。[已定]

## 0. 这份文档管什么

本文登记「挡在归途上的东西」:守门 Boss(=水域主人)、精英、高频杂兵三层的神话身份,以及量级钳制(远方的神如何在场而不下场)与复战条款(同一守关为何能反复遭遇)。术语一律引基石术语表(执 / 疏浚 / 长账 / 随潮的溺众 / 图房落墨 / 水域主人 / 远景归乡),不另造。[已定]

一条贯穿全文的世界内约束:**战斗天花板 = 英雄杀得动的东西**——大名怪物、妖异、半神以下。奥林匹斯主神、创世级绝不登场、绝不成为战斗内容。名录里能站上场的,全部是凡人英雄在神话里确实制得住的对象,量级自洽。[已定]

## 1. Boss 生成公式:主人的执,就是他的打法

这是本作把神话素材变成 Boss 的生产规范。一句总纲:**「主人的执,就是他的打法。」** 水域主人不是一个「有技能表的怪」,而是这片水的执念本身;他放不下的那件事,就直接长成你要在场上应付的那套机制。[提案]

**三步生产法:** [提案]

1. **认执**——先问「这片水底沉的是谁的什么念想」。生前是谁、卡在归途的哪一步、放不下的是哪一件事(骨灰、旧仇、那一夜、被夺走的东西)。这一步定的是敌人的**来历标签**,要广为人知到玩家零介绍就认得。
2. **译执为机**——把那件放不下的事翻译成**一个签名机制**,而不是一串数值。签名机制要满足「一眼看懂机制 = 一眼看懂他生前放不下什么」。这条是全公式的核心,也是零介绍可读性(基石设计原则)在敌人侧的落点。
3. **配阶段与场**——把签名机制铺成 Act Boss 规格:随血量推进的**阶段切换**、可预告的**技能循环**、以及把杂兵拉进来的**召唤**(召唤物就是本片水的随潮溺众)。行为必须可读——玩家几次尝试内能摸清。[对齐机制事实:Act Boss = 传奇 tier + 每幕一套独有定制机制]

**三条硬约束(生产时必须守):** [提案]

- **签名机制 ≠ 词条。** 词条是挂在被动挂载点上的通用被动(跨幕复用);Boss 的签名机制是**每幕一套的独有定制系统**,是这一位主人专属的、不进通用词条池的东西。[对齐机制事实]
- **越近岸越凶,是执重不是数值拔高。** 一次航程三片水对应三幕,第三片水正当当季执念涨潮,它的主人的签名机制最凶——凶在执最重(基石「折处必淤」:通往目的海岸的缝上,这片水的淤口本汛淤得最深),不是凭空加数值。[提案] [机制事实:第三幕 Stage 8 = 最终 Boss]
- **打赢 = 疏浚,不是斩杀。** 见第 6 节。签名机制的设计要经得起「同一位主人下一轮涨潮后重新成形、再打一次」而不穿帮。[已定]

### 三个样板(最佳实践,可直接作范本)

**样板一 · 塞壬长姊 — 乡愁叠层** [提案:专名与形态]
执 = 所有听过她歌的人的乡愁,她自己也困在「永远唱别人的家、自己回不去」的循环里。签名机制 = **乡愁叠层**:她的歌给每个听见的单位叠一层乡愁,叠满的单位丢下阵位、朝歌声自行走去;堵耳可免代价是听不见同伴的指令与呼救。阶段 = 歌声随血量换调、叠速加快;召唤 = 被歌声先留住的听众(随潮溺众)。范本价值:**把「执」做成一个会累积的状态,逼玩家在阵型与信息之间取舍**。[提案]

**样板二 · 波吕斐摩斯 — 循声** [提案]
执 = 被夺去独眼后只剩听觉,循着声音找那个害他的人,却永远抓错。签名机制 = **听觉定位**:他瞎,不打最近的、打最响的一格;攻击、技能、移动都会累积噪音,谁吵谁先挨投石,羊群可作掩护降噪。阶段 = 越受伤越暴怒、听域越广;召唤 = 惊散的羊群制造噪音诱敌。范本价值:**把「执」做成一条改写目标选择规则的机制,行为极度可读**(吵的先死),纯凭观察就能推演。[提案]

**样板三 · 沉舰统帅 — 重演沉船夜** [提案:专名;原型 = 归航途中被海处死的联军将官,取 Ajax the Lesser 小埃阿斯一路,狂言逃过海难而被海处死]
执 = 他死在归航途中,永远在重演那一夜、永远沉不下去也回不了家。签名机制 = **脚本化环境灾难**:他每回合把「沉船那一夜」推进一步(某列进水、桅倒砸某行、浪打翻某格),步骤固定、进房可预告可读,你在他反复重演的这一夜里抢位活命。阶段 = 剧本推进到「船倾 / 桅折 / 沉没」不同幕;召唤 = 一次次爬回甲板的溺水船员。范本价值:**把「执」做成一套可预测的场地脚本,把 Boss 战变成走位解谜**。[提案]

三个样板刻意各走一条机制路子——**累积状态 / 目标选择规则 / 场地脚本**——用以证明这条公式能长出彼此不重样的打法,而不是同一个 Boss 换皮。[提案]

## 2. 守门 Boss 池 名录

体例:每条先一句**认执**(这片水的执),再一句**如何遭遇**(船与它照面的方式);全部人间层、英雄可击量级。[提案] 大名允许与 Plan-1 重合(承基石 §11;2026-07-24 用户裁决)。[已定]

- **塞壬长姊 [提案]** — 塞壬浅滩。执 = 困在「永远唱着别人的家、自己却回不去」的循环里(见 §1 样板一)。遭遇:雾里传来唱着你自己家乡的歌,循声而去的人一个接一个丢下船桨。
- **波吕斐摩斯 [提案]** — 独眼牧岸。执 = 被夺去独眼后只剩听觉,循着声音找那个害他的人、却永远抓错(见 §1 样板二)。遭遇:牧岸上那只瞎眼巨人不看你、只朝最吵的地方砸石头,羊群是他的耳朵也是你的掩体。
- **沉舰统帅 [提案]** — 沉舰风暴眼。执 = 死在归航途中,永远在重演那一夜、沉不下去也回不了家(见 §1 样板三)。遭遇:风暴眼里泊着一条永远在下沉的旗舰,登舷的人被卷进他一夜夜重演的沉船里。
- **食莲之主 [提案:或描述性「忘归者之首」]** — 食莲林湾。执 = 他是最早忘归的那一个,忘了家在哪儿、也就把「回家」这件事一并放下了。遭遇:湾里飘着让人忘记家在哪儿的花香,吃过的船员坐在岸上再不肯起身。
- **喀耳刻 [提案]** — 变形之岛。执 = 独困此岛、见不得别人能走,把每个上岸的人改写成走不了的形状,好让这座岛不只有她一个回不去的人。遭遇:岛上一场过分殷勤的盛宴,伺候的猪与狼眼神太像人;女主人以法术把每个上岸的人改写成此地的形状。量级注:她是太阳神之女、近小神一档,但神话里英雄确实凭一味解药(moly)与之周旋并迫其就范——落在英雄制得住的一侧,不越量级红线。
- **斯库拉与卡律布狄斯 [提案,一对]** — 峡流双怪。主人的执落在斯库拉身上:她本是被喀耳刻的妒毒改写躯体的美丽仙女,名字还在、身体全非,回不去仙女之身,只能靠吞过往的船确认自己还在。卡律布狄斯不是无缘由的自然灾害,是同一片水的另一张嘴——一口永远吞、永远填不满的饥,把整条归途都吞进那个填不满的洞里。遭遇:海峡窄得只容一船,一侧崖穴垂下六头噬人、一侧漩涡张口吞船,过与不过都要付一份人命。
- **埃俄罗斯 [提案]** — 风袋群屿。执 = 守着「最后一口顺风」不肯轻易给出,离家只差这一口气的执念,偏要栽在同伴自己的疑心上。遭遇:守着一袋封着所有逆风的浮岛之王,离家只差一口顺风时,同伴的疑心会亲手解开那只袋子。
- **美杜莎 [提案]** — 石像礁。执 = 受诅咒变成谁也不敢直视的样子、回不去被诅咒前的自己,便把每个来客都钉成和她一样再不会变化的像。遭遇:礁上挤满历代挑战者的石像、朝向层层向内,最深处那道身影一抬眼就把活物钉成不再变化的像。
- **弥诺陶洛斯 [提案]** — 迷宫外海。执 = 生在迷宫、从没有一个家可回,守着一座连他自己也走不出去的迷宫——是唯一一个从没离开过自己关卡的守门者。遭遇:一座漂在海上的迷宫,吼声从正中心传来。
- **太阳的牧女 [提案:非赫利俄斯本尊,取守群的牧女 Phaethusa 与 Lampetie]** — 蚀阳牧场。执 = 替远方的主人看着一群永不能碰的金牛、自己也被这份看守钉在岸上回不了家——守物的人,同时是被守困的人。遭遇:金牛群在日光下反光刺眼,动了牛群的人会引来看守它们的牧女,而天上那位主人只在传闻里。
- **未渡之魂 [提案:描述性称谓]** — 冥河河口。执 = 一船攒了太久、没登册也就渡不过去的执,始终交不出可以「回家」的凭证。遭遇:河口摆渡人不肯收没登册的魂;这类主人多半落在临岸的水,但依名录轮换、不必永远钉死在最后一片。

> **候选池纪律(本作自订):** 以上是**候选池**、不是排班表。一次航程的图房只落墨三片水(=三幕),从这池里抽;最终启用几位、如何抽,须抵住「三片水全塞大名」的密度冲动——名录会轮换(见第 6 节),不必也不应把每一位都塞满。[提案] 具体抽取机理(为何本汛恰好这三片、难度递增)承基石 §6「图房落墨」的账簿式落墨 / 折处必淤 / 可航缝淤口上限,详见 mythic-structure-and-acts。[提案]

## 3. 精英 deep-cut 池

比守关冷门一档的人间层存在,做精英(对应 Greater Elite / Elite Chief);优先取归乡母题里较少被讲的 deep-cut,给航程添纹理。体例同上,一句「如何遭遇」,能带一句执更好。[提案]

- **埃尔珀诺耳 [提案]** — 醉死、尸身没被好好安葬的溺途乘员魂,拦在路上只求一件事:先替他把该下的葬礼补上。deep-cut 值在「归乡母题最小、最私人的一个」:他要回的不是家,是一抔土。
- **拉埃斯特律戈涅斯 [提案]** — 港湾两岸投巨石砸沉船队的食人巨族,归途上一次折损最惨的伏击就出自他们的港。
- **塞壬幼妹 [提案]** — 长姊起调之前,先在浅滩外围唱起和声的姐妹们,是通往长姊的**前置纵深**:大名守关前先遇其血亲或前哨、层层递进,把一位守关的份量摊成一段航程。
- **疑心的同伴 [提案:原型欧律罗科斯一路]** — 一个生前因疑心解开风袋 / 劝众吃下禁忌之牛、亲手断送归途的老同伴的执,穿着船员的形状回来挡路。
- **食莲的部民 [提案]** — 食莲林湾里更早忘归、已经忘了自己是谁的普通人,成群坐在通往主人的路上,谁碰他们谁也沾上一点「不想走了」。

> deep-cut 的选取继续守新鲜度纪律:最大的名字留给守关,精英尽量取冷门。上列均 [提案],出处与更多候选待扩充轮补。[提案] 具体条目、是否成排编排,属关卡轮取舍。[待定]

## 4. 随潮的溺众:高频杂兵的神话身份

最常出现的普通敌人不能只有 Boss 可读。基石(§9)已给定其身份 = **随潮的溺众**(这片水的执下没回成家的人),本节把它落成一眼可读的通用说法。[提案]

- **一眼可读的通用称谓(择一,均 [提案]):** 「随潮的溺众」(基石术语,泛指)/「没归的人」/「留海的人」/「溺途者」。定位一句话讲完:**他们是没回成家的人,穿着这片水的执的形状成群漂来。** 玩家不需要读设定,水域的母题本身就告诉他这些杂兵生前是谁。[提案]
- **随水域换皮(同一层杂兵,母题决定长相):** 塞壬浅滩 = 被歌声留住的听众;独眼牧岸 = 迷途的牧群与船员;沉舰风暴眼 = 一次次爬回甲板的溺水水手;食莲林湾 = 忘了要走的忘归者。皮换,内核不换——他们都是主人之执的延伸,是那位主人召唤 / 波次的来源。[提案]
- 机制侧对应 Normal / Lesser Elite 层,叙事零耦合职业 kit;杂兵身份只承诺色彩,不锁数值与词条。[对齐机制事实]

## 5. 远方的神:在场,不下场

量级防火墙。奥林匹斯在很远的地方,港口给波塞冬留着祭坛,没人见过他、也不会见到。神是天气的姓氏、诅咒的语气词、出航前泼进海里的那杯酒。**他们不下场。** [已定]

**「在场而不登场」的四种写法(生产时照此给神一个位置,又不让他上战场):** [提案]

1. **署名不现身。** 一场风暴可以叫「波塞冬的脾气」,但玩家打的是风暴 / 词条 / 场地,不是神本人。神只是灾祸的落款。
2. **来历标签。** 守关的执可以「因某神而起」——波吕斐摩斯是波塞冬之子、美杜莎受雅典娜诅咒、沉舰统帅被海处死——这给敌人一个广为人知的来历(服务零介绍可读性),但登场的永远是那个人间层的主人,不是神。
3. **传闻层。** 老水手、港口住民会谈起某位神的旧怒,当作解释这片海为何这样的背景音;传闻越多、神越大,越是只闻其名。
4. **祭坛与酒。** 港口有仪式、有祭坛、有泼进海里的酒;神受祭,但从不回应、从不显形。信仰是港城的一部分,神本身不是。

**硬规则:** 任何主神 / 创世级 / 宇宙级不作战斗内容,机制侧也无宇宙级 apex tier,「传奇」只是 tier 名、不要求 Boss 是神祇。[已定][对齐机制事实] 神的名字只用来给敌人贴来历标签、给海况署名,战斗天花板死守英雄能杀的东西。[已定]

## 6. 疏浚非斩杀:复战条款与名录轮换

**复战条款(第一条通用约束,承基石 §7,世界规则化):** 你在水域深处「打赢」主人,不是把他杀死,是把他这一程淤起来的执**打散**——清掉暗流、让这片水暂时通航。这叫**疏浚**。执有潮汐(基石推论 3),被打散的念想会随下一次涨潮重新回聚、主人随之重新成形。**「这片海上没有斩杀,只有疏浚。」** [已定]

- **同一主人、不同强度(潮汐涨退):** 执有涨退。同一片浅滩,这一程涨潮抵在岸口、是凶险的最后一片水(第三幕);另一程退回外海、只是顺路的头一片(第一幕)——同一位主人在不同航程里以不同强度出现,合情合理。[已定]
- **跨轮重现(疏浚后涨满):** 一轮团灭 / 送达后重开,图房重新落墨,被疏浚过的主人随新一轮涨潮重现。你每次面对的不是复活的尸体,是又一次涨满的同一片执。[已定]

**长账(反派侧的跨轮进展,解西西弗感):** 疏浚不是白费。每一汛的疏浚都在真正磨掉那份执的分量——一汛一汛地磨,若终有一次你把某位水域主人**真正送回了家**(彻底了结他的执:让这片水本是的那个人抵达他自己的海岸),这片水便永久消散,主人从**名录**里退出。[已定]

- **名录 = 本文第 2 节的守关池。** 长账落到本文的直接后果 = **名录轮换**:某位主人被送回家 → 退出候选池 → 幕池腾出一个口子 → 一片新的执涨成新主人补上(基石「每次大的失乡,海上就多一片新水域」)。反派侧因此有真实的、极慢的跨轮终点,不是永劫无功地被杀了又杀。[已定]
- **★桥接(避免下游误读为 Boss 跨轮变弱):** 长账是**纯叙事层的 meta 进展,不改 Boss 战力**。机制侧 Act Boss 每轮满状态重置(机制事实),不存在「同一 Boss 一轮比一轮弱」的数值物;「一汛一汛磨掉执的分量」磨的是叙事账本上这位主人离归途的远近,不是他下一次涨潮重现时的战力。他重新成形时依旧满状态,却比上一汛更近归途一步。[已定][对齐机制事实]
- **远景归乡在敌人侧的落点:** 名录不是无底的。当足够多的水域主人被真正送回家、名录一位位腾空,终有一次落墨,图房会在熟悉的水之间画出一段**没有名字的海岸线**——那不是又一片执涨成的水域,是船自己的归途头一回浮现(承基石 §10 远景归乡)。它不重新引入宇宙级、不设「通关」结算屏,只是名录轮换到极处时、墨线里多出的一道人尺度的地平线。[提案]
