## 1. 乘员是随船之魂

### 1.1 与悖论之船的关系

乘员不是「搭上船的人」，而是**船的一部分**。

基石已确立：船不是任何存在造出来的物理船只，而是「替换仍存续」这一悖论的**显形**（悖论体）。它的船板、金属、法则都是跨世界替换来的**替换件**——而乘员，是这艘船身上**能动的那一类替换件**。木板是被动的替换件，随船之魂是**能动的替换件**：同一个「替换仍存续」悖论分出的、带着意志与记忆的**一缕缕**。`[已定，依据基石 §7]`

因此乘员与船的关系不是「乘客与载具」，而是「部分与整体」——和船板与船的关系是同一回事：**部分不断被替换，整体（悖论）仍存续**。船在，他们在；船殒，他们随之被打散、随船一同重铸。他们没有独立于船之外的存在。

船板与缕的分工也由此清楚：**船板承担「在」，缕承担「做」**。悖论要在破碎的世界里行动、抉择、战斗，就得有会自己拿主意的部分——缕就是船伸出去的那些手。

落在画面上，「缕」不必是半透明的幽魂。一缕随船之魂看上去就是一个人：有重量、有呼吸，握兵刃的手会出汗。只在两种时刻露出底色。其一，跨过世界边界时，他们与船板一同被替换染色——衣饰纹样、兵刃形制、举手投足悄悄换上这个神话的样式，和船一样「多带一身那个世界的口音」（基石 §2.2；对应 §1.3 表中「缕在世界间被替换染色」）。其二，船殒时，他们不是各自倒毙，而是随整船一同散开，与木料铁钉一起归于残骸，等下一次重凝时随新船一同被重铸成形。平日里，缕与船的关系更像手指与手：手指自己动、自己拿主意，却从不需要确认自己属于这只手。

### 1.2 为何是随船之魂，而非普通船员

把乘员定为「随船之魂」而非凡人船员，是基石三条根本设定推出来的必然结果，不是风格选择：

- **本体论层面**：船常居**世界夹缝**、沿本体论边界滑行。凡人隶属于某个世界的本体论，无法跨进另一个世界。**只有和船一样「不属于任何地方」的存在，才能随船穿梭**——随船之魂正是这种「不专属任何单一世界」的存在，所以能跟着船跨界。普通船员在第一道边界就会被留下。
- **循环层面**：`永久死亡 = 船殒于夹缝、整体解体`（基石 §5）。普通船员会随之**真正死亡**，无法承载「重开仍是同一支队伍」；而随船之魂能在残骸间随悖论的重凝**一同被重铸**。随船之魂因此是 Roguelite「重铸重开」在叙事上的**载体**——他们能被打散、又重新成形。
- **母题层面**：忒修斯命题**原设想「也落在乘员身上」**（基石 §6，该层现暂缓 `[待定，暂不做]`）——届时乘员就必须是**会被替换、会失真、仍算同一支队伍**的东西。凡人不会「被替换仍是自己」，只有与船同构的随船之魂才承得住这个追问；随船之魂这一本质为将来启用该层预留了承载者。

由此还引出乘员的**身份内容从何而来**：船并非「招募」了外人，而是把**某位历史 / 传说英杰的身份投影**固定为本轮某个职业的代号（详见 §2）——乘员因此是**船自身的一部分**，其「名字与面孔」是被固定进来的一段英杰身影，而非一个记不清出身的凡人。至于「这缕魂更深一层究竟从何而来」，仍是身份母题下**可被追问、也可能永远无解**的开放项（候选见下）。

> **来历的候选框架** `[提案]`（未锁定，供后续叙事轮取舍，两者可并存）：
> - **候选 A — 悖论自分**：悖论重凝为船时，一并凝出「能动之缕」，用以在夹缝中行动、抉择、战斗。乘员是船为了「能动」而分出的自己。
> - **候选 B — 替换留痕**：船跨世界替换时，被替换掉的材料 / 存在留下印记，这些印记取了「魂」的形，随船而行。乘员是历次替换沉淀出的回声。
>
> 两条都不改「随船之魂」这一 `[已定]` 本质，只是解释其**由来**；建议保留模糊，因为「说不清自己从哪来」本身就服务于失真母题。

### 1.3 与战棋多单位的对应——每个单位一缕随船之魂

基石已把宏观映射钉死：船 = 一轮航程的载具，乘员单位 = 战棋棋子，船殒 = 航程结束。中观一层的映射如下：

- **一个棋盘单位 = 一缕随船之魂**。多个单位同场，就是同一个悖论**分布在多个格子上**、以多缕能动之魂的形态同时行动。「多单位战棋」在叙事上不是「一群人组队」，而是**一个悖论体的多点显形**。
- 一支队伍（本轮航程的乘员组合）= 这一次重凝时，悖论**恰好凝出的那一组缕**。换一轮航程，凝出的缕可能不同——这正是每轮阵容变化的叙事解释。
- 职业只为每一缕做**战斗染色**（手感 / 职业定位），不进世界观因果（基石 `[已定]`）。同一缕随船之魂「是什么职业」不改变它「是随船之魂」这一叙事身份。

| 叙事 | 玩法 |
|---|---|
| 悖论体 | 一轮航程的载具 |
| 一缕随船之魂 | 棋盘上的一个单位（棋子） |
| 本轮凝出的一组缕 | 本轮队伍 / 阵容 |
| 缕在世界间被替换染色 | 单位随幕（神话）变化的构筑上的染色差异 |
| 船殒、众缕被打散重铸 | 永久死亡、队伍重置 |

### 1.4 单位阵亡与船殒的区分

> 状态：`[提案]`

基石只锁定了「船殒 = 航程结束」。战棋战斗中**单个单位可能中途阵亡**，它的叙事落点基石没有定，此处留一个候选，交战斗 / 机制轮定：

- **候选**：一缕随船之魂的战斗形态在一场战斗中**被打散**（对应单位被击倒），这与「整船殒于夹缝」不是一回事——前者只是其中一缕暂时散开，后者才是整体解体、航程终结。散开的那一缕能否在本轮内重新凝出、代价几何，属**机制轮**范畴，本文不预定。
- 该区分的作用：让「单位阵亡」与「一轮航程结束」在叙事上不混为一谈，避免每次单位被击倒都读成「一次永久死亡」，从而与「代价非惩罚」调性一致（见第 3 节）。

## 2. 乘员 = 职业 + 英杰代号

> **当前口径（2026-07 用户裁决）** `[已定]`：乘员**每职业配一个固定英杰名**（剑圣 ＝ 裴旻 `[提案]`）。**名字轮换、以及「乘员版忒修斯 / 身份失真」暂不做**。忒修斯目前落在**船板层**（船板替换 / 概念投影）与 **航程循环**（船殒重凝、定位成功 → 流放）两层，**暂不落到乘员的名字上**；未来若做名字轮换，再让忒修斯落到乘员层。**`[已定]` 主干**：名字纯代号、不碰技能组、职业与故事彻底解耦。

### 2.1 模型：职业 + 英杰代号

一名乘员 ＝ **玩家选择的职业** ＋ 一位**以这门本事闻名的历史 / 传说英杰**充当它的**名字 / 代号**。职业是玩家实际操作的战斗单位（技能组、职业定位、手感）；英杰是套在这个职业上的**叙事皮肤**——名字、面孔、出身传说，取自各世界 / 时间线上的名人。当前**每职业固定配一个**这样的英杰名（剑圣 ＝ 裴旻 `[提案]`，见 §2.5），**暂不随轮换**。

「船固定一位英杰」＝ 把这位历史英杰的身份投影**固定为该职业的代号**（即 §1「随船之魂」在乘员层的具体内容）。「固定」这个词由此**统一了世界与英杰**：船固定小世界，也固定英杰。

### 2.2 名字纯代号：职业与故事彻底解耦

**英杰名只是代号，不影响职业本身的机制 / 技能组。** 这把基石 `[已定]` 的「职业与故事解耦」推到彻底：换名字，职业一点不变。

- 示例（`[提案]`）：选「剑圣」→ 代号固定为**「裴旻」**；无论剧情怎么走，职业（剑圣的技能组）都不因这个名字而变。
- 关于「同一职阶可换不同名人」（类比 Fate）——**这条『名字层换人』暂缓**（见 §2.4）；未来若做，也只借「一个位子可由不同名人担任」这一点，**不借技能组 / 能力、不照搬七职阶体系**。本作的职业表自成一套。`[待定，暂不做]`

### 2.3 忒修斯落在乘员——暂缓

> **本条暂缓。** 「乘员版忒修斯」靠**名字轮换**才成立，而轮换现在不做（见 §2.4），所以这层暂不启用。**忒修斯目前落在两处**：**船板层**（船板逐块替换、概念之船的投影）与 **航程循环**（船殒重凝、定位成功 → 被流放 → 再循环）——**暂不落到乘员的名字上**。未来若做名字轮换，再把下面这套落到乘员层。

以下为**未来轮换启用时**的设想口径（`[待定，暂不做]`）：

- **连续侧 ＝ 职业 / 角色位**：「剑圣」这个角色位一直在，每轮都有一个剑圣。
- **不连续侧 ＝ 轮换的英杰**：坐这个位的人换了又换（裴旻 → 武藏 → …），没有一个留下来。
- 「**位还是那个位、人已不是那个人，还算同一个剑圣吗？**」——这一问与船板层「换光了还是不是同一艘船」是同一个问题，是忒修斯在乘员身上的现身。

无论将来做不做这条，都**不改基石 §7『职业技能组不进世界观因果链、只作战斗染色』**：真被拿来当叙事锚的，只是「这个角色位一直有人坐」这一结构性事实，而非某套技能组的具体内容。

### 2.4 名字轮换——暂不做，每职业一个固定名

**当前不做名字轮换。** 每个职业**配一个固定的英杰名**（剑圣 ＝ 裴旻 `[提案]`），整轮、跨轮都是这个名字；**「每轮换一位英杰 / 从名池随机挑名」暂缓**，未来再定。`[待定，暂不做]`

- 现在**不做**：逐轮换人、随机挑名、名字用过即消耗、名池权重——这些都留到未来「若做名字轮换」时再议。
- **生效的只有解耦主干** `[已定]`：名字纯代号、不影响技能组、职业与故事彻底解耦（§2.2）。
- **未来若启用轮换**（`[待定，暂不做]`）：小世界本就把各故事分隔开（见 `mythic-multiverse-and-acts.md` §3.3），乘员不背跨幕 / 跨轮的连续叙事线，换名不欠前情、不留后债，正合 Roguelite 的分段节奏——这等于给「日后做轮换」先留好了位置，真要做也花不了多少工夫，但当前不启用。

## 3. 调性平衡——换人是代价而非惩罚，未来轮换预留

> **本节整体是「未来做名字轮换时」的预留调性** `[待定，暂不做]`。既然当前不做换人（§2.4），下面这套「换人 ＝ 代价非惩罚」暂不作为已生效机制。但**底层调性原则**（失真是代价非惩罚、重开非坠入虚无、玩家始终握有主动权）**承自基石 §6、一直有效**——它此刻落在船板层与航程循环上，未来若做轮换，再落到乘员层。

基石 §6 的调性原则：失真是「代价」不是「惩罚」；重开是又一次重铸、不是坠入虚无；玩家始终握有再起航的力量与意义（向 Hades 看齐、避开 SOMA 式纯身份恐怖 / 虚无）。以下把这条调性**预先**落到「换人」这一未来机制上（当前不生效）。

### 3.1 三条不可越的底线

> 状态：`[待定，暂不做；底线原则承基石 §6]`

- 换人是漂流的**重量**，不是对玩家的**处罚**——不做成「你玩得差就罚你换个更弱的英杰」这种把表现和惩罚绑在一起的做法；换的是名字与身影，**职业强度不因换名而波动**。
- 重开是**又一次固定 / 重铸**、不是**清算**——不把「上一位英杰没了」渲染成恐怖或虚无。
- 玩家**始终握有主动权**——永远还能再起航、再选职业、再遇一位新英杰，不陷入「只能眼看流失、无从抵抗」的无力。

### 3.2 换人为何不是惩罚，而是母题的又一次演出

（以下设想 `[待定，暂不做]`：）未来若做轮换，上一轮那位英杰这一轮就换成了另一位，乍看像失去；但在本作里，它会是**忒修斯母题在乘员层的又一次演出**：位还在、人已换，「还算同一个剑圣吗」这一问，每换一次人就被重新提起一次。**失去某一位英杰 ≠ 失去那个职业、那个位**——正如换光船板并不威胁「同一艘船」。把换人读成母题的一再演出、而不是惩罚性的「又死一个」，是这层调性的关键。

### 3.3 与五层架构 L2 / L3 的对应

「职业 + 英杰代号」模型给基石 §9 问题②「哪些随重铸清零、哪些跨轮沉淀」一个答案：

- **连续侧 ＝ 职业 / 角色位** 对应 **L3（跨轮沉淀）** 与元层——「剑圣这个角色位」跨轮一直在，是替换不掉的那条线。`[待定，暂不做；承接基石]`
- **不连续侧 ＝ 本轮这位英杰** 对应 **L2（每轮清零）**——这一道英杰投影只属于这一轮，随重铸 / 换人散去。`[待定，暂不做；承接基石]`

即：**职业沉淀、英杰轮换**，本身就是身份母题的机制表达。

### 3.4 张力校准——珍视而非恐惧

- **位在、人换**：正因每位英杰只属于这一轮、不会回来，本轮与他共战的那一程才**有分量**、值得珍视。
- **向 Hades 看齐、避开 SOMA**：Hades 让你在重复里攒起意义（此处 ＝ 攒起「这个职业一路走来坐过的一串名字」），SOMA 让身份消解成为恐怖——本作要前者：换人是「又一位英杰接过这个位」，不是「我正在一点点消失」。

## 4. 玩家视角的乘员——「有事要做的人们」

**状态：`[待定]`。** 本作**不设传统意义上的「英雄主角」**。玩家的视角落在乘员身上，而乘员是**「有事要做的人们」——可能是固定的某一个，也可能是每轮各不相同的一类**：被一桩任务、一份使命推着走的人，那使命就是船的使命（固定小世界、定位、抵达理、重启世界）。他们上路，不是因为「天选英雄的宿命」，而是因为**有该做的事**。

至于「玩家视角的乘员」到底是**某个固定角色**，还是**某一类人（每轮不同）**，**由用户裁决**，且依赖尚未锁定的待定问题（元弧、L1 / L3 映射），保持 `[待定]`。本节只给**可选框架**与决策张力，不指名任何具体角色、不硬造专有名字。

> **承 §2**：「每轮不同的人们」这一侧母题上最自然（框架 A）；但**名字轮换本身暂不做**（§2.4），当前每职业是一个固定英杰名（剑圣 ＝ 裴旻 `[提案]`）。所以本节的框架取舍留待裁决——尤其**要不要在乘员之上再叠一个跨轮恒定的锚**（框架 B / C），以及这个锚与元弧的关系。要分清：「职业 + 英杰代号」模型里「职业 / 角色位」本就是**跨轮连续侧**，但那只是**结构性延续**（位一直在），跟「框架 B / C 里说的那个**恒定核心角色**（一位恒定的**具体英杰 / 魂**）」不是一回事。

### 4.1 三条候选框架

- **框架 A — 不设恒定核心，每轮不同的人们**：每一轮航程，悖论恰好凝出的**一组缕**（各自配上其职业的英杰名）就是本轮乘员；轮与轮之间没有恒定的核心角色。最贴合失真与重铸母题（先于命名、无恒定身份），也最合 Roguelite 这类游戏的路子。**代价**：玩家没有可长期依附的对象，情感主线更难立起来，元弧缺少稳定主体。
- **框架 B — 一个恒定核心 + 浮动乘员**：设一个**很小的恒定核心**（比如一缕「最抗失真的锚定之魂」`[提案，描述性称谓，非专名]`，或干脆让**船本身**当这个核心），跨轮存续；其余乘员照常每轮轮换。**兼得**情感连续性与元弧载体，同时轮换的那部分乘员照常换人。**代价**：「有一个替换不掉的核心」与「替换一切仍是自己」的纯粹母题略有张力，得拿捏这个核心到底能不能被换掉、被触及。
- **框架 C — 船即核心，没有人类核心角色**：真正被玩家认同的是**悖论体（船）本身**，乘员都是可互换的缕。玩家依附的对象是「船 / 悖论」，而不是任何一个人。最贴合「先于命名的存在」，元弧由**船的弧线**承载。**代价**：要让玩家依附「一种存在方式」而非「一个人」，情感门槛更高，需要很强的呈现手段。

**玩家实际读到什么——三条框架的质感示意**（整节仍在 `[待定]` 伞下，以下只演示「选了之后读起来像什么」，不预定取舍）：

- **若走框架 A**：每轮起航，画面落在甲板上刚凝成形的这一组乘员身上。他们睁眼的第一件事不是自我介绍，而是接到「该做的事」——一句话钉在起航处，比如「西边那片世界的河流忘了自己该往哪儿流，去把它钉回去」。任务先于身世抵达：没有人追问「我是谁、我为何在此」，对话围绕眼前的事展开，像一支已经开工的巡夜队，而不是一群等待铺垫的主角。轮与轮之间没有人回头，上一轮的抉择与告别不被任何人提起；玩家的依附感落在「事」与这艘船的氛围上，而非某一个人身上。
- **若走框架 B**：起航时，先开口的是那个恒定核心——全船只有它记得这是第几次起航。它把「该做的事」交到这一轮乘员手里，同样只是一句话，不解释来历。玩家读到的是双层文本：乘员层每轮新鲜、轻盈应答；核心层跨轮累积，偶尔漏出半句「上一次……」又自己收住。元弧的进度就藏在核心的记忆里缓慢前移，重逢感由它一人承担。
- **若走框架 C**：没有开场白，也没有说话人。玩家读到的是船本身的「表述」——航程日志式的旁白、船板纹理里浮出的字迹，或干脆是界面本身作为船的意识。「该做的事」不是谁交代的，它像风向一样自然成立：船朝那片失稳的世界偏转，乘员便上路。乘员之间尽可以有对话，但没有谁是叙事的主人；玩家最终牵挂的，是「这艘船又一次起航」这件事本身。

**三框架对照**（定性不定量；三轴 ＝ 叙事依附感 / 母题纯度 / 呈现成本）：

| 框架 | 叙事依附感 | 母题纯度 | 呈现成本 |
|---|---|---|---|
| A 每轮不同的人们 | 弱——依附落在「事」与整体氛围上，难聚焦到具体的人 | 高——无恒定身份，失真与重铸不打折 | 低——每轮独立短文本，不欠前情、不背长线 |
| B 恒定核心 + 浮动乘员 | 强——有一个跨轮记得的人，情感与元弧都有主体 | 中——「替换不掉的核心」与母题有张力，须拿捏 | 中——须写并长期维护一条跨轮渐进的核心文本线 |
| C 船即核心 | 中——依附对象上移到船，成立但门槛高 | 高——「先于命名的存在」直接站上叙事中心 | 高——要让玩家爱上「一种存在方式」，呈现手段要求最高 |

**取舍由用户裁决**：三条框架如何取舍（含是否组合、何时定）由用户裁决，本节全部内容仅供决策参考，均不预定结论。

### 4.2 决策张力

这几个框架卡在三方拉扯之间，用户裁决时可据此权衡：

- **Roguelite 的多样性**（轮换阵容、每轮新鲜）↔ **叙事依附**（需要一个稳定的情感锚）↔ **母题纯度**（失真本就反对任何恒定身份）。
- 框架 A 偏母题纯度与多样性、依附感弱；框架 C 偏母题纯度、把依附对象上移到「船」；框架 B 是折中，用一个小核心换情感连续性。

### 4.3 与未定问题的依赖

「玩家视角的乘员」这条**不宜孤立拍板**，它与两条 `[待定]` 问题相互决定：

- **元弧收束**（基石 §9 问题①）：元弧需要一个**主体**去「抵达终点」。若走框架 C，主体是船；若走 B，可以是那缕锚定之魂或船；若走 A，元弧就只能挂在「船 / 悖论」这一层，而非某个人。**先定这条、还是先定元弧，二者要一并考虑。**
- **L1 全局映射**（基石 §9 问题②遗留项）：若存在跨轮恒定的核心 / 城镇元层，它与框架 B / C 天然亲近。

### 4.4 命名与职业纪律

无论选哪条：

- 任何恒定核心角色的**专有名字由用户裁决**，本文一律不定；需要时走 `[提案]`。文中「锚定之魂」等一律是描述性称谓，非专有名字。
- **恒定核心**指的是**跨轮存续的魂之身份 / 主体**，**不是**固定职业——职业技能组与故事解耦（基石 `[已定]`）。一个恒定核心仍可在不同轮里换上不同的战斗染色。
