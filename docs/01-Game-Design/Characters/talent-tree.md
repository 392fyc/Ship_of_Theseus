# 06 - 天赋树系统(Talent Tree System)

> 返回 [总览](../game-design-doc.md)

## 概览

天赋决定角色在**这一程**里的发展方向与转职(Class Advancement)选择。天赋点**每 run 清零**(与 [[../Progression/run-loop|run-loop]]、[[../Narrative/Plan-2/layers-and-principles|Plan-2 分层]] 一致)。跨局沉淀属于 L1 Meta 层,不属于本文。

### 天赋的组织形态 —— 卡池

**真源 = 设计库天赋实体**（当前快照入口为设计库仓 `snapshots/talents.json`）。

- **扁平卡池**：卡片之间没有坐标关系，也没有必经中间节点。
- **稀有度分档**：普通 / 稀有 / 史诗 / 传奇 / 独特；这是字段值域，不在 KB 固定各档数量。
- **解锁条件是独立字段**：出现与解锁条件由 `unlock_trigger` 承载，与战斗内生效时机 `trigger` 分开，不靠路径拓扑表达。
- **职业归属**：由 `class_id` 指向对应职业。
- **当前卡池范围**：只有 `shelf_state=已上架` 的实体进入当前卡池。
- **卡片升级**：`levels_json` 承载卡自身的等级覆写，与角色等级分开。

需要数量、名称或直接字段时，从设计库当前接口或快照读取，不在本文保存会随活数据变化的统计值。

## 等级与转职节奏

**转职在 Lv5**，且转职本身不消耗天赋点。

每级发放多少天赋点、Lv1 与 Lv5 的选择是否消耗点数，以及单局总供给，仍须在实际系统完备后通过测试裁决；当前没有可执行的固定点数表。

### 关卡与等级的对应

- 当前关卡结构为 3 Acts × 8 Stages，共 24 关。
- 预期终局等级约为 Lv25-30。
- 单局天赋点总量取决于尚未裁决的点数节奏。

## 转职模型

**真源 = 设计库 `/api/classes`** 的 `promotes_from` / `tier` 字段。

| 职业 | id | 档位 tier | promotes_from |
|------|-----|---------|---------------|
| 剑士(Myrmidon) | `myrmidon` | 下位 | 无(线起点) |
| 剑圣(Kensei) | `kensei` | 上位 | `myrmidon` |
| 剑仙(Sword Immortal) | `sword_immortal` | 上位 | `myrmidon` |

- 剑士与剑圣 / 剑仙是**同一角色转职前后的两态**,不是三个独立角色。剑士 Lv1-4,Lv5 转职后成为剑圣或剑仙。
- 转职是**等级事件**,不是一个天赋卡;转职一旦选定不可更改。
- 属性档位以设计库 `stat_tiers` 为准,换算标尺见 R2.3(C=40% / B=50% / A=60% / S=75%,「无」= 0)。
- 转职会**换成长率表**——[[class-system|职业系统]] 明写「stat_growth 可在转职后改变(进阶职业有自己的成长率)」。故引擎侧一条线上有两套 `growth_rates` 属正常,不是重复。
- 引擎侧现状:尚未实装转职,测试场景直接生成剑圣单位,因此 `data/classes/kensei.json` 的 `base_stats` 在玩家路径上其实不该存在,归属应是 `myrmidon`。详见该两个文件的 `_note`。

## 计量槽系统(Gauge System)

每个转职方向都有独立的计量槽(Gauge)机制。**它们不由天赋给出**,获得时机按职业各自的规则:

- **剑气**:剑士线自带,从 Lv1 就持有——R1.6 规定剑气由剑士 / 剑圣 / 剑仙三职业共享。
- **剑意印记**:随 Lv5 转职获得——R2.4 规定印记是剑圣转职专属,不下沉剑士。
- **其余职业的计量槽**(专注 / 自然共鸣 / 法师元素槽):获得时机尚无记载。

### 计量槽总览

| 转职职业 | 计量槽名称 | 类型 | 核心机制 | 设计关键词 |
|---------|--------|------|---------|-----------|
| 剑圣(Kensei) | 剑气(续航)+ 剑意印记(心/道/势) | 剑气 0-100 + 印记 0-3 | 斩击/居合产气产印记 → 拔刀按构成倾泻结算 → 印记池构筑 | 攒印记 vs 倾泻时机 |
| 剑仙(Sword Immortal) | 剑气(Sword Essence) | 类 MP(自然回复 / 稳定消耗) | 维持飞剑技能与剑阵 | 走位控制 + 混合伤害 |
| 狙击手(Sniper) | 专注(Focus) | 能量值(0-100) | 原地不动积累 → 移动/受伤中断 | 站位选择 = 资源管理 |
| 精灵射手(Elven Archer) | 自然共鸣(Nature Resonance) | 层数(0-5) | 闪避/附魔/近战积累 → 附魔 100% 触发 | 近战参与 = 层数来源 |
| 法师(Mage,按元素) | 狱火 / 冰霜 / 疾风(Hellfire / Frost / Gale) | 能量值(0-100) | 元素技能积累 → 元素专属强化 | 见 mage-talent-tree-design-brief |

### 计量槽设计原则

1. **不只是「攒满放大招」** —— 每个计量槽都有不同的获取/消耗循环
2. **维持某个区间本身有独立收益** —— 而不仅仅是数值堆叠
3. **与职业身份紧密绑定** —— 剑圣 = 快攻暴击循环,元素贤者 = 元素精通逐级升阶
4. **存在取舍决策** —— 例如剑意:「维持高剑意以享受持续 buff」vs「消耗它去追求爆发伤害」

### 计量槽详细定义

#### 剑气 + 剑意印记 - 剑圣(Kensei)

> 剑圣为**双资源**:剑气(续航)+ 剑意印记(构筑轴);数值为占位,留平衡阶段定稿。

**剑气(Sword Essence)——续航资源**

- 上限固定为 100,战斗开始为 0;**剑士线共享**(剑士 / 剑圣 / 剑仙,R1.6)——不再用提高上限的天赋改变这条标尺。
- **获取 / 消耗**:斩击等技能产气,一闪 / 居合 / 拔刀等消耗;额外获取与消耗逐项独立计(剑气数值取 5 的倍数,见 [设计规则总表](../../00-rules/rules.md) N07)。
- **剑士〔心眼〕**(`myrmidon_xinyan`):每拥有 20 点剑气,暴击 +1;剑气每比 100 点少 40 点,速度 +1(剑气 100 点时暴击 +5,0 点时速度 +2)。
- **剑圣〔心眼〕**(`kensei_xinyan`):剑气部分与剑士版相同,另读取当前持有的印记,见下。完整效果以设计库技能实体为准。
- 达到 100 点后再获得的剑气作废(写在设计库剑气资源的定义里)。

**剑意印记(心 / 道 / 势)——剑圣专属构筑轴**

- 最多同时持有 3 枚,不自然衰减,每场战斗开始时为 0 枚;剑圣转职专属(R2.4,不下沉剑士)。具体来源分别说明能否取得重复种类以及如何处理获得顺序。
- **获取**:斩击 / 居合等技能产生印记;**倾泻**:拔刀及其部分升级形态消耗印记。
- 印记资源本身不通用地提供属性。现行剑圣〔心眼〕读取印记种类:每枚〔心〕使技巧提高 10%,每枚〔道〕使速度提高 10%,每枚〔势〕使力量提高 10%;完整效果以设计库技能实体为准。
- 〔纳刀印〕是〔离形〕赋予的资源特性,指当前持有印记中最后获得的一枚;只有明确读取〔纳刀印〕的效果才把它按两枚计算。它与状态〔纳刀〕不是同一对象。
- **印记池天赋簇**(剑圣专属,无硬前置):离形、万象归一、残心、印心。当前名称与直接字段以设计库实体 `kensei_lixing`、`kensei_wanxiangguiyi`、`kensei_canxin`、`kensei_yinxin` 为准。回忆升级的当前完成范围见 [[kensei-memory-upgrades|剑圣回忆升级]]。

#### 剑气(Sword Essence)- 剑仙(Sword Immortal)

- 类型:类 MP(自然回复 / 稳定消耗)
- **核心机制**:转职后卸下常规武器 → 获得契约飞剑(Bonded Flying Sword)。其基础攻击技能随之变为远程混合攻击。
- **用途**:维持飞剑技能、部署剑阵、驱动终极能力

#### 专注(Focus)- 狙击手(Sniper)

- 范围:0-100,起始为 0
- **获取**:回合内不移动 +20 / 暴击命中 +15 / 命中被标记目标 +10
- **损失**:移动后 -30 / 受伤后 -20
- **区间效果**:
  - 0-39:无
  - 40-69「凝神」:射程 +1,命中 +5
  - 70-99「沉定」:射程 +1,命中 +10,暴击伤害 +0.2
  - 100「绝对专注」:以上全部 + 下一次攻击无视 50% 物理 DEF

#### 自然共鸣(Nature Resonance)- 精灵射手(Elven Archer)

- 层数系统(0-5 层)
- **获取**:成功闪避 +1 层 / 使用附魔箭技能 +1 层 / 近战攻击命中 +1 层
- **衰减**:若连续 3 回合未获得新层数,所有层数清空
- **效果**:每层:EVA +3,附魔触发几率 +8%。5 层时:下一支附魔箭 100% 触发

#### 法师元素计量槽

> 法师计量槽为三元素系统(火/冰/风)。详细规格见 mage-talent-tree-design-brief。
>
> 每个元素拥有独立能量槽(0-100),配有元素专属的获取/衰减/阈值机制。大贤者(Grand Sage)可同时管理两个元素槽;元素贤者(Element Sage)对其所选元素拥有增强阈值。

## 数值校准说明 - 暴击率分析

**暴击率没有硬上限。** 高 DEX 职业在后期可超过 50% 暴击率,使暴击流 build 持续 scale。

下表按 Lv25 算出,落在预期终局区间(Lv25-30)的下沿:

| 角色 @ Lv25 | 基础 CRIT | 有效暴击率 |
|-----------|--------|----------|
| 剑圣(Kensei) | 75 | ~57% |
| 狙击手(Sniper) | 86 | ~65% |
| 精灵射手(Elven Archer) | 71 | ~54% |
| 剑仙(Sword Immortal) | 60 | ~46% |
| 法师(Mage,平均) | 37 | ~30% |

**设计影响**:
- 「暴击率 +X%」天赋对高 DEX 职业全程保持价值
- **暴击伤害倍率 +X** 依然强力,但不再是后期唯一可行的暴击投资
- 计量槽的暴击获取条件(暴击命中 +N)在后期对剑圣 / 狙击手 触发非常稳定
- 低 DEX 职业(法师、骑士)天然低暴击率,维持职业差异化

## 卡片标签

天赋卡的分类维度是**标签 `tags`**,真源 = 设计库 `/api/tags`。每个标签都带 `definition`(定义)与 `boundary`(边界:什么属于、什么不属于),判定归属时**必须读 boundary**,不要凭标签名望文生义。

现有标签:击杀 / 奥义 / 反应 / 区域 / 位移 / 攻击 / 被动 / 机动 / 资源 / 增益状态 / 负面状态 / 破格。
