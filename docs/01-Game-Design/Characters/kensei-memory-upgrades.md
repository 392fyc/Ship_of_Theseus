# 剑圣回忆升级：现行范围

> 本文保存剑圣回忆升级的现行定性裁决、跨对象关系与完成边界，只引用决定定性结论的关键数值。技能、天赋、状态、资源和规则的结构化字段以 SoT 设计库 `master` 的 `snapshots/` 为准（本次改写对应已合并的设计库 PR #75、#76 与 #77）。设计原则见 [[00-rules/talent-design-principles|天赋设计要点]] §12；2026-10-28 的链路审查记录见设计库 `docs/proposals/2026-10-chain-review/`，第二批（写法修正与强度手算）见 `docs/proposals/2026-10-kensei-batch2/`。

## 共通边界

- 回忆天赋永久升级基础技能。明确作用于基础技能的效果默认也作用于升级版本，除非效果明确排除某个升级版本；兼容效果只能修改升级形态实际存在的内容，不能为纯防御形态凭空增加攻击、伤害、范围或位移。
- 永久升级、战斗中的临时替换和按条件占用同一技能槽的形态是三种不同关系。条件形态只有在条件成立且自身已经结束冷却时才替换原技能；各形态的冷却独立计算，离开技能槽后仍继续经过。
- 剑气上限固定为100点，并以 50 点为界分为高低两个区间（写在设计库剑气资源的定义里）。剑意印记本身不通用地提供属性，具体技能或天赋分别说明如何读取印记的种类、数量和获得顺序。
- 当前设计库的一张回忆天赋只能直接指向一个升级技能，尚不能完整表示动态显示名、多形态入口和临时技能替换。不得为适应现有结构，把不同形态压成一套虚假的冷却、射程、动作类型或范围。

## 六个基础技能的回忆

每个基础技能有 2 个回忆，同一技能的回忆互斥；每个回忆有 3 个专属节点。全部是“待审阅”，〔浮光掠影〕除外。

| 基础技能 | 回忆 → 升级技能 | 定位 |
|---|---|---|
| 〔斩击〕 | 〔化剑为气〕→〔裂空〕 | 前方直线多目标，按命中人数积累剑气 |
| 〔斩击〕 | 〔疾风骤雨〕→〔连斩〕 | 由命中决定长度的连续斩击 |
| 〔一闪〕 | 〔如影随形〕→〔踏影〕 | 选敌瞬移到其相邻格，抢先出手得剑气 |
| 〔一闪〕 | 〔浮光掠影〕→〔掠水〕 | 搁置（草稿），见下文 |
| 〔招架〕 | 〔刹那之隙〕→〔见切〕 | 输出端补强：嘲讽与反击，冷却短，防御低且不稳定 |
| 〔招架〕 | 〔若即若离〕→〔浮生若梦〕 | 确定抵抗少量攻击，冷却让释放时机成为决策 |
| 〔拔刀〕 | 〔鞘之内〕→〔满月〕 | 〔纳刀〕以输出降低换〔满月〕爆发；防御来自先用〔招架〕或节点〔守势〕 |
| 〔拔刀〕 | 〔兵无常势〕→〔决心〕〔回天〕〔霸天〕 | 按印记数量占用〔招架〕槽的三种形态 |
| 〔心眼〕 | 〔心无旁骛〕→〔心眼·澄〕 | 每回合用剑气换〔澄心〕，提高技能威力 |
| 〔心眼〕 | 〔大梦将醒〕→〔心眼·梦〕 | 满剑气进入〔空想〕，短时爆发与额外标准动作 |
| 〔居合〕 | 〔虚实相生〕→〔临摹〕 | 召唤〔影〕照做斩击、拔刀系攻击 |
| 〔居合〕 | 〔阴阳剑〕→〔太阳剑〕〔太阴剑〕 | 两剑交替，阴阳满层换额外回合 |

## 用户裁决与关键关系

### 〔招架〕组的分工

用户 2026-10-28：「〔浮生若梦〕的特点应该是，对攻击的抵抗更强，但仅限少量攻击，主要用于抵抗可预见的高伤害，具有一定cd使单位必须掌握释放时机。而〔见切〕则是提供一个输出端补强，可以更频繁的释放来持续获得收益，所以防御收益相对低且没有〔浮生若梦〕稳定」

- 〔浮生若梦〕的〔若即〕按剑气给 1～3 层，〔若离〕在造成技能伤害时回复剑气（用户 2026-10-20 的基础效果）。
- 节点〔离合〕：用户 2026-10-20 的原版是“获得〔若即〕时，消耗剩余〔若离〕转化为〔若即〕；〔若即〕最大六层”。现行版是 v9 改过结构的版本：到期的〔若即〕转成〔若离〕，消耗〔若离〕的那次攻击威力提高。用户 2026-10-28 确认保留现行版（原话：「v9」）。原版会让一次〔浮生若梦〕最多挡 6 次攻击，与“仅限少量攻击”的定位相反；现行版把挡剩的〔若即〕转成进攻收益（Claude 的解释）。
- 〔见切〕的额外闪避是技巧的一半，冷却短于〔浮生若梦〕（数值为提案）。本体反击使用自己固定的伤害口径；节点〔尽意〕才让反击改用当前的〔斩击〕及其形态。反击不递归触发反击。嘲讽的目标规则见规则表 R1.18。

### 〔兵无常势〕同按钮

用户 2026-10-28：「〔兵无常势〕的按钮规则沿用原同按钮设定」。持有 1 枚印记时〔招架〕槽为〔决心〕；2 枚且剑气不少于 10 点时为〔回天〕；3 枚且剑气不少于 20 点时为〔霸天〕；使用后消耗印记并恢复〔招架〕。代价是与〔招架〕及其回忆抢同一个按钮：同时持有〔见切〕或〔浮生若梦〕时，持有印记期间多数时间用不了它们（推断）。用户 2026-10-28 确认这是预期内的代价（原话：「如果同时持有〔兵无常势〕和〔见切〕或〔浮生若梦〕这是预期下的」）。〔回天〕没有攻击、伤害、命中或暴击，作用于〔拔刀〕的增强不会让它获得这些内容。

### 〔浮光掠影〕搁置

用户 2026-10-19 搁置〔掠水〕：它与〔一闪〕只差射程和剑气，成了〔一闪〕的小升级；2026-10-28 确认维持搁置。回忆与 3 个节点在设计库为草稿；〔掠水〕是技能，没有草稿状态，notes 标明搁置。一闪系当前只推出〔踏影〕。

### 〔鞘之内〕与〔大梦将醒〕

- 〔鞘之内〕：使用〔招架〕或其升级版本进入〔纳刀〕并得印记；〔纳刀〕期间的〔拔刀〕显示为〔满月〕，发动后解除〔纳刀〕。显示名不建立独立冷却。替换〔招架〕槽的条件与〔拔刀〕相同，以设计库为准。
- 〔满月〕的总增：设计库提案 27 号记录的“〔鞘之内〕用户 2026-10-13 版本”是 30%；Claude 在 v4–v9 草案中改为 50%，2026-10-28 按手算恢复为 30%。按 30% 算，三名敌人时每回合伤害约比基础高 15%～44%，单体约高 4%（前提：3 名敌人都在范围内，敌人数值为占位）；〔兵无常势〕的〔霸天〕在单体与重甲时更强，两者分工。〔鞘鸣〕同为 30%，对应用户原意“〔居合〕也按〔满月〕结算”。
- 〔大梦将醒〕：满剑气进入〔空想〕，期间〔空想剑〕临时替换〔心眼·梦〕；〔空想〕把获得剑气反转为失去剑气，并按实际损失积累〔剑痕〕。〔剑痕〕可以跨越多次〔空想〕保留。

### 节点

- 节点不提供跨战斗的永久增益；本场战斗内持续的增益可以（归纳，依据用户 2026-10-28 评〔两仪〕：「单回合生效也行，不提供永久增益更方便平衡」，随后确认「〔两仪〕本场战斗生效」）。
- 2026-10-28 Claude 重做了自己设计的〔明澈〕（属性堆叠）、〔止观〕（技能交互）、〔梦回〕（功能），使〔心无旁骛〕〔大梦将醒〕的节点方向不再重复；数值为提案。

### 实装中的裁决（用户 2026-10-30）

Ship 实装（gameplay-impl #89–#97）时 Claude 列出的推断，用户 2026-10-30 逐条回复：

- 〔兵无常势〕「持有 N 枚印记」按正好 N 枚判定：用户「兵无常势正确」。例如 3 枚印记、剑气 19 时保持〔招架〕，不退到〔回天〕。
- 〔若即〕对范围攻击有效：用户先确认过「若即对范围攻击失效正确」，同日逐条确认时改为「若即对范围攻击有效」，追问后选「伤害也有效」，以后者为准。不是必中的范围攻击原本会命中时，也改为回避并消耗 1 层；被回避时附带的控制随之落空，不另外消耗层数。必中攻击仍不受影响（设计库 `kensei_ruoji` rules）。
- 〔心眼·澄〕不保留基础〔心眼〕的加成：用户「默认不保留，回忆天赋是新技能替代旧技能，而不是附加效果在旧技能上，所以新技能没有的描述默认就是没有。而心眼·梦里写了『不保留』反而是多余操作」。这条原则早已写在 [[00-rules/talent-design-principles|天赋设计要点]] §12（用户 2026-10-20），本次补进 §12 硬约束表，不再作为待确认项。
- 〔阴阳调和〕只计技能效果带来的剑气增减：用户「天赋不算」。
- 〔影〕的生命值就是它能承受的攻击次数：用户「〔影〕的生命值应该是〔影〕可以承受攻击的次数，每次只能掉 1HP，类似于 dota 和 lol 中的守卫」。生命值 4，每个命中的伤害包固定扣 1 点，与伤害数值无关。
- 〔回天〕的护盾：用户「回天护盾数值需要重新模拟」。原值每名敌人 1.5%，剑圣周围 1–2 个敌人时只有 1 点。2026-10-30 重新推演后改为每名敌人 5%、护盾量向上取整 [推断]（设计库 PR #79，推演见设计库 `docs/proposals/2026-10-huitian-shield/handcalc.md`）：1–2 名敌人时与 2 枚印记加 10 点剑气的输出代价大致持平，3 名敌人时不如攒〔霸天〕；每个敌方回合承伤降 4%–12%，在基础〔招架〕与〔浮生若梦〕之间。
- 敌人选目标：用户问火纹是否“射程内打生命最低的目标”。查证后用户在方案页选定加权打分，已实装（Ship #108），现行做法见 [[01-Game-Design/Core-Systems/enemy-and-ai|敌人与 AI]]「现行实现」。
- 〔斩击〕命中但伤害为 0 时也给印记：用户「命中就给」。〔连斩〕同一口径：用户「连斩一起改」，每段命中就给 10 点剑气，第一段命中就给印记，伤害为 0 也给（剑气一并改是推断：原文剑气与印记用同一短语）。设计库两条的 effect 已改写，不再用 R1.4 的「造成伤害后」术语；〔剑气回荡〕原文明写「未造成伤害则不获得」，不变。
- 剑圣死亡时〔影〕随之消失：用户选「随主人一起消失」。否则〔影〕会一直留在场上吸引攻击，却再也不会照做。
- 〔若离〕与副手：用户「副手也算。不过要补充一下二刀开刃的效果：追加的伤害和技能同源。比如有二刀开刃的情况下，斩击的追击视为斩击，居合的追击视为居合。而且副手不是你现在该考虑的内容，还没做到普通天赋」。即学了〔二刀开刃〕后，副手追加攻击视为它所跟随的那个技能（斩击的追击视为斩击），所以〔若离〕的「造成技能伤害」也包括副手追加。副手与普通天赋尚未实装，本条留到那时一并写进设计库〔二刀开刃〕与实现。
