# 剑圣〔斩击〕回忆升级裁决与数值依据
> 本文记录用户裁决、数值依据与尚未解决的问题。技能和回忆天赋的结构化字段以 SoT 设计库生产记录为准：基础技能 `kensei_zhanji`，现行升级候选 `kensei_liekong`、`kensei_yijue`；本文不复制完整技能数据。

## 已确认修改

### 〔裂空〕（`kensei_liekong`）

- 当前名称、范围和直接数值以设计库技能实体 `kensei_liekong` 为准。
- 作用范围内至少存在一名敌方单位时才可发动。
- 每次使用只获得一枚印记；印记的获得不受是否命中和命中人数影响。
- 多目标是本技能的明确优势。目标上限由技能的范围字段决定，不在玩家文案中重复说明。

### 〔连斩〕（`kensei_yijue`）

- 当前名称和直接数值以设计库技能实体 `kensei_yijue` 为准。
- 第一刀正常判定命中，命中后自动继续斩击；任意一刀未命中或目标倒下时结束，已经完成的结算不撤销。
- 从第二刀起，命中逐刀累计降低。命中可以超过100%，超出的部分可以抵消这些降低，因此继续提高命中仍能延长连斩。
- 其他效果赋予的必定命中只作用于第一刀，不延长后续连斩。
- 其他技能、天赋或装备中写明“命中时”发动的效果，在整次连斩中最多发动一次；明确写明逐刀发动的效果除外。
- 连斩自身的伤害和剑气逐刀结算；整段连斩只使用一次标准动作和一次攻击机会。首次命中时的印记每次使用至多获得一枚。

## 数值依据

当前伤害、剑气、命中递减和其他直接字段以设计库技能实体 `kensei_yijue` 为准，本节不保存会随平衡调整漂移的完整数值表。

连斩的成长性来自命中能力提升后能够支持更多追加判定；累计命中降低仍会让越靠后的追加越容易结束。超过自然命中上限的命中投入仍可抵消后续累计降低，因此成长不会因首刀达到高命中而失去意义。

异常循环保护只用于防止运行失控，不得变成玩家可利用的技能刀数上限。
