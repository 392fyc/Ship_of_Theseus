# 核心战斗循环实证结论 — 剑圣资源打法对照

> 2026-06-30 · 对 [[battle-calculation]] 战斗循环的经验性测量，回答记忆 sot-combat-loop-design
> 的裁决"有条件能"——现循环是产打法差异还是仅数值差异。
> 完整报告与原始数据在代码仓 `tests/剑圣资源打法实证报告.md` / `tests/_exp_results.md`。
> 研判经 4 视角分析 + 1 对抗式反驳 + 综合校准（置信度：中）。

## 方法

实例化正式 TacticalScene，**5 策略 × 3 目标场景 × 120 蒙特卡洛 × 14 回合**，确定性命中。
- 场景：WALL 单·不灭木桩(HP999 DEF2 永不死) / WAVE 单·复活木桩(HP30 DEF1) / PACK 三·复活木桩簇。
- 策略：BASE 只斩击 / IAI 攒气-居合 / IAI_CD 居合-冷却流(无视剑气门槛探针) / BADAO 印记-拔刀 / GREEDY 贪婪混合。
- 约束：每回合仅 1 标准动作（斩击/居合/拔刀互斥同槽）；移动/迅捷槽未用。

## 结论

剑圣资源系统**已显现机制驱动的真打法分轴**——**单体耐久→居合 / 群体→拔刀**，
合法策略各约 **+29%~+32%**（~25σ/46σ 显著）——**强于纯数值差异，但未成熟**：
分轴主要由技能几何（拔刀菱形 AoE 随敌数缩放）驱动，**而非剑气/印记的积累-倾泻抉择**驱动，
且曾被引擎完整性问题污染。**不是"单一最优线"**：初判曾据 IAI_CD（504 碾压）误判，
对抗核验纠正——**IAI_CD 是 bug 伪策略非合法打法**，剔除后合法策略呈对称真分支。

## 已坐实的分化轴

| 轴 | 强弱 | 证据 |
|---|---|---|
| 群体规模轴（PACK 触发） | 中强 | 拔刀是唯一随敌数缩放的技；PACK BADAO 366 > 居合 278（+31.8%），拔刀伤占比 31%→49%。但停在总伤维度未抵达清场。 |
| 单体耐久轴（WALL 触发） | 强（幅度部分被计伤口径放大） | 耐久单体→居合 IAI 347 > 拔刀 270（+28.6%）。但脆敌 WAVE 该优势骤降至 +3.5%——"单体一律居合"不成立，依目标耐久。 |
| 方差/爆发轴 | 弱（被均值排序丢弃） | 拔刀高方差爆发(std 32) vs 居合稳定(std 8)，真实手感差异。 |
| 资源利用纹理 | 弱 | 动作熵/倾泻数/印记浪费在策略间分明，但区分"是否调用某技"非"何种资源状态下选择倾泻"。 |

## 引擎完整性问题（4 条）

- **P0-① 剑气门槛不被强制（纯 bug）— 已修 2026-06-30**：`validate_skill_usage` 此前只校验
  冷却+动作槽，不强制 qi_cost/requires_marks → 居合可无视 6 气只看冷却刷（IAI_CD，WALL 504 碾压
  守门槛 IAI 347）。**修复**：`game_action.gd validate_skill_usage` 增资源门槛（数据驱动，
  仅技能 JSON 声明 qi_cost/requires_marks/mark_cost 时生效，符合资源每职业独立）。
- **P0-② 拔刀结算前先扣印记（时序 bug）— 已修 2026-06-30**：拔刀在 `spend_marks` 后才结算
  伤害，吃不到自身消耗的势(STR+2)（非暴击 25 而非 29，对 30 血脆敌打不死）。**修复**：
  `tactical_manager.gd _execute_skill_action` 把印记消耗推迟到伤害结算之后（`_spend_skill_marks`）。
  附带收益：拔刀 forecast 此前算 29（印记在手）与实际 25 不符，修后一致。
- **P1 拔刀致死力/HP 错配（待裁决）**：power180 非暴击仍打不死脆敌的临界点须调；当前群体总伤优势
  无法转清场（PACK 击杀 1.3 vs 居合 7.0）。设计取向（提致死 vs 赋非伤害群控价值）待用户拍板。
- **P2 双资源裸经济下不共激活（设计漏洞非 bug，待裁决）**：GREEDY 与 BADAO 三场景完全同值、居合 0 次
  ——更便宜的拔刀经济抢先、剑气永不到 6，混合构筑坍缩。注：剑气生成类天赋可能改变此结论。

## 实验适用边界（结论仅在此范围）

仅标准动作单槽（一闪 move / 招架 swift 未用，而拔刀实由招架替换槽位才出现 → 资源主载体未进测）；
单职业零天赋零符文（肉鸽构筑设计为从组合涌现，组合空间未测）；计伤口径 WALL 计溢伤、脆敌封顶
（单体居合优势 WALL+28.6% 在 WAVE 仅+3.5%，跨场景幅度不可直接比）；复活+不还手木桩抹掉拔刀群控价值；
确定性命中折叠心眼暴击 EV。→ "资源不产决策"是证据不足，非反证。

## 净启示

P0 两 bug 已修——当前的"单一最优线"观感大半曾是 bug 产物。下一步判定底座可玩性，应在
**完整动作经济（含一闪/招架/走位）+ 至少一层天赋/符文组合**下重测，而非裸标准动作单槽。
