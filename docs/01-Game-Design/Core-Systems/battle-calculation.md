# 03 - 战斗计算系统(Battle Calculation)

> Back to [[game-design-doc|GDD]]
> 规则权威:设计库规则表(战斗计算域 R1.x),全量索引见 [[rules-catalog|规则总目录]]。本章为展开文档;涉及公式处均给出中文名与代码变量名(英文 = 代码变量名)。

## 概览

战斗计算 = 三条判定链(命中/暴击/伤害)+ 通用修正代数:

- **伤害**:加法基础层(攻击属性 + `weapon_might` − 对应防御,点数直减、面板可心算)× 外层乘区(技能 × 地形 × 暴击 × 遗物 × 最终,按比例放大)。
- **命中/暴击**:加法模型,四层公式量串联,全来源透明,玩家可精确计算。
- **全属性可见**:敌方 HP 与属性精确显示。
- **伤害类型双轴**:属性类型 × 攻击方式,由技能/天赋/遗物声明——武器不区分伤害类型。
- **武器参数**:`weapon_might` / `weapon_hit` / `weapon_crit` 唯一来源 = 所装备武器(R1.7)。

## 九属性体系(规则锚:R2.1)

```
UnitStats:
  STR  力量:物理攻击(physical / hybrid 伤害)        成长
  MAG  魔力:魔法攻击(magical / hybrid 伤害)         成长
  DEX  技巧:基础命中 + 基础暴击派生源                成长
  SPD  速度:出手顺序 + 闪避派生源                    成长
  LCK  幸运:暴击回避基值 + 减益抵抗(运气轴)         固定
  DEF  防御:物理减伤(伤害加法层直减)                成长
  RES  抗性:魔法减伤(伤害加法层直减)                成长
  HP   生命                                           成长
  MOV  移动力(格)                                    固定
```

7 成长(HP/STR/MAG/DEX/SPD/DEF/RES)+ 2 固定(LCK/MOV)。固定属性不随升级,只由初始/转职/天赋/遗物/装备改变。

### 属性在公式中的角色

| 属性 | 公式角色 |
|-----------|-------------|
| STR | physical 基础伤害:`max(0, STR + weapon_might − target.DEF)` |
| MAG | magical 基础伤害:`max(0, MAG + weapon_might − target.RES)` |
| DEX | 人物基础命中 `base_hit`(DEX×2)+ 人物基础暴击 `base_crit`(DEX/2) |
| SPD | 出手顺序(R3.1)+ 闪避 `avoid`(SPD×2) |
| LCK | 暴击回避 `crit_avoid` 层基值 + 减益抵抗(R1.5);技能系数/天赋效果可显式关联 |
| DEF | 物理防御(伤害加法层直减) |
| RES | 魔法防御(伤害加法层直减) |

LCK **不参与命中/闪避**:LCK 为固定属性,战斗触点收敛为「坏事发生率」——被暴击与吃异常;roguelite 层为其预留主场。

## 武器参数(规则锚:R1.7)

武器基础参数仅三项，唯一来源是所装备的武器，职业不自带武器档案：

| 中文 | 变量名 | 公式挂点 |
|---|---|---|
| 武器威力 | `weapon_might` | 基础伤害加法层（R1.1） |
| 武器命中 | `weapon_hit` | 人物基础命中（R1.2） |
| 武器暴击 | `weapon_crit` | 人物基础暴击（R1.3） |

- **不允许空手**：每个单位始终装备一件武器，不能卸下，只能替换；开战时每个单位都会获得一件武器，敌我遵循同一规则。
- **默认取主手**：技能和普通攻击默认使用主手武器作为计算来源；只有效果明确说明使用副手武器时，才改用副手武器。
- **武器不区分伤害类型**：物理、魔法或纯粹伤害由相应效果声明，`weapon_might` 进入对应公式。
- **武器不管理射程**：射程由相应效果声明。
- **副手特效版本**：每把剑的武器特效同时声明原版本与副手版本。剑圣将剑装备在副手时显示副手版本；副手版本的效果量为原版本的50%，触发概率不变。无法按固定比例表达的部分必须在该武器的副手版本中单独说明。装备在副手不代表特效可以发动，只有明确允许副手武器特效的效果才能触发它。
- STR、DEX 等属性加成不属于武器基础参数，归词缀层；武器类别与职业限装另行定义。

## 公式量分层与修正代数(规则锚:R1.8)

### 分层总则

命中/暴击/伤害三链分层,**每个公式量 = 一层 = 独立乘区,每层都可被效果作用**。

- 层基值 = 上一层输出(或属性/武器合成式)。
- 改属性的效果(如「DEX +2」)经属性进第一层基值;直接修正按措辞落层。
- `base_*` 用结算时点的当前属性值计算,不是开局面板快照。

### 修正代数

```
层结算值 = (层基值 + Σ加算) × (1 + Σ提升%) × Π(1 + 各「更多%」)
```

| 算子 | 规范措辞 | 算法 | 英文 |
|---|---|---|---|
| 加算 | 「X +N」 | 同层直接求和 | flat / gain |
| 提升 | 「X 提升 N%」 | 同层**先加总再一次性乘**(20%+30% = ×1.5) | increased |
| 更多 | 「N% 更多 X」 | **各自独立连乘**(20%、30% = ×1.2×1.3 = ×1.56) | more |
| 无视/穿透 | 「无视目标 N% X」「无视 N 点 X」 | 攻方效果,作用在**对方量的消耗时点**:`Q_eff = Q × (1 − Σ无视%) − Σ无视点数` | penetration |

结算纪律:

- 层内顺序固定:加算 → 提升 → 更多。
- `clamp` / `floor`(命中 1-100、暴击 ≥0)是**最外层守门**,在最终层修正算完之后才执行。
- **中间量不取整,最终量向下取整**。
- **措辞→算子→落层的映射是硬规范**:天赋/遗物/词条文案必须使用规范措辞书写,保证审阅与实装可机判归层。

### 走链示例

武器 hit 60、DEX 9;天赋「基础命中提升 20%」、遗物「命中 +15」、敌闪避 40、技能「无视目标 50% 闪避」、buff「最终命中率提升 10%」:

```
base_hit = (60 + 18) × 1.2 = 93.6
hit      = 93.6 + 15 = 108.6
avoid_eff = 40 × 0.5 = 20
final    = (108.6 − 20) × 1.1 = 97.46 → clamp(1,100) + 向下取整 = 97%
```

## 命中判定(规则锚:R1.2)

| 中文 | 变量名 | 定义 |
|---|---|---|
| 人物基础命中 | `base_hit` | `weapon_hit + DEX×2` |
| 命中 | `hit` | 层基值 = `base_hit`,吃直接命中修正(天赋/遗物/建筑/buff) |
| 闪避 | `avoid` | `SPD×2 + terrain_evade_bonus` + 直接闪避修正;攻方「无视闪避」作用后 → `avoid_eff` |
| 最终命中率 | `final_hit_rate` | 以 `hit − avoid_eff` 为层基值经最终层修正后 `clamp(1, 100)` |

- `terrain_evade_bonus` = 防守方所在基础地形的闪避加成(如森林)。
- 命中下限 1 仅为兜底;正常对局玩家命中预期 60-70+(「玩家高命中」是设计基调,命中张力由闪避词条/地形/高 SPD 特化敌种提供)。

## 暴击判定(规则锚:R1.3)

| 中文 | 变量名 | 定义 |
|---|---|---|
| 人物基础暴击 | `base_crit` | `weapon_crit + DEX/2` |
| 暴击 | `crit` | 层基值 = `base_crit`,吃直接暴击修正(心眼剑气 `crit_bonus` 挂本层,换算数值见技能「心眼」`myrmidon_xinyan`;剑气资源定义见 R1.6) |
| 暴击回避 | `crit_avoid` | 层基值 = `LCK`;攻方「无视暴击回避」作用后 → `crit_avoid_eff` |
| 最终暴击率 | `final_crit_rate` | 以 `crit − crit_avoid_eff` 为层基值经最终层修正后 `max(0, ·)` |

### 暴击倍率

- ×1.5 是暴击倍率的**初始值**而非上限,可经 `crit_damage_bonus`(加法叠加到 1.5)提高:
  - 天赋/遗物「暴击伤害 +20%」→ `crit_damage_bonus = 0.2` → ×1.7
  - 来源:技能 / 天赋 / 遗物 / 装备
- 另有**乘算型**修正,记作「暴击倍率 ×N」(等价于 R1.8「更多」作用于暴击倍率量,独立连乘),在加算结果之上再乘 N:
  - 剑圣拔刀 暴击倍率 ×1.2 → 1.5×1.2 = ×1.8(基础);若加算已把系数推到 ×2.0,则 ×2.0×1.2 = ×2.4
- **pure 伤害不参与暴击判定**(R1.1 / R1.3):既不做暴击随机判定,也不进暴击乘区;`crit_damage_bonus` 与「暴击倍率 ×N」两条通道对它都不适用,没有技能级开关能让它进入暴击链。
- 暴击率无上限(最低 0%,无封顶);敌方高暴击经遭遇设计模板管控,不设系统上限。

## 伤害类型系统(规则锚:R1.1)

伤害采用**双轴分类**:属性类型(决定防御计算)× 攻击方式(决定特殊交互)。两轴由技能数据独立声明——**武器不区分伤害类型**。

### 轴 1 - 属性类型(互斥)

| 类型 | 基础伤害公式(层 1) | 暴击 | 备注 |
|------|-------------------------------|------|-------|
| physical | `max(0, STR + weapon_might − DEF)` | ✅ 参与暴击倍率加成 | 物理系职业 |
| magical | `max(0, MAG + weapon_might − RES)` | ✅ 参与暴击倍率加成 | 法系职业 |
| pure | 原生:`max(0, [源] + weapon_might)`,**无视全部防御**;受地形乘区影响。派生:取本次结算中前置 physical/magical 的**最终伤害**按声明百分比转换 | ❌ 不参与暴击判定(R1.1 / R1.3) | 稀有高威力;纯粹是**应用层**伤害类型、不作基数类型,取原生还是派生由效果自身声明 |
| hybrid | `( max(0, STR + weapon_might − DEF) + max(0, MAG + weapon_might − RES) ) / 2` [已定] | ✅ 参与暴击倍率加成 | 双属性职业;物理与魔法各算一次再取算术平均,两侧各带各的地板 |

**pure 攻击源(`pure_atk_source`,技能 JSON 声明)**:`"phys"` → STR;`"mag"` → MAG;`"sum"` → STR + MAG(仅稀有高威力技能)。此字段只在**原生**形态下使用;派生形态不读它,基数直接取前置伤害的最终结果(R1.1)。

**hybrid 的两次结算(2026-08-03 用户裁决,[已定])**:物理与魔法**各按 R1.1 完整算一次**——每一侧各自带自己的 `max(0, ·)` 地板——再把两个结果取算术平均。

- **这不等于「一次性减去平均防御」**。只要有一侧被地板截到 0,两种写法的结果就不同。例:`STR` = `MAG` = 20、`weapon_might` = 5、目标 `DEF` = 10、`RES` = 40 → 各算一次为 `(15 + 0) / 2 = 7.5`;若先把防御平均掉则是 `max(0, 20 + 5 − 25) = 0`。
- 因此**实装与文档一律按「各算一次再平均」书写**,不得为求简洁合并成「减平均防御」的单式。
- 平均值属中间量,**不取整**;取整只在最外层对最终伤害做一次向下取整(R1.8)。

**伤害下限**:加法层计算取 `max(0, ·)`,最终伤害 `final_damage` 的下限同样为 0——防御足够高时,命中也可以结算出 0 伤害。

### 轴 2 - 攻击方式(技能声明)

| 类型 | 判定规则 | 备注 |
|------|-------------------|-------|
| melee | 技能射程仅 1 格 | 由技能数据声明,不受实际攻击距离影响 |
| ranged | 技能射程 > 1 格 | 即使实际打 1 格外目标仍算 ranged |
| area | 技能 AOE 覆盖多格 | 即使只命中单目标仍算 area |

**用途**:攻击方式主要用于特殊交互判定(如「受到近战伤害时触发反应效果」「远程伤害 +10%」、建筑耐久按攻击方式扣减等),不直接进伤害公式。

## 伤害公式(规则锚:R1.1)

| 中文 | 变量名 | 定义 |
|---|---|---|
| 基础伤害 | `base_damage` | physical `max(0, STR + weapon_might − target.DEF)`;magical `max(0, MAG + weapon_might − target.RES)`;pure `max(0, [源] + weapon_might)` 无视防御;hybrid = physical 式与 magical 式**各算一次后取算术平均**(不是减平均防御) |
| 最终伤害 | `final_damage` | `base_damage × skill_multiplier × terrain_modifier × crit_modifier × relic_modifier × final_modifier` |

外层乘区:

| 乘区 | 变量名 | 说明 |
|---|---|---|
| 技能倍率 | `skill_multiplier` | `skill.power / 100`(100 = 1.0×) |
| 地形乘区 | `terrain_modifier` | 特殊地形独立乘区(如「受伤 ×0.8」) |
| 暴击乘区 | `crit_modifier` | 暴击 1.5× 起(加算 `crit_damage_bonus` 与乘算「暴击倍率 ×N」两条通道,加算先于乘算,见上方「暴击倍率」)/ 未暴击 1.0× |
| 遗物乘区 | `relic_modifier` | Roguelite 遗物独立乘区 |
| 最终乘区 | `final_modifier` | 全部最终段修正连乘(建筑减伤、buff 增伤等) |

### 基础地形 vs 特殊地形(关键区分)

- **基础地形加成**:地形提供的属性加成直接加到单位属性,参与层 1 加法计算。
  - 例:山地 +5 DEF → `DEF` 变为 `DEF + 5`,参与 `STR + weapon_might − DEF`。
- **特殊地形乘区**:特殊地形提供的独立乘数(层 2 `terrain_modifier`)。
  - 例:某特殊地形「受到伤害 ×0.8」→ 在最终计算中作为独立乘数。

### 基础地形战斗修正表

| 基础地形 | 防守方加成 | 闪避加成 |
|-------------|---------------|---------------|
| PLAIN(平原) | 无 | 无 |
| FOREST(森林) | 无 | +闪避(数值待定) |
| MOUNTAIN(山地) | +DEF、+RES(数值待定) | 无 |
| SHALLOW_WATER(浅水) | 无 | 无 |
| LAVA(熔岩) | 无 | 无 |
| SWAMP(沼泽) | 无 | 无 |

*PEAK/WALL/DEEP_WATER 为不可通行地形,无战斗修正。浅水/熔岩/沼泽的效果经 Buff/Debuff 施加实现,不走直接属性修正。*

## 攻击结算流程

每个独立直接伤害段按以下顺序完整结算：

```text
1. 命中判定
   计算最终命中并随机判定。
   未命中时，只结算未命中事件，然后结束本伤害段。

2. 暴击判定
   命中后计算最终暴击并随机判定。

3. 建立伤害包
   以本段结算前的同一份状态为快照，计算来源直接伤害与全部可生效附伤。
   各组成部分分别保留伤害类型、来源、公式与对应减伤，但没有先后顺序。

4. 施加伤害
   对整个伤害包统一处理通用护盾或减伤；只针对特定伤害类型的防护分别处理符合条件的组成部分。
   所有组成部分计算完毕后，再统一改变护盾与生命。

5. 命中时效果
   结算绑定本次命中的效果。附伤沿用来源命中，不另行产生这一事件。

6. 伤害后效果
   结算命中后、造成伤害时以及本段直接产生的资源、状态等效果。附伤不另行产生造成伤害时事件。

7. 死亡与击杀
   本段及其直接触发全部完成后判断死亡。造成致命伤害的本段仍完整结算；目标死亡后，不再结算针对它的后续独立伤害段或其他后续效果。一次伤害包至多产生一次击杀事件，归属于来源攻击者和本次动作。
```

多段攻击的每一段分别执行这套流程，因此段与段之间可以读取前一段造成的属性、资源、护盾、生命或状态变化。效果明确声明为同时结算的内容，必须放进同一伤害包，不能在包内建立虚构的先后顺序。

## 一次效果结算几次（规则锚：R1.9—R1.15）

### 范围伤害的单位级结算（R1.9）

范围效果覆盖同一单位的多个占据格时，该单位在一个伤害段中只受到一次伤害。效果明确声明多段伤害时，按声明段数分别结算；每一段中，同一单位仍只受到一次伤害。多格单位的瞄准与范围锚点见 R4.4。

### 伤害段与死亡（R1.11）

每个独立直接伤害段及其直接触发构成一次完整结算。本段完成后才判断死亡；目标死亡后，不再结算针对它的后续独立伤害段或其他后续效果。致命段应有的资源、状态与击杀效果仍正常结算。

多段攻击在段与段之间处理死亡，不把整次技能强行合并。只有明确声明同时结算的组成部分才进入同一伤害包。

### 伤害包（R1.12）

一个直接伤害段与依附于该段的全部附伤共同组成一个伤害包：

- 所有组成部分读取同一份包前状态；
- 各自保留伤害类型、来源、公式和对应减伤；
- 包内没有先后顺序，全部计算完成后统一改变护盾与生命并判断死亡；
- 通用护盾或减伤对整个包处理一次，只针对特定伤害类型的防护分别处理符合条件的组成部分；
- 一个包至多产生一次击杀事件，归属于来源攻击者和本次动作，不归属于某项附伤；
- 来源直接伤害为0而附伤致死时，仍正常产生一次击杀事件；
- 需要来源先压低生命、击破护盾或改变状态后才生效的效果，不属于附伤，应作为后续独立效果结算。

### 伤害提升、附伤与追加攻击（R1.13—R1.15）

| 形态 | 结算对象 | 命中与暴击 | 事件 | 默认递归边界 |
|---|---|---|---|---|
| 伤害提升 | 修改技能或攻击自身的原始伤害 | 沿用原伤害段 | 不新增事件 | 不自动提高附伤或追加攻击 |
| 附伤 | 依附于每个符合条件的直接伤害段 | 沿用来源命中；默认不能暴击，也不继承来源暴击 | 不新增命中、暴击或造成伤害事件；可共同产生一次击杀事件 | 不再触发其他附伤或追加攻击 |
| 追加攻击 | 新的独立攻击 | 独立判定命中与暴击 | 正常产生自身的命中、暴击、造成伤害与击杀事件 | 是否携带附伤、触发武器特效或继续追加，由来源明确声明 |

附伤的默认效果系数为100%。如果某个技能或伤害段需要不同系数，必须在玩家可见内容中明确说明，不建立隐藏的通用折算。

### 效果触发计数与递归约束（R1.10）

效果的触发次数由它绑定的事件粒度决定：

| 挂靠点 | 计次 |
|---|---|
| 执行攻击动作时、每次攻击 | 一次攻击动作触发一次 |
| 命中、暴击、造成伤害 | 每个实际发生的直接伤害段分别触发 |
| 多目标 | 对每个目标分别计算 |

一个效果不被自己引发的事件再次触发，不同效果之间也不构成循环触发；只有效果文字明确允许时才可例外。

## 反击系统

任何单位不因受到攻击而进行反击,结算流程止于步骤 6。受击方对抗手段由反应类(Reaction)天赋/技能/遗物各自定义。

## 成长系统(规则锚:R2.2 / R2.3)

### 概率成长

```
升级时每个成长属性(HP/STR/MAG/DEX/SPD/DEF/RES)独立判定:
  if random() < growth_rate[stat]: stat += 1

LCK / MOV 不参与升级成长。
```

成长率取值以档位标尺(R2.3)为准:C=40% / B=50% / A=60% / S=75%,固定单值不设区间;SS = 每级仅判定一次(S 率):成功 +2,失败保底 +1(期望 +1.75、每级恒 ≥+1,不参与 pity 计数)。职业线标定见 [[class-system|05 - 职业系统]]。

### 保底(Pity)

```
每属性维护隐藏 fail_count:
  判定失败 → fail_count += 1;判定成功 → fail_count = 0
  fail_count >= pity_threshold → 强制 +1,重置计数

pity_threshold:
  growth_rate >= 40%:   pity = 3
  growth_rate 20%-39%:  pity = 5
  growth_rate < 20%:    pity = 8
```

## 减益施加(规则锚:R1.5)

```
Debuff 实际施加率 = skill_effect.chance × max(0.1, 1 − target.LCK / 100)

例:技能施加率 50%,目标 LCK = 20
  → 50% × (1 − 0.2) = 40%
```

LCK 的两个战斗触点之一(另一个是暴击回避,见 R1.3)。

## 判定(机制族)

凡是「按一个概率掷一次、成败各有后果」的结算,都归入**判定**这一族。本章的命中链与暴击链各贡献一条规则层判定,减益施加(R1.5)再贡献一条,另有一条由技能自身携带。设计库把这四条立成同一张注册表(`/api/judgments`),目的是让天赋 / 遗物 / 技能的 trigger 能写成「某判定成功时」「某判定失败时」这类参数化事件——**判定的成败本身就是可被效果挂靠的事件**,不只是一个算完就丢的中间数。

| 判定 | 来源 | 公式所在 |
|---|---|---|
| 闪避 | 规则层(锚 R1.2) | 本章「命中判定」 |
| 暴击回避 | 规则层(锚 R1.3) | 本章「暴击判定」 |
| 减益抵抗 | 规则层(锚 R1.5) | 本章「减益施加」 |
| 招架 | 技能自带(无规则锚) | 本章「招架」 |

前三条随规则表条文改动,招架由技能自身携带。**逐条定义以 `/api/judgments` 为准**,本章只给指针与落点,不复制副本——指针不会随规则改动失效,副本会。

### 招架(Parry)

- **性质**:技能自带的**减伤判定**,不是规则层机制,不挂规则锚。
- **判定式**:按 `SPD%` 概率生效(速度 20 → 20% 概率)。
- **可挂靠**:判定成功与否都可被其他效果挂靠(例如写作「招架成功时」触发的天赋)。
- 技能分类与行动消耗见 [[skills-and-range|04 - 技能与射程]]。

## 背水(状态)

背水是一种**持续状态**,类别 = 条件,持续方式 = 条件维持,**不可抵抗**(不走 R1.5 的减益抵抗判定)。

- **阈值**:HP 不高于 30% 时处于背水状态,HP 高于 30% 时脱离该状态。
- **即时判定**:每次结算都以**当前 HP** 重新计算,**不在进入时做快照**——被治疗回到 30% 以上即刻脱离,再掉回阈值内即刻重新进入。
- **本身不提供任何加成**:背水只作为**其他效果的触发条件**,收益全部来自挂靠它的天赋 / 遗物 / 技能。
- 玩法侧的背水流构筑(Prep 阶段主动拒绝恢复)见 [[run-loop|08 - Run 循环]];状态注册表见设计库 `/api/states`(条目 `beishui`)。

## 单位回合流程

### 标准行动流

```
[单位回合开始]
  → 结算标明在此时生效的状态
  → 检查单位能否行动

[单位行动阶段]
  → 移动
  → 攻击或使用能力
  → 结束单位回合

[单位回合结束]
  → 结算标明在此时生效的状态
  → 更新已经完整经历相应时段的状态持续时间
  → 移除已经结束的状态
```

一般情况下，单位先移动再攻击或使用能力；完成攻击后不能继续移动。条目明确允许时，可以改变这一顺序或重新获得行动。单位也可以只移动或原地结束回合。

状态不再统一规定在回合开始时生效，也不再统一规定在回合结束时减少持续时间。每项状态效果的生效时机与持续时间口径见 [[state-system|状态体系]] 和规则 R3.4。

### 行动阶段变体

| 类型 | 流程 | 来源 |
|------|------|------|
| 标准 | 移动 → 攻击或使用能力 | 默认 |
| 提前使用能力 | 使用能力 → 移动 → 攻击或使用能力 | 条目明确允许 |
| 再行动 | 移动 → 攻击或使用能力 → 重新获得行动 | 条目明确允许 |
| 只移动 | 移动 | 玩家选择 |
| 待机 | 无 | 玩家选择 |

## 效果时机双型(规则锚:R1.4)

| 时机 | 触发条件 | 常见用途 |
|---|---|---|
| on-hit | 直接伤害段命中后触发，不要求最终造成实际伤害 | 施加状态、标记 |
| after-damage | 本段伤害与伤害包完整施加后触发 | 吸血、资源获取、伤害结果相关效果 |

设计库触发事件与两类时机的对应关系如下：

- **命中时、暴击时**属于 on-hit。每个实际发生的直接伤害段分别产生对应事件。
- **命中后、造成伤害时**属于 after-damage。命中后不读取实际伤害数值，伤害为0也可以触发；造成伤害时要求实际伤害大于0。
- **击杀时**在本伤害段及其直接触发完成、目标被判定死亡后发生。一个伤害包至多产生一次击杀事件。
- 附伤沿用来源命中，不另行产生上述命中、暴击或造成伤害事件；追加攻击是新攻击，正常产生自己的事件。

逐事件字段归属见 [[talent-design-principles|天赋设计原则]] §10。
