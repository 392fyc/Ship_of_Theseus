D1 — L1 Global Meta Layer Spec

S3-side-sot · 2026-05-10 · Stream D1 stage2_proposal · parent: architecture-consensus-v2

1.L1 是什么

L1 = run-外永久 horizontal-only 解锁池。 任何 Meta 等级下，已解锁内容必须支撑完整核心玩法。
禁止任何 vertical power: 起始 HP/ATK 直加、敌人弱化、核心机制锁后。

种子需求 (用户已确认):

  • 职业解锁
  • 提升一些收益 (经济倍率)
  • 给予轻微初始属性
  • 允许玩家复活
  • run 起始赠 1 个肉鸽道具 (符文)

本 spec 在此基础上扩成 6 大类完整池, 配 cap、解锁源、horizontal 验证.

2.解锁池分类树 (SVG)

6 大类互不影响 vertical power, 仅扩选项空间. 大类 E 风险最高 (经济类倍率最易越界, 严控)。

6.Run 起始决策流 (SVG)

L1 在 run 起始 4 步注入 + 死亡路径的复活分支. token 是稀有资源, 单 run 上限 1 次, 有 stage 倒退代价.

7.复活 + 起始符文 决策 (consensus §8 OQ)

7.1 复活机制

维度决策理由
消耗稀有资源 revive_tokenfree 等于隐式 vertical, 必须 cost gate
来源L1 永久持 1 个 + Act boss 给 1 (上限 2 持)跨 run 不积压 (持有 reset)
触发全灭瞬间手动确认不自动, 防误用
复活后HP 50%, talent/装备/符文保留, stage -1"回血窗口" 而非 "免死"
单 run 上限1 次严格. 即便持 2 个也只能用 1

7.2 起始符文

维度决策
选项数1→2→3 选 1 (3 阶解锁)
池子玩家已解锁 Rune Pool (经济 + 流派 50/50)
稀有度≤ uncommon, 严禁稀有及以上 (防 power spike)
占用 slot占 L5 6 格中第 1 格
玩家可重抽?否 (1 次推送)
