TL;DR — SoT L3 成长采用简化 FE Three Houses 加性模型: class baseline growth + advancement delta. 每升级按 growth% 概率获 +1. Advancement delta 强制至少 1 个 stat ≤ 0 (避免 Engage 的 strict-dominance bug). v1 10 advancement 通过 dominance 检验. L5 经济类符文通过 EXP × stat-growth × talent-drop 三个 hook 接入.

1. 模型选择

Model核心优势风险判定
FE Three Houses (additive) class growth + char growth, advancement delta 可正可负 模块化清晰；易避免 strict dominance 无 char-innate 时全靠 class 撑多样性 SELECTED
FE Engage 同上 + stat caps + 直接 stat bump 转职瞬间反馈强 "no upside to base class" — 违反 D3 OQ REJECTED
XCOM Hybrid promotion 给固定 +N, 无 RNG 数值确定 失去 RNG 张力, 与 roguelite 弱耦合 FALLBACK
SoT 简化版 (核心公式) 
Lv N→N+1 时, for each growable stat:
  effective_growth = base_class.growth[stat]
                   + (advancement.growth_delta[stat] if advanced else 0)
                   + Σ(rune.growth_bonus[stat] for rune in equipped)
  effective_growth = clamp(effective_growth, 0, 95)
  if random() < effective_growth / 100:
    unit.stat[stat] += 1

简化点: SoT 无 character-innate growth, "class baseline" 直接承担, advancement 提供 delta override 可正可负.

5. Dominance 检验

验证准则: 任何一条 advancement, 在最有利 build 场景下, 不应使另一条 advancement 在所有场景中变得无意义.

6. L5 经济类符文 → L3 Hook

Hook公式接入点典型符文单 rune 上限6 rune 极端
A — EXP Multiplier unit.gain_exp(amount × multiplier) Apprentice Tome (+30%) +50% +200%
B — Per-Stat Growth effective_growth += rune.bonus[stat] Iron Heart (+10% HP), Witch's Catalyst (+15% MAG) +20%/stat +60%/stat
C — Talent Drop Rate awarded = base + bonus Scholar's Pendant (+1/combat) +1/combat +3/combat
单 rune 边界约束: stat growth bonus ≤ +20% (避免 1 rune 超 advancement delta 影响力 → 维持 L5 经济类 vs L2 advancement 边界清晰).
