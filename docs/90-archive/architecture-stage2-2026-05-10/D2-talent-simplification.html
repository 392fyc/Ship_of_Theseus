2. Per node-type 简化决策规则

2.1 三个判定维度 (FNG)

给定一个节点, 用三个正交维度判定:

  • F · 功能性 (Functional): 改变行为 (新动作, 反应触发, 状态机, 攻击方式改变, 槽位解锁)
  • N · 数值性 (Numeric): 仅修改既有公式常量 (ATK%, +flat stat, +% resist) 不改变行为
  • G · 量谱耦合 (Gauge-coupled): 与某 gauge (剑气/魔刃/势/明/剑元) 直接绑定的产生或消耗

保留 L2 硬条件: F=true 或 G=true. 迁出条件: F=false 且 G=false.

关键变化: passive 从 49 → 29 (-20), 其他 type 不变. 简化集中在 passive 子集. 整体节点数 83 → 60 (-23, 27.7% 缩减).

4.1 简化前后真功能性占比

真功能性 = 不含纯数值/条件数值 passive 的节点占比.

  • 简化前 (83 节点): 真功能性 ≈ 41% (~34 / 83)
  • 简化后 (60 节点): 真功能性 ≈ 92% (~55 / 60)

含义: 简化的核心收益不是节点数减少, 而是 每个保留节点都是有意义的功能选择, 玩家在 run 内升级时面对的不再是 "+5% A 还是 +5% B" 这种填充选择.

7. 5 v1 职业可推广性

职业规则适配预期保留关键 passive 类型风险
Swordsman High ~60 gauge-coupled, 反应触发 无
Mage High ~50-55 元素抗性 / 元素穿透 → L5 比例高 无
Knight Mid ~45-50 反伤类 (条件触发) + 嘲讽 (功能) 条件触发 passive 多, L5 比例可能偏高
Cleric High ~40-45 治疗 active, 圣属性穿透 无
Archer High ~40-50 射程+1 (功能), 暴击+% (L5) 无
Soldier Mid-Low ~35-40 baseline, 缺乏明显流派 需设计干预补功能性 passive

5 v1 职业平均: ~45 节点 / 类. 全 5 类合计 ~225 L2 节点. 简化收益明显且规则可推广.

警示: Soldier baseline 类需要额外设计干预 (赋予更多功能性 passive 或重新定位). Stage 3 D3 + designer 应特别关注.
