# Web Research Convergence Rules

## Research Task Levels

### L1 Precise Query
- Trigger: Clear target (version number, API usage, specific tool)
- Boundary: Max 3 searches, stop on find
- Example: "Godot 4.6 TileMap API", model version confirmation

### L2 Directed Survey
- Trigger: Clear scope (asset search, solution comparison)
- Boundary: Max 5 searches + 3 page fetches
- Deliverable: Must output structured comparison table
- Example: "itch.io GBA-style sprite packs, commercial license"

### L3 Open Research
- Trigger: Broad scope (competitive analysis, design reference)
- Boundary: Must define deliverable format + termination criteria
- Requires: Main Agent approval before execution
- Example: "TRPG turn order UI design references"

## Mandatory Fields for Every Research Task
1. Objective: What specific question to answer
2. Deliverable: Output format (table, list, or conclusion)
3. Termination criteria: When to stop searching
4. Upper bound: Max search count + max page fetch count

## Enforcement
Research tasks without termination criteria MUST be rejected. The agent must request the dispatcher to supplement before executing.
