第一章 机制定位

1.1 四条构筑轴

剑圣 = 物理单体爆发 + 位移机动 + 防御反打。（构筑轴随天赋池重做，旧四轴 燕返/背剑式/剑风/疾风怒涛 待步骤③重定。）

1.2 资源系统 ｜v4.2 重构：剑气 0-10 + 剑意印记 0-3

剑气（0-10 整数小尺度）：初始 0、上限 10、跨回合保留、跨战斗清零、无衰减。
收入：斩击命中 +1 / 居合直接击杀返 3 / 招架成功 +1（天赋「守心」，非基础）/ 节点声明项。一闪不产剑气；反击不产剑气；自动类/溅射不自带剑气。
支出：招架开启 -1 / 一闪 -1 / 居合 -6 / 拔刀 -2。
心眼（被动）= 剑气持有加成：每 1 点剑气 +1% 暴击率（Engage 暴击公式的技能型加项）；剑气 ≥7 速度 +1 → 剑气是持有型续航资源，每点立即转化为面板，不鼓励囤积。
哲学命门：常态维持高剑气吃心眼暴击；奥义（居合）一次性倾泻的爆发收益应略低于「维持高剑气稳态」——否则退化为「攒满即放奥义」。这是 v4.2 第一个要压的数值（审查点 12）。
剑意印记（0-3 离散，替代旧剑意层）：三枚印记，各限 1、最多 3、不衰减、跨战斗清零。心(+2 技巧 DEX) / 道(+2 幸运 LCK) / 势(+2 力量 STR)。
获取：斩击命中 → 随机得一枚自身尚未持有的；居合走完整 combat 后（含反击结算）→ 随机得一枚自身尚未持有的（满 3 为空集）。
满 3 兑现：招架槽变拔刀（此时不能招架，防御真空）= 主动放弃招架换 +6 属性的风险敞口，逼倾泻拔刀回零。
旧剑意天赋作废：剑心通明/斩铁/心剑合一随底层大改作废，步骤③重做。

1.3 行动经济

1 移动 + 1 标准 + 1 迅捷。击败每个大关 BOSS 选「标准 +1」或「迅捷 +1」；前期稀缺（迅捷槽竞争）是有意取舍。

1.4-1.7 其他（未变）

combat = 火纹式（射程允许被攻击方反击）；绕过 combat 危险，双口径登记。敌 AI = 火纹逻辑。敌群免疫由敌人侧声明。抽选：稀有度里程碑制，满级 20，自由点 20，锚点事件化（免费 4 选 1），取消渐进解锁（4 锚 Lv1 全开放）。（注：R6.10 已定方向「原 Lv1 锚点取消、技能变形并入 Lv5 转职」，待剑仙立项执行。）

第二章 基础技能 ｜v4.2 五技能定稿

2.1 普攻（斩击）｜标准行动｜定稿

斩击：距离 1，标准行动，物理，combat。对 1 格距离敌人 100% 物理。命中 +1 剑气。转职剑圣后追加：命中随机得一枚自身尚未持有的剑意印记（满 3 时为空集不再得）。
转职前仅 +1 剑气、不产印记；印记系统随 Lv5 转职解锁。v9：追击系统移除（方案2），斩击不再「可触发追击」。

2.2 一闪 ｜移动行动｜滑行规则｜cd 3｜定稿：消耗 1 剑气，不产剑气

指定方向位移至最远可进入格（最多 4、至少 1，无法位移至少 1 格则不可用），途经敌人 50% 物理。cd 3，消耗 1 剑气。不产剑气（消耗型位移技）。途中 area 不触发反击；滑行多次离开不同控制区各 -2。

2.3 招架 ｜迅捷行动｜定稿：cd 1，消耗 1 剑气

招架：自身，迅捷行动，cd 1，消耗 1 剑气。对自身附加 3 层「格挡预兆」，持续 1 回合。每当将受直接伤害时消耗 1 层判定——以速度%（SPD，待定）概率减免本次伤害 50%（成功 = 招架成功；本游戏无敏捷属性）。
满 3 印记时招架槽变拔刀，此时不能招架（防御真空）。基础招架不再自带回剑气——「招架成功 +1 剑气」归口为天赋「守心」（步骤③重做）。
低成本高频施放，但与一闪/拔刀争剑气；满印记时强制下线。「招架成功」= 单层判定通过，一次施放最多 3 次。

2.4 奥义·居合（一之太刀）｜标准行动｜combat｜定稿

居合：奥义，距离 1，标准行动，物理，combat，cd 3，消耗 6 剑气。对 1 格距离敌人 300% 物理，必定暴击（被格挡则不暴，R1.1）。若直接击杀目标，返还 1 cd（冷却清零）+ 3 剑气。走完整 combat 后（含目标反击结算完毕）随机得一枚自身尚未持有的印记（满 3 为空集）。
调参命门：一次倾泻 6 剑气（满条 60%）的收益应略低于用同等剑气维持心眼暴击稳态（审查点 12）。

2.5 拔刀 ｜标准行动｜combat｜满 3 印记替换招架槽｜v4.2 新增定稿

拔刀（满 3 剑意印记解锁，替换招架槽）：距离 1-2，标准行动，物理，combat，无 cd（与招架独立 cd——招架仍 cd 1）。消耗全部 3 枚印记 + 2 剑气。对 1-2 格敌人 180% 物理；暴击时暴击倍率额外 ×1.5（暴击桶内技能型乘数、非第四乘区 R3.12，基础暴击之上再 ×1.5，例 200%→300%）；命中后对主目标周围 1 格「50% × 本次实际物理伤害」（强制命中，各自算减免，area 不触发反击）。
定位：满印记（+6 属性 / 放弃招架的防御真空）的倾泻出口——累积印记一次性兑现为高倍爆发，打完回 0 印记重进招架防御态。剑意印记循环的「呼气」。
R2.5 行动预算豁免（属基础技能形态切换、比照奥义本体）；周围溅射登记 combat 绕过清单。审查点 15。

2.6 奥义·剑域（八方）｜⚠ 名实待结构决策 + 剑气待重铺

⚠ 本节剑气数值仍是旧 0-100 模型，待结构决策后随天赋池重铺（步骤③）。 80 剑气，cd 3：2 格内 1 名主目标 130% 物理完整 combat；其余敌人溅射 130%（area 不触发反击）。每命中 +5 剑气；若剑意已觉醒，每命中额外 +1 层剑意。
⚠ 名实冲突：「八方剑域」近「剑阵」，与剑仙剑阵冲突，群体/场域形态更偏中国修仙 → 归属（剑圣改名保留 vs 划归剑仙）取决于剑圣/剑仙结构决策。
⚠ v4.2 待重做：+5 剑气 / 觉醒 +剑意层 基于旧资源模型，与 0-10 剑气 + 0-3 印记不兼容，不入本轮 critic 技能组审查。

2.7 剑意印记系统 ｜v4.2 定稿：0-3 离散收集

剑意印记（剑圣转职后解锁）：三枚离散印记，各限 1、最多 3、不衰减、跨战斗清零。心(+2 DEX) / 道(+2 幸运 LCK，防御/效用向) / 势(+2 STR)。
生成：斩击命中得一枚自身没有的 + 居合使用后得一枚自身没有的（两进账口：斩击高频小步、居合一次性补位）。兑现：满 3 → 招架变拔刀；拔刀消耗全部 3 + 2 剑气倾泻回 0。
vs 旧剑意层：旧 0-5 层是「暴击→积层→衰减→觉醒门控」连续系统（机制重、UI 噪声大、与新剑气哲学冲突）；新印记 = 离散三态收集 + 满即兑现的呼吸循环（吸气集印记吃 +2 属性 → 屏息满 3 招架真空高风险 → 呼气拔刀回零）。无衰减计时、无层数 UI，只需 3 个布尔位 + 拔刀解锁判定。

2.8 被动「心眼」 ｜v4.2 定稿：剑气持有加成

心眼（常驻）：每持有 1 点剑气 +1% 暴击率（Engage 暴击公式的技能型加项）；剑气 ≥7 时速度 +1（评审团后由 >7/+2 下调）。
重设计（旧敏捷差暴击率作废）：心眼现与剑气绑定，把剑气从消耗弹药变成持有型续航资源——满剑气(10)= +10% 暴击 + ≥7 时速度 +1。每点立即转化面板、机制上不鼓励囤积。
咬合资源哲学：高剑气稳态心眼收益应略高于把剑气倾泻进居合的爆发——否则最优解退化为「攒满即放奥义」。「维持 > 倾泻」是 v4.2 核心调参命门（审查点 12）。意象：以内功（剑气）养出洞察（看破破绽=暴击）。

第七章 属性标定 + 战斗架构决策 ｜v4.3 新增

属性体系正本 = ADR-005（10 属性）+ D3 简化三houses 加性成长模型。本章对剑士/剑圣标定属性等级，并记录两项战斗架构决策。

7.1 属性体系（ADR-005，10 属性）

成长属性（升级按 growth% 概率 +1）：HP / STR(力) / MAG(魔) / DEX(技巧) / DEF(防御) / RES(魔防)。
固定属性（无成长）：SPD(速度) / MOV(移动) / VIS(视野) / LCK(幸运)。

幸运改固定（v4.3）：与火纹区分，幸运 = 固定特殊属性、全游戏无成长，剑士/剑圣初始 = B。连锁待后续：现 ADR-005/D3/代码仍把 LCK 列为成长属性，需改 KB+代码+JSON。
SPD 全程固定、不解禁成长（OQ-D3-1 解决为「否」，回拨上版「剑圣解禁」提案）：任何职业（含剑圣）速度都不成长，差异来自固定基础值 + 特殊来源（心眼「剑气≥7 速度+1」/装备/符文/天赋；道印记现给幸运 LCK、不再给速度）。理由：追击移除后速度=闪避+出手顺序，成长会让出手顺序滚雪球、闪避后期逼近 100% 退化；落进 build 层更契合肉鸽，且与已锁定的心眼「特殊修正固定速度」一致。

转职变化（v4.3）：成长侧仅 DEX A→S；固定侧 SPD 档 B→A。全程零降属（DEF/HP 维持 B）。
为何零降属成立：Lv5 转职强制（无「停在剑士」选项），D3「至少一项负 delta 防白嫖」的理由不适用；剑圣 vs 剑仙靠 focus 不同（剑圣=DEX暴击精准、剑仙=STR/MAG混合）天然不互相支配。
⚠ 成长预算偏低：剑圣成长 delta 仅 DEX 一项，低于 D3 +30~60 预算 → 机制驱动型转职（价值在居合/印记/拔刀/心眼 + 速度固定值 B→A）。同步 D3 时需接受例外或补少量成长。
角色幻想：快速精准决斗者——高 DEX 暴击机 + A 档固定高速（抢先手+中等闪避）+ 中等物理血防 + 魔法脆弱（MAG/RES C）。靠出手顺序抢先手、靠暴击/拔刀/居合爆发；物理能扛一下，被法师集火则脆（清晰 counter）。速度固定→闪避不随级膨胀→不退化为「摸不到的闪避坦」，需基础血防兜底。

7.4 战斗架构决策（v4.3）

决策一 — 速度机制方案2：速度第二效果 = 出手顺序（速度高者先行动），第一效果 = 闪避（spd*2，Engage 不变）。追击系统移除。
理由：技能形态多→追击仅翻倍普攻、结构性边缘化（剑圣居合/拔刀/一闪都不触发）；改速度→出手顺序让速度普适有意义。
连锁：追影天赋作废（步骤③）、斩击「可追击」删除、R1.9 标注「Engage 公式 + 速度排序出手」混合。
⚠ 出手顺序系统 = 独立 ADR 立项（待设计）：SPD 固定 → 出手顺序 = 职业固定基础 + build 修正 + 战内状态（心眼「剑气≥7 速度+1」），可随剑气动态变化（道印记现给 LCK、不参与速度）。开放问题（R2.8）—— 排序模型（CTB/ATB/固定排名）、与行动经济（1移动+1标准+1迅捷）咬合、平局、速度修正叠加上限（固定基础+心眼+装备/符文不得无限堆叠致先手垄断；Fell Seal 先例，cap 须随 ADR 同步）、AI 适配、UI。本轮只锁方向，不设计系统本体。
决策二 — 幸运改固定（见 7.1）：与火纹区分，无成长，固定签名属性（剑士/剑圣=B）。
