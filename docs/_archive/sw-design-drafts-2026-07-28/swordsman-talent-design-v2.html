4. 关键机制裁定（五轮沉淀）

三桶制结算（R3.12）：技能倍率桶（乘算入口）× 增伤词缀桶（桶内加算）× 暴击桶（独立，pure 锁 1.5x）。新增/替换伤害实例的基础倍率属①桶。
事件 vs 奖励路径（R0.8 / R3.13）：锚点改写默认只动奖励路径，事件挂接的节点照常生效（守心 × 背剑式判例通用化）；改写者承担引用者清单 + 适配义务。
冷却经济干预（R0.9 / R2.3）：重置/无视/缩减/替代限制器干预统一管辖，全模组唯一出口 = 剑心通明（限一闪）；传奇冷却结构改写承担适配 + 压测义务。
反应类自动化（R0.6 / R3.11d）：归类按设计本体的「有意义放弃理由」判定，自动化设置不改变结算归类；默认自动须保留改询问入口。
升级档强度封顶（R5.5a/c）：四级强度类别 × 稀有度封顶表；质变级内容不入升级档（R2.3 特许档除外）；传奇默认 1 级（数学强制）。
回合外剑气防永动：反击不产剑气（含守势）；回合外收入须显式声明 + 观察清单登记（含锚点敏感变体行：剑风局顺势斩净 0 / 见切净 -15、疾风局见切净 0）；全局硬上限仅为兜底不默认启用。

5. ⚠ 待用户裁定 6 项（决策就绪，附录 K）

#1 背剑式系回合外剑气收入：3 敌场景单次招架成功 ≈40 剑气（基准 4 倍），是否追加针对性规则？现状：观察中，无规则
#2 一闪·极覆盖真闪「储存 1 次」机制（改为本回合首闪免费）是否符合锚点意图？现状：适配条款占位
#3 无刀取对 BOSS 级单位是否免疫？现状：BOSS 免疫（占位）
#4 敌方 AI 是否做威胁规避（绕 ZOC / 不攻击招架者）——招架构筑线整线存活前提。现状：上提中，设计侧不假设（XCOM 2 / BG3 先例在案）
#5 背剑式「不会进行反击动作」文义：状态级压制（现默认：招架状态期间守势被压制）还是仅指招架自身反击？现状：字面读法落稿，窄读法有书面回退路径
#6 招架与姿态切换的迅捷槽共存规则（迅捷拥堵的结构阀）。现状：未定，监控级（矩阵已标注反协同）
