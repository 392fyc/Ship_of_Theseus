# Action Economy UI/UX and Turn Flow Design Spec

> Status: **Finalized** (Post Self-Audit V4)
> Related: [[turn-system]], [[skills-and-range]], ADR-009

## 概述 (Overview)
本文档规范了 Action Economy 系统的 UI/UX 设计与回合流程交互。此版本融合了传统 SRPG（如火焰纹章）的"先移动、再行动"的阶段式推进，以及底端一体化控制台的现代化 UI 设计。

---

## Area 1: 技能面板与底部控制台 (Skill Panel UI Design)

### 布局与位置 (Layout & Position)
- **底部综合控制台 (Bottom Dashboard)**: 屏幕正下方区域作为核心 HUD，包含角色信息和操作菜单。最终版本会将**人物基本信息 (HP/属性等)、装备、天赋**整理划分在屏幕下方。
- **主操作菜单 (Primary Action Menu)**: 底部控制台核心交互区的指令集菜单：
  - **[ 攻击 (Attack) ]** — 进入普通攻击瞄准模式（仅在攻击阶段可用）
  - **[ 技能 (Skill) ]** — 展开右侧技能条
  - **[ 道具 (Item) ]** — 预留
  - **[ 结束回合 (End Turn) ]**
- **技能条 (Skill Bar / Secondary Menu)**: 
  - 默认隐藏。点击 **[ 技能 ]** 后在主菜单的右侧/同区域平齐位置平滑展开。
  - 水平横排显示角色当前携带的技能指令。
  - **动态过滤**: 根据当前阶段过滤可用技能:
    - 移动阶段: 高亮 **Move + Swift** 技能，Standard 技能灰色不可点击
    - 攻击阶段: 高亮 **Standard + Swift** 技能，Move 技能灰色不可点击
  - 不可用技能仍然可见（附 Tooltip 说明原因）

### 视觉反馈与动画 (Visuals & Animation)
- **进出场**: 选中我方可行动角色时，底部控制台从屏幕下方滑出 (`ease_out`, 0.25s)。取消选中或回合结束时滑下隐藏 (`ease_in`, 0.2s)。
- **技能条展开**: 从主菜单右侧水平滑出 (`ease_out`, 0.15s)。
- **按钮状态**:
  - **可用**: 正常显示，鼠标悬浮时高亮/发光反馈。
  - **资源不足/时机不符**: 变暗 (modulate `0.5, 0.5, 0.5`)，禁止点击。
  - **冷却中**: 半透明黑色遮罩 (70% opacity)，居中显示冷却回合数字。

### 敌方角色信息 (Enemy Info Display)
- 点击敌方角色: 底部控制台以**只读模式**显示敌人信息（HP/属性/状态），不渲染操作菜单。右键/ESC关闭。

## Area 2: 技能展示样式 (Skill Display Style)

### 消耗类型可视化 (Action Cost Iconography)
技能图标左上角角标标识消耗类型：
- **移动类 (Move Cost)**: 蓝色角标（靴子图标）。颜色值: `#3b82f6`
- **攻击/标准类 (Standard Cost)**: 橙红角标（剑图标）。颜色值: `#f97316`
- **迅捷类 (Swift Cost)**: 绿色角标 `◆`。颜色值: `#10b981`。统合为不占用移动和攻击阶段核心资源的技能。
- **Reaction 技能**: 技能条中以灰色被动标识展示，**不可点击**，仅供参考。

### 不可用原因提示 (Unavailability Reason)
Tooltip 末尾红色字体显示不可用原因：
- "已失去移动机会" / "攻击机会已使用" / "冷却中 (X 回合后恢复)"
- "需要在移动前使用" (timing_constraint: before_move)
- "当前处于移动阶段，请先完成移动" (Standard 技能在移动阶段不可用)

## 设计边缘场景与系统闭环 (Design Edge Cases & Finalized Rulings)

### 1. 强制阶段推进: 移动阶段必须先结束
- **Ruling**: 采用火纹式的**强制阶段结束**设计。玩家必须先完成移动阶段（移动到某处，或"原地确认"跳过移动），攻击/Standard 类选项才会解锁。
- **原地不动的操作方式**: 点击角色自身所在格子 / 点击主菜单的 [结束移动] 按钮，视为放弃本回合移动，进入攻击阶段。
- **移动阶段内可用操作**: 普通移动、Move Cost 技能、Swift 技能（如 timing 允许）。

### 2. 原地攻击与"攻击后再动"的资源处理
- **Ruling (默认消耗规则)**：执行攻击或 Standard 技能后，也会**一并清空 Move 资源**。确保"走位 → 动作 → 结束"节奏。
- **系统闭环**：Canto/Hit-and-Run 天赋或技能在生效时"保留或返还"Move 资源。默认消耗的基底设计正是为了让这类高级天赋产生价值。

### 3. 迅捷 (Swift) 技能的菜单常驻
- **Ruling**: 当 Move+Standard 已消耗，但 Swift 资源未用时，主菜单**不会完全关闭**。隐藏 [攻击]/[道具]，仅保留 [技能(Swift)] + [结束回合]。

### 4. "返回/撤销定位" (Undo Move)
- **Ruling (火纹式撤销)**: 移动后，**只要尚未执行攻击/技能，就能撤销**。
  - 移动到位后弹出主菜单（攻击阶段）。
  - 右键/ESC/点击 [取消] 按钮 → 角色传送回移动前起始点，Move 资源恢复。
  - 一旦执行了 [攻击] 或 [技能]，移动被彻底"锁定"。

### 5. Move Cost 技能自带伤害后仍可进入攻击阶段
- Move Action 技能仅消耗 Move 资源，不消耗 Standard。使用后仍可进入攻击阶段。

### 6. 攻击前的伤害模拟预览 (Combat Forecast)
- **Ruling**: 在确认攻击/攻击类技能前，必须弹出**火纹式伤害模拟窗口**，预览本次攻击的命中/暴击/伤害/反击等信息。玩家确认后才执行攻击。

## Area 3: 操作触发机制与交互逻辑 (Action Trigger Timing)

### 键鼠双交互模式 (Dual-Control Scheme)
系统支持**全鼠标**与**全键盘**的无缝双发交互：
- **热键支持 (未来设计)**: 保留热键绑定机制，以备未来设置。
- **全鼠标交互**: 
  - 左键点击角色: 选中/查看信息
  - 左键点击蓝色高亮格: 执行移动
  - 左键点击目标: 确认攻击/技能
- **右键功能分离**:
  - **短按释放 = 取消操作**（取消技能/退回菜单/撤销移动）
  - **按住拖拽 = 平移视角**
- **显式取消按钮**: UI 中常驻 **[取消]** 按钮，供不习惯右键操作的玩家使用。

### [攻击] 按钮交互流程 (Attack Button Flow)
1. 点击 **[攻击]** → 棋盘高亮普通攻击范围（基于武器射程）
2. 悬停敌方目标 → 弹出**伤害模拟预览** (Combat Forecast)
3. 左键点击目标 → 执行攻击 → 消耗 Standard + Move 资源
4. 右键/ESC/[取消] → 退回主菜单

### 技能触发流程 (Targeting Flow)
1. 点击 **[技能]** → 展开技能条
2. 点击可用技能（或热键 1-9）
3. 进入瞄准模式，棋盘高亮射程+AOE预演
4. 悬停目标 → 弹出**伤害模拟预览**（若为攻击类技能）
5. 左键确认 → 执行；右键/[取消] → 退回技能条

## Area 4: 回合流程与操作节奏 (Turn Flow Rhythm)

### "火纹式" 阶段推进 (Fire Emblem-like Phased Turn)

1. **移动阶段 (Move Phase)**
   - 选中角色 → 底部控制台弹出 + 棋盘显示移动范围
   - 可执行: 普通移动、Move Cost 技能、Swift 技能
   - **不可执行**: [攻击]、Standard Cost 技能（灰色禁用）
   - 结束方式: 移动到某处 / 点自身格子原地确认 / 点 [结束移动]

2. **攻击阶段 (Action/Attack Phase)**
   - 移动阶段结束后解锁
   - 可执行: [攻击]、Standard Cost 技能、Swift 技能
   - 执行 Standard 动作后 → Standard + Move 资源一并扣除

3. **自由穿插: Swift Actions**
   - 可在移动前、移动后攻击前、攻击后结束回合前的任意时机使用

### 回合结束行为 (End Turn Behavior)
- 玩家随时可点 **[结束回合]**。
- Move + Standard 都已消耗且无可用 Swift → 自动结束（可在设置中开启/关闭）。

## UI 状态机 (State Machine for Dev Implementation)

| 状态 | 描述 | 底部控制台 | 棋盘显示 |
|------|------|-----------|---------|
| **S0 (Idle)** | 无角色选中 | 隐藏 | 无高亮 |
| **S1 (MovePhase)** | 选中我方角色 | 滑出；[攻击]灰色禁用 | 蓝色移动范围 |
| **S2 (ActionPhase)** | 移动完成（可撤销） | [攻击]+Standard解锁 | 清除移动范围 |
| **S3 (SkillTargeting)** | 选中某个技能 | 技能高亮 | 红色技能射程 |
| **S4 (AttackTargeting)** | 点击[攻击] | [攻击]高亮；显示伤害预览 | 红色攻击范围 |
| **S5 (SwiftPhase)** | Standard+Move已消耗 | 仅 [技能(Swift)]+[结束回合] | 无高亮 |
| **S6 (TurnEnd)** | 回合结束 | 滑下隐藏 | 无高亮 |

### 状态转换

```
S0 → (选中我方角色) → S1
S1 → (点蓝格移动) → S2
S1 → (点自身格/[结束移动]) → S2 (原地，可撤销)
S1 → (使用Move技能) → S2
S1 → ([结束回合]) → S6
S2 → (右键/ESC/[取消] 撤销移动) → S1
S2 → ([攻击]) → S4
S2 → ([技能]→选Standard/Swift技能) → S3
S2 → ([结束回合]) → S6
S3 → (左键确认目标) → 执行 → S5 或 S6
S3 → (右键/[取消]) → S2
S4 → (左键确认敌人) → 执行攻击 → S5 或 S6
S4 → (右键/[取消]) → S2
S5 → (使用Swift技能) → S5
S5 → ([结束回合] / 自动结束) → S6
```

### timing_constraint 在阶段推进下的语义映射

| 原始约束 | 阶段推进语义 | 示例 |
|----------|------------|------|
| `any` | 移动阶段或攻击阶段均可使用 | 大多数技能 |
| `before_move` | 仅在移动阶段开始时（角色尚未移动）可用 | 骑士"防御姿态" |
| `after_move` | 仅在攻击阶段（角色已完成移动阶段）可用 | 剑士"追击斩" |
| `before_attack` | 攻击阶段内、执行攻击之前可用 | 弓手"瞄准" |
| `after_attack` | 攻击执行之后可用（仅限 Swift Phase） | 特殊after-action buff |
