# 03 - 战斗计算系统(Battle Calculation)

> Back to [[game-design-doc|GDD]]
> 规则权威:设计库规则表(战斗计算域 R1.x),全量索引见 [[rules-catalog|规则总目录]]。本章为展开文档;涉及公式处均给出中文名与代码变量名(英文 = 代码变量名)。

## 概览

战斗计算 = 三条判定链(命中/暴击/伤害)+ 通用修正代数:

- **伤害**:加法基础层(攻击属性 + `weapon_might` − 对应防御,点数直减、面板可心算)× 外层乘区(技能 × 地形 × 暴击 × 遗物 × 最终,按比例放大)。
- **命中/暴击**:加法模型,四层公式量串联,全来源透明,玩家可精确计算。
- **全属性可见**:敌方 HP 与属性精确显示。
- **伤害类型双轴**:属性类型 × 攻击方式,由技能/天赋/遗物声明——武器不区分伤害类型。
- **武器参数**:`weapon_might` / `weapon_hit` / `weapon_crit` 唯一来源 = 所装备武器(R1.8)。

## 九属性体系(规则锚:R2.1)

```
UnitStats:
  STR  力量:物理攻击(physical / hybrid 伤害)        成长
  MAG  魔力:魔法攻击(magical / hybrid 伤害)         成长
  DEX  技巧:基础命中 + 基础暴击派生源                成长
  SPD  速度:出手顺序 + 闪避派生源                    成长
  LCK  幸运:暴击回避基值 + 减益抵抗(运气轴)         固定
  DEF  防御:物理减伤(伤害加法层直减)                成长
  RES  抗性:魔法减伤(伤害加法层直减)                成长
  HP   生命                                           成长
  MOV  移动力(格)                                    固定
```

7 成长(HP/STR/MAG/DEX/SPD/DEF/RES)+ 2 固定(LCK/MOV)。固定属性不随升级,只由初始/转职/天赋/遗物/装备改变。视野机制 v1 不做(无 VIS 属性)。

### 属性在公式中的角色

| 属性 | 公式角色 |
|-----------|-------------|
| STR | physical 基础伤害:`max(1, STR + weapon_might − target.DEF)` |
| MAG | magical 基础伤害:`max(1, MAG + weapon_might − target.RES)` |
| DEX | 人物基础命中 `base_hit`(DEX×2)+ 人物基础暴击 `base_crit`(DEX/2) |
| SPD | 出手顺序(R3.1)+ 闪避 `avoid`(SPD×2) |
| LCK | 暴击回避 `crit_avoid` 层基值 + 减益抵抗(R1.6);技能系数/天赋效果可显式关联 |
| DEF | 物理防御(伤害加法层直减) |
| RES | 魔法防御(伤害加法层直减) |

LCK **不参与命中/闪避**:LCK 为固定属性,战斗触点收敛为「坏事发生率」——被暴击与吃异常;roguelite 层为其预留主场。

## 武器参数(规则锚:R1.8)

武器基础参数仅三项,唯一来源 = 所装备武器(职业不自带武器档案):

| 中文 | 变量名 | 公式挂点 |
|---|---|---|
| 武器威力 | `weapon_might` | 基础伤害加法层(R1.1) |
| 武器命中 | `weapon_hit` | 人物基础命中(R1.2) |
| 武器暴击 | `weapon_crit` | 人物基础暴击(R1.3) |

- **不允许空手**:每单位恒持一件武器,不可卸、只可替换;初始武器由职业配置决定。敌方单位同口径发配武器(敌方武器参数 = 威胁调控杠杆)。
- **武器不区分伤害类型**:physical/magical/pure 由技能/天赋/遗物声明,`weapon_might` 通用进对应公式。
- **武器不管理射程**:射程归技能/天赋/遗物。
- 属性键(STR/DEX 等)不属武器基础参数,归词缀层(词缀体系另议);武器类别与职业限装另行定义。

## 公式量分层与修正代数(规则锚:R1.9)

### 分层总则

命中/暴击/伤害三链分层,**每个公式量 = 一层 = 独立乘区,每层都可被效果作用**。

- 层基值 = 上一层输出(或属性/武器合成式)。
- 改属性的效果(如「DEX +2」)经属性进第一层基值;直接修正按措辞落层。
- `base_*` 用结算时点的当前属性值计算,不是开局面板快照。

### 修正代数

```
层结算值 = (层基值 + Σ平加) × (1 + Σ提升%) × Π(1 + 各「额外提升%」)
```

| 算子 | 规范措辞 | 算法 | 英文 |
|---|---|---|---|
| 平加 | 「X +N」 | 同层直接求和 | flat / gain |
| 提升 | 「X 提升 N%」 | 同层**先加总再一次性乘**(20%+30% = ×1.5) | increased |
| 额外提升 | 「X 额外提升 N%」 | **各自独立连乘**(20%、30% = ×1.2×1.3 = ×1.56) | more |
| 无视/穿透 | 「无视目标 N% X」「无视 N 点 X」 | 攻方效果,作用在**对方量的消耗时点**:`Q_eff = Q × (1 − Σ无视%) − Σ无视点数` | penetration |

结算纪律:

- 层内顺序固定:平加 → 提升 → 额外提升。
- `clamp` / `floor`(命中 1-100、暴击 ≥0)是**最外层守门**,在最终层修正算完之后才执行。
- **中间量不取整,最终量向下取整**。
- **措辞→算子→落层的映射是硬规范**:天赋/遗物/词条文案必须使用规范措辞书写,保证审阅与实装可机判归层。

### 走链示例

武器 hit 60、DEX 9;天赋「基础命中提升 20%」、遗物「命中 +15」、敌闪避 40、技能「无视目标 50% 闪避」、buff「最终命中率提升 10%」:

```
base_hit = (60 + 18) × 1.2 = 93.6
hit      = 93.6 + 15 = 108.6
avoid_eff = 40 × 0.5 = 20
final    = (108.6 − 20) × 1.1 = 97.46 → clamp(1,100) + 向下取整 = 97%
```

## 命中判定(规则锚:R1.2)

| 中文 | 变量名 | 定义 |
|---|---|---|
| 人物基础命中 | `base_hit` | `weapon_hit + DEX×2` |
| 命中 | `hit` | 层基值 = `base_hit`,吃直接命中修正(天赋/遗物/建筑/buff) |
| 闪避 | `avoid` | `SPD×2 + terrain_evade_bonus` + 直接闪避修正;攻方「无视闪避」作用后 → `avoid_eff` |
| 最终命中率 | `final_hit_rate` | 以 `hit − avoid_eff` 为层基值经最终层修正后 `clamp(1, 100)` |

- `terrain_evade_bonus` = 防守方所在基础地形的闪避加成(如森林)。
- 命中下限 1 仅为兜底;正常对局玩家命中预期 60-70+(「玩家高命中」是设计基调,命中张力由闪避词条/地形/高 SPD 特化敌种提供)。

## 暴击判定(规则锚:R1.3)

| 中文 | 变量名 | 定义 |
|---|---|---|
| 人物基础暴击 | `base_crit` | `weapon_crit + DEX/2` |
| 暴击 | `crit` | 层基值 = `base_crit`,吃直接暴击修正(心眼剑气 `crit_bonus` 挂本层,见 R1.7) |
| 暴击回避 | `crit_avoid` | 层基值 = `LCK`;攻方「无视暴击回避」作用后 → `crit_avoid_eff` |
| 最终暴击率 | `final_crit_rate` | 以 `crit − crit_avoid_eff` 为层基值经最终层修正后 `max(0, ·)` |

### 暴击倍率

- ×1.5 是暴击倍率的**初始值**而非上限。非纯伤可经 `crit_damage_bonus`(加法叠加到 1.5)提高:
  - 剑圣拔刀 `crit_damage_bonus = 1.5` → 1.5+1.5 = ×3.0(暴击伤害 300%)
  - 天赋/遗物「暴击伤害 +20%」→ `crit_damage_bonus = 0.2` → ×1.7
  - 来源:技能 / 天赋 / 遗物 / 装备
- **pure 伤害默认不参与暴击判定**(需技能显式启用);启用后暴击固定 ×1.5,不受 `crit_damage_bonus` 影响。
- 暴击率无上限(最低 0%,无封顶);敌方高暴击经遭遇设计模板管控,不设系统上限。

## 伤害类型系统(规则锚:R1.1)

伤害采用**双轴分类**:属性类型(决定防御计算)× 攻击方式(决定特殊交互)。两轴由技能数据独立声明——**武器不区分伤害类型**。

### 轴 1 - 属性类型(互斥)

| 类型 | 基础伤害公式(层 1) | 暴击 | 备注 |
|------|-------------------------------|------|-------|
| physical | `max(1, STR + weapon_might − DEF)` | ✅ 参与暴击倍率加成 | 物理系职业 |
| magical | `max(1, MAG + weapon_might − RES)` | ✅ 参与暴击倍率加成 | 法系职业 |
| pure | `max(1, [源] + weapon_might)`,**无视全部防御**;受地形乘区影响 | 默认禁用;显式启用后固定 ×1.5,不受倍率加成 | 稀有高威力;源由技能 JSON 声明 |
| hybrid | ⚠️ **TBD**——待 ADR-006 定稿,代码勿引用 | ✅ 参与暴击倍率加成 | 双属性职业;打击较弱防御 |

**pure 攻击源(`pure_atk_source`,技能 JSON 声明)**:`"phys"` → STR;`"mag"` → MAG;`"sum"` → STR + MAG(仅稀有高威力技能)。

**零伤地板**:所有基础层计算取 `max(1, ·)`,有效命中至少 1 点伤害。

### 轴 2 - 攻击方式(技能声明)

| 类型 | 判定规则 | 备注 |
|------|-------------------|-------|
| melee | 技能射程仅 1 格 | 由技能数据声明,不受实际攻击距离影响 |
| ranged | 技能射程 > 1 格 | 即使实际打 1 格外目标仍算 ranged |
| area | 技能 AOE 覆盖多格 | 即使只命中单目标仍算 area |

**用途**:攻击方式主要用于特殊交互判定(如「受到近战伤害时反击」「远程伤害 +10%」、建筑耐久按攻击方式扣减等),不直接进伤害公式。

## 伤害公式(规则锚:R1.1)

| 中文 | 变量名 | 定义 |
|---|---|---|
| 基础伤害 | `base_damage` | physical `max(1, STR + weapon_might − target.DEF)`;magical `max(1, MAG + weapon_might − target.RES)`;pure `max(1, [源] + weapon_might)` 无视防御 |
| 最终伤害 | `final_damage` | `base_damage × skill_multiplier × terrain_modifier × crit_modifier × relic_modifier × final_modifier` |

外层乘区:

| 乘区 | 变量名 | 说明 |
|---|---|---|
| 技能倍率 | `skill_multiplier` | `skill.power / 100`(100 = 1.0×) |
| 地形乘区 | `terrain_modifier` | 特殊地形独立乘区(如「受伤 ×0.8」) |
| 暴击乘区 | `crit_modifier` | 暴击 1.5×(可经 `crit_damage_bonus` 提高)/ 未暴击 1.0× |
| 遗物乘区 | `relic_modifier` | Roguelite 遗物独立乘区 |
| 最终乘区 | `final_modifier` | 全部最终段修正连乘(建筑减伤、buff 增伤等) |

### 基础地形 vs 特殊地形(关键区分)

- **基础地形加成**:地形提供的属性加成直接加到单位属性,参与层 1 加法计算。
  - 例:山地 +5 DEF → `DEF` 变为 `DEF + 5`,参与 `STR + weapon_might − DEF`。
- **特殊地形乘区**:特殊地形提供的独立乘数(层 2 `terrain_modifier`)。
  - 例:某特殊地形「受到伤害 ×0.8」→ 在最终计算中作为独立乘数。

### 基础地形战斗修正表

| 基础地形 | 防守方加成 | 闪避加成 |
|-------------|---------------|---------------|
| PLAIN(平原) | 无 | 无 |
| FOREST(森林) | 无 | +闪避(数值待定) |
| MOUNTAIN(山地) | +DEF、+RES(数值待定) | 无 |
| SHALLOW_WATER(浅水) | 无 | 无 |
| LAVA(熔岩) | 无 | 无 |
| SWAMP(沼泽) | 无 | 无 |

*PEAK/WALL/DEEP_WATER 为不可通行地形,无战斗修正。浅水/熔岩/沼泽的效果经 Buff/Debuff 施加实现,不走直接属性修正。*

## 攻击结算流程

```
1.[命中判定]
  计算最终命中率 final_hit_rate(见 R1.2 命中链)→ 随机判定
  → 未命中 → 触发 Miss 相关效果(如有)→ 结束

2.[暴击判定](命中后)
  计算最终暴击率 final_crit_rate(见 R1.3 暴击链)→ 随机判定
  → 暴击成功 → 标记 crit_modifier = 1.5×(可提高)

3.[伤害计算]
  base_damage(加法层)× skill_multiplier × terrain_modifier × crit_modifier × relic_modifier × final_modifier

4.[伤害施加]
  目标 HP 扣减,判定击杀
  若目标在建筑上(哨塔/要塞),建筑另行扣耐久(独立结算)

5.[命中后效果 on-hit]
  触发概率型 Debuff 施加(如冰系减速)
  施加成功率受 target.LCK 影响(见减益施加节)

6.[伤害后效果 after-damage]
  按伤害结果触发效果(吸血、击杀奖励、遗物触发等)

7.[反击判定](规则锚:R1.4——反击为配置型能力,非全局)
  目标持有反击配置(职业机制/天赋/遗物/敌方词条)
  且本次攻击 attack_type ≠ "area"
  且目标存活、未失能
  且目标普攻技能射程可达攻击者
  → 目标普攻反击一次(完整结算流程 1-6)
  → 反击不触发二次反击或追击
```

## 成长系统(规则锚:R2.2 / R2.3)

### 概率成长

```
升级时每个成长属性(HP/STR/MAG/DEX/SPD/DEF/RES)独立判定:
  if random() < growth_rate[stat]: stat += 1

LCK / MOV 不参与升级成长。
```

成长率取值以档位标尺(R2.3)为准:C=40% / B=50% / A=60% / S=75%,固定单值不设区间;SS = 每级两次 S 判定(期望 +1.5、至多 +2,任一成功重置该属性 pity)。职业线标定见 [[class-system|05 - 职业系统]]。

### 保底(Pity)

```
每属性维护隐藏 fail_count:
  判定失败 → fail_count += 1;判定成功 → fail_count = 0
  fail_count >= pity_threshold → 强制 +1,重置计数

pity_threshold:
  growth_rate >= 40%:   pity = 3
  growth_rate 20%-39%:  pity = 5
  growth_rate < 20%:    pity = 8
```

## 减益施加(规则锚:R1.6)

```
Debuff 实际施加率 = skill_effect.chance × max(0.1, 1 − target.LCK / 100)

例:技能施加率 50%,目标 LCK = 20
  → 50% × (1 − 0.2) = 40%
```

LCK 的两个战斗触点之一(另一个是暴击回避,见 R1.3)。

## 单位回合流程

### 标准行动流

```
[单位回合开始]
  → Buff/Debuff 效果触发(燃烧伤害、再生等)
  → 若眩晕/冰冻 → 跳过行动,直接到单位回合结束

[单位行动阶段]
  标准流:移动 → 攻击/技能 → 单位回合结束

  规则:
  - 一般先移动后攻击/用技能
  - 一旦攻击/用技能,一般不能再移动
  - 部分技能可在移动前使用(技能 flag:pre_move = true)
  - 特殊职业/技能允许攻击后移动(flag:post_attack_move = true)
  - 也可只移动不攻击,或原地待机

[单位回合结束]
  → Buff/Debuff 剩余回合 −1,到期移除
```

### 行动阶段变体

| 类型 | 流程 | 来源 |
|------|------|--------|
| 标准 | 移动 → 攻击/技能 | 默认 |
| 先手技能 | 技能 → 移动 → 攻击/技能 | 技能 flag `pre_move` |
| 攻后移动 | 移动 → 攻击/技能 → 移动 | 特殊职业/技能 flag `post_attack_move` |
| 只移动 | 移动 | 玩家选择 |
| 待机 | 无 | 玩家选择 |

见 → [[turn-system|01 - 回合系统]] Buff/Debuff 时机规则(规则锚:R3.4)。
