# VA-5 通用行动资源栏设计规格

**状态：** 用户已于 2026-08-29 批准进入实施。

**目标：** 将战棋底层通用行动资源 M/A/S 从地图单位周围迁移到技能栏正上方，使行动状态集中在底部操作区读取，同时不改变任何行动经济规则。

**任务权威：** GitHub issue #18：`UI：将行动资源提示迁移到技能栏上方横条`。

## 1. 当前边界

- 本阶段只显示移动资源 M、标准行动资源 A、迅捷行动资源 S。
- 数据只读自当前信息单位的 `movement_used`、`standard_used`、`swift_used`。
- 玩家可操作当前单位时显示；敌方信息态、无单位态及非玩家操作态隐藏。
- 复用现有刷新链：`TacticalManager.get_dashboard_data()` → `dashboard_state_changed` → `TacticalScene._refresh_dashboard()` → `BottomDashboard.update_state()`。
- 地图单位不再生成 M/A/S 标签；`StatusIcons` 继续承载已有 Buff/Debuff 标签。
- 剑气、印记、遗物、技能可用性和战斗规则不在本阶段改动。

## 2. 信息结构与布局

行动资源栏作为独立 `ActionResourceBar` 控件，由 `BottomDashboard` 持有。它与技能栏水平居中，底边位于技能栏顶边上方 6 像素；不插入人物信息区、职业资源区或遗物区。

```text
                    ┌──────────────────────────────┐
                    │  M 移动  │  A 行动  │ S 迅捷 │
                    └──────────────────────────────┘
                              6 px
             ┌────────────────────────────────────────┐
             │ 被动 │ 主动技能 1 │ 2 │ 3 │ 4          │
             └────────────────────────────────────────┘
```

`BottomDashboard.get_content_top_y()` 必须把可见行动资源栏纳入计算，使伤害预测浮窗继续避开底栏。

## 3. 视觉语言

主题沿用已批准底栏的冷黑石材、暗金描边和低饱和宝石色，不复制其他游戏的具体美术。

| 角色 | 颜色 |
|---|---|
| 外壳底色 | `#0A0B12`，96% 不透明 |
| 暗金边框 | `#8F743D` |
| 主文字 | `#E5DBCB` |
| 已消耗文字 | `#6C6872` |
| M 移动强调 | `#6FAED1` |
| A 行动强调 | `#D17A50` |
| S 迅捷强调 | `#D5BC59` |

- 三个资源段各为 `76×30` 像素，外壳内边距左右 6、上下 4，段间距 4。
- 每段左侧是运行时绘制的菱形资源符号，右侧是运行时文字；不得把文字烘焙进图片。
- 可用态：强调色菱形、明亮文字和强调色细边。
- 已消耗态：暗灰背景、灰文字；菱形上增加一条斜向缺口。缺口是本控件的识别性元素，也让状态不只依赖颜色。
- 中文名称采用当前 Godot 主题字体，`M/A/S` 作为紧凑识别符；不引入新字体资产。
- 初版不使用循环动画、闪烁或粒子效果。操作后的即时静态切换就是反馈。

## 4. 数据合同

`TacticalManager.get_dashboard_data()` 增加：

```gdscript
"action_resources": {
	"movement_used": info_unit.movement_used,
	"standard_used": info_unit.standard_used,
	"swift_used": info_unit.swift_used,
},
```

`ActionResourceBar` 的生产接口固定为：

```gdscript
func update_resources(resources: Dictionary) -> void
```

`BottomDashboard` 仅在 `show_actions == true` 且 `action_resources` 非空时显示资源栏。资源栏不直接持有或读取 `Unit`。

## 5. 状态与刷新

- `*_used == false` 表示可用；`*_used == true` 表示已消耗。
- 移动、标准行动、迅捷行动完成后，由现有 `dashboard_state_changed` 链刷新。
- 新回合调用现有资源复位逻辑后，三项恢复可用并经同一链刷新。
- 无数据时隐藏整条，不猜测默认资源状态。
- 不新增第二套信号或轮询。

## 6. 验收条件

1. 实际玩家回合中，M/A/S 横条位于技能栏正上方，三个状态清楚可辨；敌方信息态不显示。
2. 移动、标准行动、迅捷行动和新回合复位后，横条经现有刷新链即时同步。
3. 地图单位不再绘制 M/A/S；真实 Buff/Debuff 标签仍保留原有节点、锚点和行为。
4. 剑气、印记、技能栏、伤害预测避让及 40 项既有回归无行为回退；新增测试一并全绿。
5. 生成至少两张真实 `TacticalScene` 的 `1280×720` 截图：全可用态、混合消耗态；由用户完成最终视觉验收。

## 7. 明确不做

- 不显示或设计反应资源 R。
- 不抽象职业资源统一协议，不移动剑气或印记。
- 不接入遗物运行数据，不调整遗物槽数量。
- 不替换整套底栏美术，不导入新的 UI 图片或字体。
- 不改变行动经济、技能消耗、回合阶段或 AI。
