# HUD 数值字体候选 Implementation Plan

> **Milestone：** `GHA-4-HUD-NUMERIC-FONT-CANDIDATE`
>
> **阶段成果：** 从 IBM 官方发行包引入一份可追溯、可随游戏分发的静态 `IBM Plex Mono SemiBold` 候选，在独立 Godot 开发画廊中比较现有回退字体与候选字体的 8px／7px 实机栅格化效果；不提前替换正式 HUD。

## 完成条件

- 官方发行 ZIP 的下载地址、版本、官方 SHA-256、取得日期和许可证均有记录。
- 下载后的 ZIP SHA-256 与官方值一致；提取出的 TTF 和许可文本另行记录实测 SHA-256。
- 仓库只保留静态 SemiBold TTF、原样 OFL 文本和来源清单，不引入其他字体文件。
- Godot 能将 TTF 加载为 `FontFile`，候选保持传统栅格化，不启用 MSDF。
- 独立开发画廊同时显示现有回退字体和 IBM Plex Mono 候选；比较 8px 普通值与 7px 长值；另以局部运行时覆盖生成一张 GHV-5 长值状态实景预览，不修改当前 GHV-5 三张截图。
- 样本覆盖 `000000/000000`、`666666/666666`、`888888/888888`、`999999/999999`、`123456/654321`，并额外显示 `0 1 6 7 8 9 /`。
- 候选图同时验证右对齐、相同右边界、无裁切、基线稳定和暗色 HUD 背景可读性。
- 新增测试、受影响回归、截图、静态检查和独立只读审查通过。
- 技术通过只使候选进入用户视觉审核；用户确认前不把字体写入正式 `HudMeterValueLabel` Theme 变体。

## 边界

- 本任务不购买素材，不调用外部图像 API，也不使用生成式图像。
- 本任务不设计中文字体、技能图标、装备图标、职业资源 HUD 或实际玩法规则。
- 本任务不修改正式 `BottomDashboard`、`SkillBar`、`ActionResourceBar`、玩法容量或 GHV-4／GHV-5 既有截图。
