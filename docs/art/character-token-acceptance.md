# 人物棋子朝向与接地验收准则

本准则适用于人物、棋子方向映射、足点、脚下环和镜头输入相关修改。人物与地形共同呈现时，还须读取[地形呈现验收准则](terrain-presentation-acceptance.md)。这些检查不改变战斗规则。

## 当前原画棋子 MVP 配置（2026-10-28）

当前范围仅为 scenes/tactical/character_pipeline/portrait_token_battle.tscn 入口。

- 1280×720 下使用当前镜头缩放 1.36。该入口拦截鼠标滚轮上下事件，保持缩放和镜头位置不变；继承的庭院入口和其他场景仍使用各自的输入行为。
- 该入口的阵营环使用原半径：普通 18/8，选中 22/10；中心偏移为零，compact_badge_layout=false。
- 保留现有 17×17 职业徽章的尺寸和足点相对位置。徽章实绘轮廓须留在所属格的菱形范围内；当前 MVP 允许徽章与原半径脚环局部重叠。这是 2026-10-28 对本入口的限定决定，用户答复原文为“当前允许”；不延伸为其他场景规则或整体美术定稿。
- tests/test_portrait_token_overhead.gd 核对脚环原半径、中心、固定镜头、徽章位置和格内轮廓。它不再以缩小脚环或“徽章不碰脚环”作为通过条件。

本轮独审实际检查了进入、停留、离开途中和离开后的四张原尺寸静帧。它们只代表这四个画面，不能表述为对 360 帧逐帧人工审查。四帧未见叶冠遮住人物；深色靴底细节仍未测清楚。整体视觉尚未获得最终定稿批准。自动血条遮挡诊断仍有未排除记录；详见地形验收准则和 .sot/lane-work/ui-ux/cloud-replacement-20261028/outside-calm-r1/cloud-evidence/receipt.json。

## 目标朝向

- 玩家与敌方 AI 均须覆盖，并分别验证目标单位攻击和目标格技能。
- 根据真实目标位置与人物位置，经当前 Grid 和画布投影得到屏幕向量，选择素材中视觉方向最接近目标的有效帧。必须直接查看素材，不能只依赖 NW/NE 等标签。
- 零距离时保留已有合理朝向；出手、命中与恢复期间保持意图方向。范围技能逐个结算副目标时，不得把施法者扭向副目标。
- 四向素材分别记录方向、实际 frame/column、目标格或目标单位及屏幕向量。

## 普通移动路线

- 玩家与敌方的普通移动必须沿现有寻路给出的上下左右相邻格依次前进，与移动预览一致；不得直接从起点向多格外的终点斜切。
- 每段按单格时长播放，转弯时面向下一格。长路线须展示中间经过的格子，不能沿用整条路线固定 0.25 秒的表现。
- 人物、脚环和头顶血条共同移动；站定后足点与目标格中心重合。移动动画期间保持输入锁，完整动作只结算一次移动资源和一次占用迁移；停止战斗后不得继续播放余下路段。
- tests/test_portrait_grid_movement.gd 采样真实单位的中途位置、转向、输入锁及停止行为；云端实战录像还须覆盖玩家与 AI 的实际移动，以及森林进入、停留和离开。技能位移按该技能自己的现行规则验收。

## 足点、环心与格中心

- 待机、转向、攻击、恢复、取消和移动终点，两脚实际地面支撑中点、全部可见脚下环中心和当前格中心必须一致。
- 移动途中人物和环随单位共同移动，到达后与新格中心对齐。
- 贴图包围盒中心、Unit 原点和配置 pivot 只能作为计算输入，不能替代对原图可见支撑点的检查。更换帧时使用该帧自己的支撑点，并盘点所有可见选择环、阵营环和旧脚下表现。
- 静态棋子可用斩弧和闪光表达动势；不得让只有 Sprite 位移造成足点与环心分离。

## 交付证据与判定

新资产、方向映射、足点或变换改变后，提供自动回归与真实游戏原尺寸画面。使用实际 TacticalScene、Unit、GameAction 和 EnemyAI，记录受影响状态、目标屏幕向量、使用帧、可见脚点、环心、格中心和误差。自动逻辑锚点一致不能代替像素足点检查；独立审阅、自动检查和用户视觉批准分别记录。

任何必检项失败或缺少证据时，不得把人物表现标为 PASS。保留历史失败和未测状态，不用代码检查覆盖视觉结论。当前回归入口包括：

- tests/test_portrait_token_facing_align.gd：四向真实结算、空格 AOE、取消和锚点。
- tests/test_portrait_token_battle.gd：真实移动、输入锁、停止与重开。
- tests/test_portrait_token_skill.gd：现有技能。
- tests/test_portrait_token_overhead.gd 与 tests/test_portrait_token_forecast_layout.gd：常驻血条、徽章、悬停详情和预测窗布局。
- scripts/art/character_pipeline/capture_portrait_token_facing_align.gd：真实玩家/AI录像及逐帧坐标。

## 当前常驻血条与详情

当前原画棋子入口平时只显示沿用阵营色的 40×4 屏幕像素小血条。所有单位统一以真实足点投影 x 为水平中心，并按四向联合头顶高度留 5px 净空。单位切换帧不应改变血条宽度或锚点；移动时血条随人物投影连续移动。

姓名与真实 HP 由选中单位的底部面板展示。普通单位悬停时复用既有提示入口显示短名和 HP，移开后隐藏；攻击瞄准使用原预测面板，悬停详情与预测面板互斥。不得为移动职业徽章而移动常驻血条。

对本 MVP 的独立四帧审阅发现一次黄色悬停格遮住中间友军血条一部分；机器跟踪还保留 head_bar_other_body_overlap 诊断记录。因此当前状态不能写成“血条遮挡已全部消除”。预测窗的矩形避让也只在有相应实测时作通过结论。
