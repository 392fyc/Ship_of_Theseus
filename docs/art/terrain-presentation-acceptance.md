# 地形呈现验收准则

新增或迭代地形前，先检查已有同类素材和邻接规则，沿用连续地形的连接原则，避免把每格都画成互不相连的独立物件。

- 单格、端部、相邻直连、转角、分叉和成片应按实际邻格形成相应轮廓；共享连接只生成一次，内部接边不重复封口。仅角接不能算作正交连接。
- 同类地面在接边处连续，朝异类地形收边，不跨入普通草地。贴图使用一致的空间坐标，避免亮度接缝或强烈的逐格边框。
- 默认镜头原尺寸下查看真实游戏画面，检查地形可辨、连续轮廓、人物主体、脚点、脚环和职业图标。按任务实际覆盖空格、有人格、进入、停留和离开状态；结构测试不能代替视觉证据。
- 棋盘内植被须从画面上归属于森林区域，并与棋盘外树冠分开。占格与离开后的落脚环境应可辨。底纹须核对实际纹理尺度，不能只凭共享 UV 公式推断画面效果。
- 不得为视觉效果改变地形类型、通行或战斗规则。结构检查、独立画面审阅和用户定稿批准分别记录。
