# 00-rules

现行设计规则。[设计规则总表](rules.md) 是设计纪律的唯一正本：每条规则一行，带编号、级别、适用范围和来源决策。系统结算规则的正本在设计库规则表，这里不复述。

先读 [rules.md](rules.md) 中与任务相关的节，再按 [设计规则面索引](design-rules-index.md) 的路由读对应实体的指引，然后读设计库现行记录。指引只解释总表、给示例与检查清单，与总表不一致时以总表为准。
