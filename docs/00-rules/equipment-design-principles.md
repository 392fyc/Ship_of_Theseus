# 装备设计指引(Equipment Design Guide)

> **读者 = 设计 SoT 装备的代理。** 本文是三级指引：解释 [设计规则总表](rules.md) E 节与 G11，给字段现状与方法，不另立规则；与总表不一致时以总表为准。入口见 [设计规则面索引](design-rules-index.md)。
>
> 相关：[职业系统](../01-Game-Design/Characters/class-system.md)（槽位、武器类型、双持）· [规则总目录](../01-Game-Design/rules-catalog.md)

## 1. 定位

装备随机捡取、局后清零，走词缀与暗金模式，影响从小到中。玩家无法围绕装备规划构筑，所以装备不改变流派（E01）。装备与遗物的配合只放大风味，例如火属性武器配燃烧类遗物。

## 2. 武器参数

武器的基础数值、副手特效与武器不决定伤害类型和射程，见设计库 R1.7、R1.16，本文不复述。设计时注意：

- 武器提供的力量、技巧等属性加成不属于武器的三项基础数值；武器特效挂在装备本身，不另建词缀实体（E02）。
- 「装备加属性」目前没有结构化字段，这类效果先占位（E03）。等它成为真实设计需求时单独立项。
- 双持的核心收益来自天赋节点而不是装备叠加；副手武器特效的效果量见 R1.16。

## 3. 字段与槽位

- 装备是全局实体，没有 `class_id`。字段以设计库模型为准，常用的有 `name`、`description`、`rarity`、`slot`、`notes`、三项武器数值、`shelf_state` 与 `trashed_at`，以及武器特效用的 trigger 五段、`effect`、`rules`、`tags`。
- trigger 五段与天赋共用同一套词汇与校验（T06），选事件的方法见 [天赋设计指引](talent-design-principles.md) §trigger。装备没有旧的自由文本 `trigger` 字段，也没有 `target_mode`：装备特效依附于携带者的攻击动作，不由玩家选目标。
- 槽位的设计叙述见 [职业系统](../01-Game-Design/Characters/class-system.md)：通用两槽是主手与护甲；副手只由剑圣的双持天赋解锁，不进通用槽位枚举；饰品槽已作废。在库实际用到哪些 `slot` 取值、有多少件，以 `/api/equipment` 为准。
- 现状提醒：较早录入的装备，特效写在 `notes` 里、`effect` 为空，回填是待办。读到 `notes` 里的特效说明不要当成错误数据，新写的特效按 E02 写进 `effect`。

## 4. 稀有度示例

规则见 E06、E07。

- 普通制式武器（铁剑、钢剑一级）不需要特效。
- 同样没有特效、但数值显著高于同档制式武器的，按数值强度拔高档位。例：银剑威力 13 定稀有，王者之剑威力 20 定史诗。
- 不按外部作品自己的军阶分档：军阶会把「有特效但军阶低」的武器错归普通档。
- 原作特性已经被数值字段表达的（例如高暴击就是 `weapon_crit` 高），`notes` 不再重复说明。
- 品阶 `tier` 在设计库中尚未落地。

## 5. 取材方法

规则见 E08。外部作品的数值联网核实、逐件记录来源 URL；同一武器在多部作品数值不同时只取一个版本，不建重复条目；促销码专属或与已有条目完全重复的跳过；来源作品的重量、耐久、射程等 SoT 没有对应机制的维度不移植，将来纳入时回到取材记录逐条重新抓取。
