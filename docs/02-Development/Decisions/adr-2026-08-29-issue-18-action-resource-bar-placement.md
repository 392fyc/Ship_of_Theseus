# ADR：行动资源栏的位置

## 状态

已接受，2026-08-29。

## 适用范围

本裁决适用于战术场景中的移动、主要行动、次要行动等行动资源提示，以及底部技能栏周边的信息布局。

## 裁决

1. 行动资源提示不显示在地图棋子脚下或棋子附近。
2. 行动资源显示在技能栏上方，使用横向资源栏。
3. 信息组织参考 BG3 的横向行动资源栏形式。
4. 该横条与技能栏构成同一底部操作区，但不占用技能格或遗物格。
5. 2026-08-29 的后续布局审核通过 Ship 提交 `61bd822` 所示关系：在 1280×720 参考画布中，横条为 188×34，水平居中于技能栏上方，并与技能栏保持 6 像素间距；其他分辨率保持该相对关系和紧凑尺度。此项取代本文早先“尺寸尚未定案”的结论。
6. 移动资源显示剩余移动格数的纯数值；标准行动和迅捷行动各预留最多 3 点的显示容量。该容量属于界面预留，不新增或修改行动经济规则。
7. 横条的材质、边框、图标造型、颜色和交互反馈仍未定案，必须与人物、战棋棋子、地形和特效进行组合设计与单独验收；不得从现有 HTML/CSS 或 M/A/S 字母占位反推正式样式。

## 辨析

本裁决只处理行动资源提示的位置，不决定 Buff/Debuff 的地图表现，也不决定职业专属资源的视觉形式。

## 权威边界

本文保存用户的界面布局裁决。当前运行实现以 Ship 仓为准；实现任务与验收证据由 Ship issue #18 和 GitHub/Git 承载；行动经济的结构化规则仍以设计库为准。
