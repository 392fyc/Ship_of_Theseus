# 战斗操作步骤与拒绝反馈

当前操作提示读取战斗状态，不改变技能判定、施放步数、行动消耗或取消行为。

- 移动阶段说明可选移动格或技能；行动阶段仅在普攻入口可用时提示攻击，仅在移动可撤销时提示撤销。
- 一闪先选方向，再选可站立的空落点。两段目标技能依次选择目标和目标旁的落点。
- 自身技能在技能说明中标明“点选即施放”，保持一次点选直接执行。
- 点击无效位置时说明当前失败原因：缺少单位、超出范围、未选方向、落点被占或无法站立。沿用取消选择并返回来源阶段的行为。
- 拒绝原因保留到下一次操作；重新选技能、点击棋盘、手动取消或切换阶段后清除。鼠标悬停不清除，留出阅读时间。

提示使用当前固定视角下的底部界面空间，沿用现有深色底与金色边线；不修改人物、脚环、地形、美术素材或镜头。
