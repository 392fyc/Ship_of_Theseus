# 剑士天赋设计模板（空白）

> **使用说明**：复制此文件后改名（如 `swordsman-design-v1.md`）再填写。每节都有「填写说明」`<!-- ... -->` 注释指明填写要求，填写后可保留或删除。配套示例：`swordsman-design-example.md`（已用 1 级 4 选 1 填好）。
>
> **设计哲学硬要求**（用户已确认）：
> 1. 节点必须真正改变玩法 — 不写「+X% 数值」式假节点
> 2. 节点间必须有联动 — 攻击不再是「使用技能造成一次伤害」的简单事件
> 3. 1 级 4 选 1 决定本局基调 — 这种「分支锚点」节点选择后同组其他节点排除
> 4. 入池按大阶段开放 — 不是每级 1 节点，而是大阶段（开局 / 转职 / 后期）解锁新节点池

## 第 5 章 — 设计自检清单

> 在 finalize 前对照自检。

### 5.1 内容质量

- [ ] 每个节点都不是「+X% 数值」型假节点（避免 Cyberpunk 1.x 失败、Ravenswatch 池稀释失败）
- [ ] 形态变化节点的工程实现成本评估完成（状态机分支数 + 动画 override 数 + AI 行为更新数）
- [ ] 5 类增强分布合理（用户哲学：形态变化与联动占比可以高于 S4 业内基准的 5-15%）
- [ ] 每个节点都有清晰的「修改了什么」和「不触发什么」

### 5.2 规则合规

- [ ] handoff §「DO NOT — 游戏机制」中所有规则已检查
  - [ ] 格挡和暴击互斥：节点是否引入两者同时生效的路径？
  - [ ] pure 伤害格挡 → 无视；pure 暴击 → 固定 1.5x 不受加成：节点不应试图修改这两条
  - [ ] hybrid → phys_atk + mag_atk 同时生效，武器倍率取平均
  - [ ] 反击 → **不触发追击**（注意：可触发反击本身，仅追击在反击下被禁）
  - [ ] area 攻击 → 不触发反击
  - [ ] 距离 → 无衰减
  - [ ] ZOC → 不叠加固定 -2，仅从控制区离开时触发

### 5.3 系统闭环

- [ ] 剑气循环闭环（积累 + 消耗 + 阈值触发都有节点支持）
- [ ] 剑意循环闭环（暴击触发 + 层数衰减 + 派生效果都被覆盖）
- [ ] 招架 / 闪避 / 暴击三大触发条件均有节点利用
- [ ] 1 级 4 选 1（或其他基调节点组）覆盖至少 3 个差异化玩法风格
- [ ] Lv5 奥义二选一形态后，A/B 面节点不会冲突
- [ ] 联动链没有产生意外的无限循环或强度溢出

### 5.4 玩家体验

- [ ] 决策密度匹配 Lv 节奏（建议每大阶段 1-3 次有意义选择）
- [ ] 单 Run 玩家拿到的天赋点数 M 与节点池 N 的取舍比例符合预期（参考 S4 业内基准：40-60% 是健康区间）
- [ ] 1 级基调选择后，2-4 级节点能与基调形成协同（不是强绑定，但能加强）
