# Version C: Resource Cycle — 设计理据

> 版本: R4 (2026-03-15) | P3-TALENT-V2

---

## 核心理念

**普攻 = 唯一稳定的量谱资源回复手段**。所有技能消耗量谱资源，普攻回复量谱，形成"普攻充能 → 技能释放 → 普攻充能"的节奏循环。不使用普攻 = 没有资源 = 无法释放技能。

## 各路径资源循环特色

### SS-A: 双刀快充
- 双刀=每次普攻+30剑意(最快充能)
- 追击+15/次，高SPD角色3回合可充满
- 消耗模式：微消耗换微增伤(ss_A17: -1剑意+5%ATK纯粹伤害)

### SS-B: 居合蓄放
- 蓄势(swift)+25%伤害+25剑意
- 满剑意快速衰减(-10/回合) → 逼迫释放技能
- 释放后下次普攻回复翻倍 → 快速回充循环
- 超充机制：满后不回剑意改为ATK暂时叠加

### SC-A: 飞剑续航
- 飞剑普攻+5%→+7%→+10%剑元(层层递增)
- 高剑元(>80/90%)时普攻获大幅增强
- 虚空斩消耗全部剑元但伤害与消耗量成正比

### SC-B: 阵法经济
- 阵法消耗剑元，阵内普攻加速回充
- 阵法越长存续→阵内回复越高(sc_B13)
- 满剑元时阵法消耗-50%(sc_B21)
- 形成"布阵→阵内普攻充能→维持/引爆→重新布阵"循环

## Open Issues

1. **回充速度平衡** — 双刀+30/次是否过快？可能需要降低到+12/刀=+24/次
2. **剑元自然恢复降为2%是否过低** — 需要验证前几回合(无飞剑增强节点时)是否能维持基本循环
3. **满资源超充机制** — ss_B16的超充(不回剑意改为ATK叠加)是否与"保持普攻竞争力"目标矛盾？
4. **技能消耗缩放** — ss_B14(消耗60-100=伤害140-180%)的曲线是否线性？需要公式化
5. **击杀退款机制** — ss_B24(修罗一闪击杀=100%退款)可能导致连续技能释放不需要普攻
