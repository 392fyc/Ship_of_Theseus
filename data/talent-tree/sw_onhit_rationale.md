# Version A: On-Hit Engine — 设计理据

> 版本: R4 (2026-03-15) | P3-TALENT-V2

---

## 核心理念

**普攻 = 被动效果链的引擎启动器**。天赋树中大量 passive/trait 节点标注 `on_hit` 标签，仅在普攻命中时触发。标准行动技能不触发 on-hit 链（终极单体技例外），确保普攻在行动经济中保持独特价值。

---

| 来源 | 借鉴点 |

| 暗黑破坏神 | on-hit 被动叠加形成正反馈循环 |
| XCOM 2 | 行动经济稀缺 → 普攻始终是零消耗选项 |
| FE 风花雪月 | 追击排他 → 战技不可追击 |

## 普攻权重分析

**每条路径的普攻增强节点链:**

### SS-A (双刀追击流)
```
sw_L2(锐伤) → sw_L3(连击) → sw_L4(暴伤) → sw_hub8(20%免费普攻)
→ ss_A11(双刀=2×on-hit) → ss_A12(追击=双on-hit) → ss_A14(50%追击)
→ ss_A15_qual(100%追击+必暴) → ss_A16(闪避→影斩) → ss_A17(双剑+10剑意)
→ ss_A18(追击+20剑意) → ss_A19(追击无视格挡+破甲)
```
**普攻期望收益**: 基础×2(双刀) + 追击100%(高SPD) + on-hit全链 = 极高

### SS-B (居合修罗流)
```
sw_L2(锐伤) → sw_hub8(20%免费) → ss_B11(暴击+15剑意)
→ ss_B12(蓄势swift:+25%伤害+20剑意) → ss_B13(满剑意吸血)
→ ss_B15_qual(双on-hit) → ss_B16(满剑意削甲) → ss_B17(+0.2暴伤)
```
**普攻期望收益**: 站桩+25%伤害 + 双on-hit + 吸血 + 削甲 = 高(但牺牲移动)

### SC-A (万法剑道)
```
sc_A11(飞剑普攻+3%剑元) → sc_A12(30%追加打击) → sc_A13(丝缚标记+15%Hybrid)
→ sc_A14(射程+1,回复5%) → sc_A15_qual(取较低防) → sc_A17(击杀+移动,减速)
→ sc_A18(拉近1格) → sc_A19(5%回复+高剑元普攻+20%)
```
**普攻期望收益**: 远程Hybrid + 剑元回复 + 追加打击 + 位移控制 = 高(远程安全)

### SC-B (诛仙四剑)
```
sc_B12(阵内真伤) → sc_B13(阵内必定丝缚) → sc_B15_qual(阵内on-hit扩散)
→ sc_B16(阵内+15%伤害) → sc_B17(友军阵内普攻真伤) → sc_B18(阵内溅射)
→ sc_B19(阵内+3%剑元)
```
**普攻期望收益**: 阵内普攻 = 真伤 + 标记 + 溅射 + 回复 = 高(但依赖阵法位置)

## 与 v1 的关键差异

| 维度 | v1 | Version A (On-Hit) |
|------|----|-------------------|
| 普攻权重 | 低 | 极高(on-hit链引擎) |
| 技能与普攻关系 | 技能直接替代普攻 | 技能不触发on-hit，与普攻各有优势 |
| 被动节点设计 | 泛用增益 | 明确"普攻命中时触发"条件 |
| Swift 技能 | 缺失 | 每路径1-2个，增益型不与普攻竞争 |
| 蓄势系统 | 无 | 居合蓄势(swift)强化普攻 |
