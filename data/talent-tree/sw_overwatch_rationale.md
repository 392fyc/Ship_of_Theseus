# Version B: Overwatch/Stance — 设计理据

> 版本: R4 (2026-03-15) | P3-TALENT-V2

---

## 核心理念

**普攻 = 架势(Overwatch)系统的核心触发手段**。不使用标准行动结束回合时进入「待机」，敌方进入射程或在射程内移动时自动发动普攻。架势普攻享受额外加成和所有被动效果。主动技能打破架势但提供瞬间高伤——形成"爆发 vs 控场"的战术抉择。

## 与 Version A (On-Hit) 的核心差异

| 维度 | Version A | Version B |
|------|-----------|-----------|
| 普攻触发方式 | 主动发动 | 主动 + 被动(Overwatch自动触发) |
| 不攻击回合 | 浪费行动 | 进入待机 → Overwatch机会 |
| 架势系统 | 无(仅居合作为swift) | 核心机制(待机/居合/飞剑待机) |
| 多次普攻来源 | 追击(SPD差) | Overwatch次数(天赋投入) |
| 战术抉择 | 普攻on-hit链 vs 技能高伤 | 待机控场 vs 技能爆发 |
| 技能使用后 | 回合结束 | 终极技进入半待机(1次,50%伤害)，非完整待机 |

---

## Overwatch 机制规则

1. **进入待机**: 未使用标准行动结束回合 → 自动进入待机
2. **触发条件**: 敌方单位进入邻接格(近战)/射程内(飞剑)
3. **基础次数**: 1次/回合(可通过天赋增加至3次)
4. **攻击性质**: 等同普攻 → 享受所有普攻增强被动
5. **居合架势(swift)**: 主动进入 → 不可移动但Overwatch+40%伤害+必暴
6. **技能打破架势**: 使用标准行动技能 = 放弃本回合Overwatch

## 各路径 Overwatch 特色

### SS-A: 双刀连斩 Overwatch
- 双刀 = 每次Overwatch 2次打击
- ss_A14: 最多2次Overwatch/回合 → ss_A15_qual: 3次
- 极限: 3次Overwatch × 2刀 = 6次打击/回合(被动等待)

### SS-B: 居合 Overwatch
- 居合架势(swift) = 不移动但Overwatch+40%+必暴
- ss_B15_qual: 居合Overwatch击杀不消耗架势
- 极限: 居合单次Overwatch = 140%伤害必暴，防御穿透

### SC-A: 远程飞剑 Overwatch
- 飞剑Overwatch射程1-3(深潜后1-4)
- sc_A20_qual: 虚空斩后全屏Overwatch 1回合
- 极限: 全屏范围的被动反应式远程打击

### SC-B: 剑阵 Overwatch 陷阱
- 剑阵 = 永久Overwatch区域(sc_B13)
- 敌人进入/经过阵内自动受打击
- sc_B20_qual: 跟随剑阵 = 移动Overwatch堡垒

## Open Issues

1. **Overwatch与反击的关系** — 敌人攻击触发反击，但Overwatch是否也触发？需要明确规则避免双重触发
2. **多次Overwatch的性能** — 3次Overwatch×2刀=6次自动计算，需要确保战斗系统支持
3. **居合架势与移动的矛盾** — 居合不移动但战棋需要走位，是否需要"居合移动"特殊技能？
4. **剑阵自动Overwatch区域** — 可能过于被动(放阵→等)，需要资源消耗平衡
