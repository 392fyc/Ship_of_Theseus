# 07 - Run循环与关卡结构

> 返回 [总纲](./README.md)

## 概述

一次Run由 **3个大关卡** 构成，每个大关卡包含约 **10个小关卡**（根据路径选择略有出入）。小关卡之间有**准备阶段**，供玩家进行城镇建设、购买装备、调整技能。每个大关末尾为Boss战。

---

## Run整体结构

```
一次Run:
  ┌─ 角色选择（单机选1-4个，联机各选1个）
  │
  ├─ 【大关卡1】（约10个小关卡）
  │   ├─ [准备] → [战斗1] → [准备] → [战斗2] → ...
  │   ├─ 中途可能遭遇精英战
  │   └─ [关底Boss战]
  │
  ├─ 【大关卡2】（难度提升，约10个小关卡）
  │   ├─ [准备] → [战斗1] → [准备] → [战斗2] → ...
  │   ├─ 精英战频率增加
  │   └─ [关底Boss战]
  │
  ├─ 【大关卡3】（最高难度，约10个小关卡）
  │   ├─ [准备] → [战斗1] → [准备] → [战斗2] → ...
  │   ├─ 精英战
  │   └─ [最终Boss战]
  │
  └─ Run完成 / 中途全灭 → 结算
```

---

## 小关卡流程

每个小关卡由 **准备阶段 → 战斗阶段** 构成。

### 准备阶段

玩家在进入下一场战斗前进行准备工作：

```
准备阶段可执行操作:
  1. 城镇建设 — 建造/升级建筑（消耗金币）
  2. 建筑修复 — 修复战斗中受损/被摧毁的战场建筑（消耗金币）
  3. 购物     — 在已建造的商店中购买装备/药剂（消耗金币）
  3. 技能调整 — 在训练场更换/学习技能
  4. 战场布置 — 放置/调整战场建筑的位置
  5. 查看情报 — 预览下一场战斗的敌人信息（可选）
  6. 确认出发 — 进入战斗
```

详见 → [11-城镇建设](./11-town-building.md)

### 战斗阶段

标准战棋战斗，胜利后获得奖励。

```
战斗结束:
  1. 经验获取 → 角色可能升级
  2. 金币奖励
  3. 战利品（装备/技能/消耗品，根据关卡类型决定）
  4. 进入下一个准备阶段
```

---

## 关卡类型

每个大关卡内的小关卡有不同类型：

| 类型 | 说明 | 出现频率 |
|------|------|---------|
| 普通战斗 | 标准敌人配置 | 最多，约6-7场/大关 |
| 精英战 | 更强的敌人，更好的奖励 | 约2-3场/大关 |
| Boss战 | 大关末尾，固定Boss | 每大关1场 |
| 特殊事件 | 非战斗关卡（随机事件/宝箱等） | 约1-2场/大关 |

### 关卡排列（示例：大关卡1）

```
关卡1:  普通战斗
关卡2:  普通战斗
关卡3:  普通战斗 / 特殊事件（分支选择）
关卡4:  精英战
关卡5:  普通战斗
关卡6:  特殊事件
关卡7:  普通战斗
关卡8:  精英战
关卡9:  普通战斗
关卡10: Boss战
```

*具体排列可以有一定随机性，增加Roguelite的重玩价值。*

## 奖励系统

### 战斗奖励

| 关卡类型 | 金币 | 经验 | 天赋点 | 战利品 |
|---------|------|------|--------|--------|
| 普通战斗 | 中等 | 标准 | 1 | 基础装备/技能 |
| 精英战 | 较多 | 较多 | 1-2 | 稀有装备/技能/遗物 |
| Boss战 | 大量 | 大量 | 2 | 传说装备/技能/遗物 + 进入下一大关 |

- **经验**：用于角色升级（提升属性成长值）
- **天赋点**：用于在天赋树中解锁节点（每次Run重置）

### 奖励选择

战斗胜利后提供奖励选择（待定方案）：
- **方案A**：固定掉落 + 三选一额外奖励
- **方案B**：全部为三选一选择
- **方案C**：固定金币 + 随机掉落战利品

联机时奖励分配：
- 每个玩家独立选择自己角色的奖励（推荐）
- 设置选择时间限制

## 特殊事件

非战斗关卡，提供风险/收益选择。

```
Event:
  id: String
  title: String
  description: String
  choices: Array[EventChoice]

EventChoice:
  text: String
  outcomes: Array[EventOutcome]

EventOutcome:
  weight: int
  effects: Array[Effect]
  description: String
```

### 事件示例

- **神秘商人**：出售稀有物品但价格极高
- **废弃矿洞**：冒险探索可能获得大量金币或遭遇伏击
- **祝福祭坛**：消耗金币/HP换取永久增益

## 难度递增

| 要素 | 大关卡1 | 大关卡2 | 大关卡3 |
|------|---------|---------|---------|
| 敌人HP | ×1.0 | ×1.5 | ×2.0 |
| 敌人攻击 | ×1.0 | ×1.3 | ×1.6 |
| 波次数量 | 1-2 | 2-3 | 2-3 |
| 精英场次 | 2 | 2-3 | 3 |
| 金币奖励 | 基础 | ×1.3 | ×1.6 |

## Meta进度（跨Run持久化）

### 核心设计原则

**Meta解锁 = 横向扩展选择，而非纵向强化数值。**

玩家在任何Meta进度下，已解锁的内容都能支撑完整的核心玩法。绝不允许出现"因缺少Meta解锁导致核心机制缺失，玩家在Run中后期发现强度不足且无法弥补"的情况。

| ✅ 允许 | ❌ 禁止 |
|---------|---------|
| 没解锁第2个转职，但第1个转职的完整玩法已可用 | 因为没解锁某天赋节点导致核心连击机制缺失 |
| 没解锁高级遗物，但现有遗物池足以构建有效BD | 因为Meta等级不够导致基础属性低于正常水准 |
| 新解锁的职业提供新玩法，而非更强的数值 | 后解锁的职业直接强于先有职业 |

### Meta解锁类别

```
MetaProgress:
  total_runs: int
  best_run: int                        # 最远到达的大关/小关
  
  # 横向解锁（更多选择）
  unlocked_classes: Array[String]      # 新职业（初始5个v1，通关条件解锁更多）
  unlocked_talent_areas: Dict[String, Array[String]]  # 各职业已解锁的天赋区域
  unlocked_relics: Array[String]       # 遗物池扩展
  unlocked_buildings: Array[String]    # 新建筑类型
  unlocked_building_levels: Dict[String, int]  # 建筑等级上限
  
  # 便利性升级（不影响核心强度）
  convenience_upgrades: Dict[String, int]
```

### 各类解锁详细说明

#### 天赋区域解锁

每个职业的天赋树分为多个区域。初始解锁的区域**包含1个转职路径的完整核心玩法**。通关后解锁更多区域，开放第2个转职选择。

```
初始状态（以剑士为例）:
  已解锁: 基础区域 + 剑圣路线区域
  → 玩家可以体验完整的剑圣玩法（暴击/速度/连击）

通关1次后:
  新解锁: 魔剑士路线区域
  → 玩家多了一个转职选择，但剑圣路线没有变强
```

**规则**：两个转职的职业，通常只需通关1次即可解锁全部转职选项。

#### 遗物解锁

遗物池随Meta进度逐步扩展。但初始遗物池已经覆盖各种BD方向的核心需求。

```
初始遗物池:
  包含各流派的基础遗物（攻击/防御/速度/辅助等）
  → 足以构建有效BD

Meta解锁:
  追加更多遗物，提供更多组合可能性
  → 横向扩展，不是"更强版本的基础遗物"
```

#### 建筑解锁

初始提供核心建筑（如哨塔、拒马）。Meta进度解锁新建筑类型和已有建筑的更高等级上限。

```
初始状态:
  可建造: 哨塔Lv1, 拒马Lv1, 生命泉水Lv1
  → 基础战场控制已可用

Meta解锁:
  新建筑: 要塞, 巨弩, 魔法塔
  等级上限: 哨塔Lv2→Lv3, ...
```

#### 职业解锁

v1初始5职业（佣兵/弓箭手/魔法师/骑士/牧师），通过特定条件解锁剩余职业。

```
解锁条件示例（待定）:
  剑士: 首次通关
  工匠: 在Run中使用3种不同建筑
  猎人: 在Run中击败50个敌人
```

#### 便利性升级

少量不影响核心战斗强度的便利性提升，使用跨Run货币购买。

```
ConvenienceUpgrade 示例:
  "starting_gold": +10 per level (max 3)     # 初始金币略多
  "shop_discount": -5% per level (max 2)      # 商店折扣
  "extra_reroll": +1 per level (max 2)        # 奖励重投次数
  "map_preview": 解锁关卡预览信息              # 情报类
```

**注意**：不包含"起始HP加成"、"起始攻击加成"等直接影响战斗数值的升级。便利性升级应局限于经济和信息层面。

## 数据结构

### 大关卡定义

```
Chapter:
  id: String
  name: String
  stages: Array[Stage]
  boss: Stage
  difficulty_multiplier: float

Stage:
  id: String
  type: "battle" | "elite" | "boss" | "event"
  map_id: String              # 对应的战斗地图（战斗类型时）
  event_id: String | null     # 对应的事件（事件类型时）
  enemy_config: String        # 敌人配置/波次ID
  rewards: RewardConfig
  preview: String             # 关卡预览信息
```
