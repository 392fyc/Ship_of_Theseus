# FE-IMPORT-R1 实机接入

当前视觉依据为用户通过的 Penpot FE-FRAME-R1 整体方案。`assets/ui/skins/hud_m2_fe/material-manifest.json` 记录固定文件、页面、源画板、导出版本及每份材质摘要。共享底框仅含底面、单条分隔、外边与底角纹章；动态内容和槽框由各自控件绘制。

行动图标使用24×24视口，标准图形可见直径20px，迅捷为24px等边三角；脚印按原SVG贝塞尔真实边界缩放到20px高。三组中心为(550.2,575.5)、(640,575.5)、(729.8,575.5)。移动数字14px，按实际文本宽度和脚印之间7px间距共同居中。标准/迅捷容量沿用显示接口的1—3范围，图标间隔5px；不扩大技能角标原有规格。

装备与遗物当前展示空槽，装备接口调整由并行任务负责；血瓶和通用槽位能力仍在各自显示接口中。当前材质包含52px空槽与40px遗物槽两种同族暗铜边。纯被动保留独立内凹纹理，轮廓层不绘制中心，以免遮挡技能图像。

单次换肤继续通过`set_skin_theme()`。共享框的`material_texture=null`回到原生后备绘制，供替换主题和测试使用；所有素材职责见`../hud-m2-skin/skin-replacement-guide.md`。

本次原生捕获命令使用`tests/capture_hud_m2_skin_theme.gd -- --capture-hud-m2-fe-import`。普通、人物悬浮、纯被动、替换/恢复主题和三档分辨率来自同一个真实战斗场景。零技能、七技能和三点容量画面明确标记为显示边界夹具，保留实际玩法对象。旧目录中的原生证据不覆盖。

阶段结果以独立审查和回执为准；本次接入不表示职业资源设计或底栏最终切换已完成。
