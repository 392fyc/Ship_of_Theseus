# 地形创作与正式试战集成记录

## 当前裁决

2026-09-27 用户原话：“通过人类审查，进行提交合并。”此前已明确地图只支持正方形，仅设置边长，最小 10、最大 25。此记录连接人类批准与本次提交内容；实际 PR 和合并提交以 GitHub/Git 为准。

## 交付范围

- 九类地形，32 种合法异类接壤与同类连续效果；四种不合场景逻辑的组合同时拒绝边接与对角接触。
- 深浅水连续过渡；墙、残墙、石柱、岩峰、苔峰五种不可进入地形外观；三张可编辑示例。
- 工作台绘制、变体、撤销、保存、导入、清空与校验；边长 10—25。放大保留已有格并补平原，缩小裁切范围外内容，可撤销。
- 使用当前地图进入正式 TacticalScene；基础剑士和枪兵出生于同一可达区域；返回工作台保持地图和编辑状态。临时试战不污染全局地图库。
- 退出时取消等待中的行动和移动；保留已合入的 HUD 与职业资源显示。

## 证据及复验

现行图像和逐项证据：`reviews/2026-09-27/terrain-map-size-v1/`。其中 `archive-manifest.json` 的 `stored_as` 是实际仓库相对路径；部分相同图片引用此前批次，使用 SHA-256 核对。此批次统一验证五阶段通过：尺寸 79 项、试战 89 项、编辑往返 19 项、旧注入 20 项；地形库 166 项、工作台 28 项以及水岸、水深、邻接、整屏和交互回归均通过。完整结果与独立审查分别见该目录内 `terrain-runtime-validation.json`、`visual-review.json` 和 `independent-review.json`。

复验入口：`tests/run_terrain_runtime_validation.ps1`，传入 Godot 4.6.3 console 路径和新的仓库外输出目录。该入口先核对已批准来源，再运行编辑、试战与地形回归。Git 属性保存受摘要校验的源文件和原始证据字节；批准记录引用的 PNG 导入参数随素材提交。

提交前从暂存区新检出的副本已完成首次 Godot 导入、46 项来源与 85 项原始证据核对，以及五阶段全量运行，退出码均为 0。新证据位于 `reviews/2026-09-27/release-clean-checkout/`。首次运行曾有一项湿地自动点击断言失败，本次改进了测试中按下与释放的派发隔离，保留真实输入处理和移动断言，随后完整回归通过；未修改生产运行代码和美术。失败记录、诊断推测边界与最终结果见该目录的 `verification-summary.json`。

`terrain-kit-approved.json` 与 `water-depth-approved.json` 记录当时批准；`terrain-map-size-receipt.json` 是尺寸任务完成时的回执。早期 `candidate-receipt.json`、来源清单中的候选状态，以及历史批次中的未批准状态描述仅代表它们的生成阶段，不作为当前发布状态。
