# 地形工作台正式战斗接入

## 阶段成果与完成条件

本轮目标是让已批准的地形拼接库成为可以实际试玩的地图创作工具。完成条件：作者绘制或加载的地图进入正式 `TacticalScene`；渲染、占格和寻路共用同一份地形；可以重开、查看胜败结果和返回编辑；返回后创作数据与撤销记录保留；退出不留下战斗对象或全局地图数据；通过实际操作、旧场景回归、看图与独立审查。

具体作业依次为：地图数据接入、工作台进入和返回、运行及原场景回归、独立审查与证据归档。本轮以本地可用功能交付，未安排提交、发布或将试战地图加入随机遭遇池。

## 使用

在 Godot 运行 `scenes/playground/terrain_painter.tscn`。

1. 绘制地图，或选择示例后点击“载入”，也可“加载 JSON”。在右上设置 10 至 25 格的边长，点击“调整大小”；地图始终为正方形，扩大或缩小均可撤销。
2. 点击右上“开始试战”。基础剑士与枪兵会出现在同一片可通行区域的两端。
3. 点击可达格移动，通过底部技能栏和“结束行动”操作。镜头支持拖动、缩放和“居中”，格线、范围和地形提示可单独开关。
4. 点击“重新试战”，恢复本次地图初始状态；地图本身不变。
5. 点击“返回编辑”，继续绘制、撤销或保存。胜败界面同样提供“返回编辑”。

地图至少需要两格通过上下左右互相连通的可通行地形。不满足时留在工作台并显示原因。仅支持 10×10 至 25×25 的正方形；每张地图沿用同一套接壤检查。熔岩与森林、浅水、深水、沼泽直接接触时仍提示组合冲突，包含对角接触。

## 数据与规则

- 工作台保存地形、铺地和外观变体。试战对地图取独立副本，战斗造成的单位变化不写回创作文件。
- `terrain_battle_definition.gd` 先调用既有地形合同验证，再按现行 `Cell.is_passable()` 与四向邻居寻找最大连通区域。出生选择确定、互不重叠；相同地图得到相同出生点。
- 试战角色配置来自 `data/battlefields/terrain_workshop_test.json`，职业与敌人沿用 `myrmidon`、`test_lancer` 的现有数据。没有复制角色数值或技能规则。
- `TacticalScene.injected_map_data` 将地图直接交给 `TacticalManager.initialize_battle_data()`。原有地图 ID 入口继续有效，自定义地图不写入 `DataLoader.maps`。
- `terrain_battle_session.gd` 复用正式战斗场景与已批准地形绘制，工作台隐藏期间停止编辑输入；返回时释放战斗并恢复画布变换。基础剑士沿用已批准 HUD，只显示剑气系统。
- 停止战斗时先发出等待结束和移动取消信号，使动作在有效节点上退出，再释放战斗。移动完成时间与原规则保持一致；取消后的动作不提交占格变化。
- 本轮不新增单位部署、剧情、奖励或保存战斗进度。地形特殊职业例外与尚未落地的状态效果继续由玩法任务处理。

## 验证与复现

```powershell
./tests/run_terrain_runtime_validation.ps1 -GodotPath <Godot-4.6.3-console> -OutputDirectory <新的仓库外绝对目录>
```

统一入口核对已批准地形绘制内容，运行尺寸调整专项、正式战斗数据与实际移动专项、工作台按钮与返回专项、原注入入口检查及地形库整套回归。出现引擎错误、资源泄漏警告、失败断言、图像摘要不符或来源中途变化时，不能报告整批通过。

新专项检查三张示例在 1280×720 与 1920×1080 的正式战斗截图、鼠标移动、移动成本、胜败与重开、敌人行动期间退出、全局地图不变，以及返回编辑后的绘图与撤销。地形原专项继续检查合法组合、错误样例、邻接、保存回读及手工与 JSON 画面一致。

实际结果、保护状态与独立审查见 `assets/prototype/battlefield_courtyard/terrain-runtime-receipt.json`。当前批准范围只覆盖现有地形外观；任意新地图的布局可读性与战斗平衡仍需实际试玩。

地图尺寸功能及其最新验证见 `terrain-map-size.md`。原地形批准记录保留；Catalog 的尺寸校验按用户要求更新，三个外观函数与数据路径继续核对原批准摘要，其余 27 个视觉来源逐文件保持相同。

取消流程参考 Godot 官方问题库中关于 [await 持有局部引用](https://github.com/godotengine/godot/issues/118781)和[中断协程后局部对象未清理](https://github.com/godotengine/godot/issues/116706)的报告。本项目以 Godot 4.6.3 本地复现、退出时机专项和资源日志核验实际行为。
