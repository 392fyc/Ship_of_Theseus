# GHV-9 底部 HUD 字体与承载区域合同

状态：Godot 候选已通过独立审查，等待用户视觉审核。

## 字体层级

- 职业名与玩家名：14px。
- 等级：12px。
- 经验、HP、护盾：普通值 11px；长度达到 13 个字符时可逆回退为 9px。
- 技能快捷键：11px；技能次数：12px；冷却回合：22px。
- 移动力：18px。

上述文字均为运行时 `Label`，不得烘焙进外框或内容图片。经验、HP、护盾继续使用 IBM Plex Mono SemiBold 和 1px 描边；其他字段保持既有字体来源。

## 角色信息区

- 角色栏外框保持 226×108；头像区保持 72×82；信息列保持 124×82。
- 名称、等级／经验、生存信息三组高度依次为 20、22、32；两处纵向间距均为 4，因此总高仍为 82。
- 等级字段宽 40，经验字段宽 80，两者间距 4，总宽仍为 124。
- 经验轨道高 12；HP 与护盾的轨道及承载区各高 13，两条之间保留 2px 间距并继续共用一个生存信息外框。
- 长职业名和玩家名继续单行省略，完整内容保留在 tooltip；极大数值不得把角色栏撑宽。

## 技能与行动资源

- 快捷键角标为 18×18，文字水平和垂直居中。
- 技能次数承载区为 24×20；冷却数字继续在完整技能格中央显示。
- 移动力数字区宽 30，按字体实际高度排版；通过压缩资源条内部上下留白，行动资源条外框继续保持 274×40。
- 技能栏、角色栏、行动资源条及底部五区的外部尺寸和相对位置均不得改变。

## 边界

- 本合同只覆盖开发 HUD 纵向切片和组合画廊，不接入正式战斗 HUD。
- 不创建技能、武器、遗物或职业资源素材，不修改行动规则、遗物容量或角色数据。
