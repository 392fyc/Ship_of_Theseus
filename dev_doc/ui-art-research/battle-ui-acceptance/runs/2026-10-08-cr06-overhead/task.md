## 验收

1. 在正式 `courtyard` 10×10 进入 `TacticalScene`，保留基础剑士及枪兵现有素材，复现相邻单位。
2. 血量默认可见；预测显示/隐藏时，数字不覆盖目标血量文字、血条，相邻单位名牌和血量文字互不遮挡。保留预测内容与单位对应关系。同一单位的信息一起避让并保持固定相对位置，不能为了矩形不相交而散落到难以对应单位的位置。
3. 血条不宽于单位实际投影身体，逻辑高度 4；保留阵营识别，在独立 UI 层中绘制。与其他单位头部发生冲突时避让。
4. 镜头平移、缩放和窗口变化后，头顶信息随对应单位更新；静止时位置稳定，死亡或场景销毁时清理。
5. 1280×720、1920×1080、2560×1440 的原生整屏与状态在同一次 `frame_post_draw` 之后取得；逐图记录实际节点矩形和原图摘要。不得以计划坐标替代实际节点或以局部合成图替代原图。
6. C4 与 C8 同批运行。原图独立审查与自动检查分别记录。

## 持续约束

Compatibility；基础剑士只有剑气、没有印记；正方形地图边长 10–25；不设计剑圣回忆技能。字体、头像、技能图标、HUD 已批准几何及玩法数值保持。

本地采集使用离屏、无焦点窗口及内部输入，不使用系统鼠标。其结果证明本机绘制与内部交互，不替代后续新 attempt 的 Dot 实际鼠标功能复测。

CR-40 浮窗避让与内容高度随后单独实施。旧 G4 缺失原图仍为 NOT_TESTED；新图不能补成旧证据。地形可读性仍未修复，立项前由 Claude 提供量化目标与参考。
