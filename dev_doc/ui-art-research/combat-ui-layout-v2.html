这版排版做了什么

  • 三段定位对齐真实布局：信息面板钉左下、技能栏居中下、动作按钮钉右下（与 _layout_dashboard 一致）。
  • 信息面板分三栏：头像 / 武将信息(名+HP+剑气+印记，左对齐、行距统一、数值右对齐) / 8 属性 2×4 格(金线分隔)——④ 密度但不再挤撞。
  • 统一对齐：每行 标签 30px · 进度条弹性 · 数值右对齐 三段网格，HP 与剑气条同宽同基线；属性键左值右。
  • 技能槽状态清晰：键位左上 / 消耗右下 / 选中金边发光 / 冷却遮罩居中数字 / 被动缩小无键位。
  • 图标暂用字符占位（⚔◈⚡✦◉），真图标走像素管线。
