## 状态板

- 普通值：验证常规职业名、玩家名、等级、经验、HP 与护盾。
- 长职业名与玩家名：验证名称单行截断；完整名称保留在 tooltip。
- 护盾为零：验证当前护盾为零、上限仍为 100 时轨道清空，数值显示 `0/100`。非法最大值的安全归零由 `test_hud_value_meter.gd` 单独覆盖。
- 满值：验证经验、HP 与护盾达到上限时的填充和文字。
- 超大数值：验证六位数值不会越出轨道或遮挡相邻字段。

## 视觉检查结果

- 五个角色栏在 1280×720 的 24 像素安全边距内横向排布；较大分辨率只增加画廊留白，不改变 226×108 的组件合同。
- 头像列为 72×82、相对面板位置为 `(12, 13)`；信息列位于 `(90, 13)`、宽为 124。左右各留 12px，头像与信息间距为 6px。
- 外围九宫格绘制边缘按 6px 计算，画像和信息区与其至少保留 4px 透明净距，不再与外围边框贴合。
- 名称、等级／经验、生存信息三组高度为 20／22／32，两处间距均为 4，上下边距仍为 13。
- 等级与经验字段宽度为 40／80；经验轨道在 22 像素字段中以 12 像素高度垂直居中，HP 与护盾在共同外框内各使用 13 像素轨道。
- 名称格式为 `职业名 · 玩家名`；等级和数值均为运行时 Label，不烘焙进图片。
- 经验、HP、护盾数值使用无空格的 `当前值/最大值` 格式，在轨道内右对齐；普通值为 11px，十三字符长值可逆回退为 9px。
- 头像缺失时只显示显示数据显式提供的 fallback 字符；组件不自行读取职业、单位或头像来源。
