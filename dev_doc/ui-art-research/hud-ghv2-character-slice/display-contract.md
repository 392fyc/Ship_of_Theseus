# GHV-2 角色栏显示合同

## 范围

本纵向切片只验证角色栏的声明式布局、显示数据和运行时刷新。它不接入现有 `BottomDashboard`，也不修改 `Unit`、`TacticalManager`、`TacticalScene`、`RunState` 或 `GameAction`。

## 当前生产事实

| 字段 | 本期状态 | 允许的生产来源 |
| --- | --- | --- |
| 职业名 | 已有真实数据，可在后续集成时接通 | 现有职业数据 |
| HP 当前值 | 已有真实数据，可在后续集成时接通 | 现有单位生命值 |
| HP 最大值 | 已有真实数据，可在后续集成时接通 | 现有单位最大生命值 |
| 玩家自定义名称 | `mock-only` | 本期不新增来源 |
| 等级 | `mock-only` | 本期不新增来源 |
| 经验当前值／最大值 | `mock-only` | 本期不新增来源 |
| 护盾当前值／最大值 | `mock-only` | 本期不新增来源 |
| 头像纹理 | `mock-only` | 本期不新增来源 |

生产代码的唯一允许刷新方向是“既有玩法状态 → 新建的纯显示数据 → `apply_view()`”。组件不得反向读取、缓存或修改玩法对象；本期也不得建立新的生产刷新链。

## 组件边界

- `HudValueMeterViewData` 只保存当前值与最大值，并提供受限到 0—1 的只读比例和运行时数值文本。
- `HudCharacterViewData` 只组合职业名、玩家名、等级、经验、HP、护盾、可选头像纹理与显式头像 fallback 字符。
- 两种显示数据均不得持有 `Unit`、`RunState`、`GameAction` 或同类玩法对象。
- `HudValueMeter` 和 `CharacterHudPanel` 的静态节点全部由 `.tscn` 声明；脚本只通过 `apply_view()` 把显示值写入既有节点。
- 名称行始终按“职业名 · 玩家名”显示。单行溢出时截断，完整内容写入 tooltip。
- 经验、HP、护盾使用运行时 `ProgressBar` 和 `Label`。数值、填充比例、文字与头像内容不得烘焙进图片。
- HP 与护盾位于同一个 `SurvivalFrame` 中，但分别拥有独立轨道、填充和数值。

## 固定几何

- 根面板：226×108。
- 内边距：左右 12、上下 13；外围 6px 绘制边缘之外至少保留 4px 透明净距。
- 头像列：72×82。
- 头像列与信息列间距：6。
- 信息列宽：124；相对角色栏 x 为 90。
- 名称组、等级／经验组、生存组高度依次为 18、20、28。
- 三组之间的两个垂直间距均为 8。
- 经验轨道在 20 像素字段中保持 8 像素高并垂直居中；HP 与护盾轨道各 11 像素高。
- 数值格式为无空格的 `当前值/最大值`，在轨道内右对齐并由高对比描边字体动态渲染。

说明文字不参与以上空间计算。
