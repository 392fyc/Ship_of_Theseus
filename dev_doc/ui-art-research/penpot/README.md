# Penpot 云端设计接手入口

当前定版入口：[2026-09-24 基础战斗 HUD](2026-09-24-hud/README.md)。

可编辑画布保存在同一个 Penpot 云服务。仓库保存文件入口、命名版本、当前画板编号、对应预览、素材及 SHA256 清单，供其他机器定位和核对。

接手机器需要能访问该云端文件：使用同一账号，或已获该文件编辑权限的账号。克隆仓库后从上述入口继续；MCP 连接在目标机器单独建立。同步仓库会同步已提交并推送的索引和素材，在线编辑内容由 Penpot 云端保存。

每次定版保存新的命名版本并更新清单，防止接手时误用其他候选。本目录保存视觉交付资料，不作为玩法规则来源。`.gdignore` 使 Godot 跳过这些参考文件；运行素材继续放在各自的正式资产目录。
