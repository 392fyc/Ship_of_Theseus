# GHV-6 行动资源三区视觉分组合同

状态：修订 3 已实现，并通过主任务测试、原尺寸截图检查与独立审查，等待用户视觉审核。

## Milestone 成果

行动资源条仍为 274×40、位于技能栏上方并保持中线居中。内部只包含三个等宽的 76px 语义区域，顺序固定为移动、标准行动、迅捷行动。

## 分组语言

- 行动资源条保留现有整体外框。
- 整体外框内部放置移动、标准行动、迅捷行动三个完整类边框；三者复用同一个 `ActionResourceSegment` 样式。
- 每个类边框都绘制相同的四条 1px 边和四角收边，内部完全透明，不使用区域色块。
- 三个完整边框之间保留 4px 间距，不再使用连续大内框、普通分割线或装饰柱。
- 分区不显示标题或类别文字。
- 移动仍以足迹和纯数值表示；标准行动仍为绿色圆点；迅捷行动仍为橘黄色三角。
- 容量、剩余量、耗尽灰化和移动可用性全部保持运行时行为。

## 边界

- 不改变行动经济、容量范围、消耗判定或 `ActionResourceViewData`。
- 不改变完整底栏尺寸、行动条坐标或与技能栏的 6px 垂直间距。
- 不修改正式 `ActionResourceBar`、`BottomDashboard` 或战术状态接线。
- 本阶段没有生成图片、调用外部 API 或购买素材。
