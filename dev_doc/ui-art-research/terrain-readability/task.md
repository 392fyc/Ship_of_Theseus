## 接收的量化目标

数值来自本项目 Claude 审查，作为本项验收值；官方参考用于说明视觉方法，不声称游戏作者采用了这些数值。

| 项目 | 条件 |
| --- | --- |
| T1 轮廓 | 内缘 2 像素与外缘 4 像素的 L* 中位数差 ≥15；至少 80% 轮廓周长的局部差 ≥10 |
| T2 墙、柱 | 受光顶面 L* ≥相邻铺地中位数 +10；侧面比顶面低至少 8；保持左上光源 |
| T3 树、灌木 | 树冠与外围草地中位数 ΔL* ≥12，或 ΔL* ≥8 且 ΔE00 ≥15；暗侧允许 1 像素、L* ≤12 的轮廓 |
| T4 接地 | 接触阴影比周围地面暗 8–12 L*；宽度不超过实际显示半格 |
| T5 地面 | 铺地 L* 四分位距不增加；草地、铺地平均明度各保持在基线 ±3；接壤、水深和 C7 保持有效 |
| T6 眯眼 | 720p 原图做 σ=2 像素高斯模糊后，内外缘中位数差仍 ≥10 |

每种地图、分辨率都含树、墙、柱、碎石各至少 3 个实例。出现灌木时同步检查 T3。不把两种地图的实例合并凑数，不通过放大 25×25 镜头规避小物体问题。C4/C8 随每批运行。
