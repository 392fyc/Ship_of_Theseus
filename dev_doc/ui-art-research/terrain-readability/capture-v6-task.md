# 地形可读性采集 V6：原生像素中心遮罩对齐

## 当前状态

TERRAIN-READABILITY-01 的像素基线、素材结论和 Milestone 均未完成。V6 是仅供审查的采集工具候选；本轮没有启动 Godot 原生像素采集，也没有测量地形或素材。本候选不修改生产代码、素材、地图、相机、阈值、排除定义或 V1–V5 文件，不创建 PR。

## 已确认依据

外部 V5 排除遮罩复核记录的 SHA-256 为 `e67bfc20487d8e4275b75a0a1e00510947d7d917ea5955f5cd3eb8d5c4f22fb3`。其六组输入中，两个 1280×720 案例在排除 bounds 像素中心覆盖上没有漏点；两个 1920×1080 案例各报告 UI 漏 18 个中心、单位分别漏 414 和 420 个中心；两个 2560×1440 案例各报告 UI 漏 24 个中心、单位分别漏 224 和 448 个中心。漏点位于 fractional bounds 映射到的原生像素边缘。V2 冻结验证器按像素索引加 0.5、逻辑半开矩形和 alpha byte `>127` 判断覆盖。

V6 只改变测试采集器为 `exclusions` 创建的 `ColorRect` 边界：使用当次主窗口 `final_transform` 把原始逻辑矩形映射到原生空间，求出其包含中心落在原始半开矩形内的完整像素单元，再反变换这些单元边界供遮罩绘制。原始 nominal bounds、既有 UI/单位排除来源及阈值均保留。算法按中心集合对齐，不对所有边界一概膨胀，也不删除或隐藏实例。

## 保留的验收门槛

V6 继续继承 V5/V4 的正式入口、出生用例、道具、镜头、阈值、12 张同帧图、完整 RGBA、C4/C8、实际排除定义、alpha byte `>127`、每类至少 3 个可见实例，以及两个旧石柱/碎石样本。新增 manifest 记录每次遮罩绘制的原始 bounds、逻辑裁剪 bounds、实际 `final_transform`、变换后的原始边界、原生像素单元边界和反变换绘制矩形。验证器保留 V5 全部检查，并核对量化值可由这些原始字段重算。

Python 定向测试读取通过 `TERRAIN_V5_ROOT_CAUSE_JSON` 指定的仓外复核 JSON，核对其 SHA、1080p/1440p 原件字节与摘要，并对每个已报告漏点验证：旧遮罩的缺点数量与报告相符，量化覆盖全部原始有效像素中心，且没有新增矩形外中心。720p 使用两份原始遮罩中的全部有效 UI/单位 bounds 核对中心集合不变；这不代表 V6 已生成或通过新的 720p PNG。另有非零平移/小数边界和不支持变换的正反例。
