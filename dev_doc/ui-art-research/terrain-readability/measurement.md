# 同帧采集与测量口径

## 采集要求

复用 `TerrainBattleSession` → 正式 `TacticalScene`，正方形 10、25，保留项目拉伸和 Compatibility。每个样本记录完整提交、场景/地图/脚本/素材摘要、原始分辨率、实际镜头及初始 fit 状态。每张输出记录 Window、Viewport、Texture、Image 尺寸和逐文件 SHA256。

正式整屏、透明道具层、可见实例 ID、顶面/侧面/接触阴影分类掩膜、地面和网格排除掩膜必须来自同一次 `frame_post_draw`。提前准备同步渲染的 SubViewport，固定同一个道具姿态与变换；回调内依次读取各 Texture 和状态，中间不得等待新帧，也不得先截图再隐藏地面重画。记录回调前后帧号、每视口 canvas/final transform 和尺寸。

实现优先采用独立的测试视口复制呈现节点，保持纹理、材质、层级、排序、动画姿态和镜头一致；ID 视口保持原纹理 alpha，只改变分类颜色。正式视口不改生产渲染层。须先用重建对照确认复制视口与正式视口的对应物体位置、轮廓完全一致；不能仅凭相同帧号就声称复制准确。Godot 的多视口 API 提供机制，实际正确性仍须原图验证。

ID 标记使用稳定的地图坐标、道具类型和序号，不能只用每次启动变化的实例整数。透明道具层 alpha >0.5 定义轮廓；逐实例可见掩膜要扣除被其他物体、单位与 HUD 遮挡的部分。ID 边缘混色、分类不明和缺失掩膜必须报告，不猜测类别。顶面、侧面与接触阴影不能由亮暗像素反推，须由实际绘制部件对应。

网格须独立标记，不按“很亮的线”猜测；T1 外环扣除其他物体、网格、HUD 和单位。T5 在同地图、镜头、姿态的纯地面层使用相同样本掩膜与基线比较。接触阴影须保存无阴影地面对照，用同位置明度差校核，避免把地板原有暗斑算作阴影。

## 离线函数边界

`terrain_readability_metrics.py` 是数组测量库，复用现有 `claude_review_checks.lab` 的 sRGB/D65 转换。它不负责验证采集来源、帧号、原件 SHA、实例数或 C4/C8；未来批次入口必须完成这些前置，不能把单个函数 PASS 当作整批验收。

- T1：原始物理像素，不先缩图。采用欧氏圆盘半径 2 腐蚀、半径 4 膨胀；有效外环扣除排除掩膜。局部样本为每个边界像素周围半径 4 的圆盘，分别取内/外环 L* 中位数。数字轮廓按暴露的四邻接像素边长度加权；无外环样本的边记为未测，不从分母删除。报告有效覆盖率；覆盖不足 80% 时 NOT_TESTED，不能判 PASS。
- 掩膜为空、被裁至边界、无法形成完整内核，或外环无样本时为 NOT_TESTED。尤其 25×25 下小碎石可能没有足够采样区域，须保留这种失败前置，不能悄悄降低半径。
- T2：分别取可见顶面、侧面和相邻铺地的中位数；光源方向与左上亮面另由原图审查。
- T3：取树冠和外围草地的 Lab 分量中位数，使用 CIEDE2000（kL=kC=kH=1）。阈值为项目约定，不是色差公式的普适可读性保证。`foliage_outline` 要求绘制的轮廓掩膜位于最终树冠掩膜的一像素内边界及独立的暗侧分类掩膜中，所有轮廓像素 L*≤12；明确为空表示没有添加轮廓。`foliage` 必须同时收到该检查的 PASS 才能判完整 T3 通过；未提供检查结果返回 NOT_TESTED。暗侧分类与实际光源的对应仍须采集部件映射及原图复核。
- T4：逐阴影像素与同位置无阴影地面求 ΔL* 后取中位数；宽度必须由采集的实际阴影掩膜测出并与同帧格宽比较。函数接受已测宽度，不验证影子方向/接触位置。
- T5：同样本的铺地四分位距与草地、铺地均值变化；地表接壤、水深与 C7 是另外的必查项。
- T6：仅对 1280×720 原始 RGB 作 σ=2 高斯分析，不改变保存的原图；使用原掩膜内外环重新计算明度差。其他分辨率不冒称 T6 已测。

## 官方技术依据

- [Godot 4.6 Viewport](https://docs.godotengine.org/en/4.6/classes/class_viewport.html)、[SubViewport](https://docs.godotengine.org/en/4.6/classes/class_subviewport.html)：独立渲染目标、透明背景、画布变换。
- [RenderingServer](https://docs.godotengine.org/en/4.6/classes/class_renderingserver.html)：`frame_post_draw` 在全部视口更新后发出；headless 禁用渲染，不能提供像素证据。
- [Sharma、Wu、Dalal 的 CIEDE2000 说明及补充数据](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/)：用于校准色差运算；没有把该论文说成游戏可读性阈值依据。
