# R12：柱子断口明暗修订

## 阶段成果与完成条件

使原尺寸下的残柱断口能够被辨认。完成路径为：限定实现、独立审查与本地提交、冻结材料后交 YC 进行同组云测、原图与测量核收、独立原图审查、签回关闭。当前阶段只做 10×10、1280×720、Compatibility；单组结论成立后再决定是否满足既定六组复测前置。不推送、不建 PR。

## 依据

- 基线：R11 提交 `a9d03437b2dd501ed8fa7cd1d54482868fc967fa`。
- TASK200 原件与独审确认 G1 十二槽通过；O1 原独立 NOT_TESTED 字段保留，新增独立归因说明体外 28 个变化像素来自阵营底座，固定本体贡献比例 630/630 不受影响。
- 原断口辨识仍失败。Claude 原图审查指出，顶面 L*56、阶差线 L*54/56、短柱断面 L*55 过于接近，缺少背光和投影。该审查原文 SHA256：`107fb9dae440c8b6d61e105280a4efaebcf6cf9a6c1e1b1787027e4913757832`。

## 写入范围与实现

只改 `scripts/ui/playground/courtyard_board_view.gd::_add_pillar` 的断口着色和本说明。

1. 阶差竖线沿用原端点与宽度。由真实阶差方向推导朝向，对左上光源：受光 L*50，背光 L*36。
2. 在阶差的较低一侧加入宽 1.6 个局部单位、L*44 的顶面投影。投影与原 `top_surface` 求交，只在原表面内绘制；复用同一石材与局部坐标 UV。
3. 短柱缺口露出的原顶面 x=4.5–6.1 使用同样投影；原 `fracture_face` 只将目标明度改为 L*38。
4. 顶面基准仍为 L*56。原实体轮廓点、柱径高度、柱身明暗剖面、凹槽、柱础与接触阴影均不变。树、墙、地面、水岸、格线、滤波、玩法和验收阈值不变。

表面投影片不扩大实体占据区域，不使用新着色器，也不修改采集或测量版本。新增片段的共边与原纹理映射须在独审中核对，再由云端原图确认。
