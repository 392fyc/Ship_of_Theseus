# TASK131 R13 柱顶轮廓修订

## 目标与依据

R12 原尺寸截图和两名首次观看者的记录显示，三根柱顶的暗线只有约 2–5 像素，投影约 10–19 像素；读者仍主要把柱顶看成连续的斜切面。独立审查核实，R12 的柱顶实体轮廓没有改变。因此，Main 依据既有人类素材修订授权采纳 Claude R13 建议，让断口直接改变柱顶轮廓，并让三根柱共用同一模板。

证据对应 TASK131 attempt25 的 `main.png`（1280×720，SHA256 `9078f9398a66da5de795a7241de412df937de1dd8d7713a613699d2a7e971b56`）和 Claude R12 原图审查原件（SHA256 `4de72c33df9937a245151b3e91cd3a22cf24bb741a6e44ff4aed6e4532576425`）。

## 阶段成果与完成条件

本阶段以可复核的 R13 柱顶候选和签回记录为成果，按以下顺序完成：独立源码审查 → 本地提交 → 冻结候选输入并使用既有 Cloud 入口 → 原图与测量结果全核收 → 两位新原尺寸读者按原辨识门复核 → 独立审查并签回。辨识门要求三根柱都读作断口残柱，主要读法为残柱或断柱，不读作方柱、墓碑、界石或石墩；读者须是本轮新增的两位首次读者。

Cloud 核验限定为原同组 `10×10` 场景、`1280×720` 输出和 `Compatibility` 渲染器；本阶段不扩大到六组，也不推送或创建 PR。

## 写入范围与几何边界

本轮仅有两条写入路径：`scripts/ui/playground/courtyard_board_view.gd` 中的 `_add_pillar` 及直接相关的柱顶、断口辅助函数；以及本任务记录 `dev_doc/ui-art-research/terrain-readability/pillar-r13-task.md`。柱顶“不外扩”按几何包络核对：新轮廓不得超过原未切柱体的最高点和径向包络，并保留原 bounds。该约束不要求 R13 像素掩膜与 R12 相同；必须建立 R13 新基线，不能声称新掩膜必为旧 R12 掩膜的子集。

## 实现

- `across` 使用绝对局部单位的统一折线：`(0,0) (0.40,0) (0.55,9) (0.70,4) (0.85,13) (1,12)`。前 40% 保留完整椭圆顶沿；后段形成两次下落与回升。曲线不按柱高缩放，也不按实例补偿。
- 低侧下落面按 R12 光向取 L*36，回升受光面取 L*50；顶面仍为 L*56。每段断面以 1.0 局部单位的窄纹理片呈现，沿用原纹理采样和局部 UV。背光面向光源反方向偏移 1.6 局部单位绘制 L*44 投影。
- 顶面、柱身前侧条带、断面纹理片、投影和凹槽起点都使用同一连续分段曲线，并在折点精确插值。断面纹理片和投影与新顶面求交后才绘制，因此不覆盖背景。
- 短柱不再绘制方形柱头，也使用同一矮断柱模板。柱身 profile、四道凹槽的 u 位置、柱础、接触阴影、柱径、三档高度、墙树地面水岸格线、滤波与玩法均保持原实现。柱子 bounds 保持原值；柱顶包络按本节的“不外扩”定义核对。
