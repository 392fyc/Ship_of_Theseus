# GHA-1 HUD 中性表面提示合同

状态：两个 B 候选已选中并接入，等待独立审查。本文只约束两个已有 Godot 消费者的组件表面，不定义技能内容图标或完整 HUD。

## 共用参考与风格

- 视觉参考：`dev_doc/ui-art-research/hud-r1-material-sample-v1/hud-r1-material-direction-v1.png`。
- 统一方向：略微精细的像素化暗黑哥特游戏界面；黑紫铁／石材底，旧金属细边，低装饰密度。
- 像素密度：保持小尺寸下仍可读的细像素，不使用粗大马赛克块，不模拟低分辨率八位机画面。
- 表面职责：只承担可复用外壳材质；中心内容区透明，外部背景透明。
- 统一禁止：文字、数字、字母、技能图标、武器、人物、徽记焦点、宝石焦点、冷却遮罩、快捷键、次数、选中光、发光状态、资源点、足迹、圆点、三角、分隔柱、场景背景、投影画布、水印。

## 技能槽中性表面 A

Use case: stylized-concept
Asset type: isolated game HUD skill-slot frame texture
Primary request: 单个正方形技能槽中性外壳，透明背景和透明中心；四边闭合、四角对称，适合缩放到 64×64 与 58×58。
Input images: Image 1 为风格参考，只参考黑紫底、克制旧金和细像素密度，不复制完整 HUD 或其中图标。
Style/medium: 略微精细的像素化暗黑哥特界面材质；黑紫锻铁与深色石材主体，少量磨损旧金角件。
Composition/framing: 单个外壳正面平视、严格居中、占据画布主体；没有透视，没有场景。
Constraints: 真实透明背景；中心内容区真实透明；边缘薄且连续；无文字、无图标、无状态；无水印。
Avoid: 粗大像素、厚重浮雕、明亮宝石、复杂尖刺、圆形框、写实摄影、三维场景渲染。

## 技能槽中性表面 B

与 A 使用相同职责、参考和禁止项。差异仅为：更简洁的锻铁薄边，旧金只作为细刻线和四角微小铆接，降低装饰密度并扩大透明内容区。

## 行动资源条中性表面 A

Use case: stylized-concept
Asset type: isolated game HUD horizontal resource-strip frame texture
Primary request: 单个狭长横向行动资源条中性外壳，透明背景和透明中心；目标显示比例约 274×40，端部闭合，长边平直且适合水平拉伸。
Input images: Image 1 为风格参考，只参考黑紫底、克制旧金和细像素密度，不复制完整 HUD 或内部资源图形。
Style/medium: 与技能槽 A 同族的略微精细像素化暗黑哥特材质；黑紫锻铁／深色石材和少量磨损旧金角件。
Composition/framing: 单个细长外壳正面平视、严格居中、占据画布主体；没有透视，没有场景。
Constraints: 真实透明背景；中心内容区真实透明；端部薄而稳定；上下长边连续；无文字、无图标、无资源点、无分隔柱、无状态、无水印。
Avoid: 中央徽记、足迹、数值、圆点、三角、粗大像素、厚重浮雕、复杂尖刺、写实摄影、三维场景渲染。

## 行动资源条中性表面 B

与 A 使用相同职责、参考和禁止项。差异仅为：与技能槽 B 同族的低装饰锻铁薄框，旧金只保留为边缘细刻线和端部微小铆接，中央透明区尽可能宽。

## 生成与迭代规则

- 使用 Codex 内置 `imagegen`，每个候选单独调用；不使用外部 API key。
- 首轮仅生成四个原始候选。每次后续编辑只能修复一个明确问题，并重复透明背景、透明中心和禁止项。
- 原始结果保存到 `dev_doc/ui-art-research/hud-gha1-neutral-surfaces/raw/`；选中并机械清理后的项目资产保存到 `assets/ui/skins/hud/`。
- 本地机械清理只允许按低色差灰白背景生成透明度、裁切透明外边、居中和生成目标尺寸派生文件，不新增装饰内容。
- 若内置生成结果把透明棋盘烘焙进 RGB，原始结果仍完整保留；机械清理脚本只处理高亮中性灰白像素，并对外部和中心透明度另行验证。

## 本轮选择

- 技能槽：选择 B。其边框更薄，缩放到 64×64 和 58×58 后仍保有清楚的四角与旧金细线，不挤占技能内容区。
- 行动资源条：选择 B。其端部装饰较弱，274×40 下不会与足迹、数值、行动点争夺视觉焦点。
- 两个 B 候选的透明编辑输出仍为烘焙棋盘背景，因此使用 `clean_neutral_checkerboard.gd` 机械提取透明度；最终资产外部与中心均已验证为真实透明。
