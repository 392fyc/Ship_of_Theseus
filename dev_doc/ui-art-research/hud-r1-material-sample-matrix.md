# 底部战斗 HUD R1 联合材质样板矩阵

## Milestone 6 阶段成果

在不改变 HUD R1 几何布局的前提下，用少量真实内容和完整控件状态建立一套可复用的 UI 材质语言。样板通过后，才能按素材类型批量生产；本阶段不把批量素材接入 Godot。

## Task 6.1 样板内容

### 现有视觉锚点

- 人物原画：`assets/prototype/visual_style/samples/portrait_preview_final.png`，使用原文件在 Penpot 中裁切显示，不生成新的衍生文件。批准文件 SHA256 为 `9f123a2022abe62472530ebd13ba43587802623c0db7ff7af711f5cec5be0cf3`。
- UI 材质方向：`assets/prototype/visual_style/samples/ui_preview_final_v3.png` 只作为略微精细、暗黑哥特、黑紫底色和克制旧金装饰的材质参考，不再代表底部界面布局。批准文件 SHA256 为 `0c6f5a7bbc78b889f09e9dccc0423caaef3323bf6e5170314d333ad2c5bc64b6`。
- 布局源：Penpot `HUD R1 · Components` 与 `HUD R1 · Layouts`；仓内复核证据位于 `dev_doc/ui-art-research/penpot-hud-r1-review-v4/`。

### 代表性真实内容

技能栏使用剑圣当前六个基础技能，覆盖攻击、位移、防御反应、被动、奥义和资源爆发等不同图形语义：

| 槽位 | 设计库 ID | 名称 | 样板图形重点 |
|---|---|---|---|
| 1 | `kensei_zhanji` | 斩击 | 基础近战斩痕，作为最朴素的攻击图标基线 |
| 2 | `kensei_yishan` | 一闪 | 带方向和位移感的高速剑光 |
| 3 | `kensei_zhaojia` | 招架 | 剑格、防御火花或交叉防御语义 |
| 4 | `kensei_xinyan` | 心眼 | 被动与洞察语义，同时验证被动技能的快捷键角标 |
| 5 | `kensei_juhe` | 居合 | 高消耗奥义，强调蓄势和单次爆发 |
| 6 | `kensei_badao` | 拔刀 | 满印记后的槽位替换形态，强调范围与资源倾泻 |

装备栏使用设计库当前已上架的 `eq_wpn_iron_sword`（铁剑）作为占用态武器图标。当前装备快照没有防具记录，因此防具槽只验证空槽、悬停和不可用材质，不虚构生产防具。

当前遗物快照没有可用记录，因此本轮不创建具有正式名称和玩法含义的遗物。遗物栏只验证空槽、悬停、选中和一个明确标注为“非生产占用测试”的中性徽记；该徽记不得进入后续内容素材清单。

全职业通用血瓶只生成视觉按钮，不新增使用次数、补充方式、冷却或治疗数值。

### 控件与状态覆盖

- 角色栏：头像框；职业/名称字段底框；等级/经验组；共享外框内的生命值与护盾双条。
- 装备栏：武器占用态、防具空槽态、32×32 血瓶按钮的常态、悬停、按下和不可用状态。
- 技能栏：6 个 64×64 技能按钮；常态、悬停、按下、选中和不可用状态；可复用的无文字快捷键角标底框。
- 行动资源：标准行动绿色圆点、迅捷行动橘黄色三角的可用与已消耗状态；移动格数的可用和整体灰化状态。
- 遗物栏：8 个 44×44 正方形槽位；空槽、悬停、选中和非生产占用测试态。
- 结束回合：52×52 按钮的常态、悬停、按下和不可用状态。
- 通用框体：五个组件的边框、角饰、分隔线和可供 NinePatchRect 切分的无文字面板素材。

## 生成与组合流程

1. 以 SoT 已批准视觉锚点和本文件为权威提示合同；外部风格库只能帮助拆分构图与材质描述，不能替代项目规则或提供素材来源。
2. 生成执行只使用当前 Codex 会话内置的 `imagegen`，不得调用外部 API key、SDK、命令行或 HTTP 服务。
3. 先生成少量材质与图标候选；本地处理只允许透明清理、裁切、分层、NinePatch 切分和尺寸转换，并记录父文件与衍生文件 SHA256。
4. 将候选放入 Penpot R1 组件，不调整 R1 外框和主要分组；分别导出 1280×720、1920×1080、2560×1440 组合图。
5. 联合样板通过用户视觉确认后，再建立按类型拆分的正式批量清单。购买任何素材仍需用户先行确认。

## 验收标准

- UI、人物原画和既有战棋人物在同屏时具有一致的像素密度、边缘锐度、黑紫与旧金层级，不出现粗大像素块或贴图风格割裂。
- 44×44 遗物槽、52×52 装备和结束按钮、64×64 技能按钮在 1 倍画布上仍能辨认主要轮廓。
- 不烘焙名称、数值、快捷键或说明文字；可复用部件保持透明，不出现白底或透明边污染。
- 生命值、护盾、经验与三类行动资源在不依赖常驻文字的情况下可区分；移动资源失效只灰化，不叠加斜杠。
- 五个 HUD 组件的材质语言一致，但信息层级清楚，技能和行动资源不会被装饰边框压低可读性。
- 三档导出不发生边框拉伸、槽位变形、内容裁切或安全边距回归。
