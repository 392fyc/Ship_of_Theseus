# GHV-3 实用 HUD 纵向切片审核入口

本目录记录装备栏、固定血瓶按钮、8 格遗物视觉网格和结束操作区的 Godot 4.6.3 实机画廊截图。当前截图已在 GHV-7 中刷新安全净距并通过独立复核，等待用户视觉审核。

## 建议先看

- `hud_utility_slice_1280x720.png`：最低验收分辨率，最容易发现裁切、边框拥挤和禁用态不清楚的问题。
- `hud_utility_slice_1920x1080.png`：常用桌面分辨率。
- `hud_utility_slice_2560x1440.png`：确认固定 HUD 尺寸不会被画布放大。

每张图从上到下依次为：空装备／空遗物／结束回合；mock 占用／局部 mock 遗物／结束移动；全部不可用。画廊标题和状态说明只用于审核，不属于正式 HUD，也不参与组件几何计算。

## 当前边界

- 8 个遗物槽只表示已批准的视觉槽壳；现行玩法容量仍为 6。
- 彩色交叉纹理仅用于证明运行时内容层，没有作为正式武器、防具、血瓶或遗物图标导入。
- 面板与 52×52 装备槽／40×40 遗物槽使用已有中性表面；人物画像、装备、血瓶和遗物内框均在外围绘制边缘之外保留至少 4px 透明净距。
- 32×32 血瓶按钮外壳、44×44 结束操作菱形框与 18×24 沙漏已经由后续 GHA-3 原子素材批次接入。
- 本批次未接入生产 `BottomDashboard`，未提交、未发布，等待用户视觉审核。
