## 视觉检查清单

- 技能槽不出现 `ACTIVE`、`PASSIVE` 或 `P` 类别标识；
- 快捷键文字在 16×16 方形角标内水平、垂直居中；
- 5／6／7 技能都位于同一个 476×108 固定容器内；
- 行动资源没有“可用”“已用”文字，没有装饰分隔柱，没有耗尽斜杠；
- 标准行动保持圆点，迅捷行动保持三角；容量 1—3 只显示实际拥有的点数并在固定区域内居中；
- 移动使用向上的单只足迹和纯数值，失效时只灰化；
- 所有板块均在安全画布内，无裁切、重叠或越界。

## 检查结果

- 5／6／7 技能均在 476×108 固定外框中居中；5、6 技能使用 64×64，7 技能仅在内部使用 58×58，不改变外框尺寸。
- 快捷键数字位于 16×16 方形角标中心；没有出现技能类别文字或类别字母。
- 技能冷却以技能槽中央的整数剩余回合数显示，并使用半透明近黑暗层压低亮度、保留图标辨识度；不再使用紫色比例色块。
- 标准行动圆点、迅捷行动三角均按实际容量 1—3 创建；耗尽态保持原形，只使用统一灰色。
- 行动资源条保留整体外框；内部三区各自使用同一个完整透明类边框，以 4px 间距保持独立，没有区域色块、普通分割线或装饰分隔柱。
- 移动图形经第二轮调整为向上的单只足迹，由分离的脚跟、前脚掌和大小递减脚趾构成；不可用时图形与数值只灰化。
- 画廊在 1080p 与 1440p 中刻意保持原生像素尺寸，用于检查细节密度；整套 HUD 的项目级缩放不在 GHV-1 范围内。
- 技能槽在 64×64 与 58×58 两档使用同一张 64×64 中性外壳，四角闭合且没有明显拉伸或内容区污染。
- 行动资源条使用 274×40 中性外壳；端部、长边与内部运行时内容没有重叠或可见接缝。
