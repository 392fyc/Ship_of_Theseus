# GHV-10 默认五技能合同

状态：Godot 候选已于 2026-09-05 通过用户视觉审核；本 Task 完成，尚未提交或发布。

## 默认规则

- 未显式指定技能数量时，完整底部 HUD 画廊显示 5 个技能。
- 三种动态状态同样固定显示 5 个技能，快捷键依次为 `1`、`2`、`Q`、`E`、`R`。
- 冷却、次数、可主动触发的被动技能等验证状态继续保留在这五个槽位内。

## 可变数量规则

- 5 技能：64×64，间距 8，总宽 352，在 476×108 技能栏内水平居中。
- 显式传入 6 技能时仍显示 6 个 64×64 槽；显式传入 7 技能时仍显示 7 个 56×56 槽。
- 技能栏外框尺寸、底部五区位置、行动资源条位置和 20×20 棋盘压力画面均不改变。

## 边界

- 本合同只改变开发画廊的默认审核数量，不修改正式技能数据、槽位上限或战斗 HUD 接线。
- 不生成新素材，不删除 6／7 技能截图，不修改玩法逻辑。
