一、底栏信息面板 BottomDashboard（②皮肤 + ④密度）

左 头像 · 中 武将信息+HP+剑气+印记 · 右 8 属性紧凑格。整块一个冷石哥特框。

原生：冷石框/角钉/HP+剑气+XP 段条/印记块/属性/战术缩览 素材：头像立绘（+ 可选的更精致金丝角饰）

二、技能栏 SkillBar（②皮肤 · 四主动 + 被动）

屏幕底部居中常驻。左上键位 1-4 / 右下消耗 / 冷却中心遮罩 / 选中金边 / 不可用置灰 / 被动无键位。

原生：冷石槽框/角钉/状态(常态·选中金边发光·冷却台阶遮罩)/键位+消耗角标/几何占位图标 素材：四技能真图标终版（按 ② 气质，过渡可用 SDF shader）

三、伤害预测窗 DamageForecaster（②皮肤 · 浮目标头顶）

原生：全部（冷石框/三角/双色描边/类型点/文本）—— 现 DamageForecaster 已是此画法，仅换冷石配色

四、原生 vs 素材 分工总表

组件原生自做（路 A · SoT）像素管线（路 B · Mercury，按 ② 气质）
信息面板冷石框 · 角钉 · HP/护盾/XP 段条 · 剑气 10 格 + 阈值线 · 心道势印记块 · 8 属性 · 战术缩览角色头像立绘 · 可选更精致金丝角饰
技能栏冷石槽框 · 全状态(常态/选中金边发光/冷却台阶/置灰) · 键位+消耗角标 · 被动小图标位四技能真图标终版（过渡用 SDF shader 或字占位）
伤害预测窗全部(框/三角/类型点/数值/命中暴击反击行)无（纯原生即可）
伤害飘字像素数字 + 几何类型字形 + 升起淡出动效(Tween)可选：类型字形换像素点阵 sprite
