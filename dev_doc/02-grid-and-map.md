# 02 - 网格与地图系统

> 返回 [总纲](./README.md)

## 概述

正方形网格，地图尺寸≤10×10。无高低差系统。通过**基础地形**、**特殊地形**和**建筑**三个层次提供战术深度。视野系统将在独立文档中介绍。

---

## 网格定义

每个格子由三层构成：

```
Cell:
  position: Vector2i
  terrain: TerrainType           # 第1层：基础地形（始终存在）
  special_terrain: SpecialTerrain | null  # 第2层：特殊地形（叠加在基础地形上）
  building: Building | null      # 第3层：建筑（覆盖基础地形效果）
  occupant: Unit | null          # 当前站在上面的单位

Grid:
  width: int (max 10)
  height: int (max 10)
  cells: Array[Array[Cell]]
```

### 三层效果叠加规则

| 情况 | 生效规则 |
|------|---------|
| 仅基础地形 | 基础地形效果生效 |
| 基础地形 + 特殊地形 | 两者**叠加**生效 |
| 基础地形 + 建筑 | 建筑效果生效，基础地形效果**被覆盖** |
| 基础地形 + 特殊地形 + 建筑 | 建筑效果生效（覆盖基础地形），Buff/Debuff类特殊地形**可叠加**到建筑上；陷阱和传送阵**不可**处于建筑上 |
| 建筑被摧毁后 | 建筑加成消失，**不恢复**基础地形效果（格子变为无效果的废墟） |

## 基础地形

基础地形是地图的底层，每个格子必有一种基础地形。

| 地形 | 移动消耗 | 效果 | 可通行 | 阻挡攻击线 |
|------|---------|------|--------|-----------|
| PLAIN（平地） | 1 | 无 | ✅ | ❌ |
| FOREST（树林） | 2 | +闪避 | ✅ | ❌ |
| MOUNTAIN（山地） | 2 | +防御, +魔防 | ✅ | ❌ |
| PEAK（山峰） | - | - | ❌（任何单位） | ✅ 阻挡远程攻击线 |
| WALL（墙壁） | - | - | ❌（特殊职业除外） | ❌ |
| SHALLOW_WATER（浅水） | 2 | 潮湿（特殊Buff） | ✅ | ❌ |
| DEEP_WATER（深水） | - | 潮湿（特殊Buff） | ❌（特殊职业除外） | ❌ |
| LAVA（熔岩） | 2 | 燃烧 | ✅ | ❌ |
| SWAMP（毒沼） | 3 | 中毒 | ✅ | ❌ |

### 山峰与攻击线

山峰（PEAK）是唯一阻挡攻击线的基础地形。远程攻击/技能在判定射程时，需要检查攻击者到目标的直线路径上是否有山峰格子。若有，则该目标不可被攻击。

```
攻击线检查:
  从攻击者到目标画直线
  若路径上经过 PEAK 格子 → 攻击被阻挡，不可选择该目标
  其他地形（含WALL）不阻挡攻击线
```

*攻击线的具体算法（Bresenham/射线检测）在实现时确定。*

### 基础地形附加效果说明

- **潮湿**：特殊Buff，具体效果将在技能/效果系统中定义（可能影响雷系技能伤害、火系技能效果等）
- **燃烧**：进入/站在熔岩上时获得燃烧Debuff，遵循01中的Buff/Debuff时机规则
- **中毒**：进入/站在毒沼上时获得中毒Debuff

## 特殊地形

特殊地形**叠加**在基础地形之上，不替代基础地形效果。

### 来源

- **地图预设**：部分特殊地形在地图数据中预先配置（如治愈之地、传送阵）
- **技能产生**：部分特殊地形由单位使用技能在战斗中动态创建（如Buff区域、Debuff区域、陷阱）

### 生效条件

一般情况下，**停留在格子上时**生效（移动路过不触发，以简化路径计算和寻路逻辑）。

### 特殊地形分类

| 分类 | 触发方式 | 来源 | 阵营规则 |
|------|---------|------|---------|
| Buff类 | 停留时持续生效 | 地图预设 / 技能产生 | 默认仅对施加者友方生效（特殊情况双方生效） |
| Debuff类 | 停留时持续生效 | 技能产生为主 | 默认仅对施加者敌方生效（特殊情况双方生效） |
| 陷阱类 | 停留时触发 | 技能产生为主 | 仅对施加者敌方生效 |
| 传送阵 | 停留时触发传送 | 地图预设 | 对所有单位生效 |

### 特殊地形示例

| 特殊地形 | 分类 | 效果 |
|---------|------|------|
| 治愈之地 | Buff | 停留时每回合回复HP |
| [技能产生的Buff区域] | Buff | 由具体技能定义 |
| [技能产生的Debuff区域] | Debuff | 由具体技能定义 |
| [技能产生的陷阱] | 陷阱 | 停留时触发（伤害/减速/眩晕等） |
| 传送阵 | 传送 | 停留时传送到配对的传送阵 |

### 特殊地形与建筑的交互

| 特殊地形分类 | 可否叠加到建筑上 |
|-------------|----------------|
| Buff类 | ✅ 可以 |
| Debuff类 | ✅ 可以 |
| 陷阱类 | ❌ 不可 |
| 传送阵 | ❌ 不可 |

### 地形改变技能

存在技能可以改变基础地形和特殊地形：
- 建筑格**不可被强制改变**，即使建筑已被摧毁（废墟格子也不可被地形改变技能影响）

## 建筑

建筑放置在网格上占据格子。详细的建筑列表、建造/升级/修复规则见 → [11-城镇建设](./11-town-building.md)。

本节定义建筑在网格和战斗中的**通用交互规则**。

### 所有权与生效范围

| 建筑来源 | 效果对象 |
|---------|---------|
| 玩家建造的建筑 | 仅对玩家方生效 |
| 地图预设的建筑 | 对双方生效 |

### 占据机制

建筑分为两种交互模式：

| 交互模式 | 说明 | 示例 |
|---------|------|------|
| 通用型 | 任何单位均可进入并自动获得效果 | 哨塔、要塞 |
| 限制型 | 符合条件的单位停留时自动占据并获得效果；不符合条件的单位可以进入但仅视为停留，不获得建筑效果 | 巨弩（弓/弩职业）、魔法塔（魔法职业） |

- **占据 = 停留**：符合条件的单位停留在建筑格上即自动占据
- 不需要专门的"占据"操作
- 离开建筑格时自动解除占据

### 建筑耐久系统

建筑使用**耐久值**而非HP。受到攻击时，根据**伤害类型**扣减固定点数耐久（不使用常规伤害公式）。

```
BuildingDurability:
  current: int
  max: int
  damage_cost: Dict[String, int]  # 各伤害类型组合扣减的固定耐久点数

示例（具体数值待定）:
  physical: 1点
  magical: 2点
  siege: 3点    # 攻城类技能
  ...
```

**设计意图**：防止高伤害单位轻松摧毁建筑，同时低伤害职业也不会被建筑困住。所有人面对建筑的拆除速度相对一致。

### 建筑被摧毁

- 耐久降至0时建筑被摧毁
- 摧毁后该格子变为**废墟**：失去建筑加成，**不恢复**基础地形效果
- 废墟格可通行，无特殊效果
- 建筑可在准备阶段消耗金币**修复**（详见11-城镇建设）

### 占据者受伤时的建筑联动

部分建筑（哨塔、要塞）在占据单位受到伤害时，建筑也会受到耐久损伤：

```
当占据者受到攻击:
  1. 先结算对单位的伤害（含建筑减伤效果）
  2. 建筑按攻击的伤害类型扣减对应固定点数耐久
```

## 移动与寻路

### 移动范围计算（BFS）

```
func get_movable_cells(unit: Unit) -> Array[Vector2i]:
  BFS from unit.position
  每步扣除对应地形的移动消耗
  总消耗 ≤ unit.move_points 的格子为可达
  不可通行格子排除（PEAK / WALL / DEEP_WATER / 拒马等，特殊职业例外）
  被敌方占据的格子不可通行
  被友方占据的格子可穿越但不可停留
```

### 路径计算（A*）

选定目标格后，用A*寻路计算实际移动路径。

### 寻路简化说明

陷阱类特殊地形**不影响寻路计算**——路径不会自动绕过陷阱。这是有意的简化设计，避免复杂的路径规划对玩家和AI造成困难。

    { "type": "teleporter", "position": [0, 7], "pair_position": [7, 0] }
