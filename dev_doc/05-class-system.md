# 05 - 职业系统

> 返回 [总纲](./README.md)

## 概述

8个基础职业，每个职业拥有2个转职方向（魔法师为4系分支）。职业决定基础属性、武器限制和初始技能。成长通过**天赋树**（每次Run重置）+ **随机奖励**（装备/遗物/额外技能）来实现Build多样性。

转职通过天赋树中的特殊节点触发，选择后不可更改。

---

## 职业数据结构

```
Class:
  id: String
  name: String
  base_stats: UnitStats
  stat_growth: UnitStats            # 每次升级时各属性成长值
  innate_skills: Array[String]      # 初始自带技能ID
  equip_types: Array[String]        # 可装备的武器/防具类型
  class_tags: Array[String]         # 职业标签（用于建筑占据判定等）
  move_type: "foot" | "armored" | "mounted"
  advancement: Array[AdvancedClass] # 转职方向
```

## Build构成

一个角色的Build由以下要素构成：

```
UnitBuild:
  class: Class                     # 基础职业
  advanced_class: AdvancedClass | null  # 转职后的职业（未转职时为null）
  level: int                       # 当前等级
  talent_tree: TalentTreeState     # 天赋树状态（每次Run重置）
  active_skills: Array[Skill]      # 主动技能槽（天赋解锁 + 随机获得）
  passive_effects: Array[Passive]  # 被动效果（天赋树解锁）
  weapon: Weapon                   # 武器
  armor: Armor                     # 防具
  accessory: Accessory | null      # 饰品（待定）
  relics: Array[Relic]             # 遗物（Roguelite随机获得）
```

### Build多样性来源

| 来源 | 类型 | 说明 |
|------|------|------|
| 天赋树 | 可控 | 每次Run重置，玩家选择路径。提供被动特性、核心技能、转职 |
| 随机技能奖励 | 半随机 | 战斗奖励/商店提供额外技能，扩展可用技能池 |
| 装备 | 半随机 | 武器/防具/饰品，影响属性和特殊效果 |
| 遗物 | 随机 | Roguelite核心随机要素，提供独特被动效果 |
| 建筑 | 可控 | 城镇建设提供的战场/功能加成 |

**天赋树 = 骨架**（决定角色方向和转职），**随机要素 = 血肉**（在骨架上填充具体Build）。

同一个弓箭手→神射手，在不同Run中可能因为获得了不同的遗物和技能而形成完全不同的打法。

## Roguelite流派映射

以下流派可通过不同的职业+天赋+随机要素组合实现：

| 流派 | 典型职业 | 核心机制 |
|------|---------|---------|
| 单回合高伤害 | 剑圣、火之贤者、圣徒 | 高倍率技能/充能型/高CD型 |
| 高速追击（多段伤害） | 剑圣、剑士 | 速度差→追击概率，剑圣天赋进一步强化追击机制 |
| 再动流 | 剑士、佣兵 | 特殊天赋/遗物在单回合多次行动 |
| 辅助Buff机器 | 水之贤者、战术大师、神官 | 为队友施加Buff提升各乘区 |
| 战略流 | 工程师、发明家、生存大师 | 建筑/陷阱/召唤物控制战场 |
| 远程炮台 | 神射手 | 超额射程，防止反击 |
| 高机动游击 | 精灵射手、猎人、佣兵 | 攻击后移动，游击式战斗 |
| 防御/反伤流 | 重甲骑士 | 高防御+嘲讽+反伤 |
| DOT/Debuff流 | 精灵射手、电之贤者 | 附魔箭/连锁反应/持续伤害 |

## 升级与成长

Run中角色通过战斗获得经验升级：

```
升级:
  each growable_stat += class.stat_growth[stat]
  获得天赋点数（用于在天赋树中解锁节点）
```

- 一次Run内预期升级3-5次
- speed/move/block/vision不随升级成长
- 转职后stat_growth可能发生变化（转职职业有自己的成长率）

## 反击系统

除范围(area)类型攻击外，被攻击的单位若攻击距离足够可以对攻击者进行**反击**。

```
反击条件:
  1. 被攻击的技能/攻击的 attack_type ≠ "area"（范围攻击不触发反击）
  2. 被攻击者存活
  3. 被攻击者当前装备的武器/技能射程能够到达攻击者的位置
  4. 被攻击者未处于无法行动的状态（眩晕/冰冻等）

反击规则:
  - 反击使用被攻击者的普通攻击（非技能）
  - 每次被攻击最多反击1次
  - 反击走完整的攻击结算流程（命中→格挡→暴击→伤害→附加效果）
  - 反击不消耗行动次数，不影响该单位的正常回合行动
```

**战术意义**：
- 远程炮台（如神射手）可以在反击射程外攻击，安全输出
- 近战攻击近战角色必定面临反击，增加进攻风险
- 骑士的高格挡+反击 = 优秀的前排威慑力
- 重甲骑士的反伤特性可以在被攻击+反击中造成额外伤害

## 追击系统

速度优势的单位在攻击结算后有概率发动一次追加攻击。该系统对**所有职业**通用。

```
追击概率 = (attacker.speed - defender.speed) × 10%

  范围: 最低0%, 最高100%
  当攻击方速度≤防守方速度时，追击概率为0%

追击条件:
  1. 攻击方存活
  2. 原始攻击命中（Miss时不触发追击判定）
  3. 追击概率判定成功

追击规则:
  - 追击使用攻击方的普通攻击
  - 走完整的攻击结算流程（命中→格挡→暴击→伤害→附加效果）
  - 追击不触发反击
  - 追击不触发二次追击
  - 追击在反击之后结算
```

### 设计概念

参考火焰纹章的追击系统。速度差作为一个额外的乘区优势，给予高速单位多段攻击的收益。为平衡这一优势，低速单位在其他维度获得补偿：

| 低速单位补偿方式 | 典型职业 | 说明 |
|----------------|---------|------|
| 单次高伤害 | 魔法师 | 技能倍率高、AOE覆盖 |
| 高格挡/高防御 | 骑士 | 减免对方追击伤害 |
| 控制/Debuff | 牧师、工匠 | 通过状态效果降低对方输出 |
| 远程安全输出 | 弓箭手 | 射程优势避免被追击 |

### 剑士系扩展（预留）

剑士为追击系统的核心受益职业（全职业最高速度SPD=12），后续天赋树将围绕追击开发专属机制：
- 追击概率额外加成
- 追击触发特殊效果（如追击命中后获得Buff）
- 追击伤害修正（如追击暴击率提升）
- 剑圣转职深度特化追击系统

*具体细节随职业天赋逐步完善，追击系统和反击系统的计算细节也将同步补充。*

| 饰品 | 多样化效果 | ✅ |

### 武器类型

| 武器 | 使用职业 | 基础属性倾向 | 备注 |
|------|---------|-------------|------|
| 剑（Sword） | 剑士系 | ATK, HIT, CRIT | 双手武器 |
| 弓（Bow） | 弓箭手系 | ATK, CRIT, 射程参数 | 双手武器；精灵射手射程1时变melee |
| 魔法书（Tome） | 魔法师系 | MAG, HIT, 技能增幅 | 双手武器 |

### 二刀流（剑圣专属）

- **解锁方式**：剑圣转职后天赋分支中的「二刀流」节点
- **副手剑属性**：仅获取副手剑ATK的50%
- **副手特效**：后续节点可解锁副手特效50%效果生效，但附带负面效果（如属性下降）
- **核心收益**：来自天赋节点（追斩40%概率power 50%等），非装备堆叠
