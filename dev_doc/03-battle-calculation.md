# 03 - 战斗计算系统

> 返回 [总纲](./README.md)

## 概述

定义角色属性体系、伤害公式、命中/暴击/格挡判定和结算流程。

设计原则：
- **伤害公式**：乘区分层（各类修正独立相乘）
- **命中/暴击**：加法模型（各来源直接加减，对玩家透明）
- **属性全可见**：敌方HP和属性精确显示，玩家可以精确计算战术
- **伤害类型**：双轴分类（属性类型 × 攻击方式）

---

## 核心属性

```
UnitStats:
  hp: int               # 生命值
  max_hp: int
  attack: int           # 物理攻击力
  magic: int            # 魔法攻击力
  physical_defense: int  # 物理防御力
  magical_defense: int   # 魔法防御力
  speed: int            # 回合内行动顺序（不随升级成长）
  move: int             # 移动力/格数（不随升级成长）
  hit: int              # 命中率基础值（百分比，如90=90%）
  evade: int            # 闪避率基础值（百分比）
  crit: int             # 暴击率基础值（百分比）
  crit_evade: int       # 暴击抗性（百分比）
  resistance: int       # 状态抵抗（百分比，影响Debuff附加成功率）
  vision: int = 3       # 视野范围（格数，默认3格，未特殊声明时）
```

### 成长规则

| 属性 | 随升级成长 | 说明 |
|------|----------|------|
| hp, attack, magic | ✅ | 主要成长属性 |
| physical_defense, magical_defense | ✅ | 防御成长 |
| hit, evade, crit, crit_evade, resistance | ✅ | 小幅成长 |
| **speed** | ❌ | 固定，仅通过装备/Buff/Roguelite改变 |
| **move** | ❌ | 固定，仅通过装备/Buff/Roguelite改变 |
| **vision** | ❌ | 固定，仅通过建筑/技能/Roguelite改变 |

## 伤害类型体系

伤害采用**双轴分类**：属性类型（决定防御计算方式）× 攻击方式（决定特殊交互）。两个轴在技能数据中独立声明。

### 第一轴：属性类型（互斥，四选一）

| 类型 | 防御计算 | 暴击 | 格挡 | 说明 |
|------|---------|------|------|------|
| physical（物理） | attack × weapon_power - physical_defense × armor_resistance | ✅ 可暴击 | ✅ 可格挡 | 标准物理 |
| magical（魔法） | magic × spell_power - magical_defense × magic_resistance | ✅ 可暴击 | ✅ 可格挡 | 标准魔法 |
| holy（神圣） | 攻击力 × 威力，**无视护甲/格挡** | ❌ 不可暴击 | ❌ 不可格挡 | 穿透型 |
| hybrid（混合） | 自动取目标 physical_defense / magical_defense 较低者进行计算，公式与物理/魔法相同 | ✅ 可暴击 | ✅ 可格挡 | 自适应破防 |

### 第二轴：攻击方式（由技能固定声明）

| 类型 | 判定规则 | 说明 |
|------|---------|------|
| melee（近战） | 技能射程仅为1格的攻击 | 由技能数据固定声明，不受实际攻击距离影响 |
| ranged（远程） | 技能射程大于1格的攻击 | 即使实际攻击了1格距离的目标，只要技能本身射程>1，依然为远程 |
| area（范围） | 技能AOE影响复数格子 | 即使实际只命中单体，只要技能本身有AOE范围，依然为范围 |

**用途**：攻击方式主要用于特殊交互判定（如"受到近战伤害时反击"、"远程伤害+10%"、建筑耐久按攻击方式扣减等），不直接参与伤害公式。

## 伤害公式（乘区分层）

### 通用公式

```
最终伤害 = 基础伤害 × 技能倍率 × 特殊地形修正 × 暴击修正 × 格挡修正 × 最终伤害增减

各乘区:
  基础伤害      = 攻击力 × 威力 - 防御力 × 抵抗
                  （最低为0，防御超过攻击时不造成伤害）
                  （防御力的选取取决于属性类型，见上表）

  技能倍率      = skill.power / 100
                  （100=1.0倍，150=1.5倍）

  特殊地形修正   = 由特殊地形提供的独立乘区（如某特殊地形"受到伤害×0.8"）

  暴击修正      = 暴击时1.5（基础倍率，可被加成），未暴击时1.0
                  （神圣伤害不可暴击，此项始终为1.0）

  格挡修正      = 格挡时0.3（固定70%减免），未格挡时1.0
                  （神圣伤害不可格挡，此项始终为1.0）

  最终伤害增减   = 所有最终阶段的增减乘区相乘
                  （建筑减伤、Buff增伤等）
```

### 各属性类型的基础伤害计算

```
physical:  attack × weapon_power - target.physical_defense × armor_resistance
magical:   magic × spell_power - target.magical_defense × magic_resistance
holy:      attack_or_magic × power（不减去任何防御）
hybrid:    attack × weapon_power - min(target.physical_defense, target.magical_defense) × resistance
```

### 各乘区详细说明

| 乘区 | 来源 | 说明 |
|------|------|------|
| 基础伤害 | 攻击属性 × 武器/法器威力 - 防御属性 × 护甲/魔抗 | 加减法区，地形属性加成直接加到防御属性上 |
| 技能倍率 | 技能数据 | 由使用的技能决定 |
| 特殊地形修正 | 特殊地形效果 | 独立乘区，与基础伤害中的地形属性加成不同 |
| 暴击修正 | 暴击判定结果 | 基础1.5倍，可被加成（神圣伤害无此项） |
| 格挡修正 | 格挡判定结果 | 固定0.3（70%减免），与暴击互斥（神圣伤害无此项） |
| 最终伤害增减 | 建筑减伤、Buff增伤等 | 所有最终阶段修正相乘 |

### 地形属性加成 vs 特殊地形修正（重要区分）

- **地形属性加成**：基础地形提供的属性直接加到角色属性上，参与基础伤害的加减法计算
  - 例：山地+5物理防御 → `physical_defense`变为`physical_defense + 5`
- **特殊地形修正**：特殊地形提供的独立乘区
  - 例：某特殊地形"受到伤害×0.8" → 作为独立乘区参与最终计算

---

## 基础地形战斗修正

基础地形提供的属性加成，**直接加到对应属性上**（不是独立乘区）。

| 基础地形 | 防御方加成 | 闪避加成 |
|---------|----------|---------|
| PLAIN（平地） | 无 | 无 |
| FOREST（树林） | 无 | +闪避（具体值待定） |
| MOUNTAIN（山地） | +物理防御, +魔法防御（具体值待定） | 无 |
| SHALLOW_WATER（浅水） | 无 | 无 |
| LAVA（熔岩） | 无 | 无 |
| SWAMP（毒沼） | 无 | 无 |

*PEAK/WALL/DEEP_WATER为不可通行地形，不涉及战斗修正。*
*浅水/熔岩/毒沼的效果通过附加Buff/Debuff实现，不直接修正属性。*

## 命中判定（加法模型）

```
命中率 = attacker.hit + weapon.hit + skill_hit_bonus
       - defender.evade - terrain_evade_bonus
       + other_bonuses

  terrain_evade_bonus = 防御方所在基础地形提供的闪避加成

  范围: 最低20%, 最高100%
```

### 命中相关修正来源

| 来源 | 加/减 | 说明 |
|------|-------|------|
| attacker.hit | + | 攻击方角色命中属性 |
| weapon.hit | + | 武器命中加成 |
| skill_hit_bonus | + | 技能命中修正 |
| defender.evade | - | 防御方闪避属性 |
| terrain_evade_bonus | - | 防御方基础地形闪避加成 |
| 建筑/Buff等 | +/- | 各类额外修正 |

---

## 暴击判定（加法 + 抵抗率乘区）

```
暴击率 = (attacker.crit + weapon.crit + skill_crit_bonus - defender.crit_evade) × 暴击抵抗率

  暴击抵抗率: 默认1.0（无额外抵抗），由装备/技能提供降低
             例: 暴击抵抗率=0.7 → 暴击率打七折

  范围: 最低0%, 最高50%
```

### 暴击倍率

- 基础暴击伤害倍率：**×1.5**
- 可被技能/遗物/装备加成（如"暴击伤害+20%"→变为×1.7）

---

## 格挡判定

```
格挡率 = class_base_block + weapon_block + shield_block + skill_block_bonus

  class_base_block: 职业固定值，不随升级成长
  格挡成功时: 伤害 × 0.3（固定减免70%）
```

### 格挡规则

- 格挡率由**职业基础值**决定，后续仅通过武器/盾牌/技能加成
- 不随升级成长
- 格挡减免为**固定70%**（即×0.3），不可被修改
- **格挡与暴击互斥**：格挡成功时不可能暴击

## 攻击结算流程

```
1.【命中判定】
  计算命中率（加法公式）→ 随机判定
  → Miss → 触发Miss相关效果（如有）→ 结束

2.【格挡判定】（命中成功后）
  计算格挡率 → 随机判定
  → 格挡成功 → 标记格挡修正=0.3，跳过暴击判定

3.【暴击判定】（格挡失败后）
  计算暴击率 → 随机判定
  → 暴击成功 → 标记暴击修正=1.5+

4.【伤害计算】
  按伤害公式（乘区分层）计算最终伤害

5.【应用伤害】
  目标HP减少，检查是否击杀
  若目标在建筑上（哨塔/要塞），建筑也受到耐久损伤

6.【命中后附加效果】
  触发概率型Debuff附加（如冰冻术的减速效果）
  附加成功率受 defender.resistance 影响

7.【应用伤害后附加效果】
  触发基于伤害结果的效果（如吸血、击杀奖励、连锁反应等）

8.【反击判定】
  若本次攻击的 attack_type ≠ "area"
  且目标存活、未处于无法行动状态
  且目标的武器/技能射程可达攻击者
  → 目标进行一次普通攻击反击（走完整结算流程1-7步，但反击不再触发反击和追击）

9.【追击判定】
  追击概率 = (attacker.speed - defender.speed) × 10%
  范围: 最低0%, 最高100%
  → 追击成功 → 进行一次追加攻击（走完整结算流程1-7步）
  → 追击不触发反击，追击不触发二次追击
```

### 追击系统

速度优势的单位有概率在攻击结算后发动一次追加攻击（追击）。

```
追击概率 = (attacker.speed - defender.speed) × 10%

  范围: 最低0%, 最高100%
  当攻击方速度≤防守方速度时，追击概率为0%

追击条件:
  1. 攻击方存活
  2. 原始攻击命中（Miss时不触发追击）
  3. 追击概率判定成功

追击规则:
  - 追击使用攻击方的普通攻击（非技能）
  - 追击走完整的攻击结算流程（命中→格挡→暴击→伤害→附加效果）
  - 追击不触发反击
  - 追击不触发二次追击
  - 追击在反击之后结算
```

**设计概念**：类似于火焰纹章的追击系统，给予高速单位多段攻击的额外乘区优势。该系统对所有职业通用，但速度较低的职业自然不易触发。后续数值设计中，低速单位应通过其他维度（单次高伤害/格挡/控制等）获得补偿。

**扩展预留**：
- 剑士系将基于追击系统开发额外机制（如追击概率提升、追击触发特殊效果等），详见天赋树设计
- 追击系统和反击系统的计算细节将在后续职业天赋逐渐完善后补充

### 反击系统

详见 → [05-职业系统](./05-class-system.md) 反击系统章节

### 两种附加效果的区分

| 时机 | 触发条件 | 示例 |
|------|---------|------|
| 命中后附加 | 攻击命中即触发（与伤害无关） | Debuff附加（减速、中毒）、标记效果 |
| 应用伤害后附加 | 伤害结算完成后触发 | 吸血（基于实际伤害）、击杀触发效果、Roguelite遗物效果 |

### Debuff附加与状态抵抗

```
Debuff实际附加率 = skill_effect.chance × (1 - defender.resistance / 100)

例: 技能附加率50%, 目标resistance=20
  → 50% × (1 - 0.2) = 40%
```

## 角色回合时序（战斗行动顺序）

### 标准行动流程

```
【角色回合开始】
  → Buff/Debuff效果触发（燃烧扣血、回复等）
  → 若眩晕/冰冻 → 跳过行动，直接进入角色回合结束

【角色行动阶段】
  标准流程: 移动 → 攻击/技能 → 角色回合结束
  
  规则:
  - 一般情况下，先移动再攻击/使用技能
  - 一旦使用攻击/技能，一般不可再移动
  - 少部分技能可在移动前使用（技能标记: pre_move = true）
  - 存在特殊职业/技能允许攻击后再移动（技能/职业标记: post_attack_move = true）
  - 也可选择只移动不攻击，或原地等待

【角色回合结束】
  → Buff/Debuff持续回合数 -1，到期移除
```

### 行动阶段可能的顺序变体

| 类型 | 流程 | 来源 |
|------|------|------|
| 标准 | 移动 → 攻击/技能 | 默认 |
| 先制技能 | 技能 → 移动 → 攻击/技能 | 部分技能标记 `pre_move` |
| 攻后移动 | 移动 → 攻击/技能 → 移动 | 特殊职业/技能标记 `post_attack_move` |
| 纯移动 | 移动 | 玩家选择 |
| 等待 | 无 | 玩家选择 |

详见 → [01-回合系统](./01-turn-system.md) 中的Buff/Debuff时机规则

## 战场建筑修正

| 建筑 | 效果（概述） |
|------|------------|
| 哨塔 | 占据者：命中提升、视野提升、受伤减少（轻微） — 减伤在最终伤害增减乘区 |
| 要塞 | 占据者：命中提升、视野提升、受伤减少（大幅） — 减伤在最终伤害增减乘区 |
