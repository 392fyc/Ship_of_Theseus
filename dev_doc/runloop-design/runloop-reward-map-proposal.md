## 0. 摘要

**核心循环 `[已定]`**：战斗胜利结算 → 出现 **2–3 扇门**（下限暂定 2，2026-07-03；门上前置预告奖励类型；精英房另显示头目的**特殊词条**）→ 选门 → **Prep**（恢复〔可拒绝〕／经**运输队**替换装备·遗物／查看情报／确认出发；**幕中与 Boss 前的两个 Prep 另含固定商店**）→ 下一战。每幕 8 关、第 8 关固定 Boss；3 幕一轮，单场 ≤10 分钟、单轮预期 3 小时以上。恢复量**不随幕变动、只随开局难度档变动**（2026-07-03）。

**五类奖励门 `[已定]`（2026-07-03 商店退出门池）**：金币 / 经验 / 装备 / 遗物 / 特殊事件。**商店改为固定插入**：每幕两次、不占门也不占关卡——幕中一次＋Boss 前一次，配置在对应的两个 Prep 阶段（幕中定位 `[占位]`）。**天赋点与技能不做掉落**——技能来自职业固定模板、天赋或遗物；天赋点基本只来自等级提升（经济类遗物可加成）。

**敌人五层阶梯 `[已定]`（2026-07-03 词条制修订）**：普通（0 词条）→ 小精英（1–3）→ 大精英（3–5）→ 精英房头目（**大精英规格＋1 特殊词条**，合计 4–6）→ 幕 Boss（传奇 + 独有机制）。**特殊词条进房前可见、基础词条不可见**；特殊与基础词条**分池、区别对待**；词条=类似人物被动的技能（非 buff/debuff）。精英房奖励品质/数量更好；Boss 固定给「金币+经验+装备+特殊遗物」且品质概率高于精英。

## 1. 真源基线 `[已定]`

- **结构**：3 幕 × 8 关，第 8 关幕 Boss（2026-06-30 裁决）。GDD 旧值 3×10 仍待同步。
- **门模式**（2026-07-02，取代线性与分支两案）：每关结算后 **2–3 扇门**（下限暂定 2，2026-07-03），门上前置预告奖励类型；玩家看不到全幕地图，但**幕进度与 Boss 位置可见**（进度条形式 `[提案]`）。
- **五类奖励门**（2026-07-03 商店退出门池）：金币 / 经验 / 装备 / 遗物 / 特殊事件。天赋点、技能退出掉落池。
- **商店固定插入**（2026-07-03）：每幕两次——幕中一次＋Boss 前一次，配置在固定两个 Prep 阶段，不计入门、不计入关卡数。
- **掉落归属**：**每个角色独立获得房间奖励**（顺带确定遗物 6 槽按角色持有）；每图另有固定金币+经验；队伍不满 4 人有额外补偿 `[数额占位]`。
- **特殊事件门不得连续出现**（生成器硬约束）；**遗物保底按出现计数**（2026-07-03，非按选中）。
- **装备**：仅武器+防具两个槽位（与架构 L4 一致），渐进品阶；**遗物池 20+ 起**（你的预期下限）。
- **敌人五层阶梯与词条制**（2026-07-03 修订）：见第 4 节；词条=类似人物被动的技能（非 buff、非 debuff）；**特殊词条与基础词条分池**；数量随难度伸缩。
- **运输队大背包**（2026-07-03）：存储非装备状态的装备与遗物；战斗场景锁定，Prep 阶段可替换。
- **难度两轴**：主轴=开局选择的难度档（类 Hades 热度，**系统细节后置**，v1 固定基础难度留接口）；副轴=幕数递进（难度倍率表已定：敌 HP ×1.0/1.5/2.0、敌攻 ×1.0/1.3/1.6、金币 ×1.0/1.3/1.6）。
- **恢复在 Prep 内**（2026-07-03 修订）：恢复是 Prep 的主动动作；恢复量**不随幕变动、只随开局难度档变动**（run 内恒定）；可主动拒绝（背水流构筑需求）。见第 5 节。
- **时长**：快节奏，≤10 分钟/场，单轮预期 3 小时以上，非阻塞（2026-07-02 裁决）。
- **城镇**：v1、v2 均不碰（准备阶段无城镇项；战场建筑不受影响）。
- **L5 = 遗物 Relic 6 槽/角色**（ADR-010，Rune 废案）；L2 天赋树每 run 清零；L4 装备不承担 build-defining；Meta 只横向不纵向，「0 meta 进度也能通关」是硬性红线。
- **特殊事件结构**：`Event/EventChoice/EventOutcome`（沿用，data/events 已有三个骨架事件）。

**被判陈旧 `[已定]`**：KB 难度表「Elite Encounters 2 / 2–3 / 3」——早期文档产物，被敌人阶梯体系取代（KB 已加注）。

## 2. 门模式地图 `[已定骨架]`

### 2.1 循环流程

```
战斗胜利 → 奖励结算（固定金币+经验 + 每角色的门奖励）
        → 出现 2–3 扇门（下限暂定 2；奖励类型图标前置可见；精英房带骷髅标+头目特殊词条）
        → 选门（即选下一关 + 选奖励类型，一次决策两重意义）
        → Prep（恢复〔可按角色拒绝·提案〕 / 经运输队替换装备·遗物 /
                查看情报 / 确认出发〔有人未恢复且非满血时提示·提案〕）
        → 下一战 …… 第 8 关固定 Boss
```

- **商店不再是门**（2026-07-03 裁决）：每幕固定两次商店——幕中一次＋Boss 前一次，嵌入对应 Prep 阶段，不占门、不占关卡。此裁决同时从根上消灭了验证发现的「商店门重掷语义」漏洞（进店免费出入=免费重抽门组）。
- 选事件门=走事件流程（可能无战斗、可能触发伏击），计入关卡数。
- 幕进度条 `[提案]`：显示「当前第 N/8 关 + 第 8 关 Boss 图标」，让节奏预期保留下限（Hades 亦有房间计数）。

### 2.2 门的构成：奖励标签 × 难度修饰（两条正交的轴）

- **奖励标签（五类）**：💰金币 / ✨经验 / 🗡装备 / 💠遗物 / ❓事件。（🛒商店已退出门池，改固定插入，见 2.1。）
- **难度修饰**：普通房 / **精英房**（骷髅标 💀 + **头目的特殊词条进房前可见**，房内头目见第 4 节）。精英房奖励=**更高品质权重或更多数量** `[已定]`；某些高稀有档**仅精英房/Boss 出** `[提案]`（保证精英门吸引力）。
- Boss 门（第 8 关）固定：**金币 + 经验 + 装备 + 特殊遗物**，品质概率高于精英 `[已定]`。

### 2.3 生成约束

**硬约束 `[已定]`**：① 特殊事件门不得连续出现；② 第 8 关固定 Boss；③ 商店不走门——每幕固定两次插入（幕中＋Boss 前的 Prep，2026-07-03）。
**遗物保底 `[已定语义]`**：**按出现计数**（触发与重置都看「遗物门是否出现过」，与是否被选无关，2026-07-03——防连续强制刷屏）；连续 N 关未出现则强制供应一扇，N `[占位 N=3，模拟显示偏紧、待调]`。原「Boss 前保证商店选项」条款删除（已由固定插入保证）。
**门数 `[已定·暂定]`**：下限 2、上限 3（2026-07-03，消灭模拟中约 1/3 的零选择门组）；组内分布细节 `[占位]`。
**同组门奖励类型互不相同 `[提案]`**（沿用「同叉不同类」防假选择思想，待你确认）。

### 2.4 预览与情报经济

- 门上奖励类型**必显**（这就是你点名的前置预告，Hades 门符号模式）。
- **可见性规则 `[已定]`（2026-07-03）**：精英房头目的**特殊词条进房前可见**——明码标价的头牌威胁，玩家可在 Prep 里经运输队针对性换装对策；**基础词条进房前不可见**（相性赌保留）。入场后战斗内点选敌人可读基础词条 `[提案]`（战棋可对策性要求）。
- `map_preview` 便利升级 `[提案]`：解锁更深情报——奖励品质档提示、**额外揭示部分基础词条**。只加情报不加战力，守 meta 横向红线。

## 3. 奖励模型 `[已定骨架]`

### 3.1 结算规则

| 项 | 规则 | 状态 |
|----|------|------|
| 固定结算 | 每图固定金币+经验（数额按幕倍率 ×1.0/1.3/1.6） | `[已定]`（数额 `[占位]`） |
| 门奖励 | **每个角色独立获得**该门类型的奖励 | `[已定]` |
| 队伍补偿 | 队伍不满 4 人时有额外奖励 | `[已定]`（形式与数额 `[占位]`） |
| 精英房 | 品质权重更高或数量更多 | `[已定]` |
| Boss | 固定包：金币+经验+装备+特殊遗物；品质概率高于精英 | `[已定]` |

连带待定（调参期一起定）`[提案]`：**经验是全队共享池还是按角色独立**——天赋点挂等级后，这直接决定少人队伍的天赋节奏，和「不满 4 人补偿」是同一天平的两个砝码。

### 3.2 奖励到 5 层的映射（第三轮修订）

| 奖励 | 对应层 | 获取途径 | 备注 |
|------|------|------|------|
| 金币 Gold | 跨层经济 | 每图固定 + 金币门 + 事件 | 排水渠=商店/药水，防末期堆积 |
| 经验 EXP | L3 成长 **+ 间接驱动 L2** | 每图固定 + 经验门 | 升级给属性成长**并产出天赋点** |
| 天赋点 | L2 天赋树（每 run 清零） | **基本只来自等级提升**；经济类遗物可加成 | `[已定]` 退出掉落池；与架构「L2 决策时机=run 内每升级」天然一致 |
| 装备 Equipment | L4（不 build-defining） | 装备门 / 商店 / Boss 包 | 武器+防具两槽；渐进品阶 |
| 技能 Skill | 职业能力 | **不掉落**：职业固定模板 / 天赋 / 遗物 | `[已定]` |
| 遗物 Relic | L5 6 槽/角色（build-defining） | 遗物门 / 商店 / 事件 / Boss 特殊遗物 | 池 20+ 起；6 槽硬上限 |
| 消耗品 Potion | 背包 | 商店 / 事件 / 部分门附带 | 应急恢复 + 金币排水 |
| 永久 buff | run 内角色状态 | 特殊事件（祝福祭坛类） | 沿用 |

### 3.3 节奏与防护（沿用第二轮，按门模式改写）

- **三幕梯度**：Act 1 慷慨（前 3 关看到构筑方向，遗物/装备门权重高 `[占位]`）→ Act 2 收缩（普通房降质、精英房保持）→ Act 3 完成（补完构筑；装备门的意义=更高品阶替换，与两槽渐进天然契合）。
- **防通胀**：天赋点通胀由**等级曲线**统一管理（掉落口径消失后只剩一个水龙头）；遗物 6 槽/角色硬上限；金币持续排水（商店+药水）。
- **防饥饿**：遗物保底（2.3，按出现计数）+ 固定商店两次/幕 + 事件做「构筑补救窗口」（花金币定向补缺）。

## 4. 敌人五层阶梯与词条系统 `[已定骨架]`（2026-07-03 词条制修订）

（KB `enemy-and-ai.md` 已同步对应节；此处为设计视角汇总。）

| 层级 | 出现位置 | 词条数 | 说明 |
|------|------|------|------|
| 普通 | 各类战斗 | 0 | 不具备词条 |
| 小精英 | 频率不低，混编在波次中 | 1–3 基础 | 普通房的日常变数 |
| 大精英 | 较稀有，**多作为普通房收尾敌人** | 3–5 基础 | 普通房也有纹理梯度 |
| 精英房头目 | **仅精英房出现** | **大精英规格（3–5 基础）＋1 特殊**，合计 4–6 | 特殊词条进房前可见、基础不可见 |
| 幕 Boss | 第 8 关固定 | 随难度 | **传奇敌人 + 独有机制系统** |

- **词条数量随难度伸缩** `[已定]`：区间内按两轴取值——开局难度档（热度，后置）+ 幕数递进（Act 1 取下限 → Act 3 取上限，解决「Act 1 精英房应显著弱于 Act 3、且不只是数值」）。取值曲线 `[占位]`。
- **词条实现口径 `[已定]`（2026-07-03 用户明确）**：词条=**类似人物被动的技能**——不是 buff、不是 debuff。引擎需要敌方单位的被动技能挂载点（我方已有心眼这类被动先例），词条以 JSON 声明式定义（`data/affixes`）。
- **两池分开、区别对待 `[已定]`**：**基础词条池**=单位被动（示例方向：反击强化、先手部署、受治疗减半、拆建筑、控制区扩大）；**特殊词条池**=房间签名级、更大更醒目的机制（接近 Hades 房间修饰的存在感）。v1 基础池 **12–15 个** `[占位]`、特殊池 **6–8 个** `[占位]`；v0 基础 5 个左右 `[占位]`＋特殊 1–2 个 `[占位]`。
- **可读性**：特殊词条在门上进房前可见 `[已定]`；基础词条入场后战斗内点选可读 `[提案]`——战棋玩家要能围绕词条做布阵对策，这是相性赌「可对冲」的前提。
- **精英惩罚组合** `[已定方向]`：磨损（恢复不满额，第 5 节）+ 相性赌（基础词条进房前不可见）。**契约门**（Hades Chaos 式「扛住 N 关诅咒换永久增益」）作为后置扩展门类 `[提案]`，事件结构现成可复用（祝福祭坛已是温和版）。

## 5. 恢复模型（Prep 内）`[已定骨架]`（2026-07-03 修订）

- **恢复是 Prep 的一个主动动作**（并入准备阶段，与运输队换装、查看情报同屏）；**恢复量不随幕变动、只随开局选择的难度档变动**，run 内恒定 `[已定]`。
- 恢复量：v0/基础难度约 **50% 最大生命** `[占位]`；更高热度档恢复更低（热度系统的第一个具体旋钮，曲线 `[占位]`）；基数建议最大生命百分比 `[提案]`。
- 执行细节 `[提案]`：① 恢复/拒绝**按角色**而非按队伍；② 原「默认恢复开启」改为**出发确认提示**——确认出发时若有人未恢复且非满血，弹一次提示（背水流玩家直接确认，不打扰）；③ 拒绝本身不另给奖励（背水收益应来自低血触发的天赋/遗物）；④ 连带设计需求——天赋/遗物池须含**低血阈值触发**条目（火纹「狂怒 Wrath / 背水」传统），否则拒绝恢复是死选项。已记入 relics-system / 天赋设计需求清单。
- 磨损逻辑（两轴解耦，2026-07-03）：恢复**不满额**（≤50% `[占位]`）+ HP 跨关继承 → 精英房的血量代价仍跨关发酵；幕间压力完全交给敌方成长轴（倍率+词条数），恢复压力交给玩家自选的难度档。战斗内治疗（牧师/生命泉/药水）照旧，背水角色自行回避即可。
