# Run-loop v0 节奏与奖励投放基准报告

> ⚠️ **全文定性：业界研究参考稿，非 SoT 设计裁决。**
> 本报告综合三份业界研究（Hades、Slay the Spire 类节点肉鸽、战棋肉鸽先例），把它们落到 SoT 的具体形态（战棋单场 ≤10 分钟 × 8 关/幕 × 约 3–4 小时/轮、门模式 2–3 扇五类、词条制敌人、遗物 6 槽、恢复并入 Prep、每角色独立掉落、4 人队）。
> 目的是给 SoT 每个 `[占位]` 参数提供**业界基准区间 + 依据 + 置信度**，并识别陷阱。**这是参考不是裁决**——SoT 的数字属用户/调参定，须保留 `[占位]` 标注。

## 1. 可用参数基准区间

> 每个参数：**业界数据 → SoT 参考区间 → 依据 → 置信度**。置信度＝三份研究间证据的一致性与可溯源度，非「建议强度」。

### 1.1 门数与门内分布

| | 数据 |
|---|---|
| Hades | 每房结算后 2–3 扇门；Mini-boss 房限定奖励类型（只出 Boon） |
| Slay the Spire | 路径拓扑决定，通常 2–3 条出口；强制「同叉不同类」 |
| Monster Train | 每战后 2–3 条路径 |

- **SoT 参考区间：门数 2–3（下限 2）＝直接可用。** 三份研究完全收敛，这是节点肉鸽的行业共识值。**置信度：高。**
- **门内分布提醒**：SoT 已定「同组门类型互不相同」。在**门数=2** 时，每关只暴露 5 类里的 2 类 → 单关信息面窄。8 关/幕的门组要能在一幕内轮转到全部 5 类（类似 Hades 的「袋子」重填思路），否则某些奖励类型整幕不出现。建议 3 扇门的出现比例不要太低（业界 Hades 3 门常见于中段、2 门多见于临 Boss）。**门内 min/max 分布曲线：[占位]。**

### 1.2 门类型权重（五类）

| | 数据 |
|---|---|
| Hades | 门权重**未公开**；Boon（≈遗物）被选中率 ~12%；MetaProgress vs RunProgress 两大类分离 |
| Slay the Spire | 节点类型分布（非奖励类型）：Act1 普通战 53% / 精英 8% / 事件 8% / 宝箱 3% / 休息 3% |

- **关键事实**：Hades 的门奖励权重**从无官方公开** → SoT 必须**主动设定**，无现成拷贝值。
- **SoT 参考排序（而非绝对值）**：遗物（L5 build-defining）应是**最稀缺/最被期待**的一类——对标 Hades Boon 12%、StS 遗物来源受限（宝箱/精英/Boss）。SoT 现值遗物 15/90 ≈ 每门槽 17%，比 Hades 略慷慨，但有 6 槽硬上限 + 保底兜底，合理。装备（L4 非 build-defining、可替换）应比遗物常见。**这个排序（遗物 < 装备/金/经）符合业界。**
- **参考带**：遗物每门槽 **12–18%**、事件 **10–15%**、金/经/装备填充其余。**置信度：中**（排序有据、绝对值无业界锚点，纯 SoT 调参）。
- **交互提醒**：「同组不重复」使**有效每类出现率高于原始权重**——门数 2 时每关强制展示 2 个不同类，稀有类的实际曝光被抬高，设权重时要把这层放大计入。

### 1.3 每 run 升级次数（→ 天赋点）

| | 数据 |
|---|---|
| Hades | 每 run 平均 3–5 个 Relic（高 Heat 可达 8–10）；每 Relic +2–5% |
| Slay the Spire | 每战约 +1 卡；遗物 ~6–9/run（3 幕，来自精英/宝箱/Boss） |

- **SoT 机制**：天赋点**只来自升级**（掉落池已移除）；经验来自每关固定 30 + 经验门 25 + Boss 100。现值升级阈值 100、平坦成长 → 每关约 30–55 经验 → **约每 2–3 关升 1 级**。
- **参考区间**：**v0（1 幕 8 关）约 3–5 次升级**（对标 Hades 每 run 3–5 个强化选择）；**整轮（3 幕 24 关）约 10–15 次升级**。天赋树每 run 清零（L2 全重置），点数要够「构筑成形」但**必须保留机会成本**（业界共识：选择感来自「取此舍彼」，点数过多＝全都能点＝无选择）。**置信度：低**（强依赖天赋树深度，属设计而非业界可锚定）。

### 1.4 遗物投放频率与保底

| | 数据 |
|---|---|
| Hades | Boon ~12%；**袋子模型**（抽中/未抽都移出袋，空袋才重填）＝隐式防干旱，无显式保底 |
| Slay the Spire | 遗物**无保底**，固定 17% 稀有；靠**楼层 9 固定宝箱**保证中幕遗物；6–9 遗物/run |
| 行业 | 「每 N 次保 1 稀有」的 N 值**无公开标准** |

- **SoT 现值**：遗物门权重 15/90，保底 N=3 关（按出现计数），模拟已标注**「N=3 偏紧」**（干旱窗口太短 → 遗物被强制供应得过勤）。
- **参考区间**：**保底 N 放宽到 4–5 关**。SoT 选的「**按出现计数**」（触发/重置都看遗物门是否出现过，与是否被选无关）比 StS 的「无保底」稳健，也优于「按选中计数」（后者会连续强制刷屏）——这一步 SoT 已做对。**置信度：中。**
- **⚠️ 4 人队放大器（战棋专属，业界无对应）**：SoT 门奖励**每角色独立** → 一扇遗物门＝一次给 **4 个遗物**（每角色 1）。这使遗物吞吐相对单主角肉鸽（Hades/StS）翻约 **4 倍**。后果：① 遗物池须足够深（现定 20+ 是下限，4 人 × 6 槽＝理论 24 槽，池 20+ 会很快见底 → 建议 **≥24**，正式版更大）；② 保底若按「组」触发则一次补 4 个，供应更猛，N 值要相应偏保守。**这是 Hades/StS 基准无法直接迁移的第一个断点。**

### 1.5 每关固定金币/经验 相对成长的比例

| | 数据 |
|---|---|
| Hades | 玩家每 run 可购 **1–2 次**商店；Supergiant 曾降价提升可及性 |
| Slay the Spire | 普通战 10–20 金 / 精英 35–45 / Boss 100 / 起始 99；移除费递增 75→100→125 |

- **SoT 现值推算**：固定 40/关 × 8 ＋ 门金 30×若干 ＋ Boss 120 ≈ **500–600 金/幕**；2 商店/幕 → 每店可支约 250–300 金。经验 30/关 → **每 2–3 关升 1 级**（与 §1.3 一致）。
- **参考原则（比例而非绝对值）**：
  - **经验/关 ÷ 升级阈值** 应落在「**每 2–3 关升 1 级**」——这是「持续但不泛滥」的强化节奏（业界：Hades/StS 约每 1–2 战给一次强化选择，天赋点可略稀）。SoT 现值符合。
  - **固定战斗金 ≈ 单件商店物 15–30%**，使约 2 关积累买 1 件小物、一整幕支撑 **1–2 次有意义采购**（Hades 基准）。
  - 金:经 现值 40:30 ≈ 4:3，合理。**置信度：中低**（经济极可调，业界只给「可购 1–2 次」这个反推锚）。

### 1.6 精英出现率

| | 数据 |
|---|---|
| Slay the Spire | Act1 **8%** → Acts2-3 **16%**（翻倍）；硬约束：精英不连续、第 6 层前不出精英 |
| Hades | 精确率未公开；skull 房散布 |
| Into the Breach | Hard＝敌方单位数↑ + 新敌种（机制难度非数值） |

- **SoT 现值**：elite_room_weight 25（与奖励标签正交的难度修饰）。
- **参考区间**：**随幕递增**——Act1 约 **10–15%** 门带骷髅 → Act3 约 **20–30%**（对标 StS 翻倍曲线）。**置信度：中。**
- **⚠️ 硬约束（战棋更刚需）**：**每门组至少保 1 扇低风险（非精英）门**。业界（StS「至少 2 条路径 + 精英不连续」）已把它当铁律；对 SoT 4 人队更关键——一场相性不利的精英可能团灭。门数下限 2 时，若两门都 roll 到精英＝**被迫高风险**，须在生成器硬约束「组内 ≥1 非精英」。

### 1.7 恢复量 %

| | 数据 |
|---|---|
| Hades | 每 biome Boss 后 **+50% 最大生命**（固定比例）；Centaur Heart +25/+50 上限；可拒 |
| Slay the Spire | 休息点（固定楼层 15）：**全回血 或 升级卡**二选一 |

- **SoT 现值**：50% 最大生命、run 内恒定、可拒、HP 跨关继承。
- **⚠️ 最重要的一处误读风险**：Hades 的 50% 是**每 biome 一次**（约每 15 房/1 个 Boss 才回一次），全 run 仅 **3–4 次**。SoT 把恢复放进 **Prep**——若**每关 Prep 都能回 50%**，磨损永远不累积 → 设计想要的「递减压力」直接归零。
- **参考修正（二选一）**：
  - **A｜若恢复每关可用**：把量**降到 20–35% 最大生命**，让单场战斗伤害（≤10 分钟持续输出）**超过**单次回复量，HP 才会净下滑。
  - **B｜若维持 50%**：把恢复**限频到每幕 2–3 次**（例如只在幕中 + Boss 前 Prep，与商店同频），复刻 Hades 的稀疏节奏。
- **置信度：中高**（原则强、具体 % 依赖 SoT 战斗致死率）。
- **配套需求**（业界火纹「狂怒/背水」传统）：「可拒绝恢复」要成立，天赋/遗物池**必须**有**低血阈值触发**条目，否则拒绝恢复是死选项——SoT 已记入需求清单，务必落地。

### 1.8 商店频率

| | 数据 |
|---|---|
| Hades | 每 biome **2 处固定 Charon**：mid-biome + pre-boss；玩家可购 1–2 次/run |
| Slay the Spire | 商人概率触发（3%+3% 递增），约 1–2/幕 |

- **SoT 现值**：固定 2×/幕（幕中第 4 关后 + Boss 前），嵌 Prep，不占门不占关。
- **参考结论：与 Hades 逐点吻合，直接可用。** 「不占门」的设计还正好规避了研究点名的陷阱——「商店 vs 高价值房间的被迫二选一」。SoT 的 agent team 验证也据此根治了「商店门重掷」漏洞。**这是全表置信度最高、最稳的一项。置信度：高。**

### 1.9 时长目标（单场 / 单幕 / 整局）

| | 单场 | 单幕/单区 | 整局 |
|---|---|---|---|
| Hades | ~2–3 分钟/房 | 15–20 分钟/biome | 30–60 分钟 |
| Slay the Spire | ~2–5 分钟（小怪） | 15–25 分钟/幕 | 45–60 分钟 |
| Into the Breach | **5–15 分钟/关** | — | 1.5 小时（2–4 岛） |
| Fire Emblem Engage | **30 分钟–3 小时**（反例） | — | — |
| XCOM 2 | ~1.5 小时/关 | — | 33–45 小时 |
| **SoT v0 目标** | **≤10 分钟** | ~1 幕 | 3–4 小时（3×8=24 关） |

- **推导出的核心张力**：24 关 × 均值 ~8 分钟 ≈ **3.2 小时纯战斗**，几乎占满 3–4 小时预算 → **门/Prep/商店的非战斗开销预算被压到极低**。这比 Hades（2–3 分钟短房、可穿插多个非战斗房）紧张得多。
- **可达性证据**：**Into the Breach（5–15 分钟/关）是最贴近的战棋肉鸽先例，证明 ≤10 分钟可达——但只靠形式约束**：固定小网格（8×8）+ **敌方意图 100% 预告** + 单位数控制（≤6 友 + 5–8 敌）。反例 Fire Emblem（动态大图 + 20+ 敌 + 无预告）＝ 30 分钟–3 小时。
- **参考结论：≤10 分钟是形式约束、不是事后调参旋钮。** SoT 已有 forecast/头顶预测数字（对标 ItB 意图预告），方向正确；须再钉死小网格 + 单位数上限。**置信度：高。**

## 2. 节奏设计原则（为何「有选择感/不拖沓」，可迁移的机制）

三份研究交叉验证出的、可迁移到 SoT 的机制性原因：

1. **前置预告 → 知情决策，不是开盲盒。** 门顶奖励类型可见，让「选门＝选下一关难度 + 选奖励类型」变成一次有后果的评估，而非随机焦虑。这是 SoT 门模式的立身之本，已 1:1 采纳。

2. **已知性 × 不确定性的配比。** Hades 的期待感＝奖励类型已知（降焦虑）+ 具体敌人/路由未知（维持新鲜）。SoT 对应：门上奖励类型 + 特殊词条可见（已知）↔ 基础词条 + 具体布阵未知（相性赌）。**配比是节奏的核心旋钮。**

3. **选择必须有机会成本。** 「同叉不同类」（StS）防止「三扇都是同一个我都想要」的假选择。SoT 已采「同组门类型互不相同」。业界反例：Hades 早期「三扇全 Boon」被玩家抱怨选择感下降，Supergiant 调整了分布算法。

4. **微观决策的高频率产生持续代理感。** Hades 一个 run 有 35–50 次门决策。SoT 8 关/幕 × 门 = 每幕 7 次门决策 + 每次 Prep 的换装/恢复决策，频率足够。

5. **锯齿难度曲线（教学友好）。** 新幕难度陡升 → 玩家变强 → 中幕平衡 → Boss 峰值 → 下幕重复。新敌种/新词条**单独引入**再组合（StS/ItB）。SoT 词条随幕从下限取到上限（Act1 弱 → Act3 强）正是此曲线。

6. **机制难度 > 数值膨胀。** ItB/StS 的共识：新敌种/新词条＝新战术约束（有解、可对策），纯加 HP/DMG＝拖沓（打不动、只是耗时）。SoT 词条制（＝被动技能，非 buff/debuff）走对了方向。

7. **恢复递减 + 跨关继承 = 结构性压力**（非 RNG 压力）。业界（Hades 磨损曲线）证明「可拒绝 + 不满额 + 继承」能造出「高效运营」张力，而不依赖运气。SoT 已采纳，但见 §1.7 的频率校准。

## 3. 对抗性适用性审视（哪些业界做法不适用于 SoT 战棋）

> SoT 与 Hades/StS 的四个结构性差异：**单场更长（10 min vs 2–3 min）/ 每角色独立掉落 / 4 人队 / 词条制**。逐一审视业界基准会在哪里失效。

### 3.1 战斗节点密度：SoT 近 100% 战斗 vs 业界 ~50%

- **业界事实**：Hades/StS 用 **40–53% 的非战斗节点**（商店/事件/休息/宝箱）给节奏「换气」。StS Act1 普通战仅 53%，其余是喘息。
- **SoT 现状**：每关＝一场战斗（事件门是唯一非战斗类型，权重 15/90 ≈ 17%），加 2 商店-Prep/幕。**战斗密度接近 100%，且单场 10 分钟。**
- **陷阱**：Hades 的 2–3 分钟短房容得下高战斗密度；**SoT 的 10 分钟长战 + 近满密度 = 拖沓/疲劳的高风险区**（Othercide 教训：关多 + 变化不足 → 后期重复感）。
- **规避**：① 保证事件门频率 ≥ ~15–20% 做真喘息（现值达标，别下调）；② 控制「连续纯战斗关」上限（建议不超过 2–3 关无事件/商店换气）；③ Prep 阶段本身要**快**，别让它变成第二个疲劳源（见 3.2）。

### 3.2 每角色独立掉落 × 4 人队：4 倍吞吐 + Prep 清单负担 + 分析瘫痪

- **业界基准前提**：Hades/StS 都是**单主角**。所有奖励/背包/构筑决策是「1 份」。
- **SoT 断点**：门奖励每角色独立 → **4 倍奖励吞吐**（一扇遗物门给 4 个遗物）、**4 倍遗物池抽取**、**4 倍 Prep 换装/情报管理时间**。
- **三重陷阱**：
  1. **奖励通胀**：4 人 × 每关掉落，遗物/装备堆积速度是业界的 4 倍 → 遗物池须 ≥24（§1.4），否则整轮见底重复。
  2. **Prep 变成清单苦役**：若每关战后都要给 4 个角色逐一分装备/遗物/恢复，**Prep 菜单相会吃掉 ≤10 分钟战斗节奏挤出的时间**，把「快节奏战棋」拖成「菜单管理游戏」。业界研究点名：奖励种类 > 5–6 类即引发分析瘫痪；SoT 是 **4 角色 × 5 类**，复合放大。
  3. **选择感稀释**：每关 4 份独立选择，可能从「有意义的赌」退化为「机械分配」。
- **规避**：Prep 要有**快速/批量/自动分配**兜底；遗物池做深；6 槽硬上限帮忙封顶；考虑「运输队自动建议」降低每关手操。**这是 Hades/StS 基准最不能照搬的一处。**

### 3.3 恢复频率：Hades 每 biome vs SoT 每 Prep

- 见 §1.7。核心：Hades 50% 是**稀疏**（每 run 3–4 次），SoT 若每 Prep 可回则**过密** → 磨损归零。**这是最容易照抄错数字的地方**（50% 看似直接可迁移，实则频率语境完全不同）。

### 3.4 词条可见性 vs 战棋 ≤10 分钟的规划需求

- **业界事实（ItB）**：战棋要压到 ≤10 分钟且公平，**极度依赖敌方高可见性**（ItB 意图 100% 预告）。
- **SoT 张力**：SoT 只让**特殊词条**进房前可见，**基础词条**进房前不可见（相性赌）。战斗内若不断遇到「没预料到的被动」→ 中途重新规划 → **战斗时间被拉长**，直接顶到 10 分钟约束。
- **陷阱**：「相性赌」（隐藏基础词条＝赌博爽感）与「战棋 ≤10 分钟可规划」是**互相打架**的两个诉求。
- **规避**：对战棋而言，基础词条至少应在**进房/开战即可读**（不必进房前，但也别等到被打了才知道）——SoT 提案已有 [提案]「战斗内点选可读」，方向对，建议把它从可选升为**默认在行动前可读**，把「赌」的成分留在「具体触发时机/数值」而非「有没有这个词条」。

### 3.5 数值膨胀在战棋框架下的放大

- **业界警告**：战棋「最怕」打不动敌方防御（拖沓）。SoT 幕倍率敌 HP ×1.0/1.5/2.0——**若玩家输出不同步 scale**，Act3 战斗会因血厚敌人（bullet sponge）**膨胀超 10 分钟**。
- **对标**：StS 的「scaling check」（Boss HP 跳升逼牌组保持节奏）；Gears Tactics 敌/玩家比约 **1.2–1.25**（很紧）。研究建议后期玩家伤害 ≤ 早期 1.5–2×、敌 HP ≤ 早期 3–4×——但**在 ≤10 分钟约束下这个差距要更小**，否则时长破线。
- **规避**：确保玩家战力（天赋 + 遗物 + 装备）的 scale ≥ 敌 HP 增速；把「10 分钟内能否打完」作为幕倍率调参的硬验收线。

### 3.6 拖沓 / 难度跳跃（内容深度依赖）

- **Othercide 教训**：敌种/词条 < 8–10 种 → 后期重复感必然触发。SoT v0 用 ~5 基础词条 + 1–2 特殊，**1 幕 v0 够用**；但正式 3 幕前必须达到 SoT 自订目标（基础池 12–15 + 特殊池 6–8），否则拖沓。**内容深度是硬前置，不是可选项。**
- **Fire Emblem Maddening 教训**：难度档若无梯度（3–5 档）跳变，新手撞墙。SoT v0 固定基础难度 → 暂不适用，但热度系统接口须预留梯度。

## 4. 给 SoT 的 top 5 可执行建议

> ⚠️ **以下为业界参考基准，非设计裁决。** 所有具体数字属 SoT 用户/调参定，落地须过 `[占位]` 标注。这里给的是「往哪个区间调 + 为什么」，不是「就用这个数」。

**建议 1 ｜把 ≤10 分钟当形式约束，不当调参旋钮。**
采用 Into the Breach 的三件套：固定小网格（8×8）+ 硬性单位数上限（~5–8 敌）+ 全量意图/forecast 预告（SoT 已有头顶预测数字，继续用）。业界反例（火纹动态大图 30 分钟–3 小时）证明：一旦这些约束松动，时长膨胀不可事后救。**[占位] 敌方单位数上限。**

**建议 2 ｜用「有保证的喘息」打断战斗密度。**
SoT 近 100% 战斗节点 vs 业界 ~50%。保持事件门频率 ≥ ~15–20% 做真喘息（现值 17% 达标，别下调），并限制「连续纯战斗关」上限（建议 ≤2–3 关须有一次事件/商店换气）。**同时保证 Prep 别变成第二疲劳源**（见建议 5）。**[占位] 连续战斗关上限、事件门权重。**

**建议 3 ｜重新校准恢复以保住磨损。**
Hades 的 50% 是**每 biome 稀疏**给的。SoT 若每 Prep 可回，要么把量**降到 ~20–35% 最大生命**（让单场伤害 > 单次回复，HP 才净降），要么把恢复**限频到每幕 2–3 次**（对齐商店节奏）复刻 Hades 稀疏感。并落实低血触发天赋/遗物，否则「可拒绝恢复」是死选项。**[占位] 恢复 % 与频率。**

**建议 4 ｜保证每门组 ≥1 低风险门 + 精英率随幕递增。**
在生成器硬约束「组内至少 1 扇非精英门」（StS「总有安全路」铁律），对 4 人队尤其关键——避免「两门都精英＝被迫团灭风险」。精英率随幕递增：Act1 ~10–15% → Act3 ~20–30%（对标 StS 翻倍）。**[占位] 各幕精英率。**

**建议 5 ｜为「4 倍每角色吞吐」重设遗物稀缺与保底，并压平 Prep 手操。**
每角色独立掉落使一扇遗物门 ≈ 一次给 4 个遗物。保持遗物门权重 ~12–18% 带、保底 N 放宽到 ~4–5 关（模拟已标 N=3 偏紧）、遗物池深度 ≥24（4 人 × 6 槽）。天赋点 ~3–5/幕（v0）且保留机会成本。**关键配套**：Prep 的 4 角色分配要有快速/批量/自动兜底，别让每关战后清单管理吃掉战斗省下的时间。**[占位] 遗物权重、保底 N、遗物池深度、天赋点/幕。**
