敌人五层阶梯 · 词条制 已定2026-07-03 修订：词条=类似人物被动的技能（非 buff/debuff）

普通各类战斗的基础单位，不具备词条
小精英频率不低，混编在波次中——普通房的日常变数（基础词条 1–3）
大精英较稀有，多作为普通房收尾敌人出现（基础词条 3–5）
精英房头目仅精英房出现——大精英规格＋1 特殊词条（合计 4–6）；特殊词条进房前可见、基础不可见
幕 Boss传奇敌人 + 独有机制系统；词条数随难度传奇
=必有基础词条 =区间上限（随难度取值） =特殊词条（进房前可见） 难度两轴：开局难度档（类 Hades 热度，系统后置）× 幕数递进（Act1 取下限→Act3 取上限） 两池分开：基础池 v1 约 12–15 占位、特殊池 6–8 占位；v0 基础 5 个左右 + 特殊 1–2 个 占位

可见性与可读性：特殊词条在门上进房前可见 已定（可在 Prep 经运输队针对性换装）；基础词条进房前不可见、入场后战斗内点选可读 提案——相性赌必须可对冲。精英惩罚=磨损（恢复不满额）+相性赌（基础词条不可见）；契约门（扛 N 关诅咒换永久增益）作后置扩展门类。

恢复模型 · Prep 内 已定2026-07-03 修订：不随幕变动，只随开局难度档变动

基础难度
约 50% 最大生命 占位（run 内恒定）
更高热度档
恢复更低（热度系统第一个旋钮，曲线 占位）

恢复是 Prep 的一个主动动作（与运输队换装、查看情报同屏）。幕间压力全部交给敌方成长轴（倍率+词条数），恢复压力交给玩家自选难度档——两轴解耦。恢复不满额 + HP 跨关继承 → 精英房血量代价仍跨关发酵（磨损）。可主动拒绝（背水流）；执行细节为 提案：按角色拒绝 / 出发时未恢复且非满血弹一次确认提示 / 拒绝不另给奖励 / 天赋·遗物池须含低血触发条目。

奖励 → 5 层映射（第三轮修订） 已定骨架

奖励对应层获取途径备注
金币 Gold跨层经济每图固定 + 金币门 + 事件排水渠=商店/药水
经验 EXPL3 成长 + 间接驱动 L2每图固定 + 经验门升级给属性成长并产出天赋点
天赋点L2（每 run 清零）基本只来自等级提升；经济类遗物可加成退出掉落池；与架构「L2 决策时机=每升级」一致
装备L4（不构筑）装备门 / 商店 / Boss 包武器+防具两槽·渐进品阶
技能职业能力不掉落：职业模板 / 天赋 / 遗物已定
遗物 RelicL5 6槽/角色（构筑核心）遗物门 / 商店 / 事件 / Boss 特殊遗物池 20+ 起；每角色独立掉落
消耗品背包商店 / 事件应急恢复+金币排水

结算规则：每角色独立获得门奖励；每图固定金币+经验（按幕 ×1.0/1.3/1.6）；队伍不满 4 人有额外补偿 数额占位。精英房=品质更高或数量更多；Boss=固定包（金币+经验+装备+特殊遗物）且品质概率高于精英。连带待定：经验共享 vs 按角色独立（与补偿同天平，调参期定）。

v0 最小门循环（已同意先做一版）

验证目标：节奏与选择感（选门期待感 / 恢复压力 / 单场 ≤10 分钟）。不验证构筑深度——勿用 v0 体验评判构筑系统。

v0 做

  • 1 幕 × 8 关跑通（第 8 关替身 Boss=数值增强头目）
  • 门 UI：2–3 扇 + 奖励图标 + 精英骷髅标；固定商店两次插入（幕中/Boss 前 Prep）
  • 生成器 v0：类型权重 占位 + 三硬约束（事件不连续 / 商店不计数 / Boss 固定）
  • 敌阶 v0：普通 + 小精英（1–3 基础词条），基础词条池约 5 个 占位；精英房用替身头目（数值增强＋1 特殊词条，特殊池 1–2 个 占位）
  • Prep 含恢复（可拒绝，常数量 占位）+ 运输队最简版（存取/替换）
  • 遗物 8–12 条 占位 + 武器/防具各几件
  • 每角色独立掉落 + 固定金币经验

v0 不做（后续补）

  • 二、三幕；3 个幕 Boss 独有机制（定制内容）
  • 大精英/头目全量（基础 3–5 档）；基础池扩到 12–15 + 特殊池 6–8
  • 保底规则全套（v0 至多做遗物保底一条）
  • 热度系统（固定基础难度、留接口；热度奖励须过 meta 横向红线）
  • 契约门；Meta（含 map_preview）；不满 4 人补偿细则；遗物替换限制旋钮（v0 先自由）
  • 遗物池 20+ 与装备全品阶（渐进补）
