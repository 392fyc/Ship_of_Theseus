# 01 - 回合系统（回合 + 速度轮动）

> 返回 [总纲](./README.md)

## 概述

采用 **回合制 + 速度轮动** 的复合模式。游戏以"回合"为单位推进，每回合内所有存活单位按速度从高到低依次行动，一般情况下每个单位每回合行动一次。全部单位行动完毕后自动进入下一回合。

---

## 词汇定义

| 术语 | 定义 | 说明 |
|------|------|------|
| **回合（Round）** | 所有单位完成一轮行动的完整周期 | 第1回合、第2回合... |
| **角色回合** | 某个单位从开始行动到结束行动的过程 | 一个回合内包含多个角色回合 |
| **角色回合开始** | 该角色即将进行行动的时刻 | 触发Buff/Debuff效果（如燃烧扣血） |
| **角色回合结束** | 该角色完成本回合行动的时刻 | 扣减Buff/Debuff持续回合数 |
| **回合开始** | 一个新回合开始的时刻 | 触发回合级效果（增援、地形等） |
| **回合结束** | 本回合所有角色完成行动的时刻 | 所有角色回合结束后才触发 |

**关键区分**：角色回合结束 ≠ 回合结束。角色回合结束仅代表该角色完成行动，需要本回合所有角色完成行动，才称为回合结束。后续技能/Roguelite效果可能分别绑定在不同的时间点上。

---

## 核心机制

### 回合流程

```
Round N:
  1. 【回合开始】→ 触发回合开始效果（增援检查、地形效果等）
  2. 生成行动队列：所有存活单位按排序规则排列（见"行动顺序排序规则"）
  3. 依次取出队列中的单位，执行该单位的角色回合:
     a.【角色回合开始】
       - 触发Buff/Debuff效果（燃烧扣血、回复、速度变化等）
       - 若该单位处于跳过状态（眩晕/冰冻）→ 直接进入角色回合结束
     b. 角色行动（玩家操作或AI决策）
     c.【角色回合结束】
       - Buff/Debuff持续回合数 -1，到期的效果被移除
       - 检查是否触发追加行动
  4. 队列清空 →【回合结束】→ 触发回合结束效果
  5. 进入 Round N+1
```

### 数据结构

```
TurnManager:
  current_round: int = 1
  action_queue: Array[Unit]     # 当前回合的行动队列（含先制排序）
  current_actor: Unit | null
  acted_units: Array[Unit]      # 本回合已行动的单位

Unit（回合相关字段）:
  id: String
  owner: PlayerID | "enemy"
  speed: int                    # 决定回合内行动顺序
  priority: int = 0             # 先制优先级（0=普通, 1=先制+1, 2=先制+2）
  status_effects: Array[StatusEffect]
```

### 速度的作用

- **核心作用**：决定每回合内的行动先后顺序，速度越高越先行动
- **战术意义**：先手意味着可以抢先击杀、抢先控制、抢占有利位置
- **可被技能/效果临时修改**：加速类Buff提升速度→后续回合排序更靠前
- **扩展空间**：Roguelite层面的遗物/技能可能额外利用速度属性（如"速度>12时获得额外闪避"）

## 行动顺序排序规则

每回合开始时，生成行动队列的排序优先级如下：

```
排序规则（从高到低）:
  1. 先制优先级（priority）降序：priority 2 > priority 1 > priority 0
  2. 同优先级内，按速度（speed）降序
  3. 同优先级且同速度时，按同速处理规则（见下文）
```

### 同速处理规则

同优先级且速度相同的单位之间的排序，**按难度区分**：

| 难度 | 规则 |
|------|------|
| 低难度 / 普通难度 | 玩家单位优先行动，敌人后行动。同阵营内按单位ID排序 |
| 最高难度 | 敌人单位优先行动，玩家后行动。同阵营内按单位ID排序 |

*难度对同速规则的影响是一个隐性但重要的平衡手段——最高难度下，玩家失去同速先手的优势。*

---

## 先制系统

### 先制优先级

先制（Priority）是一种特殊效果，使单位在行动排序时获得更高的优先级，**无视速度值**强制排在普通单位之前。

| 优先级 | 含义 | 行动顺序 |
|--------|------|---------|
| 0（默认） | 普通 | 按速度排序 |
| +1 | 先制 | 排在所有普通单位之前 |
| +2 | 超先制 | 排在+1先制单位之前 |

### 先制的来源

- **速度增益型技能**：效果是"之后N个回合速度增加X"，通过提升速度间接改变行动顺序（不改变priority，仅改变speed）
- **先制型技能**：效果是"之后N个回合获得先制+1/+2"，强制改变排序优先级
- **Roguelite遗物**：可能提供永久或条件触发的先制效果

### 先制交互示例

```
场上单位：
  玩家A (speed=10, priority=0)
  玩家B (speed=8,  priority=1)  ← 先制+1生效中
  敌人C  (speed=14, priority=0)
  敌人D  (speed=6,  priority=2)  ← 先制+2生效中

行动顺序（普通难度）：
  1. 敌人D  (priority=2)
  2. 玩家B  (priority=1)
  3. 敌人C  (priority=0, speed=14)
  4. 玩家A  (priority=0, speed=10)

行动顺序（若两个+1先制同速）：
  普通难度 → 玩家先
  最高难度 → 敌人先
```

### 先制持续管理

先制效果的持续回合数遵循通用Buff/Debuff规则：
- 角色回合开始时，先制状态已生效（本回合排序时已计入）
- 角色回合结束时，持续回合数-1，到期时priority回归0
- 下一回合生成队列时，按更新后的priority重新排序

## 特殊行动规则

### 跳过行动

某些状态效果会导致单位跳过当回合行动：

- **眩晕（Stun）**：角色回合开始时触发效果检查，确认眩晕→跳过行动→角色回合结束时扣减持续
- **冰冻（Freeze）**：跳过行动，受到攻击时解除（不等角色回合结束）
- 被跳过的单位仍然占据行动队列中的位置，UI上以特殊标记显示（其他单位可以看到"这个敌人本回合无法行动"）

### 追加行动

特殊技能或效果可能允许单位在同一回合内多次行动：

- **示例**：遗物"疾风之证"——击杀敌人后本回合获得一次追加行动
- **示例**：技能"连续行动"——使用后在本回合末尾追加一次行动
- 追加行动的单位被重新加入行动队列尾部
- 需要设置上限（如每回合最多追加1次）防止无限循环

## Buff/Debuff时机规则

标准的Buff/Debuff生命周期：

```
时间线（以燃烧3回合为例）:

  角色被施加燃烧(duration=3)
  
  [角色回合开始] → 触发燃烧伤害
  [角色行动]
  [角色回合结束] → duration 3→2
  
  [角色回合开始] → 触发燃烧伤害
  [角色行动]
  [角色回合结束] → duration 2→1
  
  [角色回合开始] → 触发燃烧伤害
  [角色行动]
  [角色回合结束] → duration 1→0 → 燃烧移除
```

**规则总结**：
- **效果触发**：角色回合开始时
- **持续扣减**：角色回合结束时
- **到期移除**：持续回合数降至0时立即移除
- **特殊说明**：个别技能/效果可能指定在"回合结束"（而非角色回合结束）触发，会在技能描述中明确标注

## 行动顺序UI

### 显示内容

游戏界面需要有**专有UI区域**（如屏幕侧边/底部的行动顺序条）实时显示行动顺序：

- 当前回合所有单位的**角色头像**按行动顺序排列
- **当前行动者**高亮显示
- **已行动单位**灰显或移出
- **被跳过的单位**（眩晕/冰冻）在头像旁显示特殊状态标记（如眩晕图标）
- **先制单位**在头像旁显示先制标记（区分+1和+2）
- **追加行动**时，头像动态插入到队列对应位置

### 动态更新

行动顺序UI需要在以下情况下**实时更新**：

| 触发事件 | UI变化 |
|---------|--------|
| 单位使用加速/减速技能 | 后续回合的预览顺序调整（当前回合队列不变，下回合重新排序） |
| 单位获得/失去先制效果 | 下回合的预览顺序调整 |
| 单位被施加眩晕/冰冻 | 该单位头像添加跳过状态标记 |
| 单位死亡 | 头像从队列中移除 |
| 追加行动触发 | 头像动态插入队列尾部 |
| 分批入场新敌人 | 新单位头像按速度插入队列对应位置 |

**注意**：速度变化（加速/减速Buff）影响的是**下一回合**的排序，不改变当前回合已生成的队列。先制效果同理。当前回合的队列一旦生成，只有追加行动、死亡、入场会动态修改。

## 回合数的游戏意义

由于存在明确的回合概念，可以基于回合数设计机制：

- **敌人增援触发**："第3回合（回合开始时），增援从地图边缘出现"
- **限时关卡**："10回合内消灭所有敌人，否则任务失败"
- **Roguelite遗物（角色回合结束）**："每次角色回合结束时，若HP<30%则回复5HP"
- **Roguelite遗物（回合结束）**："每个回合结束时，所有友方单位回复2HP"
- **区分很重要**：绑定在"角色回合结束"的效果每个角色各触发一次；绑定在"回合结束"的效果整个回合只触发一次

## 联机适配

回合+速度轮动天然适合联机：
- 同一时刻只有一个单位行动
- 其他玩家等待时可以观察/规划
- 只需同步"谁在行动"和"行动指令"
- 可设置行动时间限制（如60秒）防止挂机
- 回合的明确边界方便同步校验
