# 01 - 回合系统

> 返回 [总纲](./game-design-doc.md)

## 概述

速度轮动制回合系统。每回合所有单位按 `speed` 降序排列行动，非CT积攒模型。每个单位的回合内拥有**结构化的行动资源**，技能和操作按消耗类型分类，形成回合内的策略抉择。

---

## 速度轮动制

每回合开始时，所有存活单位按 `speed` 降序排列生成行动队列。

### 先制优先级

| 优先级 | 说明 |
|--------|------|
| +2 | 最高优先级，无视速度强制排在队列最前 |
| +1 | 次优先级，排在+2之后、普通单位之前 |
| 0 | 普通（默认），按速度排序 |

同一优先级内仍按 `speed` 降序排列。

### 同速处理

当两个单位速度相同且优先级相同时：
- **低难度**：玩家单位先行动
- **最高难度**：敌方单位先行动

### Buff/Debuff 时机规则

| 时机 | 触发 |
|------|------|
| 效果触发 | 角色回合**开始**时（如DOT伤害、再生恢复） |
| 持续扣减 | 角色回合**结束**时（剩余回合数-1） |
| 效果施加 | **立即生效**（施加时就影响属性） |

**词汇定义**：
- **角色回合开始/结束**：某个单位开始/结束其行动阶段
- **回合开始/结束**：整个行动队列的一轮循环开始/结束

## 行动资源系统

### 设计理念

参考博德之门3的行动经济（Movement / Action / Bonus Action），将每个单位的回合拆分为多种**行动资源**。技能和操作各自消耗不同的资源，迫使玩家在有限资源内做出战术决策。

**核心目标**：
- 避免"一回合释放所有技能"的无脑循环——不同技能竞争相同资源
- 保留移动和普通攻击的战术价值——高级技能有机会成本
- 创造职业差异化——某些职业擅长利用特定资源类型
- 允许存在"纯施法"型Build，但不是普遍状态

### 回合资源池

每个单位在其回合开始时获得以下资源：

| 资源 | 默认额度 | 说明 |
|------|---------|------|
| **移动力** | 由 `move` 属性决定 | 用于普通移动和\[移动行动\]技能 |
| **攻击机会** | 1次 | 用于普通攻击和\[标准行动\]技能 |
| **迅捷行动** | 1次 | 用于\[迅捷行动\]技能，不占移动/攻击资源 |

### 行动类型标签

所有主动技能和操作必须标注以下行动类型之一：

#### \[移动行动\] — `action_cost: "move"`

消耗本回合的**移动力**（部分或全部）。释放后不可再进行普通移动，但仍可进行攻击。

- 典型场景：位移技能（冲锋、闪避步、传送）
- 设计约束：使用后本回合的剩余移动力归零
- 与普通移动互斥：普通移动也消耗移动力，已移动后不可使用\[移动行动\]技能

```
示例：
  剑士「突进斩」：[移动行动] 向目标方向移动2格
  弓箭手「后撤步」：[移动行动] 向后移动1格并获得闪避+10(1回合)
  骑士「冲锋」：[移动行动] 向目标直线冲锋，造成沿途AOE伤害
```

#### \[标准行动\] — `action_cost: "standard"`

消耗本回合的**攻击机会**。释放后回合通常结束（除非拥有再动能力）。

- 典型场景：攻击类技能、强力增益/减益
- 与普通攻击互斥：已使用\[标准行动\]技能后不可普通攻击，反之亦然
- 设计原则：这是最"昂贵"的行动资源，\[标准行动\]技能应有明显强于普通攻击的效果

```
示例：
  魔法师「火球术」：[标准行动] 远程AOE魔法伤害
  牧师「群体治疗」：[标准行动] 治疗范围内所有队友
  剑士「万剑归宗」：[标准行动] 高倍率单体攻击
```

#### \[迅捷行动\] — `action_cost: "swift"`

**不消耗**移动力和攻击机会。每回合限使用 **1次** 迅捷行动。

- 典型场景：架势切换、短效增益、轻量Debuff、战场情报
- 设计约束：效果应弱于\[标准行动\]，侧重辅助/准备性质
- 使用时机灵活：可在移动前/后、攻击前/后任意时刻使用

```
示例：
  剑士「拔刀术」：[迅捷行动] 切换攻击架势，下次攻击暴击率+15%
  魔法师「魔力灌注」：[迅捷行动] 下次魔法攻击伤害+20%
  猎人「标记猎物」：[迅捷行动] 标记目标，全队攻击该目标命中+10(2回合)
```

#### \[反应行动\] — `action_cost: "reaction"`

**不占用主动回合资源**。由特定条件被动触发，发生在他人回合或特定事件时。

- 典型场景：反击强化、受击反应、队友联动
- 限制机制：可能消耗专属量谱（如剑意/剑元），或有每回合次数上限
- 不可主动释放：必须满足触发条件才会生效

```
示例：
  剑圣「剑意反击」：[反应行动] 被近战攻击时，消耗1剑意反击(power 80%)
  骑士「守护」：[反应行动] 相邻队友被攻击时代替承受伤害
  牧师「神佑」：[反应行动] 队友HP降至20%以下时自动施加护盾
```

#### \[自由行动\] — `action_cost: "free"`

**完全不消耗任何行动资源**，无次数限制（除非技能自身有CD）。

- 典型场景：被动光环的手动开关、信息查看、装备切换（如果设计允许）
- 设计约束：不应有直接战斗收益，仅用于辅助/信息/切换类操作

```
示例：
  战术大师「光环切换」：[自由行动] 在攻击光环和防御光环之间切换
  猎人「侦查」：[自由行动] 查看目标单位的详细属性（无战斗效果）
```

### 回合内行动流程

```
角色回合开始
  │
  ├─ Buff/Debuff 触发（角色回合开始时效果）
  │
  ├─ 行动阶段（可自由安排顺序）
  │   ├─ 普通移动 或 [移动行动]技能    ← 消耗移动力（二选一）
  │   ├─ 普通攻击 或 [标准行动]技能    ← 消耗攻击机会（二选一）
  │   ├─ [迅捷行动]技能               ← 每回合1次，任意时刻
  │   └─ [自由行动]                    ← 无限制
  │
  ├─ 手动结束回合 / 资源耗尽自动结束
  │
  └─ Buff/Debuff 持续扣减（角色回合结束时）
```

**行动顺序自由度**：移动、攻击、迅捷行动之间**无固定顺序**。玩家可以：
- 先攻击，再移动（打完就跑）
- 先迅捷Buff，再攻击，再移动
- 先移动到位，再释放标准行动技能
- 只移动不攻击（跳过攻击机会）

### 技能释放时机约束

部分技能除了行动类型外，还可附加**释放时机约束**：

| 约束 | 字段值 | 说明 |
|------|--------|------|
| 无约束 | `"any"` | 默认，可在行动阶段任意时刻释放 |
| 移动前 | `"before_move"` | 必须在本回合尚未移动时释放 |
| 移动后 | `"after_move"` | 必须在本回合已移动后释放 |
| 攻击前 | `"before_attack"` | 必须在本回合尚未攻击时释放 |
| 攻击后 | `"after_attack"` | 必须在本回合已攻击后释放 |

```
示例：
  弓箭手「瞄准」：[迅捷行动, before_attack] 必须在攻击前使用
  剑士「追斩」：[标准行动, after_move] 必须在移动后才能使用
  骑士「盾墙」：[迅捷行动, before_move] 放弃机动性换取防御姿态
```

## 行动资源与Build设计

### 技能数量的策略深度

行动资源系统天然限制了每回合可释放的技能数量：

| 资源 | 每回合额度 | 可释放技能数 |
|------|-----------|-------------|
| 移动力 | 1次（移动 或 移动行动技能） | 最多1个\[移动行动\] |
| 攻击机会 | 1次（普攻 或 标准行动技能） | 最多1个\[标准行动\] |
| 迅捷行动 | 1次 | 最多1个\[迅捷行动\] |
| 反应行动 | 条件触发 | 取决于触发条件和量谱 |

**一个回合内最多主动释放3个技能**（1移动 + 1标准 + 1迅捷），加上普通移动和普通攻击被技能替代。这保证了：

- **技能不是越多越好**：带5个\[标准行动\]技能 = 每回合只能选1个用，其余浪费
- **Build决策有意义**：选择带哪些技能 = 选择如何分配行动资源
- **普通攻击/移动有价值**：不使用技能时可以用普通攻击/移动，不存在"空转"

### 职业行动模式倾向

| 职业倾向 | 典型模式 | 说明 |
|----------|---------|------|
| 近战输出 | 移动→标准行动技能 | 接近目标后释放高伤害技能 |
| 远程炮台 | 迅捷Buff→标准行动技能 | 不需移动，专注增幅输出 |
| 高机动游击 | 移动行动技能→普攻 | 位移技能接近/脱离后普攻 |
| 防御坦克 | 迅捷防御→普攻+反应行动 | 主动回合简单，依赖反应行动 |
| 辅助型 | 迅捷Buff→标准行动治疗/增益 | 每回合一Buff一治疗 |
| 纯施法型(特殊) | 移动行动→标准行动→迅捷行动 | 三资源全用技能，放弃普攻和普通移动 |

### 再动能力（预留）

某些天赋/遗物可能赋予「再动」能力，即在\[标准行动\]后获得额外的攻击机会或移动力。这属于高级机制，需严格控制：

- 再动不刷新迅捷行动次数
- 再动获得的额外攻击机会仅限普通攻击（不可再用\[标准行动\]技能）
- 每回合最多触发1次再动

## 联机适配

- 轮动制下同一时刻仅1个单位行动，只需同步当前行动者的GameAction
- 所有操作封装为GameAction，单机直接执行，联机时广播后执行
- 行动资源状态（剩余移动力、是否已攻击、是否已用迅捷行动）作为回合状态同步

---

## 行动顺序UI（预留）

- 专有UI显示当前行动队列
- 标记各单位状态（Buff/Debuff图标、HP条）
- 当速度变化（Buff/Debuff影响speed）时动态更新队列
- 当前行动者高亮，预览下N个行动者

---

## 常见陷阱

- 迅捷行动和标准行动叠加 → **允许**，它们消耗不同资源
- 移动行动和普通移动叠加 → **不允许**，二选一
- 标准行动和普通攻击叠加 → **不允许**，二选一
- 迅捷行动每回合多次 → **不允许**，限1次
- 反应行动在自己回合触发 → **可以**，反应行动不限定触发时机
- 再动后使用标准行动技能 → **不允许**，再动仅允许普攻
- 先制+2的单位每回合行动两次 → **不是**，先制只影响行动顺序
