# 测试场景优化方案（简版计划）

> 状态：**简版计划**。具体内容扩充（每个天赋的测试用例、平衡指标、特殊场景细化）交由**下一 session**：研究 → 内部讨论 → 推导方案 → 以现有 base 执行。
> 本文只给方向与最小集，便于下一 session 直接据此开工。

## 目标与分工

- **实机测试场景** 专管：手感、视觉/动画反馈、天赋组合交互、攻击/受击表现、多回合平衡。
- 与现有 **headless 自动化套件**（`tests/test_swordsman_*.gd`）互补：后者管逻辑回归（断言），前者管「人眼/手感」。改占位数值后两边都要过。

## 范围与约束（初期）

- 天赋范围：**只实装「已有锁定天赋」**（SoT Codex 工具中状态=锁定的节点；清单/数量下一 session 从工具确认）。草稿/待优化/废弃天赋不进实机场景，避免测未定方案。
- 地形：**暂不做地形场景，全空地（PLAIN）**。
- 重置：场景**随时可重置**（优先「软重置」：不重载场景，复位单位 HP/资源/buff/冷却/印记/站位）。
- 天赋：场景内**自由选择/组合**（运行时勾选、应用即时生效、可清空重选）。

## 核心场景（最小集，必做）

1. **木桩攻击场景**：剑圣 vs 1+ 高血/低伤「木桩」敌（已调弱：goblin HP=80、STR=2）。
   验证：剑气产出/消耗、技能伤害与倍率、暴击、印记积累、招架↔拔刀槽位替换、心眼（暴击/速度）、**天赋组合输出**。木桩可设「不行动」。
2. **受击场景**：剑圣被 1+ 敌持续攻击。
   验证：受击/反击产气、招架架势、**受击类天赋触发**、生存向天赋、暴击回避、ZOC 离场惩罚。

## 场景内测试工具（待实装）

- **天赋选择面板**：运行时勾选锁定天赋组合，应用即时生效，可清空重选。
- **一键重置**：满血/满资源/清 buff/清冷却/清印记/单位回初始位。
- **状态读出**：剑圣/印记/buff/冷却实时可见（复用仪表盘 + 可加调试 overlay）。
- **木桩行为开关**：不动 / 只反击 / 自动攻击。

## 特殊场景区分（占位，下一 session 细化）

- **资源窗口对照**：剑气 低/中/高 窗口下最优序列差异（对接 combat-loop 的最小实证实验）。
- **天赋单点 vs 组合涌现**：验证组合空间而非幸存者密度。
- **多回合平衡**：攒气节奏、心眼速度对出手序的影响。
- **反应/反击类天赋触发**：待反应系统。
- **多职业对照**：第二职业接入后。

## 建议追加条件（已审核，纳入计划）

- **确定性开关**：可关命中/暴击随机（强制命中 + 可控暴击），精确读单技能数值，与 headless 的确定性一致。
- **快速对位**：木桩/敌位置可调（相邻 / 远程 / 包夹），覆盖近战/反击/ZOC。
- **天赋组合存档**：常用组合可保存/快速加载，省去重复勾选。
- **伤害日志/统计**（可选）：累计输出、DPS、TTK、单技能伤害分布，便于平衡观察。
