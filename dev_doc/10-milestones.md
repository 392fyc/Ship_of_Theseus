# 10 - 开发里程碑

> 返回 [总纲](./README.md)

## 概述

按里程碑推进，每个阶段结束都有可玩的成果。前5个阶段全部单机开发，Phase 6加入联机。

**总原则**：先用色块验证玩法，确认核心循环有趣后再投入美术。

---

## Phase 1: 网格原型（1-2周）

**目标**：在Godot中搭出可交互的网格系统。

- [ ] Godot 4 项目初始化
- [ ] TileMap 搭建10×10网格
- [ ] 点击格子高亮显示
- [ ] 放置单位（色块/简单Sprite）
- [ ] 点击选择单位，BFS计算并显示移动范围
- [ ] 点击目标格，A*寻路并移动单位
- [ ] 不同地形的移动消耗（颜色区分地形）
- [ ] 单位不可重叠（占据判定）

**验收标准**：能在网格上放置多个单位，选择并移动它们，地形影响移动范围。

---

## Phase 2: 回合与战斗（2-3周）

**目标**：完整的回合+速度轮动系统 + 基础攻击。

- [ ] 回合系统（TurnManager：回合推进 + 速度排序）
- [ ] 行动顺序预览UI（侧边栏显示接下来行动的单位）
- [ ] 单位行动流程：选择 → 移动 → 攻击/等待 → 结束
- [ ] 基础攻击（近战，邻接单体）
- [ ] 伤害计算公式实装
- [ ] 命中/闪避/暴击判定
- [ ] 伤害数字显示（DamagePopup）
- [ ] 单位死亡（HP归零移除）
- [ ] 胜负判定（一方全灭）
- [ ] 敌方基础AI（AGGRESSIVE：冲最近的目标攻击）

**验收标准**：玩家和AI敌人轮流行动，能打一场完整战斗到分出胜负。

---

## Phase 3: 技能与射程（2-3周）

**目标**：技能系统、射程显示、AOE范围。

- [ ] JSON数据加载器（DataLoader）
- [ ] 技能数据定义（至少6-8个技能）
- [ ] 射程模式渲染（diamond/line/cross）
- [ ] 攻击目标选择UI（在射程内选择目标）
- [ ] AOE范围预览（释放前显示影响格子）
- [ ] AOE伤害执行（对范围内所有单位结算）
- [ ] 技能冷却系统
- [ ] 行动菜单（移动/技能列表/等待）
- [ ] 地形修正和特殊地形格效果实装

**验收标准**：单位能使用不同射程和范围的技能，冷却系统正常运作。

---

## Phase 4: 职业与AI完善（2-3周）

**目标**：4个可玩职业，有战术深度的AI。

- [ ] 4个基础职业数据
- [ ] 各职业初始技能差异
- [ ] 装备系统基础（武器影响属性）
- [ ] AI行为模式扩展（DEFENSIVE/SUPPORT/HIT_AND_RUN）
- [ ] AI评分系统完善（考虑地形、击杀、位置）
- [ ] 敌人分批入场（Wave System）
- [ ] 3-5种敌人模板
- [ ] 1个简单Boss（固定技能循环）
- [ ] 战斗难度初步平衡

**验收标准**：4个职业手感有明显区别，AI有基本战术行为，Boss有可学习的模式。

---

## Phase 5: Roguelite框架 + 城镇建设（4-6周）

**目标**：完整的一次Run体验，包含城镇建设。

- [ ] Run管理器（RunManager：3大关 × 10小关结构）
- [ ] 准备阶段UI（城镇建设/购物/技能调整/出发）
- [ ] 城镇建设系统（建造/升级/扩建）
- [ ] 功能建筑实装（武器铺、药剂铺、训练场）
- [ ] 战场建筑实装（泉水、哨塔、路障）
- [ ] 战场建筑放置（受限区域内指定位置）
- [ ] 战场建筑与战斗系统交互（特殊地形格效果）
- [ ] 战斗奖励（金币 + 战利品）
- [ ] 经验和升级
- [ ] 特殊事件关卡（2-3个）
- [ ] 大关卡1完整（约10个小关 + Boss）
- [ ] Run失败（全灭）→ 返回主菜单
- [ ] Meta进度基础（永久货币 + 解锁）

**验收标准**：能完整体验大关卡1的一次Run，包含准备阶段城镇建设、多场战斗、Boss战。

---

## Phase 6: 联机（4-6周）

**目标**：1-4人局域网联机可玩。

- [ ] GameAction序列化/反序列化
- [ ] Godot MultiplayerAPI / ENet 连接
- [ ] Host-Client架构搭建
- [ ] 角色选择（各选1个职业）
- [ ] 行动同步（当前行动者操作 → 广播 → 执行）
- [ ] 非行动玩家的等待UI
- [ ] 行动超时处理（60秒自动wait）
- [ ] 奖励选择同步（各自独立选）
- [ ] 商店/事件的联机处理
- [ ] 随机数种子同步
- [ ] 断线检测 + AI接管
- [ ] 联机大厅（创建/加入房间）

**验收标准**：2-4人可以在局域网联机完成一次Run。
