# 设计思路梳理与发展方向

> 本文档梳理整个设计过程的决策脉络、当前系统状态和后续发展方向。

---

## 一、项目定位

**战棋RPG + Roguelite + 城镇建设**，面向单人/1-4人联机。

核心差异化：将城镇建设作为v1核心玩法融入战棋Roguelite，而非简单的"肉鸽+战棋"。玩家需要在角色成长、装备购买和建筑投资之间做经济抉择。

---

## 二、设计过程回顾

### Phase 1：系统框架搭建

初始阶段建立了11个核心模块的框架文档（01-11），覆盖回合系统、网格地图、战斗计算、技能射程、职业系统、敌人AI、Run循环、联机架构、数据架构、开发里程碑、城镇建设。

**关键决策**：
- 回合+速度轮动（非纯CTB），保证操作节奏清晰
- 正方形网格≤10×10，无高低差
- 数据驱动（JSON）的架构
- 联机采用GameAction指令同步模型

### Phase 2：逐文档核查与深化

从01开始逐个核查补充细节，建立文档间的交叉引用和一致性。

#### 01-回合系统核查
- 新增**词汇定义**：明确"角色回合开始/结束"与"回合开始/结束"的区分
- **Buff/Debuff时机规则**确定：效果触发=角色回合开始，持续扣减=角色回合结束
- **先制系统**：+1/+2两级优先级，无视速度强制排序
- **同速处理**：低难度玩家先，最高难度敌人先
- **行动顺序UI**：专有UI显示队列、状态标记、动态更新规则

#### 02-网格与地图核查
- **三层结构**确立：基础地形→特殊地形（叠加）→建筑（覆盖基础地形）
- 基础地形从3种扩展到**9种**（新增山地/山峰/浅水/深水/熔岩/毒沼）
- **山峰（PEAK）**成为唯一阻挡攻击线的地形
- 特殊地形重新分类为4类（Buff/Debuff/陷阱/传送阵），明确阵营生效规则
- **建筑交互**：所有权规则（玩家建造仅对己方/地图预设对双方）、占据机制、废墟规则
- **控制区(ZOC)**：敌方正交邻接时移动力-2，防止单位任意脱离接战；神射手天赋可抵抗

#### 03-战斗计算核查（核心，多轮推敲）
- **伤害公式**确定为乘区分层：基础伤害 × 技能倍率 × 特殊地形修正 × 暴击修正 × 格挡修正 × 最终伤害增减
- **命中/暴击采用加法模型**（非乘法），对玩家透明，适合属性全显示的战棋
- **格挡系统**：职业固定不成长，70%减免，与暴击互斥，先判格挡再判暴击
- **距离衰减取消**：经讨论后移除，简化公式
- **伤害类型双轴体系**：属性类型（physical/magical/holy/hybrid）× 攻击方式（melee/ranged/area）
- **反击系统**加入：非范围攻击时被攻击者可反击
- **追击系统**加入：攻击方速度优势时可追击（(atk.speed-def.speed)×10%概率），全职业通用，剑士系深度特化
- **两阶段附加效果**：命中后附加 vs 伤害后附加
- **Debuff与resistance交互公式**
- 基础伤害可为0（无保底）

#### 05-职业系统核查（大幅重构）
- 从4个基础职业扩展到**8个基础 + 16个转职方向**
- 9个职业完整定位设计：剑士、佣兵、弓箭手、工匠、魔法师（四系分支）、骑士、猎人、牧师
- v1测试5职业：佣兵/弓箭手/魔法师/骑士/牧师
- 占星术士预留为未来扩展（白天/黑夜系统）
- **天赋树系统**确立：每次Run重置，Meta解锁范围，Run中获得点数解锁节点
- 转职通过天赋树特殊节点触发，选后不可更改

#### 01-回合系统：行动资源系统
- **行动经济体系引入**：参考BG3的Movement/Action/Bonus Action，将每个回合的操作拆分为结构化的行动资源
- **五种行动类型标签**：\[移动行动\]/\[标准行动\]/\[迅捷行动\]/\[反应行动\]/\[自由行动\]
- **回合资源池**：移动力(move属性) + 攻击机会(1) + 迅捷行动(1)
- **释放时机约束**：技能可限制在移动前/后、攻击前/后释放
- **技能数据结构扩展**：新增 `action_cost` 和 `timing_constraint` 字段
- **设计哲学补充**：行动资源即策略深度——技能不是越多越好，有限资源迫使抉择
- **01-turn-system.md 独立文档建立**

#### 07-Meta进度原则确立
- **核心设计原则写入**：Meta = 横向解锁（更多选择）而非纵向强化（数值提升）
- 禁止出现因Meta不足导致核心机制缺失的情况
- 天赋树初始含1个转职完整玩法，通关后解锁第2个
- 便利性升级仅限经济和信息层面

#### 11-城镇建设联动更新
- **6种战场建筑**完整设计（哨塔/要塞/拒马/生命泉水/巨弩/魔法塔）
- 四种建筑子类型（通用/限制/阻挡/范围）
- **耐久系统**：按伤害类型固定扣减，不走常规公式
- 修复机制：准备阶段消耗金币

## 四、已确定的核心设计决策

### 战斗机制
| 决策 | 内容 |
|------|------|
| 伤害公式 | 乘区分层（基础×技能×地形×暴击×格挡×最终增减） |
| 命中/暴击 | 加法模型，对玩家完全透明 |
| 伤害类型 | 双轴：属性类型(physical/magical/holy/hybrid) × 攻击方式(melee/ranged/area) |
| 格挡 | 职业固定，70%减免，与暴击互斥，先判格挡再判暴击 |
| 反击 | 非范围攻击可反击，使用普通攻击，走完整结算，不触发追击 |
| 追击 | (atk.speed-def.speed)×10%概率，全职业通用，走完整结算，不触发反击和二次追击 |
| 距离衰减 | 无（已取消） |
| 基础伤害保底 | 无保底（防御超过攻击时不造成伤害） |
| Buff/Debuff | 效果触发=角色回合开始，持续扣减=角色回合结束 |
| 先制 | +1/+2两级，无视速度排序 |
| 同速 | 低难度玩家先，最高难度敌人先 |
| 行动资源 | 每回合：移动力(move) + 攻击机会(1) + 迅捷行动(1)；五种行动类型标签 |
| 技能行动类型 | \[移动行动\]/\[标准行动\]/\[迅捷行动\]/\[反应行动\]/\[自由行动\]，同类互斥 |

## 六、设计哲学总结

1. **一般难度要爽，高难度要有深度**：多乘区体系支撑BD多样性，BD成型后有明显碾压感
2. **Meta横向不纵向**：解锁更多选择，不解锁更强数值
3. **天赋是骨架，随机是血肉**：玩家可控的方向规划 + Roguelite的随机惊喜
4. **属性全透明**：加法模型命中/暴击，玩家可精确计算战术
5. **城镇建设是核心差异化**：金币在角色强化和建筑投资之间的抉择
6. **转职是方向选择而非单纯数值提升**：每个转职开辟不同玩法思路
7. **面多加水水多加面**：Roguelite的好处是可以创造OP的BD，也可以设计强大的敌人来应对
