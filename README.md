# 战棋Roguelite — 游戏设计总纲

## 项目概览

| 项目属性 | 决策 |
|---------|------|
| 类型 | 战棋RPG + Roguelite |
| 引擎 | Godot 4 (GDScript) |
| 玩家人数 | 单机1人 / 联机1-4人 |
| 画风 | GBA像素（初期跳过，先搭系统） |
| 开发方式 | Vibe Coding + AI素材生成 |

## 核心设计决策

- **网格**：正方形网格，地图≤10×10
- **回合制**：回合 + 速度轮动复合模式，每回合所有单位按速度排序依次行动
- **联机**：每人控制1个角色，轮动操作，同一时刻只有1个单位行动
- **核心循环**：3大关卡 × 约10小关卡，关卡间有准备阶段
- **核心机制**：武器/技能射程与范围、职业/Build多样性、特殊地形、城镇建设
